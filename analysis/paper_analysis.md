# 论文分析：基于多臂老虎机的损失感知特征图剪枝

> **arXiv ID**: 2607.22564
> **标题**: Loss-Aware Feature-Map Pruning in Convolutional Neural Networks Using Multi-Armed Bandits
> **作者**: Salem Ameen, Sunil Vadera
> **日期**: 2026-05-29

---

## 1. 核心速览

### 1.1 研究主题

本文研究**基于多臂老虎机（Multi-Armed Bandit, MAB）的卷积神经网络特征图结构化剪枝方法**。核心创新在于：

1. **将特征图剪枝建模为 MAB 问题**：每个候选特征图是一个"臂"，临时掩码后的损失变化是"奖励"
2. **单特征图掩码机制**：每次只临时掩码一个特征图进行评估，避免联合评估的组合爆炸
3. **两种 MAB 策略**：UCB1（频率学派，显式探索-利用平衡）和 Thompson Sampling（贝叶斯学派，后验采样）
4. **结构化删除规则**：剪枝后物理删除对应的滤波器、偏置和下一层输入通道

### 1.2 一句话总结

本文将 MAB 框架引入 CNN 结构化剪枝，通过单特征图掩码和 UCB1/Thompson Sampling 策略，在不重训练的情况下实现了高效的通道选择，在多个数据集上验证了其有效性和计算效率优势（比直接评估快 40-60 倍）。

## 2. 核心方法

### 2.1 问题形式化

**符号定义**：
- 网络 $f_\theta$，参数为 $\theta$
- 卷积层集合 $L$，每层 $l$ 有 $C_l$ 个输出特征图
- 候选"臂"集合 $A = \{(l,c) : l \in \text{层}, c \in \{1,\dots,C_l\}\}$
- 目标：从 $A$ 中选择 $k$ 个臂进行永久删除

**单特征图掩码**：
对于臂 $a=(l,c)$，定义掩码后的网络为将层 $l$ 的第 $c$ 个输出特征图置零。注意：这只是**临时掩码**，而非物理删除。

**奖励定义**：
在评估臂 $a$ 时：
1. 临时掩码特征图 $a$
2. 在小批量数据上计算前向传播
3. 比较掩码后的损失 $L_{\theta \setminus a}$ 与原始损失 $L_\theta$
4. 奖励：$r_a = \min\{1, \max\{0, \tau + \Delta_a / s_r\}\}$（UCB1）或 $b_a = \mathbb{1}[\Delta_a + \tau \geq 0]$（Thompson Sampling）

其中 $\Delta_a = L_{\text{batch}}(1) - L_{\text{batch}}(m_{-a})$，$\tau$ 为容忍参数，$s_r$ 为缩放常数。

### 2.2 UCB1 策略

对于每个臂 $a$，维护：
- $n_a$：臂 $a$ 被选择的次数
- $\mu_a$：臂 $a$ 的累积奖励均值

在每次迭代 $t$，选择臂：

$$a_t = \arg\max_{a \in A} \left[ \mu_a(t-1) + \sqrt{\frac{2\ln(t-1)}{n_a(t-1)}} \right]$$

最终选择 Top-K：$S_k = \text{TopK}(\mu_a, k)$

### 2.3 Thompson Sampling 策略

假设每个臂的成功概率 $\theta_a$ 服从 Beta 先验：

$$\theta_a \sim \text{Beta}(1, 1)$$

维护计数器 $n_a^+$（成功）和 $n_a^-$（失败）。后验分布：

$$\theta_a \mid \text{data} \sim \text{Beta}(n_a^+ + 1, n_a^- + 1)$$

每次迭代从每个臂的后验采样，选择采样值最大的臂。

### 2.4 结构化删除规则

对于选定的臂集合 $S_k$：
1. 删除层 $l$ 中所有 $S_l$ 对应的滤波器 $W^{(l)}[S_l, :, :, :]$ 和偏置 $b^{(l)}[S_l]$
2. 如果下一层是卷积层，删除其对应输入通道 $W^{(l+1)}[:, S_l, :, :]$
3. 如果下一层是全连接层，删除对应的权重块

### 2.5 FLOPs 减少分析

原始 FLOPs：$F_l = 2H_l W_l (C_{l-1} k_l^2 + 1) C_l$

删除 $q_l$ 个特征图后：$F'_l = 2H_l W_l (C_{l-1} k_l^2 + 1)(C_l - q_l)$

下一层额外减少：$\Delta F_{l+1} = 2H_{l+1} W_{l+1} q_l k_{l+1}^2 C_{l+1}$

### 2.6 计算复杂度

**MAB 搜索成本**：$C_{MAB} = O(T(2C_F + K))$

**直接评估成本**：$C_{direct} = O(K \times (N/B) \times C_F)$

当 $T \ll K \times (N/B)$ 时，MAB 搜索更高效。典型加速比约 80-400 倍。

## 3. 实验结果

### 3.1 主要结果

| 方法 | FLOPs 减少 | VGG-16/CIFAR-10 Top-1 | ResNet-50/ImageNet Top-1 |
|------|-----------|----------------------|-------------------------|
| 原始模型 | - | 93.5% | 76.1% |
| L1-Norm | 50%/40% | 91.2% | 73.2% |
| FPGM | 50% | 91.8% | - |
| **UCB1 (本文)** | 50%/40% | **92.8%** | **75.3%** |
| **Thompson (本文)** | 50%/40% | **92.6%** | **75.1%** |
| Direct Eval | 50%/40% | 92.9% | 75.4% |

### 3.2 统计显著性

- Friedman 检验 + Nemenyi 事后检验
- UCB1 与 L1-Norm：统计显著差异（$p < 0.01$）
- UCB1 与 Thompson：无统计显著差异
- UCB1 与 Direct Eval：无统计显著差异

## 4. 局限性与未来方向

### 4.1 局限性

1. **单特征图掩码假设**：假设不同特征图的删除效应可叠加，忽略了交互效应
2. **无重训练**：剪枝后精度可能低于重训练后的方法
3. **仅限 CNN 架构**：未扩展到 Transformer、RNN 等架构
4. **评估数据集有限**：主要在图像分类任务上验证

### 4.2 未来方向

1. **扩展到 Transformer**：将注意力头、FFN 神经元视为臂
2. **考虑交互效应**：组合 MAB、上下文 MAB
3. **与其他压缩技术联合**：剪枝 + 量化、NAS + 剪枝
4. **自动化超参数选择**：自适应 $T$、$\varepsilon$、$B$

## 5. 适配到 Qwen3-0.6B 的思路

将 MAB 框架从 CNN 特征图剪枝适配到 Qwen3-0.6B（Transformer 语言模型）：

### 5.1 注意力头剪枝

**臂的定义**：每个 Transformer 层的每个注意力头是一个臂 $a = (l, h)$

**临时掩码**：将头 $h$ 的注意力输出置零（通过掩码 $O$ 投影矩阵的对应行）

**评估**：在语言建模任务的小批量数据上计算困惑度（PPL）变化

**删除**：永久删除对应 $W_O$ 矩阵的行和 $W_Q/W_K/W_V$ 矩阵的对应块

### 5.2 FFN 神经元剪枝

**臂的定义**：每个 Transformer 层的每个 FFN 中间神经元是一个臂 $a = (l, n)$

**临时掩码**：将神经元 $n$ 的输出置零

**评估**：同上，评估 PPL 变化

**删除**：永久删除 $W_{gate}$ 和 $W_{up}$ 的对应行，以及 $W_{down}$ 的对应列

### 5.3 Qwen3-0.6B 具体参数

| 参数 | 值 |
|------|-----|
| hidden_size | 1024 |
| intermediate_size | 3072 |
| num_hidden_layers | 28 |
| num_attention_heads | 16 |
| num_key_value_heads | 8 (GQA) |
| head_dim | 128 |
| vocab_size | 151936 |

**候选臂规模估算**：
- 注意力头总数：$28 \times 16 = 448$
- FFN 神经元总数：$28 \times 3072 = 86016$
- 合计：约 86464 个候选臂

**MAB 迭代次数**：按论文建议 $T = K$（候选臂总数）或 $T = K/2$
