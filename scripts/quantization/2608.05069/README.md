# VQ-VAD: Vector-quantized Motion Representation Learning

## 论文信息
- **标题**: VQ-VAD: Vector-quantized Motion Representation Learning
- **arXiv**: 2608.05069
- **关键词**: 向量量化 (VQ)、VQ-GAN、码本、承诺损失、EMA 码本更新、异常检测
- **效果**: HR-SHT 81.83%，跨域 76.69%

## 方法概述

VQ-VAD 将 VQ-GAN 思想迁移到序列建模：用离散码本表示正常行为模式，通过重构
误差进行异常检测。核心组件：

1. **编码器 / 解码器**：将连续隐藏状态压缩到低维潜在空间再还原，提取正常模式
   的紧凑表示。

2. **向量量化 (EMA 码本)**：将潜在向量替换为码本中最近码字 (Nearest Neighbor)。
   码本通过指数移动平均 (EMA) 更新而非梯度下降，训练稳定、避免码字坍缩。

3. **损失函数**：
   - 重构损失：`‖x − x_hat‖²`
   - 承诺损失：`β · ‖z_e − sg(z_q)‖²`，约束编码器输出贴近码字
   - 码本由 EMA 更新 (不参与反向传播)
   - 直通估计器 (STE)：`z_q_st = z_e + (z_q − z_e).detach()`，把梯度传给编码器

4. **异常检测**：仅在正常数据上训练码本；测试时重构误差大的样本判为异常
   (正常模式能被码本很好重构，异常模式不能)。

本 demo 将 VQ-VAD 应用于 Qwen3-0.6B 隐藏状态压缩：用码本索引替代连续向量，
统计码本利用率、压缩比与重构误差，并演示正常 / 异常 (注入离群点) 样本的
重构误差分离。

## 运行方式

```bash
cd scripts/quantization/2608.05069
python3 demo.py
```

脚本自动尝试加载 Qwen3-0.6B；若不可用则回退到 MockTransformer。运行后输出：
- 码本利用率 (活跃码字比例) 与重构 MSE；
- 隐藏状态压缩比 (每个向量由 H×16 比特压缩为 log2(K) 比特)；
- 正常 vs 异常样本重构误差对比 (异常检测能力验证)。
