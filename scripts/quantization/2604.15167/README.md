# INT4 Collapse Probe (arXiv:2604.15167) 复现 Demo

## 论文核心

When Flat Minima Fail：对 Pythia-160m 全部 154 个训练检查点做免校准 per-group INT4 探测，发现量化鲁棒性三相结构——快速学习期（FP32 困惑度与 INT4 差距同降）→ 亚稳平台期（约 7 万步，FP32 停滞、INT4 差距有界）→ 爆炸发散期（INT4 差距 11%→517% 而 FP32 几乎不动）；发散起点恰在 FP32 收敛点；INT8 全程免疫。

## 本 demo 复现内容

1. 构造 toy 设定：小 MLP 在合成回归数据上训练，定期保存检查点。
2. 实现论文的**免校准 per-group INT4 探针**与 INT8 探针。
3. 对每个检查点计算 FP32 loss 与 INT4/INT8 量化 gap，绘制三相结构：
   - 复现"INT8 免疫、INT4 敏感"的位宽不对称性；
   - 在训练后期注入持续小幅权重扰动（模拟收敛后继续训练），观察 INT4 gap 的加速增长现象。
4. 输出各阶段 gap 数值表。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- 这是 toy 级机理复现：用小型随机模型与合成数据复现探针方法与三相趋势，不（也无法）复现 Pythia-160m 154 检查点的具体数字（11%→517%）。
- 收敛后权重更新的有害性以受控扰动模拟，非真实学习率调度实验。
- 与 Qwen3-0.6B 无关，本论文方法是架构无关的探针。
