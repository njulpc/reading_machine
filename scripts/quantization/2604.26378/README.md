# CoQuant (arXiv:2604.26378) 复现 Demo

## 论文核心

CoQuant：混合精度量化中高精度子空间的选择应**联合权重与激活**建模——线性层输出扰动由两侧量化噪声共同驱动。论文导出闭式加权 PCA 解平衡激活与权重协方差，Llama-3.2/Qwen2.5 上一致超 PTQ 基线。

## 本 demo 复现内容

1. 真实 Qwen3-0.6B 配置构造线性层（随机权重）+ 校准激活（带方向性结构）。
2. 实现：
   - 激活单边基线：仅用激活协方差 PCA 选 top-r 方向保 FP16，其余 INT4；
   - CoQuant 式联合解：对期望输出误差建模，以权重协方差加权激活协方差（加权 PCA），选 top-r 方向。
3. 对比两种子空间选择在相同高精度预算下的层输出误差。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- Qwen3-0.6B 权重未下载，用真实维度 + 随机权重验证；加权 PCA 为论文闭式解的等价实现（权重 Gram 加权激活协方差后特征分解）。
- 混合精度保真路径用 FP32 模拟 FP16 子空间。
