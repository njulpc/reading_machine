# SNN 量化 EMD 评估 (arXiv:2604.14487) 复现 Demo

## 论文核心

Quantization of Spiking Neural Networks Beyond Accuracy：同等准确率下不同量化方法/裁剪范围/位宽产生迥异**发放分布**（影响部署能耗），准确率指标对此失明；提出用 Earth Mover's Distance（EMD）度量发放分布偏移；均匀量化保精度也漂移，LQ-Net 式学习型量化行为保持更好。

## 本 demo 复现内容

1. 构造合成 SNN 层（LIF 动力学），输入随机泊松脉冲序列。
2. 实现两种权重量化：均匀量化 vs 可学习尺度量化（LQ-Net 风格，尺度按重建误差学习）。
3. 实现 1 维 EMD（推土机距离，排序差分积分）度量每层脉冲发放率分布偏移。
4. 对比：两种量化在**任务输出（读数）误差相近**时，EMD 是否能区分其发放行为差异。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- 合成 SNN（非 SEW-ResNet/CIFAR 训练），验证 EMD 指标的区分能力与两类量化的行为差异机制；不复现论文具体数字。
- EMD 为 1 维精确实现（每层发放率直方图），论文可能用高维近似。
