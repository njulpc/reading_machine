# LoRaQ (arXiv:2604.18117) 复现 Demo

## 论文核心

LoRaQ：4-bit PTQ 的低秩分支补偿——关键突破是补偿分支**自身也可量化**（免数据校准优化量化误差），实现全 sub-16 bit 管线；W4 主层 + W8A8/W6A6 低秩分支的混合精度优于全高精度分支。

## 本 demo 复现内容

1. 真实 Qwen3-0.6B 配置构造线性层（随机权重）。
2. 实现 LoRaQ 式管线：
   - 主层 W4 PTQ；
   - 免数据低秩分支：`E = W - W_q`，SVD 得 `E ≈ U_r V_r`，直接优化使 `(W4 + 分支)` 逼近原 W（无需校准数据）；
   - 分支自身量化为 W8A8。
3. 对比三种配置的权重/输出误差：纯 W4、W4+FP32 分支、W4+W8A8 分支（全量化管线）。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- Qwen3-0.6B 权重未下载，用真实维度 + 随机权重验证代码路径；论文针对扩散 transformer，本 demo 在通用线性层上验证机制。
- 免数据优化用解析 SVD 初始化 + 少量梯度微调（误差目标为权重重建，LoRaQ 的数据自由版本）。
