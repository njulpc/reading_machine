## 1. AnchorKV (2608.02901)

### 算法一致性: 部分一致
- **锚点精确保存 + 残差低比特量化**: 代码实现完整流程 — 一致
- **影响驱动精化**: demo 用 importance×(1+residual_magnitude) 启发式 — 合理近似
- **差异点**: 压缩比 ~3.9x（当前配置），论文 70B 规模报告 20x；demo 用 Qwen3-0.6B 适配

### 修复的问题 (1 项)
1. **`_simple_attention` GQA 维度错误**: 未处理 num_heads(8) ≠ num_kv_heads(4) 的 GQA 结构，且调用处双重 transpose 导致维度混乱。修复为正确复制 KV head 并修正 transpose。

### 验证结果
- 模型: 真实 Qwen3-0.6B (28 层)
- 注意力输出余弦相似度: AnchorKV 0.749 > Uniform-2bit 0.508 > Eviction-15% 0.473

## 2. TASQ (2608.03057)

### 算法一致性: 部分一致
- **共享 INT8 缓冲 + LSB 截断**: 一致
- **Temporal-Spatial LSB Mask 贪心学习**: 一致（贪心背包近似）
- **差异点**: 论文面向扩散模型，demo 适配到 LLM（去噪步→生成步）

### 修复的问题 (1 项)
1. **LSB 截断用 round 而非 truncate**: 论文明确说 "truncating least-significant bits"，代码用 `torch.round()`（四舍五入）。修复为保持符号的 floor 截断 `sign(x)*floor(|x|/factor)*factor`，与论文一致。

### 验证结果
- 模型: 真实 Qwen3-0.6B (12 层量化)
- TASQ BitOPs 相比 Static-8bit 减少 72.9%，加速 3.69x
- 平均有效精度: 2.17 bit（存储仍为 8-bit）

## 3. TaskPress (2608.03276)

### 算法一致性: 部分一致
- **Task guide 作为 meta-query 剪枝**: 一致
- **量化 scale factor 零成本 outlier 检测**: 一致
- **差异点**: head 对齐用截断而非 GQA 复制（信息损失）

### 修复的问题 (2 项)
1. **`_simple_attention` GQA 崩溃**: mock 路径 matmul 维度不匹配导致 RuntimeError。修复为正确复制 KV head。
2. **`baseline_uniform_prune` 索引错误**: 重构时误用 TaskPress 的 `kept_indices` 而非 uniform_prune 自己的索引，导致基线评估无效。修复为返回并使用各自的 `kept_indices`。

### 验证结果
- 模型: 真实 Qwen3-0.6B (28 层)
- 压缩比: 11.4x，TaskPress 平均 cos 0.895 > Uniform-Prune 0.766

## 4. Biomedical LLM 可靠性 (2608.03854)

### 算法一致性: 部分一致
- **量化×scoring rule×prompt template 受控实验**: 框架一致
- **差异点**: 论文用 Mistral-7B 三变体 + PubMed RCT，demo 用单 Qwen3-0.6B + 合成数据

### 修复的问题 (4 项)
1. **mean scoring 任意 ×10 缩放**: `F.softmax(mean_logprobs_t * 10)` 中的 ×10 在论文中不存在，人为放大差异。移除 ×10。
2. **Python `hash()` 非确定性**: 受 PYTHONHASHSEED 影响，改用 hashlib.md5 确定性 hash。
3. **`run_experiment` 重复分类**: 同一批样本分类两次，在第一次循环中保存 logprobs 并删除重复循环。
4. **temperature scaling 注释**: 添加实现说明（对 log-likelihood 而非 logits 操作，属简化实现）。

### 验证结果
- 模型: 真实 Qwen3-0.6B + 真实 tokenizer，197 个 Linear 层量化
- Prompt template 间准确率极差 20.0 个百分点（论文报告 7-24pp）
- Temperature scaling 将 INT8 ECE 从 0.587 降至 0.024

## 5. AdaMX (2608.03867)

### 算法一致性: 部分一致
- **Per-block 精度恢复方案选择 (3 种 scheme)**: 一致
- **Per-operand 编码**: 一致（weight→scheme 0/1, activation→scheme 0/2）
- **差异点**: EBW 平衡机制为简化实现（固定值，未实现位宽回收）

### 修复的问题 (2 项)
1. **微缩放 clamp_min(0.125) 不合理**: INT4 微缩放范围 [-1, 0.875]，但 clamp_min(0.125) 丢弃负值。改为 clamp_min(1e-4)。
2. **weight 分支 scales_final 冗余**: `torch.where(cond, scales_0, scales_0)` 两分支相同，简化为 `scales_0`。

### 验证结果
- 模型: 真实 Qwen3-0.6B
- AdaMX 相比 MXFP4 基线 MSE 改善显著

## 6. NAP (2608.03919)

### 算法一致性: 部分一致
- **归一化仿射参数 = 低维高杠杆子空间**: 一致（0.01% 参数量）
- **NAP-PTQ 冻结骨干微调仿射参数**: 一致
- **差异点**: NAP-QAT 简化为概念演示（内存限制）；KL 用 mean 而非 batchmean

### 修复的问题 (4 项)
1. **NAP-QAT teacher 指向已量化模型（关键）**: NAPPTQ 量化后 model 权重已变，NAPQAT 的 teacher=model 违反"全精度 teacher"设定。修复为在 NAPQAT 前恢复全精度权重。
2. **FakeQuantize scale 覆盖 buffer**: `self.scale = scale` 覆盖 register_buffer。改为 `self.scale.copy_(scale)`。
3. **evaluate_output_fidelity 冗余分支**: if/else 分支代码完全相同，合并。
4. **float32 转换**: 添加 `self.student.float()` 避免 float16 反向传播 NaN。

### 验证结果
- 模型: 真实 Qwen3-0.6B
- NAP-PTQ 输出 MSE 改善 14.9%，余弦相似度改善 2.01
- 仿射参数仅占 0.01%，验证低维高杠杆特性

## 7. BinaryPC (2608.04405)

### 算法一致性: 一致
- **二值 PCA 哈希 + Hamming 近邻 + 稀疏注意力**: 完整实现，与论文方法一致
- **差异点**: Hamming 距离用 float 模拟而非 GPU 位运算（环境限制，合理简化）

### 修复的问题 (1 项，加固)
1. **PCA 维度断言**: 在 `compute_pca` 中增加 `assert n_components <= min(data.shape)` 防止维度溢出。同时修复 SVD float32 精度。

### 验证结果
- 模型: 真实 Qwen3-0.6B (28 层, 16 heads)
- 输出余弦相似度: 0.982（保留 50% KV 对）
- 理论计算量减少 50%

## 8. PEFT 方法比较 (2608.04488)

### 算法一致性: 部分一致
- **Full FT / BitFit / LoRA / LoRA+ / QLoRA 五方法对比**: 一致
- **NetScore-E 双指标**: 一致（VRAM 代替能耗，合理简化）
- **差异点**: 仅 Transformer（无 SSM）；训练模拟仅 10 步

### 修复的问题 (3 项)
1. **LoRA+ docstring 注释与代码矛盾（关键）**: 注释说"B 学习慢, A 学习快"，但代码 B 用更高学习率（正确）。修正注释为"B 学习快, 因为 B 的梯度依赖 A"。
2. **真实模型 target 不合理**: `target = input_ids.clone()` 导致自预测。改为随机 target。
3. **dtype 一致性**: LoRA 参数 dtype 与基础权重对齐，训练前 `model.float()` 避免 float16 梯度溢出。

### 验证结果
- 模型: 真实 Qwen3-0.6B
- QLoRA VRAM 节省 13.56x（NF4 量化），NetScore-E 最优
- LoRA+ 前 3 步收敛快于 LoRA

## 9. RAC (2608.04991)

### 算法一致性: 部分一致
- **参考检索 + 分组仿射对齐 + 残差量化三步流程**: 一致
- **差异点**: 用余弦相似度检索而非 token ID 匹配；未实现三阶段区分和因果预测器

### 修复的问题 (2 项)
1. **分组仿射对齐逐元素而非逐组（数学偏差）**: 代码在每个 group 内对每个元素独立计算 scale/zero（shape [num_groups, g]），论文要求每组一个 scale/zero。修复为在 group 维度联合 reduce（shape [num_groups]）。
2. **死代码清理**: 删除从未使用的 `span_norms` 和 `q_norm`。

### 验证结果
- 模型: 真实 Qwen3-0.6B (hidden=1024)
- RAC 4bit MSE 0.000404 vs 直接量化 0.000706，对齐后残差降低 11.7%

## 10. VQ-VAD (2608.05069)

### 算法一致性: 部分一致
- **EMA 码本更新 + STE + 承诺损失**: 一致
- **差异点**: 论文用 VQ-GAN（含判别器），demo 用 VQ-VAE（无判别器）；应用域从视频迁移到 LLM 隐藏状态

### 修复的问题 (2 项)
1. **异常检测数据泄漏（关键）**: 模型在全部数据上训练，再用子集测试。修复为拆分训练集(80%)/测试集(20%)，仅在训练集训练。
2. **承诺损失用 EMA 更新后码本**: 在 EMA 更新前保存 z_q 副本，用更新前的 z_q 计算承诺损失。

### 验证结果
- 模型: 真实 Qwen3-0.6B (H=1024)
- 测试集异常检出率 100%（正常误差 0.46 vs 异常 7.78）
- 压缩 2730x（32 token → 6-bit 索引）

## 11. SSTQ (2608.05127)

### 算法一致性: 部分一致
- **紧框架旋转 + 子采样 + 随机符号量化 + LDP**: 框架一致
- **差异点**: 仅实现 1-bit（论文支持通用 b）；子采样 s=16 而非 s=1

### 修复的问题 (2 项)
1. **Flat Randomized Response 隐私机制错误（严重）**: 代码在不报告真值时生成随机 ±1（独立于真值），导致 eps-LDP 失效且去偏错误。标准二值 RR 应报告反值（-sign）。修复后 E[priv]=a·sign，去偏 1/a 正确，满足 eps-LDP。
2. **CUDA 设备不匹配**: 旋转矩阵和 Laplace 噪声在 CPU 创建。添加 device 参数支持。

### 验证结果
- 模型: 真实 Qwen3-0.6B
- 无偏性验证: ||x_hat-x||/||x|| = 0.0183（趋近 0，确认无偏）
- K=2000 聚合 MSE 降至 4.5e-5，符合 O(1/K) 衰减

## 共性问题

1. **领域适配**: 11 篇论文均非面向 Qwen3-0.6B（面向 70B 级模型/扩散模型/Mistral-7B 等），demo 均做了合理适配，影响数值复现但不影响算法逻辑验证。
2. **MockTransformer attention**: 多个 demo 的 `_simple_attention` 未正确处理 GQA，已全部修复。
3. **float16 兼容性**: 共享工具保持 float32 加载（原始设计），个别需要训练的 demo 内部自行 `.float()` 转换。

所有 11 篇 demo 均使用真实 Qwen3-0.6B 模型（HuggingFace 缓存，CPU 模式 float32）端到端跑通，无任何 mock 回退。
