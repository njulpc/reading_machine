# COD-TDQ (arXiv:2604.16855) 复现 Demo

## 论文核心

COD-TDQ：伪装目标检测 W4A4 量化的任务特异悬崖——重尾背景 token 主导共享激活范围、撑大步长，把微弱边界线索压进零仓。解法：直接求和 token 组（DSTG，按组分配尺度抑制跨 token 范围主导）+ 双约束范围投影（DCRP，约束步长-离散度比与零仓质量）。免重训 Sα 超 SOTA 0.12+。

## 本 demo 复现内容

1. 构造 COD 风格合成激活：大量重尾背景 token + 少量弱幅值但有结构的"边界 token"。
2. 实现 4-bit 激活量化三方案：
   - per-tensor（共享范围，重现零仓灾难）；
   - per-token；
   - COD-TDQ 式 DSTG（token 组尺度）+ DCRP（投影裁剪范围使步长/离散度比与零仓质量有界）。
3. 统计边界 token 的零仓占比与重建误差，验证双约束的修复作用。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- 任务数据为合成（COD 的"重尾背景 + 弱边界"结构），非真实 CFRN/ESCNet 模型；与 Qwen3 无关，机制复现。
- DCRP 的两个约束阈值按论文精神设定，非论文精调值。
