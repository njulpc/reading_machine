# Paper: 2603.25284 — SliderQuant (Sliding-layer Quantization)

复现内容：
1. 层级量化敏感度画像（leave-one-out：逐层单独量化、测端到端输出 MSE）
2. 敏感度驱动的层间比特分配：最敏感 6 层 4-bit、中间 12 层 3-bit、最不敏感 6 层 2-bit
3. 层内增量滑动量化：权重按列分 4 窗，逐窗量化并把残差带入后续窗口的缩放

目标模型：Qwen3-0.6B 同构 mock（24 层堆叠正交初始化线性层，激活不衰减不饱和，
使层级敏感度可被测量）。

## 验证方式（如实说明）

- 未使用真实权重，用 mock 探针网络验证全部代码路径与算法收益。
- 验证项：在相同平均位宽（3.0 bit）预算下，端到端输出 MSE 三方对比——
  均匀 3-bit vs 敏感度分配 vs SliderQuant（敏感度分配 + 层内增量窗口）；
  实测 SliderQuant 输出误差较均匀 3-bit 低 ~60%，层内增量窗口单独贡献 ~40% 降幅。
- 论文的"浅/深层更敏感"U 形曲线是真实 LLM 的实证性质，mock 网络不复现该曲线形状，
  仅复现"画像→分配→增量量化"的完整机制。
