# 2607.12789 AVQ-Attention: Adaptive Vector-Quantized Attention — 复现说明

## 论文信息
- **标题**: AVQ-Attention: Adaptive Vector-Quantized Attention
- **日期**: 2026-07-14
- **核心主张**: 向量量化（VQ）注意力把 O(N²) 注意力降为 O(MN)（M 为码本大小），但固定码本不考虑注意力质量分布：高注意力区域被粗糙近似，低注意力区域浪费码容量。AVQ 在前向过程中按注意力重要性打分，把最重要的码字细分为子码字，在注意力集中处细化、其余保持粗量化。

## 复现内容（demo.py）
1. **VQ 注意力近似框架**：码字 softmax + 计数加权（`softmax(q·c_m/√d + log cnt_m)`），O(M) 近似精确注意力输出；
2. **自适应细化**：按成员级注意力质量 `Σ_i exp(q·k_i)` 对码字打分，把 top-2 最热码字按成员注意力权重分位数切成 4 个子码字（注意力集中处细化）；带 sink 保护（单键占比 >80% 的码字不切）；
3. **合成对比实验**（注意力质量集中的簇状键）：等码本预算（22 码字）下 AVQ 相对误差 0.053 < 均匀 VQ 0.062，逐查询几乎一致占优；
4. **真实模型段**：Qwen3-0.6B 各层 K/V 投影，扫描注意力质量集中度，在高集中度层上验证 O(MN) 近似的可行性。

## 运行方式
```bash
python3 demo.py   # 依赖 torch；有 transformers + 本地缓存的 Qwen/Qwen3-0.6B 时自动启用真实模型段
```

## 验证方式
- 合成段：构造 3 个"宽而稀疏"的热簇（15% 键、吸引大部分注意力质量）+ 13 个紧密冷簇，比较等预算下均匀 k-means 码本 vs AVQ 细化的注意力输出相对误差；
- 真实段：直接用缓存的 Qwen/Qwen3-0.6B 前向得到的层间 K/V/Q 投影（省略 RoPE，仅作近似质量测试）；无模型时自动跳过；
- 预期结论：合成集中场景 AVQ 优于均匀 VQ；真实短上下文头中注意力由 sink 主导，两种方案误差均 ≤1e-2 量级——与论文面向长序列场景的定位一致。
