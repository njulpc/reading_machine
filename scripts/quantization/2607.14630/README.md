# 2607.14630 Cross-Layer Error Compensation — 复现说明

## 论文信息
- **标题**: Cross-Layer Error Compensation and Finite-Sample Feature-Statistics Matching for Extreme Low-Bit Quantization of Large Language Models
- **日期**: 2026-07-16
- **核心主张**: 逐层 PTQ 独立最小化每层重建误差，量化误差沿深度累积，极低比特下崩溃。论文把所有层的量化建模为联合优化：(i) 跨层误差补偿，维护网络级累积误差递归 `e_{l+1} = A_l e_l + q_l`；(ii) 有限样本特征统计匹配（均值/投影协方差/中心化核）。在 Qwen2.5-1.5B 的 1.125-bit 分组二值权重下显著优于逐层基线。

## 复现内容（demo.py）
1. **基线（独立标定）**：分组二值权重 `sign(W)` + 每组最小二乘尺度（按教师特征的 E[x²] 加权）；
2. **补偿标定**：在已量化的前缀之上，把每个块的尺度用 Adam 微调，使**块总输出**（残差流 + 分支）匹配教师块输出——误差递归的可实现前向差分形式；
3. **合成段**：12 块残差 MLP、~1.1-bit，输出相对误差 0.240 → 0.172；逐层均值漂移逐层递减（0.143→…→0.214 vs 补偿后 0.126→…→0.041）；
4. **真实模型段**：Qwen3-0.6B 前 4 个 block 的 MLP（gate/up/down）量化到 1.125-bit，末 token logits 余弦 0.447 → **0.993**。

## 运行方式
```bash
python3 demo.py   # 依赖 torch；有 transformers + 本地缓存的 Qwen/Qwen3-0.6B 时自动启用真实模型段
```

## 验证方式
- 合成段：各向异性输入（少量离群维度主导 E[x²]）+ 残差流，对比独立 vs 补偿标定的最终输出相对误差与逐层特征均值漂移；
- 真实段：hook 捕获教师模型的逐线性输入二阶矩与逐块输出；补偿时非 MLP 部分对尺度为常数，因此每块只需优化 3 个线性层的输出通道尺度（秒级）；用末 token logits 余弦衡量端到端影响；
- 模型不可用时自动跳过。
