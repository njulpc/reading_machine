# Paper: 2603.17891 — RAMP (Reinforcement Adaptive Mixed Precision)

复现内容（SAC 训练以模拟策略代替，方法结构完整保留）：
1. 逐层状态嵌入：激活统计 + 权重属性 + 结构描述子（对应论文 11 维嵌入）
2. Scale Folding：逐通道缩放把激活异常值迁入权重（SmoothQuant 式迁移强度 alpha=0.3，
   仅对嵌入判定为异常倾向的层选择性施加，矩阵乘严格不变）
3. 比特预算约束下的逐层联合 W/A 比特分配（预算精确满足 avg=3.0 bit）
   + 零样本迁移演示（64 维 mock 上定策略，直接迁到 96 维"更大模型"）

目标模型：Qwen3-0.6B 同构 mock（24 层）。构造异质敏感度：少数"敏感层"带激活异常通道，
其余层权重幅度小（输出贡献低、对量化不敏感），模拟真实 LLM 中层敏感度高度偏斜的现象。

## 验证方式（如实说明）

- 未下载真实权重，用 mock 模型验证；SAC 策略用**嵌入导出的敏感度排序**代替
  （论文核心是可迁移的逐层比特分配，本 demo 验证嵌入、Scale Folding 与分配-评估闭环）。
- 验证项（同预算 W3A3 对比）：敏感度分配使端到端误差下降 ~58%，叠加选择性 Scale Folding
  再降 ~34%（实测 0.95 → 0.40 → 0.26）；分配准确找回预设的异常层；
  同一管线零样本迁到 96 维模型仍优于均匀基线（1.01 → 0.29）。
