# QB-LIF (arXiv:2604.25688) 复现 Demo

## 论文核心

QB-LIF：把 burst 发放重构为膜电位的**饱和均匀量化 + 可学习尺度**，每层自适应发放分辨率；可吸收尺度（推理时折叠进突触权重，保持纯累加执行）；ReLSG-ET 替代梯度（线性修正 + 指数尾）维持离散多级空间梯度流；超低时延下精度超二值与固定 burst SNN。

## 本 demo 复现内容

1. 实现 QB-LIF 神经元前向：`s = clip(round(v/Δ), 0, Qmax)`（饱和均匀量化，burst 级数 Qmax），尺度 Δ 可学习；ReLSG-ET 风格替代梯度（线性区 + 指数尾衰减）。
2. 实现可吸收尺度：推理时把 Δ 折叠进突触权重 `W' = W·Δ`，验证折叠前后输出一致（纯累加路径）。
3. 在小合成时序分类任务上训练：对比二值 LIF（1 bit）与 QB-LIF（2 bit burst）在**相同时间步数**下的精度，验证信息吞吐提升。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- 合成数据、单层 SNN，验证机制而非论文的 CIFAR/ImageNet 数字；与 Qwen3 无关。
- 替代梯度为 ReLSG-ET 的近似实现（relu 线性区 + 指数尾）。
