## 2. ScaleQ-1.58 (2608.01078)

### 算法一致性: 部分一致
- **三值量化**: scale=mean(|w|), threshold=0.5*scale — 与论文一致
- **AYOT 校准**: CPU 上使用模拟推理链替代 model.generate() — 部分一致
- **CAT-Q 可微三值化**: sigmoid 软近似 + STE, temp=1.0 — 部分一致
- **CAT-Q 优化**: 逐层优化 (layer-wise) 替代端到端全模型优化 — 部分一致 (PTQ 标准做法)

### 修复的问题 (5 项)
1. STE 梯度断裂: `.data` 赋值 → 前向钩子保持梯度流
2. FP16/FP32 dtype 不匹配导致 NaN: 显式 `.float()` 转换 + `.copy_()` 赋值
3. 全模型训练 CPU 过慢: 改为逐层优化 (layer-wise)
4. 硬三值化后 dtype 不匹配: 量化权重转回模型 dtype
5. 梯度爆炸: 添加梯度裁剪 + 温度参数调整

### 验证结果
- 模型: 真实 Qwen3-0.6B (FP16)
- 10 层量化, 5 次 CAT-Q 迭代
- ScaleQ vs RTN 权重 MSE 改善: 12.4%
- 压缩率: 8.0x

## 3. DeVIT (2608.01343)

### 算法一致性: 部分一致
- **差分编码**: delta[i] = w_q[i] - w_q[i-1] — 与论文一致
- **值局部性**: 量化后相邻权重相同的比例 — 一致
- **移位-加法 LUT**: 将乘法分解为移位和加法 — 一致
- **差异点**: 论文中权重按行排序后差分编码, demo 未排序 (直接差分)

### 验证结果
- 模型: 真实 Qwen3-0.6B
- 4-bit 量化, 乘法消除率 15.7%
- 标准 vs DeVIT 输出 MAE: 6.52e-8 (数值正确)
- 非零 delta 平均移位次数: 1.30

## 4. HaTQ (2608.01653)

### 算法一致性: 部分一致
- **Hadamard 重参数化**: DH (Double-Hadamard) 和 WH (Weight-only) — 一致
- **敏感层识别**: 离线 profiling, 基于激活范围放大倍数 — 一致
- **INT8 量化**: 对变换后权重进行 per-channel 对称量化 — 一致
- **差异点**: 非幂次维度截断 Hadamard 矩阵不完全正交; 所有层均判定为 double

### 验证结果
- 模型: 真实 Qwen3-0.6B
- 197 层 profiling, 8 层量化
- Hadamard 变换后峰度: 3.76 → 0.03 (分布显著均匀化)
- 基线 INT8 token 一致率: 5/5

## 5. FOCUS (2608.01847)

### 算法一致性: 部分一致
- **FP4 E2M1 格式**: 15 个量化级别 — 一致
- **CRS (耦合松弛缩放)**: s_quant = s_dequant * alpha — 一致
- **DGS (双粒度缩放)**: 子块级量化尺度优化 — 一致
- **E8M0/E4M3 尺度格式**: MXFP4/NVFP4 两种格式 — 一致
- **差异点**: 使用网格搜索替代梯度优化 (简化实现)

### 验证结果
- 模型: 真实 Qwen3-0.6B
- MXFP4: FOCUS 输出 MSE 改善 9.3%, token 一致率 4/5
- NVFP4: FOCUS 输出 MSE 改善 -1.8% (略差), token 一致率 4/5
- CRS+DGS 优化比例: ~43% 子块找到更优 gamma
