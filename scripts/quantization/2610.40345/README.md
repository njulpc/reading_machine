# H_Z-PTQ：Qwen3-0.6B真实校准与局部数值复现

论文：[A Unified Hessian-Guided Framework for Post-Training Quantization](https://arxiv.org/abs/2610.40345)，[官方v1全文](https://arxiv.org/html/2610.40345v1)，§3.4–3.6、附录B。

本实验使用真实Qwen3-0.6B权重，执行完整模型前向与采样标签损失的反向传播。量化对象是第一层 `q_proj.weight[:64, :128]` 的转置，即128输入×64输出子矩阵；它不是一个完整线性层，也不覆盖完整模型。代码为独立可运行实现，没有占位模型。

## 运行

在仓库根目录执行：

```bash
python3 scripts/quantization/2610.40345/demo.py
```

本次环境：Python3.9.6、PyTorch2.8.0、Transformers4.57.6，CPU4线程，主体BF16、曲率与量化计算FP64。模型使用本机缓存的 `Qwen/Qwen3-0.6B`，revision `c1899de289a04d12100db370d81485cdf75e47ca`。默认只读本地权重；其他机器应先准备同一revision，再用 `--model /path/to/snapshot` 指定。结果默认写入同目录 `results.json`，可用 `--output` 改路径。

## 实现对应关系

- 校准：随机种子7，从完整模型输出分布采样标签，以交叉熵反向取得首层q_proj输出梯度。前两条人工文本各64tokens用于校准，后两条用于留出误差；具体文本与版本写入结果。不是随机权重或凭空生成的激活。
- 式12：估计权重输入曲率与输入梯度曲率，通过SPD矩阵几何均值的平方根，再接归一化Hadamard变换。保持 `X T T^-1 W = X W`。
- 式14–16：量化tile为 `(group, 1)`，两侧block-LDL；按曲率trace排序，从右下反对角线开始，500个range候选覆盖 `[max|w|, 2max|w|]`，signed INT4网格为−8至7，用输入D块加权误差选scale，并通过 `L_i.T @ delta @ L_o` 更新剩余tile。
- 通道模式：本子矩阵输入宽度128，故group128即每输出通道一组；transform block128，激活每token一组。式17用平均token梯度能量及变换后的输入曲率，在100个 `[0.5,1]` 候选中选裁剪系数。
- g32模式：transform和权重/激活组宽32；按论文附录B不做激活裁剪。每输出通道有4组，共256个权重scale。
- 为极少样本曲率额外加均值对角线1%的阻尼（下限1e-12）。这是本机稳定性设置，不声称是论文原始阻尼值。

## 证据边界与未完成项

论文使用2048×2048 DCLM-Edu校准、完整模型和6个CSR任务；本机仅用两条短人工文本，以CPU资源进行组件验证，没有执行上述大规模校准与基准。截取输入/输出子矩阵后，`Gx = Gz W^T`只代表这部分连接的敏感度，不能当完整层Hessian。

代码输出反量化浮点张量，不打包INT4权重，也不生成压缩检查点；没有量化KV cache、验证完整模型W4A4KV4、编写融合CUDA内核或测吞吐。保留变换与浮点副本的本机实现不节省总显存。理论4bit/16bit载荷比4倍不等于包含scale、变换和未量化参数后的实测文件压缩比。

原始结果见同目录 `results.json`；本次命令日志留存在自动化审计目录的 `qwen_run.log`。这些限制明确记录，不以小矩阵MSE替代论文WikiText或CSR结果。
