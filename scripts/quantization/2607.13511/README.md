# 2607.13511 ExTernD: Expanded-Rank Ternary Decomposition — 复现说明

## 论文信息
- **标题**: ExTernD: Expanded-Rank Ternary Decomposition — Ternary LLM PTQ with Accuracy Approaching Any Quantization Level
- **日期**: 2026-07-15
- **核心主张**: 把权重矩阵分解为 A ≈ B·diag(D)·C，其中 B、C 为三值矩阵（{-1,0,+1}），内秩 k = μ·min(m,n) 有意扩展超过满秩（μ>1），满秩之后的分量持续修正前面分量的量化误差；论文证明残差随 k 单调下降、可压到任意 ε 以下。在 Gemma-4-E2B/Qwen3.5-4B 上以 5.2–5.5 有效 bpw 匹配 Q4_K 逐矩阵精度。

## 复现内容（demo.py）
1. **贪心三值秩-1 扩展**：每步对残差做幂迭代取主奇异对，两侧分别做最优阈值三值量化（搜索阈值 τ 最小化 `||v − s·t||²`），残差减去该分量；
2. **尺度联合最小二乘重拟合**：固定三值 B、C，周期性地对实尺度 D 解正规方程 `G_ij = (b_i·b_j)(c_i·c_j)`（对应论文尺度向量的可优化性）；
3. **单调性验证**：128×128 矩阵 μ=4，残差从 0.98 单调降到 0.013，满秩（k=128）之后仍持续下降——验证 any-ε 主张；
4. **精度-码率对比**：256×256 上 ExTernD μ=2（6.46 bpw）误差 0.104 ≤ int4 分组量化（4.25 bpw）的 0.108；μ=3 降到 0.038；
5. **真实权重段**：Qwen3-0.6B 第 0 层 q_proj 的 384×384 切片，同样呈现单调下降与随 μ 增大的精度提升。

## 运行方式
```bash
python3 demo.py   # 依赖 torch；有 transformers + 本地缓存的 Qwen/Qwen3-0.6B 时自动启用真实权重段
```

## 验证方式
- 单调性：打印残差序列并断言非递增（论文定理的直接数值验证）；
- 有效 bpw 公式：`(k·(m+n)·log2(3) + 16·k)/(m·n)`，与 int4 g=64（4.25 bpw）同表对比；
- 真实段：模型不可用时自动跳过。
