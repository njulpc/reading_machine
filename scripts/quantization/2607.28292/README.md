### 修复的问题清单

1. **LoRA 秩错误** (§4.1): 论文 "rank-1" 指扰动秩，LoRA 适配器秩 r=16。原代码 `lora_rank=1` 误解为适配器秩，已修正为 16。
2. **编辑目标错误** (§4.1): 论文核心创新是编辑 LoRA B 矩阵而非冻结的 W₀。原代码 `module.weight.data += delta_w` 直接修改基础权重，已重构为 A/B 矩阵结构，编辑作用于 B，W_quant 保持冻结。
3. **领域优先级公式不一致** (§4.2): 论文使用二值评分 s_uk,s_bank∈{0,1} 和乘法公式 Δ'=Δ·λ(1+β_uk·s_uk+β_bank·s_bank)。原代码使用计数式评分和线性插值，已修正为二值评分+乘法公式，并区分 UK 金融/银行两类关键词。
4. **退化债务公式不一致** (§4.3): 论文公式4使用整数计数器 (deg>T 时+1，否则-δ)。原代码使用连续值衰减 (×0.5/×0.3)，已修正为整数计数器。
5. **hash() 不可复现**: 原代码用 `hash()` 设置随机种子，改用 `torch.Generator` + `abs(hash())` 提高可复现性。

### 功能验证结果

**验证方式**: 真实 Qwen3-0.6B 模型端到端量化+编辑+稳定性控制 (CPU, float32)

**验证结果**:
- 模型: Qwen3-0.6B (596.0M 参数, 197 个 Linear 层)
- 4-bit 量化: 平均量化误差 MSE=3.52e-05，压缩至 FP32 的 12.5%
- LoRA 编辑 (r=16): 3 轮顺序编辑，每轮对 197 层通过 B 矩阵注入 rank-1 扰动
  - 编辑强度: 2.25/2.25/2.50 (由二值领域优先级公式计算)
  - 编辑总扰动幅度: 0.000958 → 0.001207 → 0.001380 (B 矩阵累积)
- 稳定性控制 (整数计数器):
  - 基线损失: 6.7154
  - 退化轨迹: 0.0035 → 0.0045 → 0.0057 (均 < T=0.05)
  - 退化债务: 0 (始终正常)
  - 控制动作: normal × 3
- LoRA 参数量: 12.5M (197 层 × (16×in + out×16))
- 内存: FP32 2.38GB → W4 0.30GB (12.5% of FP32)
