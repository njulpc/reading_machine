# LBLLM (arXiv:2604.19167) 复现 Demo

## 论文核心

LBLLM：三阶段蒸馏实现 W(1+1)A4 二值化——(1) PTQ 初始化；(2) 逐层蒸馏量化二值权重 + 组级位图 + 量化参数（激活保持全精度）；(3) 学习可学习激活量化因子动态压至 4 bit。解耦权重与激活量化训练，0.016B token 单卡训练超 SOTA，且无高精度旁路、无旋转矩阵。

## 本 demo 复现内容

1. 真实 Qwen3-0.6B 配置构造 2 层小型 transformer 块（随机权重）。
2. 实现核心量化结构：
   - 权重量化：`W ≈ α·B + β·M`（1 bit 符号 B + 1 bit 组级位图 M + 逐组标量），即 W(1+1)；
   - 激活 4 bit 动态量化，尺度为可学习参数；
   - 直通估计器（STE）反向传播。
3. 模拟三阶段流程：stage1 PTQ 初始化 → stage2 只训权重侧量化参数（逐层蒸馏目标：匹配全精度层输出）→ stage3 只训激活尺度。验证训练可收敛、量化层输出逼近 FP32 层输出。

## 运行

```bash
python3 demo.py
```
