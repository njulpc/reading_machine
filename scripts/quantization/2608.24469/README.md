# 2608.24469 低秩三值适配复现

从 Qwen3-0.6B `q_proj` 截取真实 128×128 权重 tile，先三值化，再用 rank=4 的两个小因子通过 STE 学习乘法 mask；目标任务是一个 seeded、可验证的低秩三值符号变换。训练后直接把 mask 合并到基座，并断言权重仍严格属于 `{-1,0,1}`，无需反量化。

```bash
PYTHONPATH=/private/tmp/quant_review_pydeps_20260826 python3 demo.py
```

该测试验证论文最关键的“低秩乘法更新可直接合并且保持三值域”，不复现六模型下游微调、精度恢复或专用 ternary kernel。

实测：1024 个可训练因子参数替代 16,384 元素稠密更新；目标 mask MSE 从 0.839722 降到 0.252136，合并后唯一取值严格为 `[-1, 0, 1]`。
