# DuQuant++ (arXiv:2604.17789) 复现 Demo

## 论文核心

MXFP4 微缩放格式（32 元素共享一个 E8M0 指数尺度）下单个激活离群值会撑大整块共享尺度，压缩其余元素动态范围。DuQuant++ 把离群值感知的细粒度旋转块与微缩放组（B=32）对齐，单一旋转替代原 DuQuant 的双旋转 + zigzag 置换管线，在线旋转成本减半，LLaMA-3 上 MXFP4 W4A4 达 SOTA。

## 本 demo 复现内容

1. 用真实 Qwen3-0.6B 配置构造同架构线性层（随机权重）。
2. 实现 MXFP4 格式：32 元素一块，块内共享 E8M0 尺度（2 的幂），元素 FP4 (E2M1 近似为 4-bit 均匀格点以简化）。
3. 构造带通道离群值的激活，对比：
   - 朴素 MXFP4；
   - 离群值感知旋转（把离群通道的能量分散到组内，单旋转、块对齐 32）后 MXFP4。
4. 报告量化前后层输出 MSE，验证旋转显著降误差。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- Qwen3-0.6B 权重因网络受限未下载，使用真实架构配置 + 随机权重 + 人工注入的离群通道激活验证代码路径；该现象（离群值撑大共享尺度）为格式固有，与具体权重无关。
- FP4 元素用均匀 4-bit 格点近似 E2M1；E8M0 尺度严格实现为 2 的幂。
- 旋转矩阵为贪心构造的置换-符号-块 Hadamard 组合（DuQuant 风格），非论文原始权重。
