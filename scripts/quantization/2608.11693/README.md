# Paper: 2608.11693 - INT8 Audit on Blackwell

## INT8 W8A8 Quantization Demo

This script demonstrates INT8 weight and activation quantization, highlighting calibration strategies and stack-level deployment considerations.

## Run

```bash
pip install torch
python3 demo.py
```

## Core Content

This is a hardware audit paper rather than an algorithm paper. The demo shows:
1. INT8 W8A8 quantization implementation
2. Different calibration strategies comparison
3. Simulated stack-level availability check
