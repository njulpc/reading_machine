# MoE-nD (arXiv:2604.17695) 复现 Demo

## 论文核心

MoE-nD：KV cache 多轴压缩的**逐层异构路由**——不同层对 token 驱逐/量化的敏感度差异巨大，统一配方浪费精度；离线校准贪心 solver 在全局显存预算下为每层选（驱逐率, K-bits, V-bits）；14× 压缩追平未压缩基线。

## 本 demo 复现内容

1. 用真实 Qwen3-0.6B 架构（缩小的层数与维度，随机权重）构造多层注意力 KV cache。
2. 实现敏感度画像：对每层单独施加驱逐/低比特，测输出扰动 → 逐层成本矩阵。
3. 实现贪心 solver：全局显存预算约束下逐层分配（keep_ratio, k_bits, v_bits），最小化预测质量损失。
4. 对比统一配方 vs MoE-nD 路由在**同预算**下的端到端输出误差。

## 运行

```bash
python3 demo.py
```

## 限制（如实说明）

- Qwen3-0.6B 权重未下载，用真实架构配置 + 随机权重构造敏感度差异（随机权重下层间敏感度差异来自随机结构，真实模型差异更大，结论方向一致）。
- 质量损失预测用单层扰动线性叠加（论文同款贪心假设）；未实现真实 attention patch kernel。
