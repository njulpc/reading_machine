# 深度技术分析：DP-OPD: Differentially Private On-Policy Distillation for Language Models

## 1. 核心速览

**研究主题**：差分隐私约束下的在线策略蒸馏——免合成的隐私压缩框架。

**一句话总结**：DP-OPD 仅对学生施加 DP-SGD，冻结教师在学生生成轨迹上提供稠密 token 级目标（私有广义知识蒸馏），严格预算 ε=2.0 下困惑度优于 DP 微调与离策略 DP 蒸馏（Yelp 44.15→41.68；BigPatent 32.43→30.63），并把隐私压缩坍缩为单一 DP 学生训练循环。

## 2. 研究背景与动机

私有语料适配 LLM 需要 DP 保证，但 DP-SGD 噪声在自回归长 rollout 上放大暴露偏差；现有私有蒸馏要么师生都 DP（算力翻倍、效用更差），要么先 DP 训练教师再生成 DP 合成文本（管线复杂）。

## 3. 核心方法与创新点

- **仅学生 DP**：冻结教师免 DP，隐私噪声只进学生训练；教师在学生轨迹上给稠密监督，缓解暴露偏差。
- **免合成**：不需 DP 教师训练与离线合成文本生成，管线大幅简化。
- **私有广义 KD**：对续写 token 的 token 级目标。

## 4. 实验设计与结果

ε=2.0：Yelp PPL 44.15→41.68、BigPatent 32.43→30.63（相对合成式 DP 蒸馏），同时优于 DP 微调与离策略 DP 蒸馏。

## 5. 局限性与未来展望

局限：教师需访问私有数据提供目标（部署边界需明确）；ε=2.0 偏宽松，更严预算下表现未知；对长推理链任务验证有限。未来方向：更严预算分析、教师侧安全边界形式化、与联邦/安全飞地结合。

## 6. 学术启发

- 隐私-效用-管线的三重权衡中，“只对学生加噪”是简单有效的帕累托改进。
- 在线策略信号对缓解 DP 噪声下的复合错误有独立价值。
