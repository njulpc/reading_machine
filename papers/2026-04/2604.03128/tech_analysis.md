# 深度技术分析：Self-Distilled RLVR

## 1. 核心速览

**研究主题**：RLVR 与在线自蒸馏（OPSD）的有机结合——RLSD 框架。

**一句话总结**：作者发现仅依赖特权教师（带参考答案的自教师）的学习信号会造成严重信息泄露与长训不稳，提出 RLSD：用自蒸馏提供 token 级策略差异以决定细粒度更新幅度，用 RLVR 环境反馈决定可靠更新方向，兼得两者优势，收敛上限更高、训练更稳定。

## 2. 研究背景与动机

OPD 用大模型教师提供稠密信号，RLVR 只有环境可验证结果的稀疏信号。近期 OPSD 让同一模型兼任师生、教师获得特权信息（如参考答案）实现自进化，但纯特权教师信号会导致信息泄露与长训不稳定。

## 3. 核心方法与创新点

- **病灶定位**：纯特权教师信号 → 信息泄露 + 不稳定；明确自蒸馏的“最佳生态位”。
- **RLSD 分工**：自蒸馏只决定 token 级更新幅度（细粒度），RLVR 决定更新方向（可靠）——幅度与方向解耦。
- **兼得优势**：更高收敛上限 + 更强训练稳定性。

## 4. 实验设计与结果

实验（具体基准见原文）表明 RLSD 同时取得 RLVR 的稳定性与 OPSD 的细粒度优势，收敛上限更高。

## 5. 局限性与未来展望

局限：方向/幅度解耦的理论性质（如偏差-方差）未形式化；特权信息形式（答案 vs 提示）的影响未系统比较；计算开销较纯 RLVR 增加。未来方向：理论分析、自适应混合权重、无验证域推广。

## 6. 学术启发

- “信号分工”（方向 vs 幅度）是组合异质训练信号的通用原则。
- 自蒸馏不是越多越好：识别其失效区间并限定其作用范围反而更强。
