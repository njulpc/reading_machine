# 深度技术分析：RCP: Representation Consistency Pruner for Mitigating Distribution Shift in LVLMs

## 1. 核心速览

**研究主题**：缓解视觉 token 剪枝导致隐状态分布漂移的累积剪枝 + 延迟修复框架。

**一句话总结**：RCP 用 LLM 内在注意力为基线的交叉注意力剪枝器预测累积掩码以保证跨层一致单调削减，再用延迟修复适配器（DRA）缓存被剪 token 精华并对答案生成 token 做 FiLM 调制，配一二阶统计匹配的修复损失；最高剪除 88.9% 视觉 token、降 85.7% FLOPs，平均精度仅小幅下降。

## 2. 研究背景与动机

LVLM 推理成本源于海量视觉 token。现有剪枝不可逆地移除 token，导致隐状态偏离预训练全 token 分布，性能显著退化。如何既物理丢弃 token 又补偿分布漂移是关键。

## 3. 核心方法与创新点

- **累积掩码剪枝**：以 LLM 内在注意力为基线的交叉注意力剪枝器，保证跨层一致、单调的 token 削减。
- **延迟修复适配器（DRA）**：缓存被剪 token 的精华，仅对答案生成 token 做 FiLM 调制——修复只花在刀刃上。
- **一二阶统计匹配修复损失**：对齐剪枝后与全 token 教师的表示统计。
- **轻量插件**：只训练插件模块，推理时真实物理丢弃 token。

## 4. 实验设计与结果

多个 LVLM 基准：最高移除 88.9% 视觉 token、FLOPs 降 85.7%，平均精度仅边际下降；在多个基准上优于其他免微调原模型的方法。

## 5. 局限性与未来展望

局限：需训练插件（非完全免训练）；DRA 对答案 token 的依赖使其不适合无生成任务的纯理解场景；与量化叠加未验证。未来方向：免训练版修复、与 KV cache 压缩结合、视频 token 扩展。

## 6. 学术启发

- “剪枝 + 针对性修复”比“更聪明的剪枝准则”更能逼近无损压缩。
- 修复只在最终消费信息的 token 上进行（延迟修复）是成本敏感的优雅设计。
