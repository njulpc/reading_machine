# 深度技术分析：Zero-Shot Quantization via Weight-Space Arithmetic

## 1. 核心速览

**研究主题**：量化鲁棒性作为权重空间中可迁移方向的发现与零样本量化增强。

**一句话总结**：PTQ 鲁棒性可用“量化向量”刻画——从供体任务经简单权重空间算术提取后修补受体模型，3-bit 设置下无受体侧 QAT 即提升 post-PTQ Top-1 最多 60 个百分点；跨 4 个 ViT 规模、22 个分类任务验证，并严格证明量化向量良定义、不受重参数化对称性影响。

## 2. 研究背景与动机

极低比特部署通常需要 QAT，但 QAT 需要训练数据与算力。如果量化鲁棒性像任务向量一样可以分离、存储、迁移，就能为零样本、低成本量化开辟新路径。

## 3. 核心方法与创新点

- **量化向量**：供体任务上“QAT 后权重 − 原权重”的差方向即为量化鲁棒性方向，可迁移到其他模型。
- **零样本修补**：受体模型无需训练数据与 QAT，权重空间加法即可获得量化鲁棒性。
- **理论保证**：证明量化向量良定义、不受重参数化对称性影响，并给出局部几何解释。

## 4. 实验设计与结果

4 个 ViT 规模 × 22 个图像分类任务：3-bit 下 post-PTQ Top-1 最高 +60 点；即使供体与受体任务差异显著也常取得实质增益。

## 5. 局限性与未来展望

局限：仅在 ViT 图像分类验证，LLM 等生成模型未覆盖；向量强度/缩放需调；对权重-激活联合量化的迁移性未知。未来方向：LLM 验证、量化向量库与检索、与其他权重空间算术（模型合并/编辑）的统一。

## 6. 学术启发

- “能力即方向”的权重空间算术范式扩展到量化鲁棒性，提示各种部署属性都可能被向量化。
- 为零资源场景下的压缩提供了全新工具箱。
