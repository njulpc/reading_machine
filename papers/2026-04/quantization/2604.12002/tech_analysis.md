# 深度技术分析：Self-Distillation Zero: Self-Revision Turns Binary Rewards into Dense Supervision

## 1. 核心速览

**研究主题**：单模型双角色（生成器 + 修订器）把二元奖励转为稠密 token 级自监督。

**一句话总结**：SD-Zero 让同一模型先生成、再以生成结果与二元奖励为条件修订，然后将修订器的 token 分布 on-policy 蒸馏回生成器；Qwen3-4B 与 Olmo-3-7B 上较基座至少 +10%，同问题集同样本预算下优于 RFT、GRPO、SDFT，并展现 token 级自定位与迭代自进化两个新特性。

## 2. 研究背景与动机

RLVR 奖励稀疏；蒸馏需外部教师或高质量示范，昂贵或不可得。能否既不要教师又获得稠密监督？

## 3. 核心方法与创新点

- **生成-修订双角色**：修订器以二元奖励为条件产生改进回答，充当临时教师。
- **on-policy 自蒸馏**：修订器分布 → 生成器，二元奖励被转化为稠密 token 监督。
- **两新特性**：token 级自定位（修订器识别需修改的关键 token）；迭代自进化（定期师生同步）。

## 4. 实验设计与结果

Qwen3-4B-Instruct、Olmo-3-7B-Instruct 数学与代码基准：≥+10% 于基座，优于 RFT/GRPO/SDFT（同预算）。

## 5. 局限性与未来展望

局限：修订质量依赖模型已有能力（弱模型冷启动难）；需可验证奖励；迭代同步频率需调。未来方向：无验证域扩展、多轮修订链、与过程奖励结合。

## 6. 学术启发

- “条件化即教师”：同一模型换个条件就能产生更强分布供蒸馏，是自监督信号构造的强通用模式。
