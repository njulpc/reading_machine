# 深度技术分析：OSC: Hardware Efficient W4A4 Quantization via Outlier Separation in Channel Dimension

## 1. 核心速览

**研究主题**：通道维离群分离的硬件高效 W4A4 量化。

**一句话总结**：发现激活离群在固定通道跨 token 持续聚集（token-persistent 结构聚类），OSC 离线组级识别离群通道、在线结构化子张量抽取将其聚合为紧凑稠密张量走 16-bit 分支 GEMM，其余走 4-bit GEMM；Qwen3-8B/30B 平均精度仅降 2.19/1.12 点，现代 AI 加速器上较 W8A8 GEMM 基线峰值加速 1.78 倍。

## 2. 研究背景与动机

4-bit 量化是高吞吐部署关键，但激活离群在低比特有限动态范围下造成严重退化。

## 3. 核心方法与创新点

- **离群结构聚类发现**：高幅离群在固定通道跨 token 持续出现。
- **双路 GEMM**：4-bit 主路 + 16-bit 离群支路，全部为规则高吞吐 GEMM，与现代 4-bit 微缩放硬件无缝适配。
- **W2 输入 FP8 回退**：离群聚类弱处的兜底。

## 4. 实验设计与结果

Qwen3-8B/30B：平均精度降 2.19/1.12 点；较 W8A8 GEMM 基线峰值 1.78× 加速。

## 5. 局限性与未来展望

局限：双路 GEMM 的调度与同步开销依赖硬件实现；离群通道比例过高时支路膨胀；对非 Transformer 层覆盖未说明。未来方向：与旋转方法对比组合、KV cache 通道分离、更多硬件验证。

## 6. 学术启发

- 离群处理的关键是“规则化”——把不规则离群重排为规则稠密计算才能吃到硬件红利。
