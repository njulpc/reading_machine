# 深度技术分析：Quantization of Spiking Neural Networks Beyond Accuracy

## 1. 核心速览

**研究主题**：脉冲神经网络（SNN）量化评估范式：超越准确率的发放行为保持性。

**一句话总结**：作者证明在同等准确率下，不同量化方法、裁剪范围与位宽会产生迥异的发放分布（影响实际稀疏度、状态存储与事件处理负载），并提出用 Earth Mover's Distance（EMD）作为发放分布偏移的诊断指标；均匀量化即使保精度也会引起分布漂移，而 LQ-Net 式学习型量化能保持接近全精度基线的发放行为。

## 2. 研究背景与动机

量化与 SNN 的稀疏事件驱动计算天然互补，可降内存带宽与算术成本。但现有 SNN 量化评估几乎只看准确率，忽视量化网络是否保持全精度网络的发放行为——而发放率直接决定部署时的有效稀疏度、膜电位状态存储与事件负载，相同精度下能耗可能天差地别。

## 3. 核心方法与创新点

- **提出 EMD 诊断指标**：用推土机距离度量量化前后各层脉冲发放分布的偏移，弥补准确率盲区。
- **系统性量化审计**：在 SEW-ResNet 架构（CIFAR-10/100）上，对权重量化与膜电位量化，系统扫描量化方法（均匀 vs LQ-Net 学习型）、裁剪范围、位宽的组合效应。
- **核心发现**：均匀量化在精度保持时仍诱发分布漂移；LQ-Net 式可学习量化在行为保持上显著更优——"保精度≠保行为"。

## 4. 实验设计与结果

在 CIFAR-10/100 上训练 SEW-ResNet，施加不同权重量化与膜量化配置，用准确率 + EMD 双指标评估。结果确认了上述方法间显著的行为差异，EMD 能有效区分精度指标无法区分的配置。

## 5. 局限性与未来展望

局限：仅在 CIFAR 级数据集与 SEW-ResNet 上验证，未覆盖大规模 SNN 与神经形态硬件实测；EMD 是诊断而非优化目标，尚未给出"保行为量化"的训练方法；能耗收益需硬件实测确认。未来方向：把 EMD 纳入量化感知训练目标、在神经形态芯片上实测行为-能耗关联、推广到 LLM 量化的激活分布保持评估。

## 6. 学术启发

- 对 LLM 量化同样有警示： perplexity 保持不代表内部动态保持，KV cache 量化、激活量化研究可借鉴 EMD 类分布级指标做更严苛评估。
- 评估指标研究本身是低成本高价值的科研切口：找对"看不见的失效模式"比刷精度更能开辟方向。
