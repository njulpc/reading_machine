# 深度技术分析：REAM: Merging Improves Pruning of Experts in LLMs

## 1. 核心速览

**研究主题**：MoE LLM 专家压缩——以路由加权合并替代剪枝。

**一句话总结**：REAM 按路由器权重与激活对专家分组并合并权重（而非 REAP 式直接删除），在多个 MoE LLM 的选择题与生成基准上常优于基线、多数情况下与原模型相当，并揭示 MC/GEN 性能权衡取决于校准数据混合（通用/数学/代码）。

## 2. 研究背景与动机

MoE LLM 数百亿参数带来部署显存压力。专家剪枝（REAP）直接删除专家损失能力；合并权重有望更好保留原模型行为。

## 3. 核心方法与创新点

- **路由器加权专家合并（REAM）**：分组 + 权重合并，比删除更保性能。
- **MC/GEN 权衡刻画**：合并后选择题与生成性能的权衡受校准数据混合比例控制，给出 Pareto 前沿分析。

## 4. 实验设计与结果

多个 MoE LLM、MC QA 与 GEN 基准：REAM 常优于 REAP 及其他基线，许多情形下与未压缩原模型相当；通用/数学/代码校准混合决定权衡位置。

## 5. 局限性与未来展望

局限：合并分组策略启发式；对路由分布的长期漂移（合并后路由再训练）未探索；与专家量化的叠加未覆盖。未来方向：可学习合并、路由重校准、合并+量化联合。

## 6. 学术启发

- “合并替代删除”原则在 MoE 压缩中同样成立，信息保留优先。
- 校准数据组成是压缩效果的隐藏变量，应作为实验报告标准内容。
