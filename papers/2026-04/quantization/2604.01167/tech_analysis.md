# 深度技术分析：AdaLoRA-QAT: Adaptive Low-Rank and Quantization-Aware Segmentation

## 1. 核心速览

**研究主题**：胸部 X 光分割中自适应低秩适配与量化感知训练结合的部署友好微调框架。

**一句话总结**：AdaLoRA-QAT 将自适应秩分配的 LoRA 编码器适配与选择性混合精度 INT8 QAT 结合，在大规模 CXR 数据集上达到 95.6% Dice（持平全精度 SAM 解码器微调），可训练参数减少 16.6 倍、模型压缩 2.24 倍，Wilcoxon 检验确认量化不显著降低分割精度。

## 2. 研究背景与动机

SAM 等基础模型在医学影像分割上效果强，但临床部署受算力约束。PEFT 减少训练参数但不降推理成本；量化降推理成本却可能破坏对临床可靠性至关重要的结构保真度。两者如何协同且不伤精度是实际落地痛点。

## 3. 核心方法与创新点

- **两阶段框架**：自适应秩 LoRA 编码器适配 + 全量化感知训练的分阶段组合。
- **自适应秩分配**：按层重要性分配 LoRA 秩，提升参数效率。
- **选择性混合精度 INT8**：对结构敏感部位保留高精度，兼顾压缩与结构保真。
- **统计显著性验证**：用 Wilcoxon 符号秩检验证明量化引起的精度变化不显著——比单纯报均值更严谨。

## 4. 实验设计与结果

大规模 CXR 数据集：95.6% Dice，与全精度 SAM 解码器微调持平；可训练参数降 16.6 倍；模型体积压缩 2.24 倍；Wilcoxon 检验 p 值支持“量化无显著退化”。

## 5. 局限性与未来展望

局限：仅验证 CXR 单模态任务；INT8 相对保守，未探索 INT4 等更激进位宽；自适应秩的搜索成本未详细报告。未来方向：扩展到 3D 医学影像、更低位宽 QAT、与蒸馏结合进一步缩小模型。

## 6. 学术启发

- PEFT + QAT 的组合应在训练流程层面协同设计，而非简单串联。
- 医学等高风险场景应采用统计检验论证压缩不显著影响性能。
