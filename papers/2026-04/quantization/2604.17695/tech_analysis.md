# 深度技术分析：MoE-nD: Per-Layer Mixture-of-Experts Routing for Multi-Axis KV Cache Compression

## 1. 核心速览

**研究主题**：KV cache 多轴压缩（驱逐/量化/低秩/跨层共享）的逐层异构路由。

**一句话总结**：指出现有方法对所有层套用同一压缩配方的同质性浪费了精度——不同层对各压缩操作的敏感度差异巨大；MoE-nD 用混合专家框架在全局显存预算下为每层路由专属（驱逐率、K 比特、V 比特）元组，离线校准贪心求解；LongBench 4 任务（16k 输入）上 14× 压缩（1.9GB→136MB）追平未压缩基线，而同等或更小显存的其他压缩基线得分均低于 8/100。

## 2. 研究背景与动机

KV cache 是长上下文推理的显存瓶颈。现有方法各作用于 KV 四维张量的单一轴：token 驱逐（序列轴）、量化（精度轴）、低秩投影（头维轴）、跨层共享（层轴），且对所有层用同一配方。本文实证：层间敏感度高度异质，最优的逐层驱逐-量化混合远非均匀。

## 3. 核心方法与创新点

- **MoE 路由式压缩**：每层作为"专家选择"问题，路由到自己的（eviction-ratio, K-bits, V-bits）配置。
- **离线校准贪心求解**：在全局显存预算约束下，用预测质量损失最小的贪心 solver 选路由。
- **单注意力补丁联合执行**：推理时逐层异构的驱逐与量化通过一个 attention patch 统一施加，工程上干净。
- **诚实的负结果**：MATH-500 与 LongBench TREC 上的两个无效案例有原则性解释（输入短、solver 在多数层选 keep=1.0），清晰刻画了逐层驱逐路由的收益边界。

## 4. 实验设计与结果

LongBench-v1 4 任务子集（16k 输入，每任务 n=50，推理模型协议）：14× 压缩下追平 1.9GB 未压缩基线（136MB）；AIME 推理基准上比最强逐层量化基线高 +6 至 +27 分（八个配置）。

## 5. 局限性与未来展望

局限：评测规模小（4 任务×50 样本），统计功效有限；离线 solver 按模型校准一次，跨模型/任务迁移需重校准；收益依赖输入足够长（短输入驱逐无空间）。未来方向：纳入低秩与跨层共享轴的完整路由、在线自适应预算、与投机解码/前缀缓存的系统级整合。

## 6. 学术启发

- "逐层异构"是 KV cache 压缩的下一个主战场：与混合精度量化的逐层位宽分配思想汇合，核心都是敏感度画像 + 预算分配。
- 该文的负结果报告（何时无效及为何）是方法论典范，增强了结论的可信度——压缩论文应标配适用边界分析。
