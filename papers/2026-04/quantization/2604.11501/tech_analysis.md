# 深度技术分析：Quantization Dominates Rank Reduction for KV-Cache Compression

## 1. 核心速览

**研究主题**：KV cache 压缩两条路线（量化 vs 降秩）的系统性对决。

**一句话总结**：5 个模型（124M–14B，MHA/GQA）等存储预算下量化一致优于降秩 4–364 PPL；LAMBADA 上 INT4 匹配 FP16（Mistral 7B +0.23 PPL）而同存储 rank-32 崩溃至 0.4% 准确率；理论分析表明投影损伤在 softmax Fisher 度量下超出量化损伤 3×2^(2b)/方向；K+V INT4 以 +0.18 PPL 实现 75% KV 削减。

## 2. 研究背景与动机

降秩（丢弃维度）与量化（降精度保维度）是 KV cache 压缩两大路线，缺乏受控对比与机理理解。

## 3. 核心方法与创新点

- **等预算受控对比**：量化一致大胜，GQA 越激进差距越大；混合基线也打不过纯量化。
- **结构不对称机理**：softmax 注意力路由下，丢维度可翻转被注意 token（离散失效），量化噪声有界且保序。
- **扰动理论**：投影损伤 vs 量化损伤 = 3×2^(2b)/方向；基无关消融（<0.4 PPL 散布）证明优势来自保维度而非坐标系。

## 4. 实验设计与结果

5 模型 × 多压缩率：INT4 接近无损；K+V INT4 = 75% 削减、Mistral 7B 仅 +0.18 PPL。

## 5. 局限性与未来展望

局限：PPL 与检索类任务为主，长生成 agentic 任务待验证；极低秩 + 量化混合的更细配比未穷尽；对 MLA 等低秩原生存 KV 架构不适用。未来方向：任务谱验证、逐层混合策略、与驱逐方法组合。

## 6. 学术启发

- “保维度、降精度”优于“降维度、保精度”——离散路由失效 vs 有界噪声的机理刻画可推广到其他压缩选择。
- 等存储受控对比 + 机理解释是压缩方法对决研究的范本。
