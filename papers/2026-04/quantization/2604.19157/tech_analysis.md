# 深度技术分析：SAW-INT4: System-Aware 4-Bit KV-Cache Quantization for Real-World LLM Serving

## 1. 核心速览

**研究主题**：真实服务约束下的 4 比特 KV cache 量化系统设计。

**一句话总结**：在分页显存布局、规则访存、融合注意力执行三大真实服务约束下甄别可行的 4 比特 KV 量化方案，核心发现：简单的"token 级 INT4 + 块对角 Hadamard 旋转"设计一致取得最佳精度-效率权衡，恢复朴素 INT4 损失的几乎全部精度，而向量量化、Hessian 感知量化等复杂方法在服务兼容性约束下仅带来边际收益；融合旋转-量化 kernel 零可测端到端开销，吞吐持平朴素 INT4。

## 2. 研究背景与动机

许多 KV cache 压缩方法在离线精度或压缩率上亮眼，却违反服务系统的硬约束（paged memory 布局、规则访存、融合 kernel），部署即失效。本文把问题从"哪种量化最准"重述为"服务约束下哪种量化可行且最优"。

## 3. 核心方法与创新点

- **约束导向的方法筛选**：系统性识别在服务约束下仍可行的最小 4 比特方法集合。
- **简单设计的胜利**：token 级 INT4 + 块对角 Hadamard 旋转一致最优；复杂方法（VQ、Hessian 感知）的额外收益在约束下被摊薄至边际。
- **零开销融合 kernel**：旋转-量化融合进 paged KV 布局，各并发级别下吞吐与朴素 INT4 持平。

## 4. 实验设计与结果

多模型多基准：恢复朴素 INT4 几乎全部精度损失；端到端吞吐与 INT4 基线持平，无额外时延。

## 5. 局限性与未来展望

局限：仅评估 4 比特档位，2/3 比特下"简单设计最优"的结论可能翻转；块对角 Hadamard 对非 LLM 架构（SSM、线性注意力）适用性未知；未与逐层异构位宽（MoE-nD 式）联合。未来方向：向更低比特扩展约束分析、与连续批处理/投机解码的系统集成、约束感知量化设计方法的形式化。

## 6. 学术启发

- 服务约束是压缩方法的"隐形筛子"：离线 SOTA 与部署 SOTA 的鸿沟需要用系统共设计弥合，本文是该方向 KV 量化的标杆。
- "简单方法 + 系统优化击败复杂方法"的教训反复出现：学术新颖性与部署价值的相关性弱，评估压缩方法必须过"系统兼容性"这关。
