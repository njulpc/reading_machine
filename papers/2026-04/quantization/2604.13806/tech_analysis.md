# 深度技术分析：DASH-Q: Robust Ultra Low-Bit PTQ via Stable Diagonal Curvature Estimate

## 1. 核心速览

**研究主题**：对角 Hessian 近似 + 迭代加权最小二乘的稳健超低比特 PTQ。

**一句话总结**：Hessian 类 PTQ 在低比特下因小校准集曲率估计噪声而退化；DASH-Q 丢弃噪声敏感的跨通道依赖，仅保留对角曲率并迭代加权最小二乘，过滤采样噪声同时优先保留显著特征能量；5 个 LLM 上零样本精度平均 +7.01%、较最强基线最高 +14.01%，且极小校准数据下稳健。

## 2. 研究背景与动机

跨通道补偿（GPTQ 类）在小校准集 + 超低比特时曲率估计噪声淹没有益信号。

## 3. 核心方法与创新点

- **对角近似**：舍去噪声敏感的离对角依赖，换取估计稳定性。
- **迭代加权最小二乘**：优先保留显著特征能量。
- **小数据稳健**：校准集极小时仍稳定。

## 4. 实验设计与结果

5 个基座 LLM：零样本平均 +7.01%、最高 +14.01%（vs 最强基线），超低比特区间领先。

## 5. 局限性与未来展望

局限：丢弃跨通道依赖在中高位宽可能反而损失（对角假设的适用区间）；对激活离群未专门处理；与其他低比特技术（旋转）的组合未验证。未来方向：稀疏化离对角（保留少量强依赖）、与旋转组合、校准集自适应。

## 6. 学术启发

- “少即是多”：噪声环境下简化模型（对角）可优于复杂模型（全 Hessian）——估计偏差-方差权衡的典型案例。
