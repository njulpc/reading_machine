# 深度技术分析：AXELRAM: Quantize Once, Never Dequantize

## 1. 核心速览

**研究主题**：直接在量化 KV cache 索引上计算注意力分数的 SRAM 宏架构。

**一句话总结**：AXELRAM 利用设计时固定码本（正交变换使坐标分布集中到 N(0,1/d)，最优量化器只依赖维度 d 与位宽 b）与“写入变换、读时查表”的非对称路径，使每查询乘法减少 102.4 倍；并发现符号模式敏感会在部分模型（Qwen2.5-3B）上造成灾难性 PPL 尖峰（Δ>50），用免梯度符号模式选择（200 候选、8 校准样本）零硬件成本消除。

## 2. 研究背景与动机

KV cache 量化通常需在计算前反量化，抵消部分收益。若注意力分数能直接从量化索引计算，可彻底免除反量化。但固定码本量化对旋转/符号模式的敏感性缺乏系统研究。

## 3. 核心方法与创新点

- **设计时固定码本**：正交变换将坐标分布归一到 N(0,1/d)，最优量化器与数据无关，只取决于 d 与 b。
- **非对称路径**：写入时变换、读出时查表无逆变换，每查询乘法减少 102.4 倍（数学恒等）。
- **符号模式敏感性发现**：将 SpinQuant 的旋转变差现象扩展到 KV cache 域且更严重；根因追溯到逐层范数异质性。
- **免梯度符号模式选择**：200 候选 × 8 校准样本一次性选择，零额外硬件成本消除灾难尖峰。

## 4. 实验设计与结果

10 seeds × 3 模型：部分模型（Qwen2.5-3B）出现 PPL 尖峰 Δ>50，LLaMA-3.1-8B 完全稳定；符号模式选择后灾难尖峰消除。

## 5. 局限性与未来展望

局限：固定码本对分布假设（变换后近似正态）的稳健性需更多模型验证；SRAM 宏为架构设计，流片验证未报告；对不同 GQA 配置的适配待研究。未来方向：与混合精度结合、硬件实测、码本-架构联合设计。

## 6. 学术启发

- “量化一次、永不反量化”的计算范式把量化从存储压缩提升到计算压缩层面。
- 旋转/符号敏感性是量化研究中反复出现的“隐形杀手”，应作为新方法的常规体检项。
