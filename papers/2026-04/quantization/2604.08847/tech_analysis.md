# 深度技术分析：DeFakeQ: Enabling Real-Time Deepfake Detection on Edge Devices via Adaptive Bidirectional Quantization

## 1. 核心速览

**研究主题**：面向深伪检测器的专用量化框架，端侧实时检测。

**一句话总结**：针对深伪检测依赖极易被量化破坏的细粒度伪造痕迹这一特性，DeFakeQ 提出自适应双向压缩策略同时利用特征相关性并消除冗余，在 5 个基准数据集、11 个 SOTA 骨干检测器上一致超越量化与压缩基线，并完成移动设备真实场景实时部署。

## 2. 研究背景与动机

深伪检测需要捕捉极细微伪影，这些细粒度线索对模型压缩高度敏感，通用量化技术在此任务上明显退化——需要任务感知量化。

## 3. 核心方法与创新点

- **首个深伪检测专用量化框架**。
- **自适应双向压缩**：同时利用特征相关性 + 消除冗余，平衡紧凑性与判别特征保留。
- **真机部署验证**：移动设备实时检测。

## 4. 实验设计与结果

5 基准数据集 × 11 个 SOTA 骨干：一致超越现有量化与模型压缩基线；真实移动端实时运行。

## 5. 局限性与未来展望

局限：对新一代生成模型伪影的泛化待持续验证；双向策略的额外校准成本；与对抗攻击鲁棒性的交互未评估。未来方向：与 QAT 结合、在线更新、更多硬件平台。

## 6. 学术启发

- 任务敏感度分析应前置：细粒度判别任务需要专门量化策略，通用 PTQ 不够。
