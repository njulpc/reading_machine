# 深度技术分析：Beyond SFT-to-RL: Pre-alignment via Black-Box On-Policy Distillation for Multimodal RL

## 1. 核心速览

**研究主题**：多模态 RL 前的分布预对齐：黑盒在策略蒸馏（PRISM）。

**一句话总结**：在 SFT 与 RLVR 之间插入显式分布对齐阶段：基于 OPD 原理把对齐建模为策略与 MoE 判别器（感知、推理专家分立）间的黑盒响应级对抗博弈，无需访问教师 logits 即获得解耦的纠正信号；配合 113K Gemini 3 Flash 高保真示范（最难未解问题上的稠密视觉定位与逐步推理），Qwen3-VL 上 4B/8B 分别较 SFT-to-RLVR 基线 +4.4/+6.0 平均准确率。

## 2. 研究背景与动机

标准后训练配方 SFT→RLVR 中，SFT 引入分布漂移——既不保持模型原能力也不忠实匹配监督分布；多模态推理中感知错误与推理失败各有漂移模式并在 RL 中复合放大。

## 3. 核心方法与创新点

- **三阶段管线**：SFT→分布预对齐→RLVR，中间段是本篇核心。
- **黑盒 OPD 对抗博弈**：MoE 判别器（感知专家 + 推理专家）在响应级提供解耦纠正信号，无需教师 logits——黑盒 API 教师也可用。
- **数据分层**：1.26M 公开示范够 SFT 初始化，但分布对齐需更高保真监督，精选 113K Gemini 3 Flash 示范专攻最难问题。

## 4. 实验设计与结果

Qwen3-VL 4B/8B × GRPO/DAPO/GSPO 多算法：下游 RLVR 平均准确率 +4.4（4B）/+6.0（8B）。代码、数据、检查点开源。

## 5. 局限性与未来展望

局限：判别器训练引入额外成本与对抗训练不稳定性；依赖 Gemini 3 Flash 示范存在蒸馏许可与能力上限问题；感知/推理专家之外的错误类型（知识、指令遵循）未覆盖。未来方向：与 PAINT 式稀疏特权蒸馏结合、预对齐阶段的自动化程度提升、向纯语言 RLVR 推广。

## 6. 学术启发

- "SFT 与 RL 之间需要一个对齐层"可能成为后训练新标准结构：SFT 学格式、预对齐修分布、RL 提能力。
- 黑盒蒸馏（无需 logits）的对抗式设计拓宽了蒸馏的可用场景：API 教师时代，响应级蒸馏是唯一选择。
