# 深度技术分析：Towards Joint Quantization and Token Pruning of Vision-Language Models

## 1. 核心速览

**研究主题**：VLM 低比特量化与视觉 token 剪枝的统一协同框架。

**一句话总结**：QUOTA（量化统一离线 token 分配器）把低比特校准信号转化为逐层 token 分配方案并物化为剪枝配方，token 重要性在部署态 W4A4 算子与量化 KV cache 下结合激活幅值、注意力线索与显式低比特风险信号评估；同等低比特设定下平均性能保持 95.65%（仅留 30% 视觉 token），优于分阶段组合的约 94.3%。

## 2. 研究背景与动机

VLM 推理成本由 prefill 的长视觉 token 前缀与解码期增长的 KV cache 主导。token 剪枝与低比特量化互补，但朴素的分阶段组合（先量化校准、再独立剪枝）很脆弱——量化校准分布与剪枝执行状态不匹配。

## 3. 核心方法与创新点

- **统一管线**：量化与确定性视觉 token 剪枝在同一可部署流水线内完成，消除校准-执行失配。
- **QUOTA 分配器**：把量化校准信号翻译成逐层 token 预算分配，剪枝位置由校准数据自动决定。
- **部署态重要性评估**：在真实 W4A4 算子 + 量化 KV cache 下评估 token 重要性，融合激活幅值、注意力线索与显式低比特风险信号，实现预算内确定性 top-k 选择。

## 4. 实验设计与结果

标准 VLM 基准：同低比特设定下，仅保留 30% 视觉 token 时平均性能保持 95.65%，分阶段组合基线约 94.3%；鲁棒性更优。

## 5. 局限性与未来展望

局限：1.35 个百分点的保持率提升相对温和；QUOTA 是离线方案，对分布偏移的自适应性有限；仅视觉 token，未联合文本侧与层剪枝。未来方向：在线自适应分配、推广到视频 VLM、与 KV cache 逐层路由（MoE-nD 式）统一成多轴压缩调度。

## 6. 学术启发

- "联合压缩"的关键不在两个算法各自多强，而在校准与执行的一致性——部署态评估重要性这一原则适用于一切压缩组合。
- 压缩调度器（QUOTA、MoE-nD 的 solver、VisPCO 的 Pareto 搜索）正在成为独立研究对象：压缩的元问题（在哪压、压多少）比单个压缩算子更有杠杆。
