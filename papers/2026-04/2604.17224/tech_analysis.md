# 深度技术分析：LASER: Low-Rank Activation SVD for Efficient Recursion

## 1. 核心速览

**研究主题**：递归架构（TRM）隐式推理轨迹的低维结构发现与动态激活压缩。

**一句话总结**：发现 Tiny Recursive Models 递归展开时激活占据近似线性的低维子空间，其主方向可用廉价幂迭代动态追踪；LASER 通过无矩阵子空间追踪 + 保真度触发重置维护演化低秩基，实现约 60% 激活显存节省且无统计显著的精度下降。

## 2. 研究背景与动机

递归架构（如 TRM）通过迭代潜计算做隐式推理，但推理轨迹的几何结构鲜有人研究。理解并利用这一结构既可压缩显存，也可能揭示递归架构如何分配表征容量。

## 3. 核心方法与创新点

- **低维流形发现**：权重共享使迭代计算集中在少数主导特征方向，激活流形近似线性且低维；集中度在不同计算位点差异显著。
- **动态子空间追踪**：用无矩阵（matrix-free）幂迭代在线维护演化的低秩基，避免全量 SVD。
- **保真度触发重置**：当低秩表示失真超阈值时重置基，兼顾效率与精度；实测约 60% 激活显存节省、精度无统计显著退化。

## 4. 实验设计与结果

在 TRM 递归展开上：~60% 激活显存节省，精度损失无统计显著性。

## 5. 局限性与未来展望

局限：仅在 TRM 类小模型验证，向 LLM 规模递归/循环结构的适用性未知；重置频率与保真度阈值需调节；低维集中是否随模型规模扩大而减弱是开放问题。未来方向：用该结构指导递归架构设计（容量分配）、与 KV cache 低秩压缩（如 MoE-nD 的头维轴）比较、理论解释权重共享与子空间集中的关系。

## 6. 学术启发

- 激活的低秩结构不仅存在于权重压缩中，还存在于时间维（递归展开）——压缩的维度观值得全面盘点：空间（层/头）、精度、时间。
- "先发现结构、再设计压缩"的路线再次奏效：理解计算的几何本质后，压缩方法几乎是顺理成章的推论。
