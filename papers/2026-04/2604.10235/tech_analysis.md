# 深度技术分析：CodeComp: Structural KV Cache Compression for Agentic Coding

## 1. 核心速览

**研究主题**：融入静态程序分析先验的智能体编程 KV cache 免训练压缩。

**一句话总结**：注意力-only 的 KV 压缩会系统性丢弃调用点、分支条件、赋值等代码理解关键结构 token；CodeComp 用 Joern 提取的 Code Property Graph 先验注入重要性估计，同等显存预算下一致优于注意力-only 基线，激进压缩下恢复大部分全上下文精度，补丁生成质量与未压缩持平，无缝接入 SGLang 管线。

## 2. 研究背景与动机

故障定位、补丁生成等 agentic 代码任务需在显存受限下处理长代码库，KV cache 是主要瓶颈。注意力信号不足以识别代码的结构关键 token。

## 3. 核心方法与创新点

- **结构先验注入**：CPG（代码属性图）标识调用/分支/赋值等关键 token，补偿注意力盲区。
- **免训练**：与 SGLang agentic 管线无缝集成、无需改模型。

## 4. 实验设计与结果

bug 定位与代码生成基准：等显存预算一致优于注意力-only 压缩；激进压缩恢复大部分全上下文精度；补丁质量与全上下文持平。

## 5. 局限性与未来展望

局限：依赖 Joern 静态分析的语言覆盖与解析质量；对动态语义（运行时行为）不敏感；与自然语言混合上下文的策略未细分。未来方向：更多语言支持、与语义聚类结合、在线更新 CPG。

## 6. 学术启发

- 领域结构先验（程序分析）应进入通用压缩管线——纯注意力信号有系统性盲区。
