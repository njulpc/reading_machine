# 深度技术分析：On the Quantization Robustness of Diffusion Language Models in Coding Benchmarks

## 1. 核心速览

**研究主题**：扩散语言模型（d-LLM）在代码任务上的 PTQ 鲁棒性研究。

**一句话总结**：在扩散式代码 LLM（CoDA）上应用 GPTQ 与改进的 Hessian 感知量化（HAWQ），标准化评测下 CoDA 在 2–4 比特低比特档的量化鲁棒性显著优于同规格自回归对照 Qwen3-1.7B，HumanEval 与 MBPP 精度退化更小；HAWQ 衍生的混合精度配置提供平滑的精度-时延-显存权衡。

## 2. 研究背景与动机

自回归 LLM 显存与推理成本高；扩散语言模型以迭代去噪实现有界推理成本，是新兴替代。但 d-LLM 在 PTQ 下的行为几乎未被探索——其迭代精化机制是否天然抗量化误差，是有理论趣味的开放问题。

## 3. 核心方法与创新点

- **首次系统对比**：d-LLM 与 AR LLM 同管线量化对比，发现 d-LLM 在 2–4 bit 档退化更小。
- **改进 HAWQ**：适配 d-LLM 的 Hessian 感知量化与混合精度配置推导。
- **机理暗示**：迭代去噪的多步修正可能部分"洗掉"量化误差（摘要暗示但未深入）。

## 4. 实验设计与结果

CoDA vs Qwen3-1.7B，HumanEval 与 MBPP：低比特下 CoDA 精度退化更小；混合精度实现平滑三角权衡。

## 5. 局限性与未来展望

局限：仅单一 d-LLM（CoDA）与单一对照（Qwen3-1.7B），规模也仅 1.7B 级；"更抗量化"的机理未实验证明（可能是迭代修正也可能是训练目标差异）；代码任务外的普适性未知。未来方向：机理受控实验（固定步数、干预精化过程）、更大规模 d-LLM 验证、d-LLM 专属的量化方法设计（利用多步结构）。

## 6. 学术启发

- 架构范式影响量化鲁棒性：迭代精化类模型（扩散 LM、递归模型）可能对扰动天然鲁棒——这为"按部署需求选架构"提供了新维度。
- 量化鲁棒性对比应加入架构变量：未来的量化评测基准应跨 AR/d-LLM/SSM 报告，而非只在 LLaMA 系上内卷。
