# 深度技术分析：Don't Waste Bits! Adaptive KV-Cache Quantization for Lightweight On-Device LLMs

## 1. 核心速览

**研究主题**：受 Huffman 编码启发的端侧 LLM KV cache 自适应位宽量化。

**一句话总结**：用 token 频率、质量分数、注意力方差、熵不确定性等轻量特征训练紧凑控制器，在解码时从 {2/4/8-bit, FP16} 中按 token 重要性动态选择 KV 精度；SmolLM-360M HellaSwag 上较静态 KV 量化解码延迟降 17.75%、精度 +7.60 点，且距 FP16 仅 0.30 点。

## 2. 研究背景与动机

端侧 LLM 推理被 KV cache 的显存与带宽开销主导（随上下文线性增长）。固定精度或手工启发式量化在低风险 token 上浪费位宽、在高信息量 token 上过度压缩，造成本可避免的精度损失。Huffman 编码的变长分配原则提示：位宽应与 token 重要性成正比。

## 3. 核心方法与创新点

- **学习式位宽策略**：紧凑数据驱动控制器实时选择每个 token 的 KV 精度（{2,4,8,FP16} 四档）。
- **轻量 token 特征**：token 频率、质量分数、注意力方差、熵不确定性——解码时可廉价获得。
- **内存-延迟-精度联合优化**：期望内存与延迟最小化而不牺牲有竞争力的精度。

## 4. 实验设计与结果

SmolLM-135M/360M/1.7B、多个常识推理基准：一致改善精度-延迟折中；SmolLM-360M HellaSwag：较静态 KV 量化延迟 -17.75%、精度 +7.60 点，距 FP16 仅 0.30 点。

## 5. 局限性与未来展望

局限：仅在小模型（≤1.7B）与短上下文验证，长上下文下特征稳定性未知；控制器本身引入微小推理开销；与层/头级混合精度的组合未探索。未来方向：大模型与长上下文验证、层-token 二维位宽分配、与 token 驱逐结合。

## 6. 学术启发

- 信息论经典原理（Huffman 变长分配）是混合精度量化的自然理论根基。
- token 级特征 + 小型控制器是实现“学习式系统决策”的轻量范式，可推广到稀疏化/驱逐决策。
