# 深度技术分析：ST-Prune: Training-Free Spatio-Temporal Token Pruning for Vision-Language Models in Autonomous Driving

## 1. 核心速览

**研究主题**：自动驾驶多视图多帧 VLM 输入的免训练时空 token 剪枝。

**一句话总结**：ST-Prune 含运动感知时间剪枝（MTP，把运动剧烈度与时间新近性编码为多样性选择的软约束，优先动态轨迹与当前帧）与环视空间剪枝（RSP，利用环视相机几何惩罚双侧跨视图相似度、消除重复投影），90% token 削减下接近无损且部分指标反超全模型基线，推理速度与现有剪枝方法相当。

## 2. 研究背景与动机

自动驾驶 VLM 需处理多目相机 × 多帧视频，token 量爆炸。现有剪枝为单图设计，逐帧逐视图孤立处理，无法利用驾驶场景固有的时空冗余（相邻帧大面积静态背景、环视相机的视野重叠）。

## 3. 核心方法与创新点

- **MTP 时间剪枝**：运动剧烈度 + 时间新近性作为软约束融入多样性选择目标，动态目标与新帧优先，静态历史背景被压。
- **RSP 空间剪枝**：利用环视几何结构，惩罚相邻相机视图间的双侧相似 token，消除重叠区的重复投影——这是纯 2D 方法无法利用的结构先验。
- **免训练即插即用**：无需微调，直接接入现有 VLM。

## 4. 实验设计与结果

感知、预测、规划四基准：90% token 削减下近无损，部分指标反超全模型基线；推理速度与已有剪枝方法相当；免训练剪枝新 SOTA。

## 5. 局限性与未来展望

局限：依赖环视相机几何标定，非标定车队配置适用性降；"部分指标反超基线"需谨慎解读（可能是剪枝降噪效应）；极端场景（雨夜、无标线城市）鲁棒性未知。未来方向：与 Geo3DPruner 式 3D 几何剪枝统一、向车载芯片的 kernel 级实现、剪枝与量化（QUOTA 式）联合部署。

## 6. 学术启发

- 领域结构先验是免训练剪枝的最大杠杆：运动、时序、相机几何都是无需学习的免费信号——免训练方法的天花板由先验质量决定。
- 剪枝后部分指标反超基线提示：冗余 token 不仅浪费算力还可能引入噪声，剪枝本身可以是正则化。
