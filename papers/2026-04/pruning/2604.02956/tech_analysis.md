# 深度技术分析：Collaborative Multi-Mode Pruning for Vision-Language Models

## 1. 核心速览

**研究主题**：VLM 参数剪枝与 token 剪枝的协同多模式框架（CoMP）。

**一句话总结**：CoMP 设计协同重要性度量（CIM）建模参数与 token 的相互干扰，并用多模式剪枝策略（MPS）按剪枝成本自适应切换剪枝模式、融合历史成本与随机探索，在高剪枝率下显著优于 SOTA。

## 2. 研究背景与动机

现有 VLM 剪枝多为单模式：只剪参数或只剪 token，忽略两类冗余的耦合关系，高剪枝率下性能退化严重。

## 3. 核心方法与创新点

- **协同重要性度量（CIM）**：把 token 显著性纳入参数重要性计算，同时缓解被剪参数对 token 重要性分数的影响——双向耦合建模。
- **多模式剪枝策略（MPS）**：将整体剪枝分解为阶段序列，每阶段按剪枝成本估计各模式优先级并自适应切换最优模式。
- **历史成本 + 随机探索**：稳定剪枝过程、避免局部最优。

## 4. 实验设计与结果

多种视觉-语言任务与模型：高剪枝率下性能显著优于 SOTA 方法（具体数值见原文实验表）。

## 5. 局限性与未来展望

局限：阶段式流程超参较多；CIM 的耦合项计算有额外开销；与量化/蒸馏的三重协同未探索。未来方向：端到端可微的多模式剪枝、与 QAT 结合、压缩率-模式联合搜索。

## 6. 学术启发

- 参数与 token 是 VLM 冗余的两个正交维度，联合建模的重要性度量是必要而非可选。
- “模式切换 + 探索”的调度思想可迁移到混合精度位宽搜索。
