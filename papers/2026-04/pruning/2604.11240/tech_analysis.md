# 深度技术分析：DeSAP: Decoupled Similarity for Task-Aware Token Pruning in LVLMs

## 1. 核心速览

**研究主题**：解耦相似度引导的任务感知视觉 token 剪枝。

**一句话总结**：DeSAP 引入解耦相似度捕捉视觉特征与文本 token 的细粒度跨模态相关性（显式任务引导），与视觉注意力显著性信号融合指导剪枝；LLaVA-1.5-7B 仅保留 11.1% 视觉 token 实现 10 倍 FLOPs 削减与 2.3 倍 prefill 加速，保留 98.1% 原性能。

## 2. 研究背景与动机

现有剪枝依赖 LVLM 各组件的单一注意力来源，注意力分布有偏导致剪枝决策不完整。

## 3. 核心方法与创新点

- **解耦相似度**：细粒度跨模态相关性的显式任务引导。
- **双信号融合**：任务相关 + 视觉显著性，激进剪枝率下仍稳健。

## 4. 实验设计与结果

多基准多架构：精度与效率一致优于 SOTA；LLaVA-1.5-7B：11.1% token → 10× FLOPs↓、2.3× prefill 加速、98.1% 性能。

## 5. 局限性与未来展望

局限：跨模态相似度计算有额外成本；对视频时序 token 的扩展未验证；与 KV cache 剪枝叠加未覆盖。未来方向：轻量相似度估计、视频扩展、与量化组合。

## 6. 学术启发

- 任务引导（文本条件）是视觉 token 剪枝从“通用显著性”走向“任务感知”的关键。
