# 深度技术分析：Evolutionary Negative Module Pruning for Better LoRA Merging

## 1. 核心速览

**研究主题**：LoRA 多专家合并前的"负模块"剪枝。

**一句话总结**：发现 LoRA 合并的关键瓶颈——存在合并后固有损害全局性能的"负模块"（特定 LoRA 层）；ENMP 用进化搜索在离散不可微的模块选择空间定位并排除这些模块，即插即用地提升现有合并算法性能，在语言与视觉领域均刷新 SOTA。

## 2. 研究背景与动机

把多个 LoRA 专家合并进单一骨干是高效多任务部署的主流路线。现有方法（权重插值、子空间对齐）隐含假设所有 LoRA 矩阵对合并都是建设性的。本文证伪该假设：某些 LoRA 层合并即有害。

## 3. 核心方法与创新点

- **负模块发现**：首次系统揭示 LoRA 合并中的负模块现象——特定层天然损害合并性能。
- **进化搜索剪枝**：模块选择是离散不可微问题，用进化策略高效导航组合空间，找到最优剪枝配置。
- **即插即用**：作为前置步骤与任意现有合并算法组合，一致提升。

## 4. 实验设计与结果

在语言与视觉两个领域的 LoRA 合并任务上，ENMP 加持后的合并算法达到新 SOTA。代码开源。

## 5. 局限性与未来展望

局限：进化搜索的计算成本随 LoRA 数量与层数增长；负模块是否可在不评估的情况下先验预测（结构特征）未解决；对满参微调增量合并的适用性未知。未来方向：负模块的机理解释与免搜索预测、与 D-QRELO 类 delta 压缩结合（先剪负模块再压缩）、扩展到 MoE 专家合并。

## 6. 学术启发

- "少即是多"在模型合并中同样成立：先删除有害成分再合并，比设计更复杂的融合规则更本质。
- 进化搜索在离散压缩配置问题（这里、VisPCO、MoE-nD）上的反复出现，说明黑盒搜索是压缩元优化的实用主力。
