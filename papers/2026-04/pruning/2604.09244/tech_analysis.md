# 深度技术分析：2D or 3D: Who Governs Salience in VLA Models? — Tri-Stage Token Pruning Framework

## 1. 核心速览

**研究主题**：多视觉模态 VLA（2D+3D）模型的模态显著性感知三阶段 token 剪枝。

**一句话总结**：按 MVLA 数据应用流程做三阶段分析捕捉 2D/3D 模态显著性的差异与动态，对应设计三阶段 token 剪枝框架，实现最优 2D/3D token 选择；推理最高加速 2.55 倍、精度损失极小，开销仅 5.8%。

## 2. 研究背景与动机

MVLA 引入 3D 模态后 token 数进一步膨胀，加速需求更迫切；但现有 token 剪枝为 2D-only VLA 设计，忽视 2D/3D 模态显著性差异。

## 3. 核心方法与创新点

- **三阶段显著性分析**：沿数据在 MVLA 中的处理流程刻画 2D/3D 显著性的差异与动态。
- **对应三阶段剪枝框架**：按阶段特性分配 2D/3D token 保留策略。

## 4. 实验设计与结果

最高 2.55× 推理加速，精度损失极小，额外开销 5.8%。

## 5. 局限性与未来展望

局限：分析依赖特定 MVLA 架构，迁移性待验证；3D token 质量（点云密度）对剪枝的影响未细分；闭环任务验证有限。未来方向：自适应模态预算、与动作蒸馏组合、真机验证。

## 6. 学术启发

- 多模态压缩必须先回答“谁主导显著性”——模态异质性是预算分配的第一依据。
