# 深度技术分析：SVD-Prune: Beyond Attention Scores — SVD-Based Vision Token Pruning for VLMs

## 1. 核心速览

**研究主题**：基于 SVD 统计杠杆分数的免训练视觉 token 剪枝。

**一句话总结**：注意力分数与 token 范数等局部启发式存在位置偏置与信息弥散；SVD-Prune 分解视觉 token 特征矩阵，用统计杠杆分数选出对全局主导方差贡献最大的 top-k token，在仅 32 甚至 16 个视觉 token 的极端预算下仍保持强性能。

## 2. 研究背景与动机

局部剪枝准则在高剪枝率下保不住关键内容，尤其视觉细节丰富图像上退化严重。

## 3. 核心方法与创新点

- **全局方差视角**：SVD 杠杆分数度量 token 对全局方差的贡献，克服位置偏置。
- **免训练即插即用**。

## 4. 实验设计与结果

极端 token 预算（32/16 token）下持续优于先前剪枝方法。

## 5. 局限性与未来展望

局限：SVD 计算成本随 token 数增长（虽可离线）；全局方差最大 ≠ 任务相关，任务条件化缺失；与文本引导方法的对比范围可扩大。未来方向：任务条件 SVD、增量 SVD 加速、与注意力方法混合。

## 6. 学术启发

- 统计杠杆分数这一经典矩阵工具为 token 重要性提供了全局视角基线。
