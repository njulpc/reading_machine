# 深度技术分析：Student-in-the-Loop Chain-of-Thought Distillation via Generation-Time Selection

## 1. 核心速览

**研究主题**：学生在环的生成时 CoT 蒸馏——蒸馏数据由学生参与筛选生成。

**一句话总结**：Gen-SSD 让学生在教师采样过程中实时评估候选续写，只扩展可学习的推理路径并及早剪除无益分支，数学推理基准上较标准 KD 提升约 5.9 分、较其他基线最高提升 4.7 分，且产生更稳定可学的推理轨迹。

## 2. 研究背景与动机

长 CoT 蒸馏到小模型效果受限：并非所有教师轨迹都适合学生学习。现有做法是生成后过滤（post-hoc），无法控制生成过程本身，仍会产生超出学生学习能力的推理路径。

## 3. 核心方法与创新点

- **生成时选择**：学生在教师采样过程中评估候选续写，引导只扩展可学习路径——从“事后过滤”变为“过程干预”。
- **早剪枝**：对无益分支及早剪枝，节省生成成本。
- **学生在环框架**：学生能力反馈直接参与蒸馏数据的生产。

## 4. 实验设计与结果

数学推理基准：Gen-SSD 较 Standard KD +5.9 分，较近期基线最高 +4.7 分；轨迹稳定性与可学习性分析均为正。

## 5. 局限性与未来展望

局限：学生在环评估增加推理开销；学生早期能力弱时筛选信号噪声大；仅验证数学推理域。未来方向：轻量学生代理筛选、与课程学习结合、扩展到 agent 轨迹蒸馏。

## 6. 学术启发

- 蒸馏数据质量的决定因素在生成阶段，干预点从“后处理”前移到“生成时”是范式性改进。
- 学生反馈信号（可学习性）是比答案正确性更细粒度的数据选择准则。
