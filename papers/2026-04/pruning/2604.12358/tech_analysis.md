# 深度技术分析：Why and When Visual Token Pruning Fails? RVIS in MLLMs Decoding

## 1. 核心速览

**研究主题**：视觉 token 剪枝在复杂推理任务失效的机理（RVIS）与解码阶段感知框架（DSTP）。

**一句话总结**：系统分析发现相关视觉信息随解码进程漂移（RVIS）是剪枝在复杂视觉推理失效的主因；DSTP 作为免训练插件让现有剪枝方法在解码阶段对齐漂移的推理需求，显著缓解复杂推理退化并在各视觉理解基准一致增益。

## 2. 研究背景与动机

现有剪枝在简单视觉理解上可靠，但复杂推理任务上失效——此前的盲区。剪枝决策在 prefill 阶段一次性做出，而推理需求随解码变化。

## 3. 核心方法与创新点

- **RVIS 现象**：相关视觉信息在解码中漂移，静态剪枝决策过时。
- **DSTP**：解码阶段漂移感知 token 对齐，免训练附加到现有方法。

## 4. 实验设计与结果

多 SOTA 架构：复杂推理退化显著缓解，视觉理解基准一致增益，开销极小。

## 5. 局限性与未来展望

局限：解码阶段调整引入额外计算；对超长生成（CoT 数百步）的漂移追踪稳定性；与 KV cache 剪枝的关系未厘清。未来方向：漂移预测、与 KV 管理统一、视频扩展。

## 6. 学术启发

- 压缩决策的“时间维度”（prefill vs decoding）是被忽视的设计空间。
