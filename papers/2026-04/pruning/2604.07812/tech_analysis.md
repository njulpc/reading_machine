# 深度技术分析：HAWK: Head Importance-Aware Visual Token Pruning in Multimodal Models

## 1. 核心速览

**研究主题**：注意力头重要性感知的 MLLM 视觉 token 免训练剪枝。

**一句话总结**：揭示不同注意力头捕捉不同视觉语义、在视觉处理中角色不同，HAWK 以头重要性权重 + 文本引导注意力评估 token 显著性，免训练应用于多种 MLLM；Qwen2.5-VL 剪除 80.2% 视觉 token 后保留 96.0% 原精度，端到端延迟降至 74.4% 且显存下降。

## 2. 研究背景与动机

现有视觉 token 剪枝默认所有注意力头对视觉理解贡献均等，与事实不符。

## 3. 核心方法与创新点

- **头异质性发现**：不同头捕捉不同视觉语义。
- **头重要性加权 + 文本引导注意力**：双重信号评估 token 显著性，最大化保留任务相关 token。
- **完全免训练**：即插即用于多种 MLLM。

## 4. 实验设计与结果

多个主流视觉-语言基准：SOTA 精度；Qwen2.5-VL 剪 80.2% token 保留 96.0% 精度；延迟降至 74.4%，GPU 显存下降。

## 5. 局限性与未来展望

局限：头重要性估计依赖任务分布，跨任务稳定性待验证；极高剪枝率（>90%）下精度骤降点未标明；与 KV cache 压缩组合未覆盖。未来方向：头重要性在线估计、逐层剪枝率分配、视频扩展。

## 6. 学术启发

- 注意力头的功能异质性是剪枝/压缩中反复出现的结构性机会（与 HybridKV 呼应）。
