# 深度技术分析：Geometry-Guided 3D Visual Token Pruning for Video-Language Models

## 1. 核心速览

**研究主题**：3D 空间视频（带深度与位姿的图像序列）在视频-语言模型中的视觉 token 剪枝。

**一句话总结**：Geo3DPruner 先用几何感知全局注意力建模跨帧相关性，再两阶段剪枝——体素内阶段在每个体素内选代表性多视图特征、体素间阶段保持空间多样性选取全局分布的体素子集；剪掉 90% 视觉 token 仍保持 90% 以上原性能，显著优于文本引导与视觉引导的现有剪枝。

## 2. 研究背景与动机

把 3D 场景表示为空间视频后可用预训练视频-语言模型做 3D 推理，但 token 量巨大。现有剪枝方法忽视空间视频的视图一致性与保留 token 的空间多样性，既去不掉帧间冗余又保不住场景完整性。

## 3. 核心方法与创新点

- **几何感知跨帧建模**：利用深度与相机位姿信息做全局注意力，刻画帧间几何相关性。
- **体素内代表性选择**：将多视图特征映射到体素网格，每个体素内选代表特征，消除多视图重复观测的冗余。
- **体素间多样性保持**：全局均匀选取体素子集，保证场景覆盖完整——这是与 2D 剪枝的本质区别（2D 只需保留显著性，3D 还需空间覆盖）。

## 4. 实验设计与结果

多个 3D 场景理解基准：剪 90% token 保持 >90% 原性能，显著优于现有方法。

## 5. 局限性与未来展望

局限：依赖准确的深度与位姿输入，SLAM 误差下的鲁棒性未评估；体素分辨率是敏感超参；仅离线场景理解，实时在线建图场景未知。未来方向：与在线 SLAM 联合的动态剪枝、向具身智能 3D 推理推广、几何引导与语义引导的混合。

## 6. 学术启发

- 3D 结构信息是剪枝的免费先验：多视图冗余在 2D 特征空间难以识别，在几何空间（体素）一目了然——降维打击的经典案例。
- 自动驾驶（ST-Prune）与室内 3D（本文）几乎同期出现时空剪枝工作，说明"视频/多视图 token 剪枝"正从单图剪枝中分化成独立方向。
