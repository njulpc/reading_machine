# 深度技术分析：GRASPrune: Global Gating for Budgeted Structured Pruning of Large Language Models

## 1. 核心速览

**研究主题**：预算硬约束下的 LLM 结构化剪枝：FFN 通道与 KV 头组联合全局门控。

**一句话总结**：GRASPrune 用投影直通估计器学习轻量门控分数，每步都强制满足全局预算的硬掩码（骨干权重冻结），联合剪 FFN 通道与 KV 头组；掩码固定后校准保留单元缩放因子并折叠进剪枝权重，得到零额外参数的稠密小模型；LLaMA-2-7B 剪 50% 参数 WikiText-2 困惑度 12.18，仅用 512 条无标注校准序列、4 epoch、单卡 A100、无全模型微调。

## 2. 研究背景与动机

LLM 服务成本来自参数、注意力计算与 KV cache 三处。现有结构化剪枝先无约束学重要性分数、训后再施加预算，导致"学到的"与"要的"不一致。

## 3. 核心方法与创新点

- **投影 STE 硬预算**：把预算约束嵌入训练每步——投影操作保证掩码始终满足预算，所学即所得。
- **FFN + KV 头组联合剪枝**：单一全局预算下跨模块分配，直击参数与 KV cache 双重成本。
- **缩放校准折叠**：剪枝后校准保留单元的缩放因子补偿尺度失配，折叠回权重，推理零额外参数、纯稠密小模型。
- **极低资源门槛**：512 条无标注序列、4 epoch、单卡 A100、冻结骨干。

## 4. 实验设计与结果

LLaMA-2-7B 剪 50% 参数：WikiText-2 PPL 12.18，五个零样本基准平均精度保持竞争力。

## 5. 局限性与未来展望

局限：50% 剪枝下 PPL 12.18 相比原模型（约 5 量级）仍属显著退化，高稀疏率下的恢复依赖后续微调；仅 LLaMA-2-7B 验证；门控学习与真实硬件收益的对应未实测。未来方向：与蒸馏恢复管线（SDFT）串联、向 MoE 与 GQA 新架构验证、联合量化（剪枝后 W4）的端到端方案。

## 6. 学术启发

- "约束进训练循环"优于"训练后施加约束"：投影 STE 把硬约束变成可微训练的组成部分，这一模式适用于所有预算化压缩（混合精度位宽预算同理）。
- KV 头组剪枝与 KV cache 量化的目标重叠，未来会走向统一（头组级删除可视为 0 比特量化）。
