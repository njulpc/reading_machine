# 深度技术分析：AdaCluster: Adaptive Query-Key Clustering for Sparse Attention in Video Generation

## 1. 核心速览

**研究主题**：视频扩散 Transformer 的免训练自适应聚类稀疏注意力。

**一句话总结**：AdaCluster 对 query 用保角度相似聚类实现高压缩、对 key 用保欧氏相似聚类并配合簇数分配、阈值自适应聚类与高效关键簇选择，在 CogVideoX-2B、HunyuanVideo、Wan-2.1 上免训练实现 1.67–4.31× 加速且质量损失可忽略。

## 2. 研究背景与动机

视频 DiT 注意力的二次复杂度使推理延迟高不可攀。现有稀疏注意力要么忽视语义相似性（固定模式稀疏），要么无法适应层间异质的 token 分布，导致生成质量退化。

## 3. 核心方法与创新点

- **Q/K 非对称聚类**：query 用保角度（余弦）相似聚类以追求高压缩率，key 用保欧氏相似聚类以维持注意力 logits 的数值保真——对 Q/K 采用不同几何度量是核心创新。
- **自适应簇数与阈值**：按层的 token 分布异质性自适应决定簇数与聚类阈值。
- **关键簇选择**：高效选出对输出影响大的簇参与计算，其余跳过；全程免训练。

## 4. 实验设计与结果

单卡 A40 上，CogVideoX-2B、HunyuanVideo、Wan-2.1 三个视频 DiT：1.67–4.31× 加速，质量退化可忽略。

## 5. 局限性与未来展望

局限：加速比跨度大（1.67–4.31×）说明收益依模型与分辨率波动；聚类开销本身随序列长度增长，超长视频（分钟级）上占比未知；质量评估依赖自动指标，人眼感知验证有限。未来方向：与蒸馏（TurboTalk 式步数压缩）叠加的端到端加速、向 LLM 长序列注意力推广、聚类结果的跨步复用。

## 6. 学术启发

- Q 与 K 的几何角色不同，理应区别对待：query 决定"去哪看"（方向敏感），key 决定"看到什么"（数值敏感）——这一非对称设计哲学可推广到 KV cache 压缩中 K/V 的不同位宽策略（MoE-nD 的 K-bits/V-bits 分离与此呼应）。
- 免训练加速在视频生成上接近实用临界点，2026 年或成视频 DiT 系统优化大年。
