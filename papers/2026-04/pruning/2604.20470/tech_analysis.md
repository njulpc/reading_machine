# 深度技术分析：DynamicRad: Content-Adaptive Sparse Attention for Long Video Diffusion

## 1. 核心速览

**研究主题**：长视频扩散的内容自适应稀疏注意力。

**一句话总结**：DynamicRad 在径向局部性先验内做自适应选择，双模式（静态比率求速度 / 动态阈值求质量），并用离线贝叶斯优化在物理代理任务上优化注意力重建误差、配合轻量语义运动路由器把 prompt 嵌入映射到最优稀疏档位；HunyuanVideo 与 Wan2.1-14B 上 1.7–2.5× 推理加速、有效稀疏度超 80%，部分长序列设定动态模式追平甚至超过稠密基线，mask 感知 LoRA 进一步改善长程一致性。

## 2. 研究背景与动机

视频扩散的时空能量衰减是自然稀疏化的依据，但固定静态掩码在复杂动态下会丢失关键长程信息。如何按内容自适应地选稀疏度，且避免在线搜索开销？

## 3. 核心方法与创新点

- **径向先验内的自适应选择**：稀疏不是全空间搜索，而是在径向局部性约束内自适应——先验缩小搜索空间、保留长程关键连接。
- **双模式设计**：静态比率模式面向速度、动态阈值模式面向质量，同一框架两档运行。
- **离线 BO + 语义运动路由器**：离线贝叶斯优化在物理代理任务上以注意力重建 MSE 为目标快速收敛，轻量投影模块把 prompt 嵌入映射到最优稀疏档位，运行时开销极小——用"离线优化 + 在线路由"替代昂贵的在线 profiling。

## 4. 实验设计与结果

HunyuanVideo、Wan2.1-14B：1.7–2.5× 加速、>80% 有效稀疏度；部分长序列设定动态模式匹配或超过稠密基线；mask-aware LoRA 提升长程一致性。代码开源。

## 5. 局限性与未来展望

局限：路由器按 prompt 预测稀疏档位，对同 prompt 内场景切换（镜头变换）的粒度可能不足；BO 的代理任务与真实生成质量的对应是间接的；长视频（分钟级）验证有限。未来方向：帧级动态路由、与步数蒸馏叠加、路由器的跨模型迁移。

## 6. 学术启发

- "离线搜索 + 在线轻量路由"是自适应压缩系统的实用范式：与 MoE-nD 的离线 solver、AdaCluster 的阈值自适应共同指向——压缩决策正在从规则走向学习的调度器。
- 稀疏注意力在长序列下偶超稠密基线（降噪效应）再次出现，值得系统研究。
