# 深度技术分析：Nucleus-Image: Sparse MoE for Image Generation

## 1. 核心速览

**研究主题**：稀疏 MoE 扩散 Transformer 文生图模型，建立质量-效率新 Pareto 前沿。

**一句话总结**：17B 总参数、64 路由专家/层、Expert-Choice Routing，每前向仅激活约 2B 参数即在 GenEval/DPG-Bench/OneIG-Bench 上匹配或超越领先模型；解耦路由设计分离时间步感知分配与时间步条件计算，无任何后训练（无 RL/DPO/人类偏好调优），首个该质量级全开源 MoE 扩散模型。

## 2. 研究背景与动机

图像生成质量随模型规模提升，但稠密放大推理成本高。稀疏 MoE 在 LLM 已证明有效，在扩散模型中的工程化路径尚不成熟。

## 3. 核心方法与创新点

- **稀疏 MoE DiT**：17B 总容量 / 2B 激活；Expert-Choice Routing。
- **推理效率架构**：文本 token 完全移出 backbone、联合注意力实现跨时间步文本 KV 共享。
- **解耦路由**：时间步感知的专家分配与时间步条件的专家计算分离，稳定调制下路由。
- **训练配方**：1.5B 高质量对（700M 独立图像）、渐进分辨率课程 + 专家容量因子渐进稀疏化、Muon 优化器分组配方。

## 4. 实验设计与结果

GenEval、DPG-Bench、OneIG-Bench：匹配或超越激活参数大得多的模型；无后训练优化。

## 5. 局限性与未来展望

局限：总参数 17B 的存储与训练成本仍高；路由坍缩风险需持续监控；视频扩展未验证。未来方向：专家剪枝/量化叠加、视频 MoE、路由正则理论。

## 6. 学术启发

- 稀疏激活（MoE）是与量化/剪枝正交的“第四压缩维度”，可叠加使用。
