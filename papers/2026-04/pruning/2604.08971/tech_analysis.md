# 深度技术分析：SentryFuse: Modality-Aware Zero-Shot Pruning and Sparse Attention for Efficient Multimodal Edge Inference

## 1. 核心速览

**研究主题**：模态感知的零样本剪枝 + 稀疏分组查询注意力的边缘多模态推理框架。

**一句话总结**：SentryGate 训练时经一阶显著性监督学习模态条件化重要性分数，部署时免微调剪注意力头与 FFN 通道；SentryAttend 以稀疏 GQA 替代稠密自注意力净降 15% GFLOPs；三应用三骨干上较最强剪枝基线平均 +12.7% 精度（模态缺失下最高 +18%），显存 -28.2%、延迟最高降 1.63 倍。

## 2. 研究背景与动机

边缘多模态管线面临功耗波动与传感器缺失。现有剪枝需微调恢复（能耗超部署 10 倍）且静态重要性分数对传感器在场性盲目。

## 3. 核心方法与创新点

- **SentryGate**：模态条件化重要性分数 + 零样本（免微调）剪枝。
- **SentryAttend**：稀疏分组查询注意力替代稠密自注意力。
- **联合框架**：显存 -28.2%、延迟最高 1.63×，无需部署后微调。

## 4. 实验设计与结果

3 应用 × 3 多模态骨干：平均精度较最强基线 +12.7%，模态缺失下最高 +18%；GFLOPs -15%。

## 5. 局限性与未来展望

局限：重要性分数需训练期学习（非完全免训练）；模态组合极多时条件化参数增长；剪枝率固定。未来方向：在线自适应剪枝率、与量化组合、更多传感器类型。

## 6. 学术启发

- 边缘压缩的评估必须包含模态缺失与能耗预算波动，静态 benchmark 不够。
