# 深度技术分析：MI-Pruner: Crossmodal Mutual Information-guided Token Pruner for Efficient MLLMs

## 1. 核心速览

**研究主题**：基于跨模态互信息的 MLLM 视觉 token 剪枝。

**一句话总结**：MI-Pruner 不依赖注意力分数，直接在视觉与文本特征交互前计算二者的互信息以度量跨模态依赖，方法简单、高效、非侵入（无需访问注意力图或修改架构），以极小延迟开销超越注意力型剪枝方法。

## 2. 研究背景与动机

MLLM 中视觉信息相对文本更稀疏，视觉 token 剪枝是提效热点。现有方法依赖视觉编码器或 LLM 解码器的注意力分数——机制相关、可能偏置，且需侵入式访问内部状态。

## 3. 核心方法与创新点

- **互信息直接度量**：在特征交互前直接计算视觉-文本特征的 MI，显式度量跨模态依赖，不依赖任何机制特定信号。
- **非侵入式**：无需注意力图、无需架构修改，部署友好。
- **简单高效**：延迟开销极小。

## 4. 实验设计与结果

实验表明 MI-Pruner 以最小延迟开销超越此前注意力型剪枝方法（具体基准与数值见原文）。

## 5. 局限性与未来展望

局限：MI 估计本身在高维特征上有方差；对生成式长输出的逐步剪枝适配未验证；与 KV cache 剪枝的叠加效果未知。未来方向：高效 MI 估计器、与层内自适应剪枝率结合、视频 token 扩展。

## 6. 学术启发

- 信息论度量（MI）可作为跨模态剪枝的机制无关基础，避免被注意力实现细节绑架。
- 非侵入式剪枝对闭源/黑盒模型场景尤其有价值。
