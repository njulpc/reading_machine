# 深度技术分析：Multi-Aspect Knowledge Distillation for Language Model with Low-rank Factorization

## 1. 核心速览

**研究主题**：结合低秩分解的多方面知识蒸馏（MaKD）用于预训练语言模型压缩。

**一句话总结**：MaKD 从更深层次模仿自注意力与前馈模块，捕捉不同方面的细粒度语言知识，在同存储参数预算下优于多个强基线，并对自回归架构模型同样有效。

## 2. 研究背景与动机

KD 是 PLM 压缩的有效技术，但现有方法只关注层间知识分布对齐，对齐过程中会丢失细粒度信息。

## 3. 核心方法与创新点

- **多方面蒸馏**：对自注意力与 FFN 模块做更细粒度的多方面模仿，减少对齐损失。
- **低秩分解结合**：以低秩结构承载压缩，存储预算内保持性能。
- **跨架构适用**：对自回归模型同样有效。

## 4. 实验设计与结果

在相同存储参数预算下与多个强基线对比达到有竞争力性能；自回归架构蒸馏实验同样良好（具体数值见原文）。

## 5. 局限性与未来展望

局限：实验规模相对有限；与注意力蒸馏现有方法的公平对比范围可进一步扩大；低秩秩值选择策略未深入讨论。未来方向：与 logit/特征蒸馏统一框架、大模型规模验证、自适应方面加权。

## 6. 学术启发

- 蒸馏监督粒度（层→模块→方面）的细化是稳定提升蒸馏效果的低成本手段。
- 低秩分解与蒸馏是天然互补：前者压缩参数、后者补偿能力。
