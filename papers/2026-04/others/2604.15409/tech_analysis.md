# 深度技术分析：The Illusion of Equivalence: Systematic FP16 Divergence in KV-Cached Autoregressive Inference

## 1. 核心速览

**研究主题**：FP16 精度下 KV cache 推理与无缓存重计算的非等价性机理研究。

**一句话总结**：KV cache 因 FP16 非结合性（累加顺序不同）产生确定性解码分歧：在 LLaMA-2-7B、Mistral-7B-v0.3、Gemma-2-2B 上 GSM8K 全采样策略（含贪心解码）出现 100% token 分歧率，且 8/9 条件下 cache-ON 精度更高说明分歧方向是系统性而非随机；FP32 对照将分歧降低八个数量级、翻转率归零，确认 FP16 非结合性为唯一因果驱动。

## 2. 研究背景与动机

KV cache 是自回归推理的标配优化，长期被默认与无缓存计算数值等价。这一假设在 FP16 下是否成立从未被系统检验——而它的答案影响所有基于 KV cache 的压缩、复用、投机解码研究的正确性基础。

## 3. 核心方法与创新点

- **受控因果实验设计**：FP32 证伪实验把分歧降八个数量级并消除 token 翻转（0.0%），干净地将因果锁定到 FP16 非结合性；贪心解码下仍 100% 分歧排除了采样随机性。
- **逐层漂移画像**：发现架构可预测的漂移传播模式——GQA 模型在第一层即出现尖锐分歧，Gemma 的大 head dim 与滑窗注意力则产生全层均匀累积。
- **因果定位**：对整个残差流做 activation patching 仍无法恢复无缓存轨迹，将因果变量定位到有状态的 KV cache 本身。

## 4. 实验设计与结果

三个开源模型（LLaMA-2-7B、Mistral-7B-v0.3、Gemma-2-2B）× GSM8K：100% token 分歧率；8/9 条件下 cache-ON 精度反而更高；FP32 对照翻转率精确为 0.0%。

## 5. 局限性与未来展望

局限：仅 GSM8K 单任务、7B 以下规模；未量化分歧对长文本生成质量的下游影响；FP16 之外的 BF16/FP8 未覆盖。未来方向：将结论推广到更长上下文与更大模型、研究 KV cache 量化误差与固有数值分歧的叠加效应、为推理引擎提出确定性累加顺序方案。

## 6. 学术启发

- KV cache 压缩研究必须重新锚定基线：既然 FP16 KV cache 本身已与"真值"系统性偏离，评估量化 KV cache 时应与 cache-ON 而非 cache-OFF 比较，否则结论可能失真。
- "cache-ON 反而更准"这一反直觉发现提示数值噪声有时起正则化作用，值得从随机平滑角度理论研究。
