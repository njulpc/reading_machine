# 深度技术分析：Multitask Prompt Distillation and Decomposition for Clinical NLP

## 1. 核心速览

**研究主题**：多任务提示蒸馏与分解实现临床 NLP 的参数高效迁移。

**一句话总结**：从 21 个临床源任务蒸馏出单一共享元提示，以 <0.05% 可训练参数适配未见目标任务；10 个留出数据集 × 3 个骨干（LLaMA3.1-8B、Meditron3-8B、gpt-oss-20B）上较 LoRA 高 1.5–1.7%（参数量低数个数量级），较单任务提示调高 6.1–6.6%。

## 2. 研究背景与动机

逐任务独立学习提示在多系统部署时算力与存储开销随任务数线性增长。临床 NLP 任务间共享大量领域知识，适合蒸馏为共享表示。

## 3. 核心方法与创新点

- **元提示蒸馏**：21 个源任务蒸馏为单一共享元提示。
- **提示分解**：低秩式分解支持向未见任务的高效适配。
- **极致参数效率**：<0.05% 可训练参数且优于 LoRA。

## 4. 实验设计与结果

5 类临床任务（NER、RE、QA、NLI、摘要）、10 个留出数据集、3 个骨干：一致优于 LoRA 1.5–1.7%、优于单任务提示调优 6.1–6.6%；零/少样本迁移性强。

## 5. 局限性与未来展望

局限：临床域专用，跨域迁移性未知；元提示容量随任务多样性饱和的风险；与全量微调在上限任务上的差距未报告。未来方向：分层元提示、跨域扩展、与检索增强结合。

## 6. 学术启发

- 提示空间的“蒸馏 + 分解”与权重空间的低秩压缩思想同构，提示工程可以借用压缩方法论。
