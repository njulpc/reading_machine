# 深度技术分析：Rényi Attention Entropy for Patch Pruning

## 1. 核心速览

**研究主题**：基于注意力 Rényi 熵的 ViT patch 剪枝准则。

**一句话总结**：低熵 patch（注意力集中）保留、高熵 patch（注意力弥散）剪除；将 Shannon 熵推广到 Rényi 熵以强调尖锐注意力峰并支持按任务/算力调节剪枝策略，在细粒度图像识别上降算力保精度，Rényi 调节进一步改善精度-计算折中。

## 2. 研究背景与动机

自注意力随 token 数二次增长，patch 剪枝是关键提效手段，但重要性估计准则直接影响剪枝质量。注意力分布的熵天然刻画“该 patch 被集中关注还是被泛化关注”。

## 3. 核心方法与创新点

- **熵准则**：注意力分布 Shannon 熵低的 patch 更可能是关键 patch。
- **Rényi 推广**：Rényi 熵参数化强调尖峰，支持剪枝策略随任务需求与算力预算自适应。

## 4. 实验设计与结果

细粒度图像识别（patch 选择敏感场景）：计算量下降且精度保持；Rényi 调节带来进一步收益。

## 5. 局限性与未来展望

局限：依赖注意力分布质量，对注意力本身不准的层/模型效果受限；Rényi 参数需按任务调；仅图像域验证。未来方向：与 token 合并结合、视频/多模态扩展、层自适应熵阈值。

## 6. 学术启发

- 信息论度量（熵族）为剪枝提供了可调参的统一语言；Rényi 参数本质上是“选择性偏好”旋钮。
