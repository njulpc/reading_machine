# 深度技术分析：WAND: Windowed Attention and Knowledge Distillation for Efficient AR-TTS Models

## 1. 核心速览

**研究主题**：自回归 TTS 模型的常数复杂度改造——窗口注意力 + 知识蒸馏。

**一句话总结**：WAND 将注意力拆为对条件 token 的持久全局注意力 + 对生成 token 的局部滑窗注意力，用课程学习渐进收紧窗口并以全注意力教师蒸馏恢复质量；三个现代 AR-TTS 模型上保持原质量，KV cache 显存最高降 66.2%，每步延迟近常数（长度不变）。

## 2. 研究背景与动机

AR-TTS 全自注意力使显存与计算随序列平方增长，长语音合成成本高昂。

## 3. 核心方法与创新点

- **双路注意力**：条件 token 全局 + 生成 token 滑窗，复杂度降为常数。
- **课程式窗口收紧**：稳定微调。
- **全注意力教师蒸馏**：高数据效率恢复高保真质量。

## 4. 实验设计与结果

3 个 AR-TTS 模型：质量保持；KV cache 最高 -66.2%；每步延迟长度不变近常数。

## 5. 局限性与未来展望

局限：窗口大小对韵律长程依赖的影响未细分；蒸馏教师成本；对 streaming 以外场景（批量合成）的收益递减。未来方向：自适应窗口、与 KV 量化组合、多说话人长语音验证。

## 6. 学术启发

- “条件全局 + 生成局部”的注意力拆分对一切条件自回归生成（TTS/音乐/视频）可迁移。
