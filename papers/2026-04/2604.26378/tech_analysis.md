# 深度技术分析：CoQuant: Joint Weight-Activation Subspace Projection for Mixed-Precision LLMs

## 1. 核心速览

**研究主题**：混合精度 LLM 量化的权重-激活联合子空间投影。

**一句话总结**：现有混合精度方法仅靠激活统计选择高精度保留的子空间，忽视输出扰动由激活与权重量化噪声联合驱动的本质；CoQuant 理论建模期望输出误差，导出闭式加权 PCA 解平衡激活与权重协方差以选最优高精度子空间；Llama-3.2 与 Qwen2.5 上 WikiText 困惑度与零样本常识推理一致超越强 PTQ 基线。

## 2. 研究背景与动机

超低比特量化靠"关键子空间保持高精度"续命，但子空间的选择只看激活统计（如激活幅值/协方差），丢弃了权重侧的量化噪声信息。线性层的输出误差其实是 W 误差与 A 误差共同驱动——单边建模必然次优。

## 3. 核心方法与创新点

- **联合误差建模**：理论上把期望输出误差写成激活与权重量化噪声的联合函数。
- **闭式加权 PCA**：导出平衡两侧协方差的加权 PCA 闭式解，直接给出最优高精度子空间——无迭代搜索。
- **原理性提升**：在 Llama-3.2 与 Qwen2.5 上一致超基线。

## 4. 实验设计与结果

Llama-3.2、Qwen2.5：WikiText PPL 与零样本常识推理一致优于强 PTQ 基线。代码开源。

## 5. 局限性与未来展望

局限：加权 PCA 依赖校准数据统计的稳定性；高精度子空间的推理实现（稀疏/分组保留）的硬件开销未充分分析；与旋转类方法（DuQuant++）的组合未探索。未来方向：联合子空间 + 旋转的统一框架、向 KV cache 混合精度推广、闭式解向分组量化扩展。

## 6. 学术启发

- 量化误差建模回到线性代数本质：输出扰动 = f(W误差, A误差)，联合建模是比单边启发式更原理化的路线。
- 闭式解在量化方法中的价值：免搜索、免调参，比进化搜索/梯度学习类方案更易落地与复现。
