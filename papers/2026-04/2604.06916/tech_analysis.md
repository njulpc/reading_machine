# 深度技术分析：FP4 Explore, BF16 Train: Diffusion Reinforcement Learning via Efficient Rollout Scaling

## 1. 核心速览

**研究主题**：扩散 RL 后训练中 FP4 采样探索与 BF16 策略优化解耦（Sol-RL）。

**一句话总结**：第一阶段用高吞吐 NVFP4 rollout 生成海量候选池并提取高对比度子集，第二阶段以 BF16 重新生成选中样本并仅在其上优化策略；在 SANA、FLUX.1、SD3.5-L 上保持 BF16 训练完整性的同时训练收敛最高加速 4.64 倍。

## 2. 研究背景与动机

扩散 RL 扩大 rollout 组规模可显著提升对齐效果，但 FLUX.1-12B 等大模型上 rollout 计算负担沉重。直接全面 FP4 化又会引入性能退化风险。

## 3. 核心方法与创新点

- **探索-优化解耦**：FP4 负责“看得多”，BF16 负责“学得准”——候选探索与策略优化分离。
- **高对比度子集提取**：海量 FP4 候选中筛选信息量大的样本 BF16 重生成。
- **算法-硬件协同**：NVFP4 吞吐增益与 rollout scaling 算法机制融合。

## 4. 实验设计与结果

SANA、FLUX.1、SD3.5-L：多指标对齐性能更优，训练收敛最高加速 4.64 倍，保持 BF16 管线训练完整性。

## 5. 局限性与未来展望

局限：BF16 重生成仍有成本，端到端加速比低于纯 FP4；FP4 候选池的分布偏差对子集代表性的影响未理论分析；对 LLM RL 的迁移未验证。未来方向：自适应 FP4/BF16 配比、LLM RLVR 迁移、FP4 策略优化的误差补偿。

## 6. 学术启发

- “量化用于探索、全精度用于学习”的分工原则可推广到一切采样密集型训练（RL、主动学习）。
- 量化研究的战场正从推理扩展到训练管线各环节。
