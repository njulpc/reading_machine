# 深度技术分析：CLASP: Class-Adaptive Layer Fusion and Dual-Stage Pruning for MLLMs

## 1. 核心速览

**研究主题**：类别自适应层融合 + 双阶段剪枝的即插即用 MLLM token 削减框架。

**一句话总结**：CLASP 多层视觉特征融合构建类别特异表示，双阶段剪枝将预算分配给注意力显著的 pivot token（相关性）与冗余感知的补全 token（覆盖度），实现提示条件化的特征融合与预算分配；在广泛基准、剪枝率与架构上一致优于现有方法。

## 2. 研究背景与动机

现有方案用单层 ViT 特征 + 静态剪枝策略，在多样指令下脆弱。

## 3. 核心方法与创新点

- **类别自适应层融合**：多层特征按类别组合。
- **双阶段预算**：pivot（相关性）+ completion（覆盖度）分工。
- **提示条件化**：融合与预算随提示自适应。

## 4. 实验设计与结果

广范围基准 × 剪枝率 × 架构：一致优于现有方法。

## 5. 局限性与未来展望

局限：类别估计本身的误差传播；层融合增加少量计算；极端预算下覆盖度策略的极限。未来方向：与 RVIS 解码感知结合、视频扩展、免类别估计版本。

## 6. 学术启发

- “相关性 + 覆盖度”的双通道预算分配与校准研究（2604.12035）互相印证，渐成剪枝设计共识。
