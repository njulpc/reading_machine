# 深度技术分析：A Survey of On-Policy Distillation for Large Language Models

## 1. 核心速览

**研究主题**：On-Policy 蒸馏（OPD）的统一综述——教师对学生自身生成轨迹提供反馈的蒸馏范式。

**一句话总结**：本综述将 OPD 形式化为学生采样轨迹上的 f-散度最小化，沿“优化什么、信号来源、如何稳定训练”三条设计轴梳理文献，指出 OPD 可将暴露偏差的复合误差从约平方级降为线性，并总结成功条件、典型失效模式及与 KL 约束 RL 的联系。

## 2. 研究背景与动机

工业界主流的静态模仿教师文本的蒸馏存在结构性弱点：学生训练时看到完美教师前缀，推理时却基于自己的（可能有错的）前缀生成，小误差累积成训练中从未见过的轨迹，暴露偏差随序列长度约按平方增长。在长推理任务上该问题尤为严重。OPD 文献散落在 KD、RLHF、模仿学习三个社区，缺乏统一处理。

## 3. 核心方法与创新点

- **统一形式化**：将 OPD 表述为学生采样轨迹上的 f-散度最小化问题。
- **三设计轴分类法**：优化目标（散度设计）、信号来源（教师反馈/奖励/自博弈）、稳定化技术，覆盖现有方法版图。
- **成功条件与失效模式总结**：归纳 OPD 生效的前提、反复出现的失败模式，并阐明 OPD 与 KL 约束强化学习的理论联系。
- **开放问题**：蒸馏 scaling law、不确定性感知反馈、智能体级蒸馏、KD 与 RL 的融合边界。

## 4. 实验设计与结果

作为综述，本文以定性综合为主：指出暴露偏差复合项约随序列长度平方增长，而 OPD 通过在学生实际产出上提供教师反馈，将复合误差压向线性；并系统比较了各类散度设计与奖励引导优化方法的适用场景。

## 5. 局限性与未来展望

局限：综述本身不提供新的基准实验；OPD 各分支方法的横向量化对比受限于原论文报告口径不一。未来方向：蒸馏 scaling law 的实证建立、不确定性感知的教师反馈、面向 agent 轨迹的蒸馏、KD 与 RL 统一框架。

## 6. 学术启发

- “在学生分布上计算损失”应成为推理型蒸馏的默认设计；静态 SFT 蒸馏在长链任务上有理论性劣势。
- f-散度视角为比较不同蒸馏目标提供了统一语言。
- 做蒸馏实验时应主动报告误差随序列长度的复合曲线。
