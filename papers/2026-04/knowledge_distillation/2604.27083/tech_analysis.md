# 深度技术分析：Co-Evolving Policy Distillation

## 1. 核心速览

**研究主题**：多专家能力整合：RLVR 与 OPD 的统一分析及协同进化策略蒸馏（CoPD）。

**一句话总结**：统一分析指出混合 RLVR 受能力间发散成本之苦，而"先训专家再 OPD"管线因师生行为模式差距大吸收不全；CoPD 在各专家 RLVR 训练进行中（而非完成后）引入 OPD，专家互为人师双向蒸馏、协同进化，行为模式更一致且互补知识充足；实现文本、图像、视频推理能力 all-in-one 整合，显著超混合 RLVR 与 MOPD，甚至超越领域专属专家。

## 2. 研究背景与动机

把多个专家能力整合进单一模型是后训练核心诉求。混合 RLVR 多目标互扯（发散成本）；先专家后蒸馏的管线避免互扯，但专家训练完成后行为模式已固化，与学生差距大，蒸馏吸收不全。

## 3. 核心方法与创新点

- **统一分析框架**：RLVR 与 OPD 在能力整合上的失效模式对照——发散成本 vs 行为模式差距。
- **进行中蒸馏**：专家 RLVR 训练期间即引入 OPD，而非完成后。
- **双向互为人师**：专家间互相蒸馏、协同进化，行为模式自然趋近而知识保持互补。

## 4. 实验设计与结果

文本、图像、视频推理三能力 all-in-one：显著超混合 RLVR、MOPD 基线，甚至超过领域专属专家。

## 5. 局限性与未来展望

局限：并行训练多专家的算力开销大；互蒸馏的稳定性（模式塌缩风险）需机制保障；能力数量扩展（5+ 领域）的可行性未知。未来方向：与模型合并（ENMP 式）路线对比、异步协同进化、向持续学习场景推广。

## 6. 学术启发

- "训练过程即蒸馏时机"：蒸馏不必是训练后的独立阶段，嵌入训练过程可规避分布固化——时机本身成为设计变量。
- 并行专家 + 互蒸馏可能开启新的训练扩展范式（如作者所言），与稀疏 MoE 的训练哲学形成有趣对照。
