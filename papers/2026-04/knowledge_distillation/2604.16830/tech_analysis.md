# 深度技术分析：The Illusion of Certainty: Decoupling Capability and Calibration in On-Policy Distillation

## 1. 核心速览

**研究主题**：在策略蒸馏（OPD）中能力与校准的系统性解耦——"误校准缩放定律"。

**一句话总结**：发现 OPD 提升任务准确率的同时系统性地把模型推向严重过度自信；根源是教师监督在训练期的特权上下文下形成，与部署期信息不匹配；所提 CaOPD 用学生 rollout 估计经验置信度替代自报置信度作为蒸馏目标，在多模型多领域上取得 Pareto 最优校准且能力不降，并在 OOD 与持续学习下稳健。

## 2. 研究背景与动机

OPD 是后训练的重要范式，但本文发现一个普遍规律：蒸馏越强、模型越"迷之自信"。理论上，教师的成功概率是在特权上下文（如解题路径、额外信息）下估计的，而部署时模型只能基于部署期信息表达置信——用前者做目标必然导致熵塌缩与系统性乐观偏置。

## 3. 核心方法与创新点

- **误校准缩放定律**：实证揭示 OPD 准确率提升与置信度恶化同步缩放，是范式性问题而非个别现象。
- **信息不匹配形式化**：证明教师条件成功概率一般不是部署期置信度的有效目标，特权上下文引发熵塌缩与乐观偏置。
- **CaOPD 框架**：从学生自身 rollout 估计经验置信度，替换自报置信度，再经同一自蒸馏管线蒸馏修正后的回复——目标校准而非行为校准。

## 4. 实验设计与结果

跨多模型与多领域：CaOPD 实现 Pareto 最优校准同时保持有竞争力的能力，并在分布外与持续学习场景稳健泛化。代码开源。

## 5. 局限性与未来展望

局限：rollout 估计置信度增加训练成本；经验置信度在低资源任务上估计噪声大；校准指标（ECE 等）本身的局限未讨论。未来方向：免 rollout 的置信度估计、校准感知蒸馏向 RLHF/推理模型推广、置信度目标与 TIP 式 token 选择结合。

## 6. 学术启发

- 与 π-Play 的特权蒸馏形成有趣对照：π-Play 用特权信息增强监督，本文揭示特权信息污染置信度——特权蒸馏的设计必须区分"知识迁移"与"置信度迁移"。
- 能力蒸馏≠校准蒸馏应成为后训练的基本共识：部署安全性要求置信度成为独立优化目标。
