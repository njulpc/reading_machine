# 深度技术分析：Mem²Evolve: Self-Evolving Agents via Co-Evolutionary Capability Expansion and Experience Distillation

## 1. 核心速览

**研究主题**：agent 经验蒸馏与能力资产扩张的共进化框架。

**一句话总结**：Mem²Evolve 以经验记忆指导资产（工具/专家 agent）动态创建、资产扩张又反哺新经验，实现共进化；6 类任务 8 基准上较标准 LLM +18.53%、较仅经验进化 +11.80%、较仅资产创建 +6.46%。

## 2. 研究背景与动机

现有自进化 agent 把“积累经验”与“创建资产”孤立处理：前者受限于静态预定义工具集，后者从零造资产缺乏经验指导，能力增长受限且进化不稳。

## 3. 核心方法与创新点

- **共进化范式**：经验蒸馏 ↔ 资产创建双向耦合。
- **双记忆架构**：Experience Memory + Asset Memory。

## 4. 实验设计与结果

6 任务类 × 8 基准：较标准 LLM +18.53%、较单路进化 +11.80%/+6.46%，稳定性更好。

## 5. 局限性与未来展望

局限：资产创建的可靠性（错误工具的积累）；记忆规模增长管理；对底层 LLM 能力依赖。未来方向：资产验证机制、记忆压缩、跨任务迁移。

## 6. 学术启发

- agent 系统中“经验蒸馏”的对象从模型权重扩展到工具与流程资产，蒸馏概念持续外延。
