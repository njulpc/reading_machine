# 深度技术分析：Cross-Tokenizer LLM Distillation through a Byte-Level Interface

## 1. 核心速览

**研究主题**：跨分词器 LLM 蒸馏（CTD）的字节级接口基线（BLD）。

**一句话总结**：将教师输出分布转换为字节级概率、给学生挂载轻量字节级解码头，经共享字节接口蒸馏；在 1B–8B 模型的多种蒸馏任务上与显著更复杂的 CTD 方法相当甚至超越，同时指出全任务一致改进仍难实现、CTD 仍是开放问题。

## 2. 研究背景与动机

师生分词器不同时，logit 级蒸馏词汇表对不齐。现有方法靠启发式词汇对齐，复杂且易错。字节是任何分词器的共同底层表示——天然的公共接口。

## 3. 核心方法与创新点

- **字节级公共接口**：教师分布 → 字节概率；学生加字节解码头，蒸馏经字节空间进行。
- **极简基线**：无启发式对齐、实现简单，却达到或超越复杂方法。

## 4. 实验设计与结果

1B–8B 模型、多蒸馏任务：BLD 与复杂 CTD 方法竞争力相当，多个基准超越；但无方法在所有任务一致最优。

## 5. 局限性与未来展望

局限：字节序列更长，蒸馏计算成本增加；字节级分布可能丢失 token 级语义结构；对超大词表多语言教师的效果待验证。未来方向：字节-token 混合接口、理论分析接口粒度影响、与 on-policy 蒸馏结合。

## 6. 学术启发

- 寻找“公共底层表示”是解决一切跨系统蒸馏/迁移问题的通用思路。
- 简单基线打平复杂方法往往说明领域陷入局部复杂化，值得反思。
