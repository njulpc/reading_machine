# 深度技术分析：PAINT: Partial-Solution Adaptive Interpolated Training for Self-Distilled Reasoners

## 1. 核心速览

**研究主题**：推理模型特权在策略自蒸馏的精细化：部分揭示 + 稀疏插值。

**一句话总结**：PAINT 从"上下文重评分"视角重审特权自蒸馏：关键不仅是是否有特权上下文，而是揭示多少、在哪塑造学生分布——按 rollout 与参考解的重叠度自适应掩码已验证解答，并仅在熵不匹配的稀疏 token 位置做小幅度能量空间插值；三个 Qwen3 规模上一致超越强在策略自蒸馏基线，Qwen3-8B macro Avg@12 较前者 +2.1、较 GRPO +2.9。

## 2. 研究背景与动机

RLVR 提供在策略探索但信用稀疏高方差；SFT/蒸馏提供稠密目标但轨迹固定或依赖更强教师。特权在策略自蒸馏（同一模型在已验证解答上下文下给学生 rollout 打分）是中间路线，但"特权信息给多少、在哪给"未被精细研究。

## 3. 核心方法与创新点

- **自适应部分揭示**：按学生 rollout 与参考解的重叠度掩码解答——学生走得越远、揭示越少，避免直接抄答案。
- **稀疏插值**：仅在熵不匹配的少数 token 位置做能量空间插值，其余位置不动——干预最小化。
- **上下文重评分视角**：把特权蒸馏统一理解为"特权上下文如何重评分学生行为"的设计空间。

## 4. 实验设计与结果

竞赛级数学基准，三个 Qwen3 规模：一致超在策略自蒸馏基线；Qwen3-8B macro Avg@12 +2.1（vs 基线）、+2.9（vs GRPO）。

## 5. 局限性与未来展望

局限：重叠度度量与熵不匹配阈值引入超参；仅数学推理验证，代码/规划任务未测；与 TIP（token 重要性）的选择规则有重叠但未比较。未来方向：揭示比例的学习化（课程化）、向 agentic 任务推广、与 π-Play 的 QCP 特权蒸馏统一框架。

## 6. 学术启发

- 特权蒸馏的精细化三部曲已成形：π-Play（发现特权信号）→ CaOPD（特权污染置信度）→ PAINT（特权给多少、在哪给）——2026 上半年该方向快速成熟。
- "最小干预"原则：稀疏 token 插值而非全序列蒸馏，与 TIP 的 <20% token 训练共同指向蒸馏的稀疏化趋势。
