# 深度技术分析：Rethinking On-Policy Distillation: Phenomenology, Mechanism, and Recipe

## 1. 核心速览

**研究主题**：OPD 训练动力学的系统机理研究与失效修复配方。

**一句话总结**：OPD 成败由两条件支配：师生思维模式兼容；教师须提供学生训练中未见的真正新能力（弱到强反向蒸馏显示同族 1.5B 与 7B 教师在学生视角分布不可区分）；token 级机理为成功 OPD 在学生访问状态的高概率 token（集中 97–99% 概率质量的小共享集）上渐进对齐；提出 off-policy 冷启动与教师对齐提示选择两种修复策略，并指出稠密 token 奖励的“免费午餐”暗藏成本。

## 2. 研究背景与动机

OPD 已成为后训练核心技术，但其何时有效、为何有效的动力学理解薄弱。

## 3. 核心方法与创新点

- **两成败条件**：思维模式兼容 + 真正新能力。
- **token 级机理**：成功 OPD 的特征是小共享高概率 token 集上的渐进对齐。
- **修复配方**：off-policy 冷启动、教师对齐提示选择。

## 4. 实验设计与结果

弱到强反向蒸馏等受控实验验证两条件；修复策略可挽救失败的 OPD（具体数值见原文）。

## 5. 局限性与未来展望

局限：两条件的可操作度量仍偏定性；“新能力”的事先判定困难；长程蒸馏的可扩展性存疑（作者自指）。未来方向：能力差距预测器、思维模式对齐度量、长程 OPD 设计。

## 6. 学术启发

- 选教师先看“分布可区分性”与“能力增量”，而非绝对分数。
- 高概率小共享 token 集是蒸馏监督的真正载体——可在其上集中优化。
