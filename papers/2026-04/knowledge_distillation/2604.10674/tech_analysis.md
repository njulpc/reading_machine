# 深度技术分析：Skill-SD: Skill-Conditioned Self-Distillation for Multi-turn LLM Agents

## 1. 核心速览

**研究主题**：多轮 agent 的技能条件化自蒸馏——用自身轨迹生成动态特权信息。

**一句话总结**：Skill-SD 将完成的轨迹总结为紧凑自然语言技能（成功行为/错误/工作流）作为仅条件化教师的动态特权信息，学生始终以普通任务提示行动并内化指导；重要性加权 reverse-KL 提供梯度正确的 token 级蒸馏，教师随学生动态同步；AppWorld/Sokoban 上较 vanilla GRPO +14.0%/+10.9%、较 vanilla OPD +42.1%/+40.6%。

## 2. 研究背景与动机

RL 训练多轮 agent 样本效率低；OPSD 的固定特权信息（标准答案）无法覆盖 agent 任务的多样合法策略，且与 RL 朴素结合易训练崩溃。

## 3. 核心方法与创新点

- **轨迹→技能**：动态特权信息来自 agent 自身经验总结，随策略进化。
- **师生素材分离**：技能只给教师，学生保持真实部署条件。
- **重要性加权 reverse-KL**：梯度正确的 token 级蒸馏；师生动态同步稳定训练。

## 4. 实验设计与结果

AppWorld/Sokoban：较 GRPO +14.0%/+10.9%，较 OPD +42.1%/+40.6%。

## 5. 局限性与未来展望

局限：技能总结质量依赖模型自身能力（冷启动问题）；技能库增长的管理成本；仅两个基准。未来方向：技能检索与组合、跨任务技能迁移、理论分析自蒸馏收敛。

## 6. 学术启发

- “特权信息动态化”解决了自蒸馏信号陈旧的问题，是自改进训练的关键设计。
