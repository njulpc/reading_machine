# 深度技术分析：TabDistill: Selecting Feature Interactions for GAMs by Distilling Foundation Models

## 1. 核心速览

**研究主题**：蒸馏表格基础模型的隐式特征交互知识到可解释 GAM。

**一句话总结**：TabDistill 先用表格基础模型拟合数据，再以后验交互归因提取显著特征交互作为 GAM 项；跨任务一致提升 GAM 预测性能，桥接高容量模型与可解释加性框架。

## 2. 研究背景与动机

GAM 可解释但交互选择靠启发式，易漏高阶/上下文依赖效应；基础模型隐式学到了丰富交互但不可解释。

## 3. 核心方法与创新点

- **基础模型 → 归因 → GAM**：把黑箱交互知识转译为显式加性项。
- **性能与可解释兼得**。

## 4. 实验设计与结果

跨任务：TabDistill 识别的交互一致提升 GAM 下游性能。

## 5. 局限性与未来展望

局限：归因方法的保真度上限；极高阶交互的枚举成本；对高维稀疏表格的扩展性。未来方向：交互归因改进、与符号回归结合、在线交互发现。

## 6. 学术启发

- 蒸馏的目标可以是“结构/知识”而非权重——可解释性是重要接收方。
