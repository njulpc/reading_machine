# 深度技术分析：SCOPE: Signal-Calibrated On-Policy Distillation Enhancement with Dual-Path Adaptive Weighting

## 1. 核心速览

**研究主题**：按信号质量校准的双路径 on-policy 蒸馏。

**一句话总结**：SCOPE 按正确性路由 rollout：错误轨迹用教师困惑度加权 KL 蒸馏（教师真有纠错能力处加权、不可靠指导降权），正确轨迹用学生困惑度加权 MLE（聚焦能力边界的低置信样本而非重复强化已掌握内容），组级归一化自适应校准；6 个推理基准 Avg@32 平均相对提升 11.42%、Pass@32 7.30%。

## 2. 研究背景与动机

OPD 对所有 rollout 均匀施加 token 级 KL 监督，忽视信号质量差异：教师在错误轨迹上并非总有纠错能力，学生在已掌握样本上继续强化浪费容量。

## 3. 核心方法与创新点

- **双路径路由**：错误 → 教师困惑度加权 KL；正确 → 学生困惑度加权 MLE。
- **困惑度作为信号质量探针**：双向使用（教师能力与学生学习状态）。
- **组级归一化**：适配提示难度方差。

## 4. 实验设计与结果

6 推理基准：Avg@32 平均相对 +11.42%、Pass@32 +7.30%（较竞争性基线）。

## 5. 局限性与未来展望

局限：困惑度加权引入额外前向计算；权重分布的方差可能影响训练稳定（虽有归一化）；对非验证任务的正确性判定依赖外部信号。未来方向：轻量信号代理、与 SRPO 类路由方法对比统一、理论分析加权偏差。

## 6. 学术启发

- “监督强度 ∝ 信号质量”应成为蒸馏损失设计的默认原则。
- 能力边界样本优先是高效利用固定算力的通用策略。
