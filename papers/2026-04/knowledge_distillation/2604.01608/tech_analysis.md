# 深度技术分析：From Multi-Agent to Single-Agent: When Is Skill Distillation Beneficial?

## 1. 核心速览

**研究主题**：多智能体系统（MAS）蒸馏为单智能体技能的收益可预测性研究。

**一句话总结**：作者发现技能蒸馏的收益由评估指标而非任务本身决定，提出先验预测器 Metric Freedom（F，用 Mantel 检验量化指标打分景观的拓扑刚性，与技能效用 r=-0.85, p<0.0001），并据此设计两阶段自适应蒸馏框架 AdaSkill，在匹配或超越原 MAS 的同时成本最高降 8 倍、延迟最高降 15 倍。

## 2. 研究背景与动机

MAS 通过分工处理复杂任务，但协调开销大、上下文碎片化、阶段顺序脆弱。蒸馏为单 agent 技能可绕过这些成本，但“何时蒸馏、蒸馏什么”缺乏原则性答案：同一任务在不同指标下技能提升从 +28% 到 -2% 不等。

## 3. 核心方法与创新点

- **Metric Freedom (F)**：首个技能效用的先验预测器，通过 Mantel 检验量化输出多样性与分数方差的耦合程度，刻画指标打分景观的拓扑刚性。
- **AdaSkill 两阶段框架**：阶段一在“自由”指标上做选择性提取（提取工具与知识、丢弃限制性结构以保留探索）；阶段二选择性迭代精炼，利用自由指标宽容的打分景观安全挖掘余量。
- **实证核心发现**：相同 agent 轨迹在刚性 vs 自由指标下产生截然相反的技能提升——技能效用本质是指标级属性。

## 4. 实验设计与结果

4 任务、11 数据集、6 指标：F 强预测技能效用（r=-0.85, p<0.0001）；AdaSkill 匹配或超越原 MAS，成本最高降 8 倍、延迟最高降 15 倍。

## 5. 局限性与未来展望

局限：F 的计算需要一定量的输出-分数样本；任务与指标覆盖有限；对开放式生成指标（如 LLM-as-judge）的适用性未充分验证。未来方向：将 F 推广到更多评估范式、蒸馏过程中的在线 F 估计、指标设计与蒸馏目标的联合优化。

## 6. 学术启发

- 评估指标本身是方法设计的自变量，做蒸馏/压缩对比实验时应先审计指标的“自由度”。
- 先验预测器（a priori predictor）能避免大量无效蒸馏实验，值得在其他压缩决策中借鉴。
