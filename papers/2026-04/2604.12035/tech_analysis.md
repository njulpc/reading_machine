# 深度技术分析：When Does Visual Token Pruning Improve Calibration? The Role of Evidence Coverage in MLLMs

## 1. 核心速览

**研究主题**：视觉 token 剪枝对 MLLM 校准（置信-正确一致性）的影响机理。

**一句话总结**：选择规则比 token 预算更影响校准：POPE/LLaVA-1.5 上覆盖型剪枝（576→128 token）将 ECE 从 0.041 降至 0.016 且精度无统计显著损失，而注意力型选择保置信但精度恶化、激进预算下比随机剪枝更不准；保留集覆盖率与精度强相关（ρ=+0.89）、与过自信强负相关（ρ=-0.92）。

## 2. 研究背景与动机

剪枝几乎只按精度评估，校准这一部署关键属性被忽视。

## 3. 核心方法与创新点

- **证据覆盖账户**：保留集覆盖率解释校准变化的机制，受控干预实验支持。
- **两条边界**：FastV 过自信超出覆盖预测；语言先验主导的 ScienceQA 上覆盖不再决定校准。
- **评估陷阱发现**：FastV 将被剪 token 置零而非移除，可使精度降至随机水平。

## 4. 实验设计与结果

POPE/GQA/ScienceQA、LLaVA-1.5/NeXT、Qwen2-VL：选择器排序可迁移；覆盖型优于随机；校准增益任务与模型相关。

## 5. 局限性与未来展望

局限：校准增益不稳定（任务/模型依赖）；覆盖率计算开销；对生成式长回答校准的扩展未验证。未来方向：覆盖-注意力混合选择、校准感知剪枝目标、生成场景扩展。

## 6. 学术启发

- 压缩方法评估应加入校准维度——“压缩改变置信质量”是被忽视的一阶效应。
- “置零 vs 移除”的实现细节可颠覆结论，复现压缩方法时需审计。
