## 1. 核心速览

研究主题：剪枝。压缩后监督适应仍可成功，并不意味着无标签测试时适应也能恢复。

## 2. 研究背景与动机

部署往往同时要求模型小和分布漂移下可适应，但现有压缩评测通常只看静态准确率。

## 3. 核心方法与创新点

- 把结构压缩表示为参数投影，比较剪枝和因子化
- 在相同允许更新子空间内对照 TTA 与带标签 Oracle，诊断表示多样性和适应子空间兼容性。

方法及实验证据见[官方全文](https://arxiv.org/html/2609.03604)；下述局限和学术启发包含本次评读判断。

## 4. 实验设计与结果

使用 ResNet-18、ViT-Base 和 CIFAR-10-C、ImageNet-C；压缩增强时 TTA 恶化，而 Oracle 保留较强恢复能力。已读正文未提取统一可横比数值，故不虚构改善百分比。

## 5. 局限性与未来展望

结论受 TTA 更新范围和压缩结构影响；不是证明所有压缩算法都会损害可适应性。

可行的后续验证：围绕这一限制设置保持模型、数据与推理预算一致的对照，分开测量质量、实际内存、延迟与前期训练/校准成本。

## 6. 学术启发

将压缩目标从源域精度扩展为目标域可恢复性，并以 Oracle 差距定位学习信号不足。
