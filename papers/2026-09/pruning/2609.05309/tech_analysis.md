# How Does mHC Use Its Residual Streams? Selective Routing and Near-Identity Mixing

官方证据：[摘要及提交历史](https://arxiv.org/abs/2609.05309)、[v1 全文](https://arxiv.org/html/2609.05309v1)。v1：2026-09-04 16:02:20 UTC，即北京时间 **2026-09-05 00:02:20**。主分类 cs.LG，交叉 cs.AI。本次读取方法、实验、讨论与结论；以下数字是论文报告值，未本机复现 DeepSeek。

## 1. 核心速览

**研究主题：** 多流残差网络的推理期路由稀疏化与算子消除，归入剪枝；不是权重量化。

**一句话总结：** DeepSeek-V4-Flash 的四流 mHC 并未均匀使用所有路由，自适应删除每个位置最弱的一条路由、或移除后半层的残差混合，只带来较小质量变化，但尚无实测整机压缩或加速倍率。

## 2. 研究背景与动机

mHC 将单一残差通道拓宽为多个流，通过读取映射 Hpre、写回映射 Hpost 与流间混合 Hres 提供更多计算自由度。四条流存在，不代表每一条路径、每个混合算子都必要。仅看门控权重或向量相似度也不能证明可以删除：低负载流仍可能保存独特信息。

作者因此把统计诊断与无需重训的干预连接起来，测试“局部低使用率”能否转化为可移除的推理操作，而不把整条流直接视作冗余。

## 3. 核心方法与创新点

1. **三类互补诊断。** 将非负路由权重归一化为 p，以 `1/sum(p²)` 衡量有效流数；统计一个序列中最常获胜流的比例；以 Hres 对单位阵的平均绝对偏差测量混合强度。另用流间余弦相似度检查表示是否坍缩（§3.1–3.3）。
2. **保持总尺度的 top-k 路由。** 每个 token、每个位置保留最大的 k 个权重，并乘 `原权重总和/保留权重总和`；分别对读、写映射做实验。删除支持集与改变总幅值因此得到区分（式10–11）。
3. **按深度替换混合器。** 在 22–42 层将 Hres 换为 I4，在早期层则额外测试用 C4 诊断样本的逐位置平均混合器代替动态混合器。前者可省去对应 Sinkhorn–Knopp 迭代，后者检验静态结构与逐 token 变化的贡献（§3.4、§4.5）。
4. **局部冗余而非全局删流。** 不同深度最强与最弱流会切换；读取和写回获胜流在 38.4% 的 86 个位置不同，故不能直接删除固定的一个全局流。

## 4. 实验设计与结果

模型为公开 0731 checkpoint 的 DeepSeek-V4-Flash：43 层、总参数 284B、激活 13B、隐藏宽度 4096、四流 mHC。统计覆盖注意力与 FFN 共 86 个位置。诊断使用 C4 训练集 512×1024 token；困惑度使用验证集 256×2048 token；下游为 ARC-E/C、PIQA、HellaSwag、MMLU、GSM8K 零样本，六项等权平均（§4.1）。

## 5. 局限性与未来展望

- 仅单 checkpoint，覆盖指定语言数据与六任务，缺少长上下文、其他 mHC 模型及训练种子的系统验证。
- **没有端到端延迟、显存或 checkpoint 体积结果。** top-3 是局部路由支持减少25%，并非模型参数压缩25%，更不是1.33倍整机加速；动态 top-k 自身也有代价。
- 各读/写干预分别测量，不能把表中的微小损失当成所有优化叠加后的结果。
- 梯度反馈与 Sinkhorn 传输的机制解释仍是待检验假说。需要训练轨迹、匹配预算训练及融合内核来确认实际可部署收益。

## 6. 学术启发

有价值的剪枝单位可能是“token×层×读写角色”的连接，而不是整条流。实验应先保持尺度、定位可删除支持，再测计算消除效果。尤其应同时报告有效宽度统计和干预曲线，避免把低有效秩或低平均权重直接等同于可压缩性。

**评分（1–10）：** 精度效果8（top-3损失小但更激进删除失败）；压缩3（仅操作消除潜力，无系统倍率）；创新8（流角色、深度和干预结合）；可复现性6（协议明确，但284B模型成本高，本次未运行）。
