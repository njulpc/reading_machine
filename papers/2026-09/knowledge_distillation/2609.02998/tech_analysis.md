## 1. 核心速览

研究主题：知识蒸馏。先验证教师在当前提示上的可靠性，再决定蒸馏还是强化学习。

## 2. 研究背景与动机

反向 KL 倾向集中到教师模式；教师自信但答错时，逐 token 监督会放大错误。

## 3. 核心方法与创新点

- 用少量教师探针和可验证结果估计提示级可靠性
- 通过门控的提示执行 OPD，其余提示执行 GRPO，两条路互斥
- 利用异步训练中空闲教师容量做探测。

方法及实验证据见[官方全文](https://arxiv.org/html/2609.02998)；下述局限和学术启发包含本次评读判断。

## 4. 实验设计与结果

4B 多域七项均值由 MOPD 53.40 提升至 54.54；35B 由 60.99 至 61.94。4B 单域教师 GPU 利用率由 9.8% 到 78.9%，是训练利用率而非推理压缩率。

## 5. 局限性与未来展望

依赖可靠 verifier；额外探针成本随异步空闲容量而变。不是所有单项都最优，例如 4B HMMT-Feb 低于部分基线。

可行的后续验证：围绕这一限制设置保持模型、数据与推理预算一致的对照，分开测量质量、实际内存、延迟与前期训练/校准成本。

## 6. 学术启发

蒸馏的数据选择单位可从 token 上移到提示可靠性；应对照错误教师与 verifier 失效两种情况。
