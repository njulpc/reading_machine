# A Unified Per-Token Gating Family for On-Policy Distillation: FKL/RKL Mixing with Multi-Channel and Bias Coefficients

> 主分类：Artificial Intelligence (cs.AI)；完整分类：Artificial Intelligence (cs.AI) ; Computation and Language (cs.CL); Machine Learning (cs.LG)。

## 1. 核心速览

**研究主题**：Qwen3-32B 到 Qwen3-4B 的在线知识蒸馏，逐 token 混合正向/反向 KL。

**一句话总结**：四参数门控把教师熵、样本不确定性和师生分歧放进同一比较框架；方向性收益存在，但三种子优势均未达显著性。

## 2. 研究背景与动机

正向 KL 强调覆盖教师分布，反向 KL 更偏向教师的高概率模式。固定混合系数难以适应样本和 token 的差异；不同论文的门控方向、输入信号和实现还可能同时变化，使比较难以归因。本文将这些选择写入共同参数空间，研究门控结构是否提供独立于平均 KL 比例的收益。

这是明确的大教师到小学生的模型压缩：32B/4B 的名义参数比为 8 倍，但论文没有据此证明实际文件、峰值显存或吞吐量也改善 8 倍。

## 3. 核心方法与创新点

1. **四系数门控**：λ_t = sigmoid(a h_t + b u(x) + c + d gap_t)，用 λ_t 混合反向 KL、用 1−λ_t 混合正向 KL。h_t 是教师 top-K 预测的归一化熵；u(x) 是 prompt 后首个 token 的教师熵；gap_t = 1−p_student(y_teacher-top1)。c 提供显式偏置。
2. **统一受控比较**：gap-only 限制为 (0,0,0,d)，entropy-only 使用 (−a,0,0,0) 对齐前作门控方向；这些是框架内代理，不能冒充 ToDi/EOPD 官方实现复现。ToDi 的 log-ratio、stop-gradient 及 EOPD 硬切换等细节不相同。
3. **平均混合比例隔离**：为每个动态设置另外训练 λ=E[λ_t] 的静态模型，区分“平均使用更多 RKL”与“按 token 调节”的作用。
4. 学生先生成 rollout，教师在学生所经过状态上给出逐 token 概率；作者使用 verl/vLLM、ZMQ 教师服务和 Megatron 反向传播。

## 4. 实验设计与结果

依据正文 §4–6 与附录 A/B。Qwen3-4B 学生、Qwen3-32B 教师；TweetEval emotion/hate/offensive 的测试数为 1,421/2,970/860，训练 100/200/200 步，batch=72，学习率 1e−6，6×L20Y 80GB。关闭 thinking，greedy 解码，32 token 上限，以解析后的类别准确率计分。

- emotion/hate 各 13 个门控设置，完整家族在 36 个可比单通道格子中赢 33 个；26 组平均 KL 匹配实验中赢 19 个。格子共享数据和参数结构，不能当作独立假设检验。
- 九个重点比较在 seeds={42,2,3} 上成对重训；八个均值差为正，所有比较 p=0.29–0.51。三种子效应约比单种子小 1.5–3.1 倍。
- Table 3 的 emotion HG5,d+4 三种子准确率为 0.7868/0.7713/0.7706，对应静态 0.388 的 0.7727/0.7727/0.7692；均值由这些表值计算约 77.623% 对 77.153%，仅 +0.47 个百分点。
- hate 的负例 HG4,d+2 相比其对照从单种子 −1.78pp 缩小为三种子 −0.72±0.92pp，不宜宣称已证实反转。

## 5. 局限性与未来展望

完整网格只有单种子；重点比较又是观察网格后选出，存在选择偏差。只验证一对 Qwen3 模型和短输出分类，不能推广到长链推理或开放生成。内部训练栈未发布，top-K 等实现选择应在重实现时明确，不可自行补成论文设定。对手是等幅值代理限制，并非每种方法最佳调参版本。最关键后续是预注册多种子完整网格，扩大模型对与任务，并报告实际服务成本。

## 6. 学术启发

设计量化或蒸馏的自适应控制器时，应配套“平均资源预算相同”的静态对照。统一坐标系有助于拆分信号、方向和偏置的效果；但统一实现的代理实验只能支持代理层面的结论。优先采用多种子效应量，而非把大量相关格子的胜率当显著性。
