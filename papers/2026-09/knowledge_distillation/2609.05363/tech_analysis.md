# Distill Globally, Adapt Locally: Reasoning Distillation and Product-Type Test-Time Training for Scalable Trade-Up Recommendation

官方证据：[摘要及提交历史](https://arxiv.org/abs/2609.05363)、[v1 全文](https://arxiv.org/html/2609.05363v1)。v1：2026-09-04 17:08:50 UTC，即北京时间 **2026-09-05 01:08:50**。主分类cs.LG，无交叉分类。本次读取§3–7及附录A.1.1/A.2/A.5；未重训教师或学生。

## 1. 核心速览

**研究主题：** 黑盒教师推理蒸馏到小型非生成分类器，再按商品类型做有监督少样本适配。

**一句话总结：** 将离线LLM理由压入只吃两个768维商品向量的学生，可使商品升级推荐AUC达到0.924；按品类适配进一步到0.941，线上不再调用生成式教师。

## 2. 研究背景与动机

升级推荐需要区分真正改善材质、配方或品牌定位，与单纯数量/口味变化，同时保留购物意图。LLM可解释这些细粒度关系，但逐对生成难以扩展至海量商品对。作者把“训练时的理由获取”与“服务时的轻量判断”分开，并处理不同品类的升级标准差异。

## 3. 核心方法与创新点

1. **保留四类关系的教师监督。** 教师对每个商品对检索同品类5个人工示例，输出四类标签及最多两句理由；标签包括同档、两个方向的升级及不兼容。理由用冻结bge-base-en-v1.5编码为768维向量。教师不提供logits或隐藏状态（§3、附录A.1.1）。
2. **非生成的有序双商品学生。** 两个角色分支及一个有序交叉分支的输出拼接，再接512/256/128的MLP，dropout0.3。必须注意：各分支的序列长度为1，注意力softmax恒为1，实际是参数化变换，并不是内容相关的token选择。方向性来自不同角色参数与有序拼接（§4.1、附录A.2.1）。
3. **任务、理由和关系结构联合蒸馏。** `L=Ltask+0.1Lalign+0.01Lcon`；理由对齐用MSE，`Lcon=InfoNCE+0.05Lrelational-KL`，InfoNCE温度0.07，关系KL温度1。训练期理由投影在服务时删除（式2–4、附录A.2.2）。
4. **按商品类型适配。** 每类从相同学生和适配器初始化出发，在分类头和理由投影上训练LoRA，rank8、alpha16、AdamW lr1e−3、50步，支持集K=4/8/16/32；下一类别重置，禁止跨类累计。理由适配权重0.1，因小支持集负例不足而不使用对比损失。这是有人工标签的few-shot adaptation，不是无监督TTT（算法1）。

## 4. 实验设计与结果

人工标注17,200对，8,848用于教师示例及适配支持池，8,352作为固定golden测试；覆盖29类商品。12,830件商品构造1,019,241个教师标注silver商品对，90/10训练/验证，golden不参与checkpoint选择。AUC置信区间使用2,000次bootstrap（§3、§5.1）。

| 对照 | Golden AUC | 关键解释 |
|---|---:|---|
| 浅层四类、仅标签 | 0.912 [0.906,0.918] | 14.3M参数 |
| 浅层四类、加理由 | 0.924 [0.918,0.929] | 论文列15.5M，包含训练时理由投影 |
| 浅层二类、仅标签/加理由 | 0.911 / 0.911 | 理由收益依赖标签粒度 |
| 深层四类、加理由 | 0.911 | 65.9M，更多参数并非更优 |
| 同928条人工支持的pooled LoRA | 0.929 | 控制额外人工监督收益 |
| 每类LoRA，K=32，仅标签 | 0.940 | 大部分额外收益来自按类别适配 |
| 每类LoRA，K=32，加理由 | 0.941 | AP从0.920到0.940 |

四类理由学生较对应标签学生的未舍入配对AUC差为+0.013，95% CI [+0.010,+0.016]，显示数字相减为+0.012，口径应保留。宏平均品类内AUC从0.910到0.925，说明收益不只来自跨类别分数整体平移（表1–4）。

教师RAG配置F1=0.749，学生F1=0.843，主要来自召回提升，不能推断学生普遍超过前沿LLM。§5.4在约100K商品对代理负载、单台8GPU机器上报告约5,000倍速度、约10,000倍估计推理成本改善；这是相对直接LLM生成的特定系统比较，**不是参数或字节压缩倍率**。论文未公开教师型号和足以重建该倍率的完整成本计时分解。

## 5. 局限性与未来展望

- 仅29个已知品类；每类需专家支持及50步优化，尚未建立未见品类零样本迁移。
- 支持/测试仅pair-disjoint，未明确做到商品或品牌不重叠，实体泄漏与记忆效应值得独立检查。
- 15.5M包含训练时投影，不能直接作为部署参数总数；商品向量预计算、存储与教师标注成本也需摊销。
- 品类适配与更简单的品类校准尚未完全分离，理由在适配阶段的额外收益仅0.001 AUC左右。
- 测试类别比例不等同生产候选流，F1和precision不能直接当线上业务指标。黑盒教师不可精确重建，本次未运行端到端蒸馏。

## 6. 学术启发

蒸馏的目标可以是保留任务充分信息的小型非生成器，而非更小的聊天模型。应将标签粒度、理由信息、学生容量和额外人工监督分别控制：本论文最有价值的证据是四类/二类及pooled/per-type的匹配对照，而不仅是很大的服务倍率。

**评分（1–10）：** 精度效果8（配对CI、同监督控制较扎实）；压缩8（服务时移除生成教师，但系统倍率信息不足）；创新7（理由蒸馏与类别适配的组合）；可复现性5（损失和适配参数明确，教师及人工支持材料限制精确复现）。
