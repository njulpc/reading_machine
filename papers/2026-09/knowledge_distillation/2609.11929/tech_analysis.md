# SenseNova-U1.5: Towards Native Unified Visual Intelligence

> arXiv: [2609.11929](https://arxiv.org/abs/2609.11929)；v1 UTC：2026-09-10T17:59:55Z；北京时间提交日：2026-09-11。
> 主分类：Computer Vision and Pattern Recognition (cs.CV)；完整分类：Computer Vision and Pattern Recognition (cs.CV)。
> 证据：[官方 HTML v1](https://arxiv.org/html/2609.11929v1)，本次已下载，核对方法与结果；评分见本次日报。

## 1. 核心速览

**研究主题**：原生多模态模型的多专家在线蒸馏与能力合并。

**一句话总结**：SenseNova-U1.5 将四个专门专家的速度场蒸馏进单一学生，减少需要维护的专家副本，但论文未隔离蒸馏贡献，也未报告整机压缩倍率。

## 2. 研究背景与动机

美学、文字渲染、信息图和编辑的优化目标不一致，把所有奖励直接混合可能导致任务互相损害。分别训练专家能保持专门能力，但部署多个 checkpoint 增加维护和存储负担。本文相关性来自“四个专家到一个学生”的知识合并，而不是标题中的统一架构或普通 BF16 训练。

## 3. 核心方法与创新点

1. **原生视觉接口**：两次卷积下采样 16×与2×，每32×32像素产生一个视觉 token，无外部视觉 encoder/VAE。Pixel Shuffle 按2、2、8倍逐步重建并加入3×3卷积，改善 patch 边缘连续性。
2. **专家分工**：分别训练 aesthetics、OCR、infographic 和 editing 专家，使用不同数据、奖励与采样策略。
3. **on-policy 速度场蒸馏**：学生生成轨迹；每个样本按能力硬路由至对应冻结专家，在同一学生状态、时间和条件下，最小化学生与专家速度场的平方差。轨迹状态 stop-gradient，不穿过整条采样链反传。
4. **课程化查询时刻**：每条轨迹30步确定性 ODE，只查询一个时间点；第n个epoch采用 Beta(2+3n/N,5−3n/N)，从高噪声早期逐渐移向低噪声细节阶段。到查询转移完成立即停止，省去未用轨迹后缀。
5. aesthetics/OCR/infographic 使用 CFG scale=4，editing为1；各epoch用一个能力分区及对应专家，固定顺序轮换。

## 4. 实验设计与结果

架构表列42层、hidden=4096、Q/KV heads=32/8，理解/生成参数分别为8.2B/8.2B；排行榜“8B”明确指生成分量，不能解释成整个多模态系统总共8B。

Stage 5 蒸馏训练800步、global batch=128、每域25,600样本；AdamW lr=2e−5、β=(0.9,0.999)、weight decay=1e−4、梯度范数上限1、BF16。冻结理解分支、最后三个生成层和输出head。预训练与多阶段微调也大幅改变，因此下列是**完整系统结果，不能归因于蒸馏单一组件**。

- Table 6 GenEval：U1.5=0.92、U1=0.91。
- Table 16 ImgEdit：4.59 对 U1 的3.90，+0.69。
- Table 17 GEdit 英文/中文 overall：8.26/8.24，对U1的7.47/7.70。
- Table 4 Qwen-Image-Bench-EN：不带 prompt enhancement 为52.82，带PE为60.22；U1=48.28。额外提示增强效果不可混作模型本体提升。
- 理解并非全面提升：Table 3 MMMU 从74.78到73.86，OCRBench-v2从61.30到59.07。

四专家→单学生说明能力合并，但共享理解分支、专家是否共驻/卸载等会改变总内存开销。没有实测 bytes 或端到端吞吐，不报告4倍整机压缩或4倍加速；30步轨迹也不是少步扩散蒸馏。

本次阅读官方HTML方法、训练设置与实验表格；未本机复现多模态训练。本篇没有新增量化算法，BF16训练不单独算量化论文，因此无Qwen3-0.6B量化目录。

## 5. 局限性与未来展望

缺少同预算的四专家、蒸馏前学生、蒸馏后学生逐能力对照，难以量化能力保留与遗忘。完整结果同时受数据扩充、4K训练、解码器、RL和PE影响。作者声明将开放训练代码不等于本次已验证其可复现；本次未验证对应权重和训练数据的完整可用性。后续应记录四专家共存/按需载入/单学生三个部署方案的显存、存储、时延，并分析epoch能力轮换带来的遗忘。

## 6. 学术启发

压缩多模型系统时，可把知识合并作为独立优化目标：在学生会访问的状态上比较专家，比只拟合专家轨迹更能控制部署分布偏移。分能力路由和噪声时间课程是可迁移的蒸馏设计。必须保留每个专家的能力测试，避免总体榜单掩盖单项退化；必须分清分支参数量与系统总参数量。
