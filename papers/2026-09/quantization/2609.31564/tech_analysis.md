# Weight Pair Encoding: Inducing a Smaller Grammar in Neural Network Weights

## 1. 核心速览

研究主题：使量化权重更适合语法压缩的训练。

一句话总结：WeightPE把受全局L2预算约束的有损Re-Pair改写放入STE，使ViT的MLP权重语法比对应INT8 QAT基线更小；语法符号数减少不等于部署文件字节或推理延迟同倍下降。

## 2. 研究背景与动机

传统INT8量化减少单个权重的位宽，但不会主动产生跨位置、跨层可复用的长模式。固定长度码本也难以递归复用不同长度的子串。论文试图让训练同时适应任务目标和可压缩的权重结构，而不是事后对固定模型直接运行通用压缩器。

## 3. 核心方法与创新点

1. 每个权重矩阵逐行对称INT8量化，按row-major展平；所有受扰动MLP矩阵共享一个语法，但规则不能跨行。
2. REWRITE按相邻符号展开长度分桶，选频率最高且通过去重半径的T个leader；相对不可变原码字计算增量平方误差，按成本选择不重叠位置，严格不超过τ²全局预算。leader最多考察8T个候选，ρ=τ/√N，最短展开长度和桶最少出现数均为2。
3. MERGE批量合并重复相邻对，创建可递归展开的新规则；与逐次只合并最频繁对的标准Re-Pair不同。目标语法大小n_max=64；无变化、两轮停滞或达到目标时停止。
4. 用W+(P(W)−W).detach()传递STE梯度，每10次优化刷新扰动。实验MLP受语法改写，注意力仅INT8，patch embedding、norm及分类头保留高精度。

## 4. 实验设计与结果

ViT-B/16、ViT-L/16使用ImageNet-21k预训练，CIFAR-10微调6轮，有效batch128；AdamW lr=1e−5、weight decay0.1、500步warmup、cosine schedule、梯度裁剪1。τ_frac扫描0.15/0.20/0.25/0.30，L模型另含0.35；T=32/64/128/256。A100-40GB与H100-80GB分别用于两模型。

ViT-B的MLP Re-Pair语法可达基线0.49倍、精度损失0.7个百分点；0.43倍对应97.3%准确率、损失1.9点。L模型摘要写0.38倍/损失1.1点，而正文结果首段写0.37倍/1.1点，正文另有约0.38倍/0.3点配置；这些是不同描述或设置，不能合成唯一最优点。只测MLP语法 |s|+2|G|，且分母为相同INT8 QAT基线的语法。

本次真实Qwen首层gate/up各4行、完整1024输入维，35校准token和14测试token。11步局部MSE训练、step0/10刷新、T32、τ_frac=.15后，批量语法符号比为0.70520；测试相对L2为0.10605，QAT对照为0.00504，明显存在精度代价。权重实际变化L2=0.00961。附录12码字示例的REWRITE、无损解码、行边界及STE梯度测试通过。

## 5. 局限性与未来展望

论文未给全模型实际字节率、解压开销或推理吞吐收益；训练相对耗时最高约5倍且运行环境为共享集群，不能当作严格微基准。仅两种ViT与CIFAR-10，不能外推到LLM。

本次移植采用τ=τ_frac×原INT8码字L2范数（文中比例到绝对预算的映射需显式约定），用局部激活重构MSE代替分类任务；周期之间固定扰动位移，未复现全网络、6epoch或500步warmup。CPU批量合并的确定性随机打破平局可能不同于作者GPU实现；本次语法评估使用同一批量实现，不是作者用于评估的串行贪心Re-Pair。

## 6. 学术启发

压缩率必须记录“压什么、分母是什么、按符号还是按位计”。可学习压缩应同时检查失真预算不变量、语法解码一致性和任务质量，而不能只优化语法长度。面向LLM的下一步应研究列置换、敏感层保护、实际熵编码和解压后GEMM成本。
