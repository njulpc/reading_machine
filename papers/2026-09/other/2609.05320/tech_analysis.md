# Adaptive Gated Deepfake Detection for Low-Resolution and Resource-Constrained Environments

官方证据：[摘要及提交历史](https://arxiv.org/abs/2609.05320)、[官方 PDF](https://arxiv.org/pdf/2609.05320)。v1：2026-09-04 16:14:57 UTC，即北京时间 **2026-09-05 00:14:57**。主分类 cs.CV，交叉 cs.LG。官方 HTML v1 返回404，本次读取8页PDF的方法与实验，并渲染核对第6页表II/III；非量化论文，未做 Qwen 量化复现。

## 1. 核心速览

**研究主题：** 质量驱动的早退与动态计算削减，归入 other 的推理计算压缩，不是输入图像压缩。

**一句话总结：** AdaGate-DF 用质量门控选择 RGB/DCT 双分支的浅、中、深出口，在 Celeb-DF 上取得 AUC 0.9370，但 FF++ 的 AUC 0.5163 表明其跨设置判别能力仍很弱。

## 2. 研究背景与动机

低质量、低分辨率图像需要更深的伪造特征分析，而固定深度模型让简单样本承担同样成本。频域分支可补充空间纹理，却增加固定推理开销。作者将图像质量估计用于决定网络内部执行深度，试图让双分支表征与早退机制共存。

纳入原因是明确跳过网络后续层，改变单样本执行图；摘要中的图像 compression 仅是退化来源，不是判断模型压缩相关的关键词依据。

## 3. 核心方法与创新点

1. **双分支多出口。** RGB 卷积编码器和灰度 DCT 编码器均有三个出口；fast 使用浅层，medium 使用中层，full 融合两路深层特征（§III-C，图1）。
2. **质量驱动路由。** 以分辨率、清晰度、模糊、压缩伪影代理、亮度和对比度构成 q，由轻量门控 G(q) 选择路径。门控使用质量规则生成的路由标签，而非单凭分类置信度早退（§III-B）。
3. **所有出口联合训练。** 分类损失覆盖 RGB、DCT 及融合输出，再加门控监督；§IV-B式1为 `Lrgb+Ldct+Lfused+λLgate`。正文没有完整给出质量阈值和 λ 数值，算法1则将门控损失直接相加，应结合作者实现核查。
4. **不确定性同时评估。** AdaGate-DF 使用最大分类置信度小于0.65标记不确定；部分概率模型采用[0.4,0.6]区间。因此不同模型的“不确定率”并非完全同阈值校准后的指标。

## 4. 实验设计与结果

Celeb-DF 划分为80,824/10,104/10,103张训练/验证/测试图像。FF++ 包含7,000段视频、真实:伪造约1:6，以2FPS、每视频最多8帧得到55,953帧；按视频80/10/10切分以防同视频泄漏。训练为 AdamW、lr=2e−4、weight decay=1e−4、batch=32、15 epochs、seed=42；随机训练分辨率128/224/256/384。硬件为 NVIDIA L40 48GB（§IV）。

| 配置 | Celeb-DF AUC | Celeb-DF F1 | FF++ AUC |
|---|---:|---:|---:|
| 门控双分支 | 0.9370 | 0.8654 | 0.5163 |
| fast only | 0.7114 | 0.6622 | 0.5295 |
| medium only | 0.9047 | 0.8224 | 0.5101 |
| full only | 0.9709 | 0.9107 | 0.4182 |
| ShuffleNetV2 | 0.9993 | 0.9877 | 0.5693 |

数据来自PDF第6页表II；门控并未超过所有基线。门控较 full only 的 Celeb-DF AUC 低0.0339，说明动态计算具有实际质量代价。FF++ 的门控准确率85.71%、召回1.0、精确率0.8571与多数类预测一致，不能用高准确率宣称鲁棒检测。

分辨率消融（表III）：门控 Celeb-DF AUC 从128像素0.8954上升到384像素0.9708；FF++仅0.5043–0.5253。§V-C报告224像素下 Celeb-DF 训练6.07小时、推理0.14ms/图；FF++为5.58小时、0.25ms/图。是L40上的作者报告，未本机验证，也不是手机延迟。

## 5. 局限性与未来展望

- FF++近随机AUC是核心失败结果，比摘要中“保持有效”更值得重视；需要混淆矩阵、balanced accuracy及跨数据集测试。
- 没有统一参数体积、每条路径FLOPs、出口分布及相同骨干强制full的完整延迟对照，故无法给出可靠模型压缩倍率。
- 质量门控计算开销、GPU计时同步及真实低端硬件部署仍需复核。论文的低资源动机不能代替实际边缘评估。
- 质量规则和损失权重在论文中未完全展开。作者给出[代码入口](https://github.com/CodeGhost157/AdaGate-DF)，本次未运行其训练流程。

## 6. 学术启发

动态推理应在同一训练骨干、相同输入分布下比较门控与强制full，并将AUC损失对齐到实际节省的计算量。不确定率降低也可能来自有偏且过度自信的分类器；同时检查类别条件错误率与校准，可避免把“零不确定”误解为可靠。

**评分（1–10）：** 精度效果4（Celeb-DF可用、FF++近随机且逊于ShuffleNet）；压缩3（动态削减合理，缺少严谨倍率）；创新6（质量监督与双分支早退结合）；可复现性6（代码入口与设置可用，关键阈值及计时仍需核验）。
