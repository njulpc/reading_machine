# MEOX: Compact Multimodal Mixture-of-Experts for Earth Observation

官方证据：[摘要及提交历史](https://arxiv.org/abs/2609.05351)、[v1 全文](https://arxiv.org/html/2609.05351v1)。v1：2026-09-04 16:59:36 UTC，即北京时间 **2026-09-05 00:59:36**。主分类cs.CV，无交叉分类。本次读取§III–VI的方法、协议、结果和讨论；数字来自论文，未本机重新预训练。

## 1. 核心速览

**研究主题：** 共享权重与低秩专家残差、稀疏执行及多模态token融合的紧凑模型设计，归入other；不是仅因出现MoE就纳入。

**一句话总结：** MEOX 用共享专家投影与rank-8私有残差实现2.939M参数编码器，在部分遥感任务上竞争力较强，但224像素输入使计算量升至51.477G，暴露低存储与低算力需求之间的分离。

## 2. 研究背景与动机

遥感数据具有不同传感器、波段数量及缺失观测。直接拼接所有传感器token会让深层注意力成本随模态数增长，而独立专家复制全部投影又使参数数目膨胀。作者希望保留模态特化与缺失值语义，同时把存储控制在数百万参数。

## 3. 核心方法与创新点

1. **显式缺失表示。** 输入token叠加内容、有效掩码、传感器身份和波段存在向量；缺失像素不能和标准化后真正的0混为一谈。元数据的经纬度、月份与ERA5各有缺失状态（式1–2）。
2. **共享首层，延迟融合。** 每个传感器独立经过同一个首层MoE块；按patch以内容分数加 `log(max(有效比例,1e−6))` 做模态softmax。深层14个块仅处理融合后的一个空间序列，外加4个元数据token和CLS。三传感器时由`3N+5`变为`N+5`（§III-B）。
3. **低秩约束专家增长。** 15层专家数分段为3/4/5、top-2路由、宽度144、8头、专家隐藏宽度144逐渐降至72。SwiGLU专家的门投影私有，value/output主投影在层内共享，再加rank-8私有残差：`h_e=SiLU(Wg,e x)⊙(Wv x+Uv,e Dv,e x)`，`E_e=Wo h_e+Uo,e Do,e h_e`。U零初始化；不同层不共享（式7–8）。
4. **缺失传感器重建。** 同步遮盖75%空间patch；10%的batch随机删去部分输入传感器，却仍重建全部有效目标。各传感器先归一化重建损失后等权平均，避免13波段S2压过2波段S1。路由平衡损失系数0.01，不设置token容量丢弃（§III-D/E）。

## 4. 实验设计与结果

MMEarth64使用1,228,121训练和12,405验证样本；50 epochs、batch128、AdamW、lr3e−4、weight decay0.05、5% warmup、余弦衰减、梯度裁剪1。A100 MIG 2g.20gb运行约166.9小时；不可直接换算成完整A100小时。第31轮最优重建损失0.1046。GEO-Bench冻结迁移报告5次头部训练均值，另列完整微调结果（§IV–V）。

| 指标 | MEOX 64像素 | MEOX 224像素 | 解释 |
|---|---:|---:|---|
| 完整参数（含训练decoder） | 3.115M | 3.115M | 编码器单独2.939M |
| S2编码计算量 | 1.029G | 51.477G | FMA算1次，排除decoder/任务头/不支持元素操作 |
| EuroSAT平均准确率 | 89.70±0.30 | 90.56±0.27 | 强于CSMoE最佳88.3 |
| Cashew mIoU | 64.42±0.22 | 64.08±1.07 | CSMoE最佳59.4 |
| 冻结BigEarthNet micro-mAP | 55.16±0.16 | 57.22±0.11 | CSMoE最佳66.5 |
| 微调BigEarthNet micro-mAP | 67.78 | 72.95 | 不可与冻结结果直接混用 |

表IV中CSMoE P=14为271M参数，`271/3.115≈87.0`，这是两个不同模型的参数比，并非同一模型压缩前后的受控倍数。64像素1.029G较CSMoE P=32的2.92G少约2.84倍，但输入采样不同。224像素产生3,136个patch，MEOX算量反而超过CSMoE P=14的13.40G。

路由诊断只覆盖128个验证样本；每个专家均收到token，最小执行率25.12%。抑制专家输出但不重新归一化权重会增大重建损失，提供局部功能证据。WorldCover移除全部元数据、重训相同任务头后mIoU下降0.64点；跨传感器检索弱于同传感器，表明重建学习不自动产生一致的跨模态度量空间。

## 5. 局限性与未来展望

- CSMoE等对照沿用其论文数字，未重新训练；输入波段、预训练分布与pooling并非完全匹配，部分其他模型数字由图读取。
- 缺少针对共享投影、低秩、融合等全部组件的匹配消融，不能把87倍差异都归因于某个组件。
- 低参数并不保证高分辨率算量低；应探索多尺度或局部注意力，并加入端到端任务头和显存/延迟测量。
- 尚未验证随机波段丢失、完整大场景拼窗，以及所有数据条件下的路由特化。低特征有效秩也不意味着冗余：删前8个主成分使探针准确率89.0→70.1。

## 6. 学术启发

共享主投影加低秩私有残差可作为专家压缩的结构先验；融合位置决定多模态token成本。应分别核算参数、激活序列长度与注意力复杂度，并通过匹配消融判断哪项节省来自模型结构、哪项来自较低输入分辨率。

**评分（1–10）：** 精度效果7（两任务强、其他任务仍落后）；压缩8（约87倍参数差异有明确口径，高分辨率算量不占优）；创新7（紧凑专家与缺失感知融合组合）；可复现性7（[实现与实验notebook](https://github.com/AlbughdadiM/compact-multimodal-moe-eo)和数据协议明确，但预训练成本高，本次未重跑）。
