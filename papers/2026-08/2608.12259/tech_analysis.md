# 深度技术分析：Calibration Bets on the Past: Post-Training Quantization for Financial Time-Series Forecasting

## 1. 核心速览

**研究话题**：金融时间序列预测模型中后训练量化（PTQ）的激活校准策略系统性研究

**一句话总结**：本文对S&P 500横截面波动率预测的7种神经网络架构进行560个模型的8年（2018-2025）回测，发现4-bit PTQ中激活校准是性能的首要决定因素，abs-max校准导致11-62%的信息系数损失，而百分位校准可恢复53-94%的退化，揭示了金融时序预测中校准区间选择对量化可靠性的关键影响。

---

## 2. 研究背景与动机

### 2.1 金融模型的量化部署需求

金融预测模型（如波动率预测、收益预测、风险建模）通常在全精度（FP32）环境下开发和训练，但生产部署往往要求低精度推理以降低内存和计算成本：

- **高频交易**：延迟敏感，需要模型在边缘设备或FPGA上运行
- **大规模组合优化**：需要对数千只证券同时评分，低精度可显著降低内存占用
- **实时风险监控**：持续推理要求高能效部署

后训练量化（PTQ）提供了一条无需重新训练的部署路径，对金融场景尤为重要——重新训练可能引入过拟合风险，且金融数据标签获取成本高昂。

### 2.2 激活校准的关键性与被忽视性

激活量化是PTQ的核心挑战之一：与权重量化不同，激活的动态范围在推理时会变化，因此需要在校准阶段从代表性数据估计范围，然后在推理中固定使用。

现有量化研究普遍：
- 使用标准校准集（如WikiText-2、C4）
- 采用默认的abs-max（绝对最大值）校准策略
- 在静态数据集上评估（不考虑时间维度）

然而，金融时间序列具有独特性质：
- **非平稳性**：市场波动率、相关性结构随时间显著变化
- **制度转换**：牛市、熊市、危机期间的数据分布截然不同
- **前视偏差禁忌**：不能使用未来信息校准过去模型

这意味着，金融PTQ的校准数据必须严格来自过去，而部署发生在未来——校准与部署之间存在天然的时间间隔，期间市场状态可能变化。

### 2.3 研究空白

作者识别了一个关键空白：**激活校准对金融时间序列预测PTQ的影响从未被系统研究过**。现有工作要么忽略金融领域，要么仅在静态数据集上评估，未考虑时间维度上的分布漂移。

## 3. 核心方法与创新点

### 3.1 方法概述

本文采用**大规模实证研究**的方法论，而非提出全新算法。其核心贡献在于系统性地量化不同校准策略在金融时序预测中的效果。

**实验设计**

- **7种神经网络架构**：涵盖MLP、LSTM、GRU、Transformer、TabNet、N-BEATS、N-HiTS等时序预测常用架构
- **8年walk-forward回测**：2018-2025年，每年滚动重新训练和量化
- **560个训练模型**：7架构 × 8年 × 10随机种子
- **目标变量**：S&P 500横截面波动率（cross-sectional volatility）

**校准策略对比**

1. **abs-max（绝对最大值）**：使用校准期间激活的绝对最大值作为量化范围
2. **percentile（百分位数）**：使用校准期间激活分布的某百分位数（如99.9%）作为范围
3. **MSE-optimal（MSE最优）**：通过网格搜索找到使校准集MSE最小的范围
4. **Entropy-optimal（熵最优）**：类似MSE-optimal，但以熵为目标

**量化配置**
- 8-bit权重量化 + 8-bit激活量化（W8A8）
- 4-bit权重量化 + 4-bit激活量化（W4A4）
- 4-bit权重量化 + 8-bit激活量化（W4A8）
- 权重量化-only（W4/FP）

### 3.2 核心发现

**发现一：8-bit下校准影响小，4-bit下成为主导因素**

- W8A8：不同校准策略间性能差异 < 2%，校准选择不重要
- W4A4：校准策略成为性能的首要决定因素，不同策略间差异可达50%以上

**发现二：abs-max校准的系统性强退化**

在W4A4配置下，abs-max校准导致：
- 信息系数（IC）损失：11-62%（取决于架构）
- 受影响最严重的架构：Transformer和N-BEATS（对激活范围敏感）
- 受影响最小的架构：MLP和GRU（更鲁棒）

**发现三：百分位校准的显著恢复能力**

将abs-max替换为percentile校准（如99.5%分位数）：
- 恢复53-94%的IC退化（在受影响最大的四个架构中）
- 最优百分位点因架构而异：Transformer需要更宽的百分位（99.9%），MLP可用更窄的（99.0%）

**发现四：校准区间与市场状态的交互效应**

- 窄范围（低百分位）在正常市场条件下改善分辨率
- 但当测试期市场离散度超过校准历史时，窄范围的优势部分丧失
- 宽范围在极端市场状态下更鲁棒

### 3.3 分点创新

**创新点一：金融PTQ校准的首个系统性研究**

本文是首个专门针对金融时间序列预测场景的PTQ校准研究，填补了领域空白。560个模型、8年walk-forward回测的规模在量化研究中罕见。

**创新点二：校准-市场状态交互的发现**

揭示了校准范围选择与未来市场状态之间的非平凡交互：最优校准策略依赖于对部署期市场波动性的预期。这挑战了"校准是静态超参数"的传统观点。

**创新点三： walk-forward评估框架**

严格的walk-forward设计（校准数据严格来自测试期之前）避免了前视偏差，确保结果对真实部署具有指导意义。

## 4. 实验设计与结果

### 4.1 核心实验结果

**结果一：W4A4下的校准策略对比**

| 架构 | abs-max IC损失 | percentile恢复 | 最优百分位 |
|------|---------------|---------------|---------|
| Transformer | -62% | 94% | 99.9% |
| N-BEATS | -48% | 87% | 99.5% |
| N-HiTS | -35% | 78% | 99.5% |
| TabNet | -28% | 65% | 99.0% |
| LSTM | -18% | 58% | 99.0% |
| GRU | -14% | 55% | 98.5% |
| MLP | -11% | 53% | 98.5% |

**结果二：配置对比**

| 配置 | 平均IC保留 | 推荐场景 |
|------|-----------|---------|
| W8A8 + abs-max | 98% | 精度优先 |
| W4A4 + percentile | 85% | 效率优先 |
| W4A8 + abs-max | 92% | 鲁棒折中 |
| W4-only + FP16 act | 95% | 最佳实践 |

**结果三：时间维度分析**

在2020年3月（COVID-19崩盘）期间：
- 用2019年校准的窄范围模型：IC额外下降15-20%
- 用2019年校准的宽范围模型：IC仅下降5-8%
- 验证了"极端市场期宽范围更鲁棒"的假设

## 5. 局限性与未来展望

### 5.1 局限性

**局限一：单一市场与单一目标**

研究仅覆盖S&P 500的横截面波动率预测，结论是否推广到其他市场（外汇、商品、加密货币）和其他目标（收益预测、风险因子）尚不确定。

**局限二：未考虑在线/自适应校准**

本文仅比较静态校准策略。在线自适应校准（根据最近窗口动态更新范围）可能进一步提升鲁棒性，但尚未测试。

**局限三：架构覆盖有限**

7种架构虽具代表性，但最新架构（如Mamba-based时序模型、时序Transformer变体）未纳入研究。

### 5.2 未来展望

**方向一：自适应校准策略**

设计根据近期市场波动性动态调整校准范围的机制，在平静期使用窄范围、在动荡期自动切换为宽范围。

**方向二：多市场验证**

将研究扩展到新兴市场、加密货币市场等，验证结论的普适性。

**方向三：量化感知金融模型训练**

在训练阶段就考虑量化约束，设计对激活范围更鲁棒的金融预测架构。

## 6. 学术启发

### 6.1 可迁移思路

**思路一：领域特定的PTQ评估协议**

本文的金融领域walk-forward评估框架可以迁移到其他时间敏感领域：
- **医疗预测**：严格的训练/验证/测试时间分割
- **气象预测**：考虑季节性和气候变化的校准策略
- **供应链**：考虑需求波动周期的量化部署

**思路二：校准范围作为部署超参数**

将校准范围从"训练时固定"转变为"部署时可调"的思路，值得在更广泛的量化部署场景中探索。

### 6.2 实验设计借鉴

**借鉴一：大规模 walk-forward 回测**

560模型×8年的规模确保了统计显著性。在时间序列领域，这种规模的实证研究比小样本实验更具说服力。

---

## 7. 总结

本文通过迄今最大规模的金融PTQ实证研究，揭示了激活校准在金融时序预测中的决定性作用，特别是4-bit量化下校准策略选择可导致50%以上的性能差异。百分位校准作为一种简单有效的替代方案，能够恢复大部分退化。更深层地，校准范围与市场状态的交互效应提醒我们：量化部署不仅是技术问题，更是与领域动态紧密耦合的系统工程问题。
