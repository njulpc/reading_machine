# 技术深度分析：Compress and Forget

> arXiv: [2608.18578](https://arxiv.org/abs/2608.18578) · v1: 2026-08-19 06:17:13 UTC · 主分类：cs.CL

## 1. 核心速览

**研究主题**：bitsandbytes INT8 与 NF4 量化对 LLM 主动干扰记忆的影响。

**一句话总结**：量化在聚合精度上只损失 1.1–2.4 个百分点，却会在高语义干扰检索中暴露显著缺陷；Qwen2.5-7B 在最高干扰下由 FP16 的 81.0% 降到 INT4 的 68.3%，错误机制集中为更频繁地召回同一 key 的旧值。

## 2. 研究背景与动机

PTQ 已是开放权重 LLM 的常见部署方式，主流评估却多看 perplexity 或综合基准。主动干扰任务会反复覆盖同一 key 的值，再查询最新绑定，能够测试模型是否把相似旧记忆与当前目标分开。若量化噪声破坏这种细粒度表征，平均基准可能看不出来，但长期、频繁更新的上下文应用会受影响。

## 3. 核心方法与创新点

- 固定同一套 PI-LLM 提示和生成设置，只改变 FP16、LLM.int8()、NF4+double quantization 三种精度，保证逐样本配对。
- 覆盖 Qwen2.5-7B-Instruct、Mistral-7B-Instruct-v0.3 与 Phi-3.5-mini-instruct，区分语义相似 word-type 与数字控制条件。
- 用 McNemar 配对检验、混合效应 logistic 回归和 Interference Endurance Score 同时衡量单一高干扰点与整条退化曲线。
- 回溯错误答案在覆盖序列中的来源，并补做 lm_head 量化消融，定位影响来自量化骨干而非输出投影。

## 4. 实验设计与结果

在所有属性和干扰等级汇总时，FP16 到 INT4 仅下降 1.1–2.4 个百分点。高语义干扰下三模型 INT4 均显著变差，优势比范围 2.6–20.0；Qwen 在 k=64 时 81.0%→68.3%。INT8 更温和但并非普遍安全：Mistral 与 Phi 的配对 p 值为 0.018、0.004，Qwen 为 0.629。

word-type 条件的 INT4×log(干扰等级) 系数为 -0.046，p=5.7×10^-8；数字控制中方向反转，排除了“量化只会普遍加噪”的简单解释。同 key 旧值侵入占全部 word-type 试验的比例从 FP16 21.5% 升至 INT8 23.2%、INT4 24.6%，FP16 对 INT4 的 McNemar p=4.8×10^-7。额外量化 lm_head 没有显著改变三模型准确率，说明主要损伤来自骨干。

## 5. 局限性与未来展望

只测试 bitsandbytes 的 INT8/NF4、三个 4–7B instruct 模型与合成绑定任务，不能替代 GPTQ/AWQ、激活量化或真实 agent 记忆评估。Qwen3-0.6B 等小模型可能被基础能力地板效应限制。未来应扩展到更长上下文、持续编辑记忆、校准型 PTQ 和量化感知训练，并寻找能预测干扰脆弱性的内部表征指标。

## 6. 学术启发

压缩评估要寻找“平均分掩盖的结构化失败”：不仅问准确率降多少，还要问在哪类干扰、哪种错误路径和哪一层发生。部署时，INT8/INT4 的安全性应按应用的记忆更新密度与语义相似度评估，而不是只凭通用基准。
