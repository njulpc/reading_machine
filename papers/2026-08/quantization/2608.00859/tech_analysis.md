# 深度技术分析：SparseKAN: Compressing Kolmogorov-Arnold Networks Across Basis Functions, Neurons, and Bits

## 1. 核心速览

**研究话题**：面向 Kolmogorov-Arnold Networks（KAN）的三轴统一压缩框架——基函数、神经元/通道、数值精度。

**一句话总结**：本文提出 SparseKAN，通过层次化可学习门控（hierarchical learnable gates）在可微分 active-cost 目标下训练，沿基函数、神经元/通道和比特精度三个互补轴压缩 KAN。物理压缩在 MNIST 上可移除多达 73.0% 参数而无精度损失，大 batch CUDA 延迟降至密集执行的 0.51×，在 ZCU104 FPGA 上稀疏低比特模型实现高达 23.63× 的推理延迟降低。

---

## 2. 研究背景与动机 (Background & Motivation)

### 2.1 KAN 的独特结构与冗余来源

Kolmogorov-Arnold Networks（KAN）用可学习的单变量函数替代 MLP 连接上的标量权重。在基于样条的 KAN 中，每条边将残差基础激活与基函数展开结合，因此一条连接携带多个系数而非一个标量。对于输入宽度 d_in、输出宽度 d_out、每条边 K 个基函数，主导系数张量的规模为 d_in × d_out × K。

这种额外的函数能力也是成本的来源。**KAN 的冗余不仅存在于边和神经元之间，还存在于每个学习函数内部**——并非每条边都需要全部基函数，删除整条边可能同时移除有用计算和冗余项。

### 2.2 标准剪枝粒度的不足

标准神经网络剪枝的粒度无法直接适用于 KAN：

- **边级剪枝**：保留的边可能仅需其基函数的一个子集，删除整条边会同时移除有用计算和冗余项。
- **通道/神经元剪材**：无法触及函数内部的基函数维度。
- **精度量化**：独立于结构剪枝，但需要与结构压缩协调。

KAN 压缩因此暴露出三个互补的轴：**基函数**、**神经元/通道**和**精度/比特**。现有工作分别处理这些轴的局部问题，但缺乏一个统一机制来暴露内部基函数维度、协调宽度和精度，并将结果结构转化为物理更小的可执行张量。

### 2.3 现有 KAN 压缩工作

- **高效基函数参数化**：FastKAN（Gaussian RBF）、ChebyKAN（Chebyshev 多项式）、Wav-KAN（小波）、KAN 卷积等，通过更简单或低维的函数参数化降低成本。
- **系数共享或向量量化**：MetaCluster 聚类系数向量，SHARe-KAN 应用后训练向量量化。
- **低精度推理**：QuantKAN、KANtize 研究低精度 KAN 推理。
- **学习型架构稀疏**：通过可微分架构优化学习紧凑 KAN 结构。
- **专用硬件**：FPGA LUT 映射、脉动阵列、可重构稀疏流水线、存内计算设计。

然而，这些工作缺乏一个**通用机制**来暴露内部基函数维度、协调宽度和精度，并将结果结构转化为物理更小的可执行张量。

### 2.4 本文要解决的核心问题

如何设计一个统一的 KAN 压缩框架，能够：
1. 暴露并利用函数内部的基函数冗余
2. 协调基函数、神经元/通道和精度三个压缩轴
3. 将学习到的稀疏结构物理压缩为更小的密集张量（而非保留稀疏掩码）
4. 在软件和硬件层面实现可测量的效率提升

## 3. 核心方法与创新点 (Methodology & Innovations)

### 3.1 从函数冗余到结构化压缩

SparseKAN 的核心思想是**分离结构发现（structure discovery）和结构实现（structure realization）**：

1. **结构发现**：训练可微分门控，暴露每条 KAN 边内部计算的相对重要性
2. **结构实现**：将学习到的软结构转化为沿两个结构维度（基函数和神经元/通道）的显式压缩
3. **精度适配**：对剩余参数进行量化
4. **物理压缩**：将结构化掩码物理压缩为更小维度的密集张量

### 3.2 Cost-Gated KANs

考虑 KAN 层中边 (i→o)，具有 K 个基函数。其门控形式为：

```
φ̃_{o,i}(x_i) = g^b_{o,i} · w^b_{o,i} · a(x_i) + g^r_{o,i} · Σ_{k=1}^{K} g^t_{o,i,k} · c_{o,i,k} · ψ_k(x_i)
```

其中：
- a(·) 是基础激活
- ψ_k(·) 是第 k 个基函数
- c_{o,i,k} 是其系数
- g^b 控制基础分支
- g^r 控制非线性基函数分支
- g^t 控制单个基函数项

这一公式是**基函数无关的**（basis-agnostic），适用于样条、多项式、RBF、小波和卷积 KAN 家族。默认使用 sigmoid 松弛的可学习门控。

### 3.3 归一化 Active-Cost 目标

为偏置模型趋向更廉价的结构，SparseKAN 优化归一化 active-cost 惩罚：

```
R_cost = (λ_b·C_b·Σg^b + λ_r·C_r·Σg^r + λ_t·C_t·Σg^r·g^t) / (C_b·N_b + C_r·N_r + C_t·N_t)
```

其中 C 和 N 分别表示每种组件类型的相对成本和密集计数。乘积 g^r·g^t 反映了门控的层次结构：基函数项只有在分支门 g^r 激活时才被计数。

### 3.4 两个结构轴：基函数和神经元

SparseKAN 沿两个结构轴进行压缩：

**基函数轴**：
- 通过门控 g^t 学习每个基函数项的重要性
- 硬化阶段在显式基函数预算下选择保留的基函数项
- 支持三种选择规则：per-edge top-k、input-shared top-k、layer-shared top-k

**神经元/通道轴**：
- 通过结构化剪枝移除不重要的隐藏单元/通道
- 与基函数轴组合使用

关键发现：**基函数和宽度减少可预测地组合**。在 MNIST EfficientKAN 上，因子 0.556 和 0.4651 预测 active cost 为 0.2585，实测为 0.2584——几乎完美匹配。

### 3.5 物理压缩与低比特表示

**物理压缩（Physical Compaction）**是 SparseKAN 的关键创新之一：

- 当支撑结构兼容时，SparseKAN 收集保留的基函数项并切片死亡的隐藏维度
- 将学习到的稀疏性转化为更小的密集张量（从 d_{ℓ-1}·d_ℓ·K_ℓ 到 d'_{ℓ-1}·d'_ℓ·K'_ℓ），而非在原始模型中保留为零
- 这意味着硬件接收到的是**更小的密集问题**，而非包含零的密集问题

**量化感知训练（QAT）**：
- 8-bit QAT 广泛鲁棒
- 4-bit 卷积 KAN 需要量化感知适配（朴素 4-bit PTQ 在 CIFAR-10 上降至 50.19±11.78%，CIFAR-100 上降至 9.04±2.43%）
- 支持联合门控/QAT 训练（单流水线选项）和分层压缩

### 3.6 训练与压缩流水线

SparseKAN 的完整流程：
1. **Cost-gated 训练**：使用归一化 active-cost 惩罚训练门控，暴露冗余
2. **硬化（Hardening）**：在显式基函数和宽度预算下硬化学习到的结构
3. **精度恢复**：在全精度或低比特 QAT 下恢复模型
4. **物理压缩**：将兼容的支撑结构压缩为更小的密集张量

## 4. 实验设计与结果 (Experiments & Results)

### 4.1 实验设置

- **数据集**：MNIST、CIFAR-10、CIFAR-100
- **KAN 变体**：spline、polynomial、RBF、wavelet、convolutional KAN
- **对比基线**：匹配剪枝基线、匹配参数 MLP 控制
- **评估维度**：精度、物理检查点大小、CUDA 延迟、FPGA/HLS 实现（18 设计研究）
- **统计协议**：五种子审计（five-seed audit）

### 4.2 主要结果

| 指标 | 结果 |
|------|------|
| 参数移除（MNIST，无精度损失） | **73.0%** |
| 大 batch CUDA 延迟 | 降至密集执行的 **0.51×** |
| FPGA 推理延迟降低 | 高达 **23.63×**（稀疏 4-bit EfficientKAN） |
| Gram-polynomial MLP FPGA 延迟降低 | **18.21×** |
| 基函数选择 vs 低阶截断 | 系数选择超出匹配低阶截断多达 **15.25** 精度点 |
| 物理压缩 top-1 一致性 | ≥ **0.9997**（54 个压缩检查点） |

### 4.3 基函数身份的影响

论文发现了强烈的**基函数依赖性差异**：

- **Gram-polynomial 设置**：基于系数的选择超出匹配低阶截断多达 15.25 精度点，说明哪些基函数项被保留很重要
- **B-spline 模型**：对支撑身份几乎不敏感，说明保留哪些基函数项不太重要

这一发现表明：不同基函数族的冗余结构存在本质差异，压缩策略需要基函数感知。

### 4.4 精度边界

- **8-bit QAT**：广泛鲁棒（benign），对精度影响很小
- **朴素 4-bit PTQ**：CIFAR-10 上 50.19±11.78%，CIFAR-100 上 9.04±2.43%——严重退化
- **4-bit QAT**：恢复有用的低比特操作点，特别是对卷积 KAN

### 4.5 结构轴的组合性

基函数和宽度减少**可预测地组合**：在 MNIST EfficientKAN 上，预测 active cost 0.2585 vs 实测 0.2584。这意味着两个结构轴的压缩效果可以独立预测后相乘，简化了压缩规划。

### 4.6 物理压缩的有效性

- 在 54 个压缩检查点上，与对应掩码模型的 top-1 一致性至少为 0.9997
- 物理压缩将稀疏掩码转化为更小的密集张量
- 掩码模型的 CUDA 延迟仍接近密集延迟，而物理压缩模型的延迟显著降低

### 4.7 FPGA/HLS 实现

- **平台**：ZCU104 FPGA
- **稀疏 4-bit EfficientKAN**：23.63× 延迟降低
- **稀疏 4-bit Gram-polynomial MLP**：18.21× 延迟降低
- **稀疏 4-bit KAGN-conv**：DSP 占用从 96.2% 降至 29.1%，仅损失 0.09 精度点

### 4.8 与常规剪枝和匹配 MLP 的对比

论文与常规 KAN 节点剪枝基线和匹配参数 MLP 控制进行了对比。匹配成本的边级 L_0 结果作为范围条件：基函数稀疏性并非普遍比边稀疏性更准确；其价值在于更细粒度的函数控制和可压缩结构。

## 5. 局限性与未来展望 (Limitations & Future Work)

### 5.1 局限性

1. **实验规模有限**：实验仅在 MNIST、CIFAR-10 和 CIFAR-100 上进行，未涵盖更大规模数据集（如 ImageNet）或更复杂的任务（如 NLP）。KAN 在这些场景下的表现本身仍在探索中，限制了结论的泛化性。

2. **基函数兼容性要求**：物理压缩要求支撑结构兼容（compatible supports），对于某些基函数族可能不直接适用。当基函数项的支撑结构不兼容时，物理压缩可能无法实施。

3. **4-bit 量化的脆弱性**：朴素 4-bit PTQ 严重退化（CIFAR-100 上仅 9.04%），即使 QAT 恢复后，4-bit 卷积 KAN 仍需要特别适配。这表明 KAN 的低比特量化比传统 MLP 更具挑战性。

4. **门控训练的超参数敏感性**：归一化 active-cost 惩罚中的 λ 参数需要调优，不同 KAN 变体和数据集可能需要不同的配置。论文虽提供了五种子审计，但超参数选择的鲁棒性仍需更系统的研究。

5. **KAN 本身的成熟度**：KAN 作为新兴架构，其在实际应用中的优势仍在争议中。SparseKAN 的价值部分取决于 KAN 是否能在大规模应用中展现足够的竞争力。

6. **FPGA 实现的特定性**：FPGA 结果基于 ZCU104 平台和 HLS 实现，不同平台和实现方式可能产生不同结果。论文也承认"内存流量和实现细节可能主导名义 KAN 算术成本"（引用 FlashKAT 的发现）。

### 5.2 未来展望

1. **更大规模验证**：在 ImageNet 等更大规模数据集和更多任务上验证 SparseKAN 的效果。

2. **自适应基函数选择**：当前硬化阶段的基函数选择规则（per-edge、input-shared、layer-shared top-k）是预定义的，未来可探索完全学习型的选择策略。

3. **与架构搜索联合**：将 SparseKAN 的门控机制与神经架构搜索（NAS）结合，从零开始搜索紧凑的 KAN 结构。

4. **混合精度扩展**：探索学习型逐层精度选择（论文附录 A.7 提到了 learned layer-wise precision），使不同层自动选择最优比特宽度。

5. **硬件协同设计**：与 KAN 专用加速器协同设计，利用物理压缩后的小密集张量进一步优化硬件效率。

6. **KAN 与 MLP 的统一压缩框架**：探索是否能将 SparseKAN 的三轴压缩思想统一到包含 MLP 和 KAN 的混合架构中。

## 6. 学术启发 (Takeaways for My Research)

### 6.1 "函数内部冗余"这一新压缩维度的发现

SparseKAN 最重要的贡献是识别并系统性地利用了 KAN 独有的冗余维度——函数内部的基函数冗余。传统神经网络的压缩轴是神经元/通道和精度，KAN 额外引入了基函数轴。这启发我：在研究新兴架构的压缩时，应首先分析该架构引入了哪些新的冗余来源，这些冗余可能不存在于传统架构中。

### 6.2 结构发现与结构实现的分离

SparseKAN 将"结构发现"（soft gating）和"结构实现"（hardening + compaction）分离，这是一个重要的方法论模式。在结构发现阶段使用可微分门控暴露重要性，在结构实现阶段做出硬性决策并物理压缩。这种分离使优化过程更稳定，且允许在两个阶段使用不同的策略。在我的压缩研究中，可以采用类似的"软探索 + 硬决策"两阶段模式。

### 6.3 物理压缩 vs 稀疏掩码的关键区别

SparseKAN 强调将稀疏结构物理压缩为更小的密集张量，而非保留稀疏掩码。论文清楚地展示了这一区别的实际意义：掩码模型的 CUDA 延迟仍接近密集延迟（因为零仍然需要被处理），而物理压缩模型的延迟显著降低。这提醒我：在研究中评估压缩效果时，不能仅看参数减少比例，还要关注压缩是否转化为实际的执行效率提升。稀疏掩码≠物理压缩。

### 6.4 多轴压缩的可组合性

论文发现基函数和宽度减少"可预测地组合"（预测 0.2585 vs 实测 0.2584），这一可组合性极大地简化了压缩规划。在我的多维度压缩研究中，可以测试不同压缩轴的组合是否具有可预测性，如果存在，则可以独立优化各轴后简单组合。

### 6.5 基函数依赖性的启示

不同基函数族（Gram-polynomial vs B-spline）对基函数选择策略的敏感度截然不同，这一发现提醒我：压缩策略需要与模型的具体参数化方式匹配。没有"一刀切"的最优压缩方案，必须针对不同的基函数/参数化方式设计感知型的压缩策略。

### 6.6 从软件到硬件的完整验证链

SparseKAN 建立了从软件（CUDA 延迟）到硬件（FPGA/HLS 实现）的完整验证链，证明了压缩方法在两个层面的实际效果。这种完整的验证方法值得学习：压缩研究不应止步于精度和参数量报告，还应验证在实际硬件上的延迟、资源占用和功耗。特别是论文中 KAGN-conv 的 DSP 占用从 96.2% 降至 29.1% 这一数据，直观地展示了压缩对硬件资源的影响。

### 6.7 五种子审计的统计严谨性

论文采用了五种子审计（five-seed audit）来验证结论的统计稳健性，并明确指出联合门控/QAT 训练是"鲁棒的单流水线选项，而非普遍的精度改进"。这种不夸大结果的科学态度值得学习。在我的研究中，应同样采用多种子实验来验证结论的统计显著性，并诚实地报告方法的局限性。
