# Bit-Flip Attacks on Vision-Language-Action Models：技术精读

> arXiv: [2608.15475](https://arxiv.org/abs/2608.15475) · submitted 2026-08-16 · Yudong Gao 等 · cs.CR / cs.AI

## 1. 核心速览

**研究主题**：量化 VLA 模型的 INT8 权重位翻转安全性。
**一句话总结**：INT8 并不只是部署格式，也形成了可被 Rowhammer 类故障利用的攻击面；梯度定向的极少数位翻转即可让部分 VLA 的闭环成功率归零。

## 2. 研究背景与动机

已有位翻转研究多聚焦分类器或语言模型，具身模型还叠加了动作头结构和闭环误差累积。论文因此问：不同动作解码头是否会改变“最少破坏位数”，以及保护少量关键权重能否形成有效防线。

## 3. 核心方法与创新点

- 在量化权重上用梯度选择候选 bit，而非随机破坏；针对流匹配头提出固定方向的 manifold-escape 损失。
- 覆盖直接回归、动作 token 和 flow matching 三类动作头、四个模型变体，并做五方向对照，避免结论依赖单一正方向。
- 根据危险位集中层构造选择性保护，仅保护很小的权重子集。

## 4. 实验设计与结果

定向攻击把直接回归和 token 策略的破坏预算压到 **1–5 bit**，而所测 flow-matching 策略通常需约 **100–300 bit**；随机翻转数百位仍基本无害。固定方向损失把 π0 的预算从约 **1000** 降至约 **100**。在直接头上，保护 **3.1%** 权重可在 K=100 时保留 **60%** 成功率，保护 **5.3%** 可把开放环破坏阈值从 3 推到 100。真实机器人校准的 K=100 攻击得到 **0/20** 成功，对照为 clean **14/20**、全局随机 **16/20**。

## 5. 局限性与未来展望

威胁模型依赖可控 INT8 位故障，尚未覆盖其他精度格式、ECC/内存布局和更多 VLA 家族；模型间预算不能脱离具体量化映射与硬件直接比较。后续应联动硬件故障注入、关键层冗余和完整性校验。

## 6. 学术启发

压缩评估不能只报任务精度和速度，还应把离散编码的安全鲁棒性作为第三轴；“动作头架构决定攻击预算”也说明，压缩格式与输出参数化需要联合设计。

**证据边界**：方法、设置和数字核对自 arXiv 官方 HTML 全文；本文复现仅验证 Qwen3 INT8 位翻转机制，不声称复现实机 VLA 闭环。
