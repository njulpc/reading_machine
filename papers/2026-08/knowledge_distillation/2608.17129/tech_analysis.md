# PROBE: Manipulation-Grounded Visual Question Answering with VLM Agents

- arXiv: [2608.17129](https://arxiv.org/abs/2608.17129)
- 提交日期（v1）：2026-08-17
- 作者：Vineet Bhat, Siyi Chen, Alex Zook, Xuning Yang, Stan Birchfield, Valts Blukis, Jonathan Tremblay
- 分类：cs.CV, cs.RO
- 证据边界：基于 arXiv 摘要与 11 页 v1 PDF。论文把教师轨迹监督称为 distillation，但训练形式是混合直接/agentic 轨迹上的 SFT，而非 logit 或特征蒸馏。

## 1. 核心速览

**研究主题：** 将强闭源 VLM 教师在可交互场景中的成功工具调用轨迹蒸馏到 8B/15B 开源 VLM agent。

**一句话总结：** PROBE-Agent 用 Gemini 3.1 Pro 生成的 2,947 条模拟轨迹微调 Qwen3-VL-8B 与 NVILA-15B，使五类训练任务宏平均成功率分别从 48.1%→67.8% 和 51.7%→69.1%，并在未见 Beneath 任务及真实机器人上保持迁移。

## 2. 研究背景与动机

传统 VQA 默认视觉证据已经可见，但真实机器人常需先移动遮挡物才能回答问题。单次图像感知无法解决“药还在柜子里吗”这类动态场景问题，agent 必须决定何时使用 grasp、push、observe 等工具，并在动作改变场景后继续推理。

强前沿模型能完成部分任务，却难以本地部署；小型开源 VLM 即使获得同一工具集，也常在目标选择、动作时机和长程规划上失败。因此论文不仅提出 PROBE-Sim/Bench，还测试能否把教师成功轨迹压入较小模型。

## 3. 核心方法与创新点

1. **MG-VQA 任务定义。** PROBE-Bench 包含 150 个任务、6 类问题，要求 agent 在桌面遮挡场景中感知、移动物体再作答。
2. **混合教师数据。** 用 Gemini 3.1 Pro 分别以 direct 与 agentic 模式在程序生成场景中采样轨迹；训练资产池含 1,437 个对象/布局，与评测完全不重叠。
3. **能力组合留出。** 训练覆盖 Count、Find、Compare、Size、Reduce，共 2,947 条；Beneath 的 26 个评测样本完全不出现在训练中，用来测试已学技能的组合泛化。
4. **小模型轨迹蒸馏。** Qwen3-VL-8B 与 NVILA-15B 以学习率 `2e-5`、batch 32、2 epochs 在 8×A100 上 SFT。知识载体是动作—观察—答案序列，不要求访问教师权重。

## 4. 实验设计与结果

- 模拟评测：两个 student 各在 150 个任务上运行 3 次。Qwen3-VL-8B 从 48.1% 升至 67.8%，NVILA-15B 从 51.7% 升至 69.1%，达到或超过教师在五类训练任务上的 67.6% 宏平均。
- 未见任务：Qwen3-VL-8B 在 Beneath 从 46.2%→53.8%（+7.6pp）；NVILA-15B 从 30.4%→45.8%（+15.4pp），但仍低于教师 76.9%，说明组合规划尚未被完全压缩。
- 真实机器人：Kinova Jaco、25 个对象、15 个任务。Qwen3-VL-8B-SFT 成功率由 34.4% 升至 70.0%，接近 Gemini 3.1 Pro agentic 的 78.9%；教师 direct 模式只有 10.0%。
- 论文观察到 agentic 工具访问相对纯感知平均提高约 8.0%，但 Reduce 等任务仍容易因早期选错目标而级联失败。

## 5. 局限性与未来展望

- 只覆盖固定机械臂、桌面环境和离散工具库，模型无法在失败后创造新工具或连续控制策略。
- 训练数据来自单一强教师，无法区分提升来自教师质量、数据量还是 direct/agentic 混合比例。
- Bench 由单一领域专家验证，场景与标注多样性有限；真实机器人仅 15 个任务，置信区间未充分展开。
- SFT 轨迹蒸馏没有显式压缩倍率或延迟/内存比较，属于能力迁移而非结构压缩；后续应报告小模型相对教师的部署成本并加入多教师、失败轨迹和在线纠错。

## 6. 学术启发

agent 蒸馏的关键不只是复制最终答案，而是保留“何时调用工具、选哪个目标、何时再次观察”的决策边界。PROBE 的未见 Beneath 任务说明，轨迹数据若覆盖可组合的原子技能，较小模型能出现一定组合迁移；这为把昂贵 agent 压缩成端侧策略提供了比静态问答蒸馏更贴近部署的评测范式。
