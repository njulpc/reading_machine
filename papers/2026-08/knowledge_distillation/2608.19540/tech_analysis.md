# 技术精读：Continuous Adversarial MeanFlow Transfer

> arXiv: [2608.19540](https://arxiv.org/abs/2608.19540)；v1 提交：2026-08-20；主分类：cs.LG。

## 1. 核心速览

**研究主题**：异构扩散/流模型的统一少步迁移与对抗蒸馏。
**一句话总结**：MF-T 先把 ε/x/v/u 四种预测参数化映射到统一 velocity，再训练 MeanFlow；CAMF 用有限区间平均速度上的对抗信号补回细节，在五个目标域平均改善少步 FID 29%，最高用 125× 更少 NFE 追平或超过微调教师。

## 2. 研究背景与动机

小数据域迁移通常只解决“换域”，保留了源扩散模型多步采样成本；现有加速方案又常绑定某一种预测参数化。MeanFlow 预测有限时间区间的平均速度，已有连续对抗流方法却针对瞬时速度，直接套用会产生目标错位。

## 3. 核心方法与创新点（分点）

1. 将 DiT(ε)、SiT(v)、JiT(x)、iMF(u) 的输出统一变换为 velocity，直接用源权重初始化 MeanFlow 学生。
2. MF-T 在目标域联合完成域适配与少步生成训练，不再为每种源参数化维护独立蒸馏接口。
3. CAMF 在真实端点与预测区间端点之间学习 potential change，把连续对抗目标扩展到有限区间平均速度；区间趋零时退化为原瞬时准则。
4. 对抗阶段补偿均方 MeanFlow 回归容易平均掉的高频细节，形成回归稳定性与分布级锐度的互补。

## 4. 实验设计与结果

实验从四种 ImageNet 源模型迁移到五个目标域，比较微调教师和多种少步基线，并用 FID/FDD 衡量分布质量。MF-T 显示 velocity mapping 比 schedule alignment 更稳定；加入 CAMF 后少步 FID 平均改善 29%，在最多 125× 更少 NFE 下仍能匹配或超过 fine-tuned source teacher。论文同时做参数化映射、初始化和 CAMF 消融，说明收益不是单纯来自更多后训练。

## 5. 局限性与未来展望

对抗后训练引入额外判别器、训练不稳定和超参数成本；五个目标域仍集中于图像生成。125× 是 NFE 比，不等价于端到端墙钟或能耗同比，且少步 kernel/批大小可能改变真实收益。未来需要视频、文本到图像大模型和真实部署吞吐验证。

## 6. 学术启发

“先统一预测语义，再统一压缩算法”是迁移异构生成器的有效范式。对扩散蒸馏，回归目标负责轨迹，分布目标负责感知细节；二者的对象必须与学生真正预测的数学量一致，不能只复用名字相近的损失。
