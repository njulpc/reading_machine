# UniFed-VLM：技术精读

> arXiv: [2608.15516](https://arxiv.org/abs/2608.15516) · submitted 2026-08-16 · Pengyu Wang 等 · cs.LG

## 1. 核心速览

**研究主题**：任务、模态和模型架构同时异构时的联邦 VLM 指令微调。
**一句话总结**：UniFed-VLM 用补偿式低秩子空间聚合解决同构 adapter 冲突，再用两阶段协同蒸馏跨 LLaVA 与 Show-O 传递知识。

## 2. 研究背景与动机

FedAvg 假定参数结构一致，而真实客户端可能分别承担 VQA、分类、描述和视觉定位，并使用完全不同的 VLM。只做 LoRA 聚合会丢失异构方向，只做 logit 蒸馏又难以同时处理任务和模态差异。

## 3. 核心方法与创新点

- FedCSA 先对 adapter 子空间对齐，再动态加权聚合；补偿参数用于恢复低秩聚合损失的信息。
- TCoD 先训练 Mutual Distillation Adapter，再以 MoE 路由组织跨模型蒸馏，保留客户端原注意力作为 anchor expert。
- 把参数级协作和跨架构知识转移拆成两个阶段，适配多维异构。

## 4. 实验设计与结果

实验使用 Fed-Nature（COCO 派生、每任务 5000 train/1000 test）和非 IID 的 Fed-Crossdomain；模型为 LLaVA-1.5（ViT-B/32 + Llama-3.2-3B）与 Show-O-1.5B。训练 **20** 轮通信，4×A100-40GB，Adam 学习率 1e-4 衰减到 1e-6。Fed-Nature 场景 1 中，方法达到 VQA **0.743**、VG IoU **0.519**、分类 **0.918**；去掉 TCoD 后 VQA 降 **3.6 点**、IoU 降 **0.061**。分类 91.8% 还略高于集中式上界 91.3%。

## 5. 局限性与未来展望

验证集中在两个 VLM 架构和固定任务组合，且真实隐私仍取决于更新泄露防护；20 轮小规模客户端设置不能证明大规模异步 FL 的稳定性。可继续研究安全聚合、客户端动态加入和蒸馏通信压缩。

## 6. 学术启发

跨架构蒸馏不应替代参数聚合，而应成为“不可对齐部分”的补偿通道；消融结果也表明，异构压缩/协作需同时关心表示空间和输出知识。
