# 技术深度分析：SparsePR Training-Free Sparse Attention

> arXiv: [2608.18484](https://arxiv.org/abs/2608.18484) · v1: 2026-08-19 03:16:09 UTC · 主分类：cs.CV

## 1. 核心速览

**研究主题**：视频生成与世界模型中的无训练块稀疏注意力。

**一句话总结**：SparsePR 用响应耦合分区解决共享路由支持不一致，再用 64 条精确 probe 行拟合被跳过交互的残差；在 22%–26% 实际执行 pair 密度下保持接近稠密生成质量，并取得 1.48×–2.61× 端到端加速。

## 2. 研究背景与动机

注意力行的质量集中并不自动产生可执行块稀疏模式：共享同一路由块的 query 可能拥有低重合支持，而且保留的 softmax mass 不能决定 renormalized hard-drop 的输出误差。视频 Transformer 序列巨大，现有无训练稀疏注意力常把“支持选择”和“跳过项处理”分开，导致稀疏率相近但误差差异很大。

## 3. 核心方法与创新点

- **Response-Coupled Partitioning**：用采样 query 对 K/V 的响应形成配对分组，以 K/V centroid 构造 query-response 坐标，令共享路由与实际响应几何一致。
- **Probe-Fitted Residual Reconstruction**：预留 M=64 条 query 行做精确注意力，利用其稀疏输出与真实残差拟合 call-specific 仿射修正。
- 将残差限制在 probe 观察到的 rank-16 输出子空间，并用 ridge λ=0.1 稳定估计。
- 显式计入 probe 行的 pair 成本，报告真实执行密度而非理想路由密度。

## 4. 实验设计与结果

全部实验用单张 H100 BF16，覆盖 HunyuanVideo-13B、Wan2.2-I2V-A14B、Cosmos-Predict2.5-14B 与 Cosmos3-Nano-16B。前三者目标执行密度 22%，Cosmos3 为 26%。SparsePR 在四模型上的实际密度约 21.92%、21.97%、22.14%、25.96%，端到端加速分别 2.61×、1.80×、1.51×、1.48×；Wan2.2 总生成延迟从 1650 秒降到 917 秒，残差拟合仅占 1.1% 延迟。

质量方面，HunyuanVideo 的 ImgQual/SubCons 为 0.850/0.976，与稠密 0.850/0.976 一致；Wan2.2 为 0.687/0.973，对比稠密 0.689/0.974。22% 左右密度的注意力输出 mean/p99 归一化误差在 HunyuanVideo 上从 semantic partition hard-drop 的 0.0887/0.7136 降至 0.0330/0.2285，在 Wan2.2 从 0.1634/1.7338 降至 0.0707/0.4305。

## 5. 局限性与未来展望

论文依赖 H100 与特定视频模型实现，没有验证语言模型长上下文或消费级硬件；分区、probe 与残差拟合虽无训练但仍有在线开销。固定 M=64、rank=16 和密度目标可能不是所有层/时刻的最优选择；未来可学习动态 probe 数和按误差自适应密度。

## 6. 学术启发

稀疏注意力应作为完整数值算子设计：支持共享方式决定可执行块，跳过项的残差决定输出误差。仅比较 retained mass 或理论稀疏率容易失真；更可靠的评价应同时报告实际 pair 密度、端到端延迟、输出误差尾部和任务质量。
