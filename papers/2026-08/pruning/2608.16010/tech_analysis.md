# BRIDGE：技术精读

> arXiv: [2608.16010](https://arxiv.org/abs/2608.16010) · submitted 2026-08-17 · Zhaocen Liu 等 · cs.LG / cs.CV

## 1. 核心速览

**研究主题**：极端稀疏区间的反向再生式剪枝边界学习。
**一句话总结**：BRIDGE 先故意把模型推过性能悬崖，再定位结构破坏最严重的层并分层 regrow，使“压缩极限”从前向删减问题变成边界恢复问题。

## 2. 研究背景与动机

常规剪枝从 dense 向 sparse 单向推进，在临界稀疏度后准确率突然坍塌；不同剪枝准则都出现类似悬崖，说明问题更像模型内生边界而非某个准则失效。

## 3. 核心方法与创新点

- 由准确率-稀疏度曲线的二阶差分定位 collapse point。
- 以 layer-wise SSIM 选出结构破坏层；空间维过小时用 cosine similarity 补充。
- coarse stage 选层，fine stage 用 REINFORCE 选参数/通道 regrowth，奖励为相对同稀疏度基线的归一化精度改善。

## 4. 实验设计与结果

覆盖 4 种 CNN/Transformer 架构、结构化与非结构化剪枝，单模型搜索低于 **10 GPU-hours**。最高精度增益为非结构化 **+1.49%**、结构化 **+4.77%**。Raspberry Pi 5（8GB、ONNX Runtime 1.26、4 CPU threads）部署中，结构化 VGG16 最高达 **43.2×** 加速；论文强调 FLOPs 并非设备延迟的可靠代理。

## 5. 局限性与未来展望

方法需要先越过性能悬崖并微调 regrow 模型，搜索成本高于一次剪枝；SSIM/cosine 仍是代理指标。超大模型、无校准数据和不可训练权重场景尚未验证。

## 6. 学术启发

压缩边界可以通过“破坏后修复”识别；局部层的表示坍塌比全局权重幅值更适合作为极端稀疏诊断信号。
