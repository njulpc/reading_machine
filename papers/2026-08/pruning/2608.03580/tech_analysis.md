- 作者: Yaozhi Wen, Jialong Guo, Zhenliang Ni, Han Shu, Xinghao Chen

## 1. 核心速览

### 1.1 研究主题

本文研究视觉-语言模型（VLMs）的结构化剪枝压缩问题。核心主题是如何在压缩 VLM 参数规模的同时保持其多模态任务性能，关键创新在于将自适应视觉 token 选择与敏感度感知的动态剪枝机制相结合——前者消除冗余视觉 token 对重要性估计的干扰，后者根据各模块对稀疏性的不同容忍度自动确定剪枝比例。

### 1.2 一句话总结

论文提出 SlimVLM 结构化剪枝框架，通过基于文本-视觉注意力分数的自适应视觉 token 选择策略剔除冗余视觉 token 以优化重要性计算，并引入基于线性重建误差的敏感度感知动态剪枝机制为不同模块分配差异化剪枝比例，在多个多模态基准上超越现有方法达到 SOTA 性能。

## 2. 研究背景与动机 (Background & Motivation)

视觉-语言模型（VLMs）在处理和理解文本与图像方面展现了卓越性能，但其庞大的参数规模带来了显著的计算开销，严重限制了其在资源受限设备上的部署。这一矛盾在移动端、边缘端等场景中尤为突出——用户期望获得强大的多模态理解能力，但设备算力、内存和功耗预算有限。因此，如何有效压缩 VLMs 同时保持其任务性能，成为了一个关键的研究问题。

**剪枝在 LLM 上的成功与 VLM 上的失败。** 剪枝（pruning）作为模型压缩的经典手段，在压缩大型语言模型（LLMs）方面已被证明是有效的。结构化剪枝能够实际减少参数和计算量（而非仅产生稀疏矩阵），适合硬件加速。然而，论文敏锐地发现：**直接将 LLM 剪枝方法应用于 VLMs 会导致显著的性能下降**。这一现象背后的根本原因是 VLM 独有的多模态结构——VLM 在 LLM 基础上引入了视觉编码器和视觉-文本连接器，产生了大量的视觉 token。这些视觉 token 与文本 token 的统计特性、重要性分布截然不同。

**冗余视觉 token 干扰重要性估计。** 这是论文识别的核心痛点。VLM 中视觉 token 通常数量庞大且存在大量冗余（一张图像产生数百甚至上千个视觉 token，其中许多对应背景或无关区域）。在进行结构化剪枝时，需要对模型各通道/模块的重要性进行评估，而重要性评估通常依赖于激活值或梯度等统计量。冗余视觉 token 的存在使得重要性统计被"稀释"或"污染"——大量低信息量的视觉 token 参与计算，使得真正重要的通道或模块的重要性信号被掩盖，导致剪枝决策错误，进而引发性能崩塌。

**不同模块对稀疏性的容忍度差异。** VLM 由多个功能模块组成：视觉编码器、投影层（projector）、LLM 各层等。这些模块承担不同功能，对参数稀疏性的容忍度各不相同。视觉编码器可能对剪枝较敏感（因为视觉特征提取需要更密集的表示），而 LLM 的某些 FFN 层可能对剪枝较鲁棒。如果对所有模块施加统一剪枝率，敏感模块会过度受损，鲁棒模块又压缩不足。这一"一刀切"问题也是现有方法的不足。

论文的动机由此清晰：需要一种（1）能消除冗余视觉 token 对重要性估计干扰的、（2）能根据模块敏感度差异化分配剪枝比例的 VLM 专用结构化剪枝框架。

## 3. 核心方法与创新点 (Methodology & Innovations)

SlimVLM 框架包含两个核心创新组件，二者协同构成完整的 VLM 剪枝方案：

**1. 自适应视觉 token 选择策略**

这是解决"冗余视觉 token 干扰重要性估计"痛点的关键创新。具体设计如下：

- **重要性指标**：利用**平均文本-视觉注意力分数（average text-to-visual attention scores）**来评估每个视觉 token 的重要性。这一指标直接反映了视觉 token 与文本内容的关联程度——注意力分数高意味着该视觉 token 被文本查询频繁"关注"，对理解文本-图像关系贡献大；注意力分数低则意味着该 token 是冗余的背景或无关信息。
- **阈值驱动的移除**：基于设定的阈值，移除注意力分数低于阈值的冗余视觉 token。阈值的选择控制了移除的激进程度。
- **优化重要性计算**：通过先移除冗余视觉 token，再进行模块重要性评估，使得重要性统计不再被低信息量 token 稀释或污染，从而获得更准确、更可靠的重要性估计，指导后续结构化剪枝做出更优决策。

这一策略的关键洞见是：**视觉 token 选择与结构化剪枝不应是独立的两个步骤，而应耦合在一起**——视觉 token 的清理是确保剪枝决策正确性的前提。

**2. 敏感度感知的动态剪枝机制**

这是解决"不同模块容忍度差异"痛点的核心创新。具体设计如下：

- **敏感度度量**：通过计算剪枝前后模块输出的**线性重建误差（linear reconstruction error）**来衡量每个模块对剪枝的敏感度。具体地，对某模块进行剪枝后，用其未剪枝版本的输出作为目标，衡量剪枝版本输出的重建误差。误差越大说明该模块对剪枝越敏感（剪枝后输出偏离越大），误差越小说明越鲁棒。
- **动态剪枝比例分配**：根据计算得到的敏感度，为每个模块动态确定适当的剪枝比例。敏感度高的模块分配较低的剪枝比例（少剪以保护），敏感度低的模块分配较高的剪枝比例（多剪以压缩）。这种"按需分配"确保了整体性能稳定——不会因为某个敏感模块被过度剪枝而导致全局性能崩塌。

这种基于重建误差的敏感度度量是一种数据驱动、无需人工调参的自适应方法，能够自动为不同 VLM 架构找到合适的模块级剪枝配置。

**3. 协同设计**

两个组件并非简单串联，而是协同设计：自适应视觉 token 选择为敏感度计算提供更干净的重要性信号，敏感度感知的动态比例确保在 token 选择的基础上对模型结构进行最优压缩。整个框架形成"视觉 token 清理 → 模块敏感度评估 → 差异化结构剪枝"的闭环优化流程。

## 4. 实验设计与结果 (Experiments & Results)

论文在多个多模态基准上进行了实验评估，核心设计如下：

**核心成果**：
- SlimVLM 在多个多模态基准上**超越了现有方法**，达到了**当前最优（state-of-the-art）性能**。这验证了"视觉 token 选择 + 敏感度动态剪枝"协同设计相对于现有剪枝方法的优越性。

**实验设置推断**：
- 测试了多个多模态基准任务（如图像描述、视觉问答、图像分类等多模态理解任务），全面评估压缩后模型的能力保持情况。
- 对比基线预期包括：直接应用 LLM 剪枝方法到 VLM、无视觉 token 选择的剪枝、固定统一剪枝率的剪枝等，以分别验证两个核心组件的贡献。
- 消融实验预期验证：视觉 token 选择对重要性估计质量的提升、动态比例相对于固定比例的增益。

**效率收益**：
- 虽然摘要未给出具体的参数压缩比和加速比数值，但作为结构化剪枝框架，SlimVLM 能够实现实际的参数和 FLOPs 减少（而非仅产生非结构化稀疏），这意味着压缩后的模型可以直接在标准硬件上获得推理加速，无需专用稀疏计算支持。

## 5. 局限性与未来展望 (Limitations & Future Work)

**注意力分数依赖的局限**：自适应视觉 token 选择依赖文本-视觉注意力分数，这要求在剪枝时有代表性的校准数据（含文本-图像对）来计算注意力。注意力分数的分布可能受输入分布影响，若校准数据与实际部署数据分布不匹配，token 选择质量会受影响。

**线性重建误差的近似性**：敏感度度量使用线性重建误差，这是一个局部线性近似。对于高度非线性的模块或存在模块间复杂交互的情况，线性近似可能不足以准确刻画真实敏感度，导致比例分配偏离最优。

**视觉编码器与 LLM 的联合优化**：当前框架可能主要关注 LLM 部分的剪枝，视觉编码器本身的结构化剪枝是否同样受益于 token 选择机制有待探索。VLM 的视觉编码器通常占相当比例的参数，压缩空间较大。

**未来展望**：可探索将 SlimVLM 与量化、知识蒸馏联合，实现多级压缩；研究在线/动态视觉 token 选择（根据每个输入自适应，而非固定阈值）；将敏感度感知机制扩展到更细粒度（如通道级、头级）；探索在训练感知（training-aware）剪枝范式下引入 token 选择。

## 6. 学术启发 (Takeaways for My Research)

**"先清理干扰再做决策"的方法论**：SlimVLM 最深刻的洞见是——冗余视觉 token 会干扰重要性估计，导致剪枝决策错误。这一"干扰源清理优先于决策"的方法论具有广泛迁移价值。在任何基于统计量的决策系统中（如特征选择、超参搜索、模型选择），都应先识别并消除可能干扰统计量的噪声源，再做决策。例如在量化敏感度评估中，应先识别激活异常值并隔离处理，再评估各层量化敏感度。

**模态特异的剪枝设计**：VLM 不能直接套用 LLM 剪枝方法，因为多模态结构引入了新的复杂性。这启示我在研究任何多模态或多组件模型的压缩时，都应深入分析各模态/组件的特殊性，设计针对性的压缩策略，而非简单迁移单模态方法。

**基于重建误差的敏感度度量**：用"剪枝前后输出的重建误差"作为敏感度指标，是一种简洁有效的数据驱动度量方式。这种思路可迁移到：量化中用输出 MSE 评估各层量化敏感度、蒸馏中用特征距离评估各层蒸馏难度、模型分片中用重建误差评估各层对通信的敏感度。

**差异化分配理念**：不同模块/层应有不同的压缩力度，这是压缩优化中的普遍原则。动态比例分配避免了"一刀切"的次优性。在自己的研究中，遇到任何需要全局分配资源（压缩率、比特宽度、缓存大小）的场景，都应考虑基于敏感度/重要度的差异化分配。
