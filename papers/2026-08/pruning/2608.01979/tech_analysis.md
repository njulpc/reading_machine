# 深度技术分析：ET-Prune: Evidence-Aware Dynamic Budgeting for Visual Token Pruning in Text-Rich MLLMs

## 1. 核心速览

**研究话题**：面向文本密集（text-rich）多模态大语言模型（MLLM）的视觉 token 剪枝，将剪枝重新表述为问题条件化的"证据分配"问题，并提出逐样本动态预算。

**一句话总结**：ET-Prune 是一个 training-free 框架，通过解码侧 partial-QK 读取问题条件证据、保护文本样区域、并将证据不确定性与密度转化为逐样本 token 下限，再经三层渐进压缩达成预算；在保留约一半视觉 token 时，于六组 backbone-基准对比中全部领先或持平，OCRBench-v2 上较最强剪枝基线在 Qwen3-VL-8B 与 InternVL3.5-8B 分别领先 1.80 与 0.68 pp，MMBench v1.1 上以 54.45% 平均保留达到 0.8467 环形精确匹配精度（Vanilla 为 0.8437）。

---

## 2. 研究背景与动机 (Background & Motivation)

### 2.1 文本密集 MLLM 的推理成本困境

MLLM 在 OCR 类任务（场景文本问答、文档理解、图表推理、屏幕推理）上表现优异，但这些能力依赖高分辨率视觉输入，进而产生极长的视觉 token 序列，推高解码计算、KV-cache 显存与 prefill 延迟，在资源受限的边缘设备上尤甚。视觉 token 剪枝是直接降低该开销的手段。

### 2.2 固定保留比例在文本密集输入上的三大失效

现有方法（FastV、SparseVLM、PyramidDrop、IVC-Prune、ZOO-Prune）通常用通用注意力、特征幅度或冗余准则排序 token，并施加**固定保留比例**。论文观察到三个关键挑战：

1. **证据小而隐蔽**：与答案直接相关的文本区域可能很小且视觉不显著，通用显著性易将其丢弃。
2. **相关性随指令剧变**：识别一种颜色与誊写收据总额需要截然不同的视觉区域；同一张图，不同问题需要保留的 token 完全不同。
3. **所需证据量因输入而异**：全局保留比例对简单样本过度分配 token，对困难样本保护不足。

### 2.3 数据集级证据异质性分析

论文在 15,194 个 Qwen3-VL 输入（来自 TextVQA、OCRBench-v2、OCRBench-mini）上做了证据异质性分析，用"有效证据跨度"（question-to-visual 亲和度的熵等价支撑规模）刻画：

- 最小 token 桶中，固定 50% 预算平均留 66 token，而证据跨度为 86 token（保护不足）；
- 最大 token 桶中，留 277 token 而证据跨度仅 255 token（过度分配）。

这用数据证明了"全局比例既非一致保守也非一致激进"，从而驱动了逐样本动态预算的设计。

### 2.4 动机总结

文本密集 OCR 任务的证据往往既局部化又条件化：一个问题可能要求精确誊写一个小数字/标签/字段，其相关性由问题指定；不加区分的剪枝会擦除该证据却保留视觉显著但无关的区域。这促使 ET-Prune 将剪枝表述为"问题感知的证据分配"。

## 3. 核心方法与创新点 (Methodology & Innovations)

ET-Prune 是 training-free 的中间层剪枝框架，由三个协同组件构成，全部在当前输入与冻结的 MLLM 表示上操作，不改变模型权重与解码流程。

### 3.1 问题条件证据读取器（Question-Conditioned Evidence Reader）

从解码侧的 **partial query-key block** 提取 question-to-visual 亲和度。具体地，利用问题 token 跨度 $Q$ 对视觉 token 的注意力分布，得到每个视觉 token 的"问题条件证据分数"。这与仅用视觉塔自身显著性或早期 text-to-vision 注意力的方法不同：它直接建模"该 token 对回答当前问题有多重要"。

### 3.2 文本证据保护（Text-Evidence Safeguard）

将轻量空间线索映射到"文本样"成分，并显式保护其 token 支撑。理由是：文本样区域的证据在 patch 级移除下非常脆弱——一个小字可能横跨几个 patch，移除任一就可能断裂答案承载 span。该组件确保文本密集区域不被通用显著性低估。

### 3.3 风险校准的动态预算器（Risk-Calibrated Dynamic Budgeting）

将三类信号转化为**逐样本 token 下限**：

- **证据不确定性**：question-to-visual 亲和度的弥散程度。弥散表示多个区域可能支撑答案，需保留更多 token。
- **文本密度**：文本样区域占比高时，逐 patch 移除更易断裂答案 span，应保留更多。
- **保护区域流行度**：受保护文本区域的规模。

公式化目标为：

$$\max\;\mathbb{E}[\mathcal{A}(I,x;\widehat{V})]\quad\text{s.t.}\quad\mathbb{E}[|\widehat{V}|]\leq\bar{K}$$

即平均视觉预算受控，但不强加相同压缩强度于每个输入。证据弥散或文本密集时分配更多容量，证据集中时更激进剪枝。

### 3.4 渐进中间层实现（Progressive Middle-Layer Realization）

三个渐进的中间层"事件"将序列推向逐样本预算：

- 在中间层分阶段压缩，保留更多 token 给弥散/文本密集证据，对集中证据更激进剪枝；
- 模型权重与解码过程保持冻结。

这种渐进式而非一次性剪枝，避免了单层剧烈剪枝的信息断裂，同时保证最终 token 数收敛到动态预算。

### 3.5 复杂度与部署

所有组件在输入与冻结表示上操作，无需训练，无需修改解码器，可与现有 MLLM 即插即用。代码开源于 https://github.com/Labyrinth0419/ET-Prune。

## 4. 实验设计与结果 (Experiments & Results)

### 4.1 实验设置

- **Backbone**：Qwen3-VL-8B、InternVL3.5-8B 两个核心 MLLM。
- **基准**：OCRBench-v2（双语定位/解析/知识/推理）、TextVQA、MMBench v1.1，以及跨基准迁移测试。
- **基线**：五个 training-free 剪枝基线——FastV（早期 text-to-vision 注意力一次性移除）、SparseVLM（文本相关性多层稀疏）、PyramidDrop（随深度渐进剪枝）、IVC-Prune（隐式视觉坐标）、ZOO-Prune（零阶扰动估计输出敏感度）。
- **预算**：匹配的剪枝预算（约保留一半视觉 token），单次确定性前向的点估计。

### 4.2 核心质量结果

**六组 backbone-基准对比**：在保留约一半视觉 token 时，ET-Prune 在全部六组对比中**领先或持平**所有剪枝基线。

**OCRBench-v2（代表性工作点）**：

| Backbone | ET-Prune 相对最强剪枝基线领先 |
|---|---|
| Qwen3-VL-8B | +1.80 pp |
| InternVL3.5-8B | +0.68 pp |

保留约一半视觉 token，在 Qwen3-VL-8B 上保留 Vanilla 分数的 93.0%、FLOPs 的 69.0%，体现质量-效率权衡。

**MMBench v1.1**：环形精确匹配精度 0.8467（ET-Prune）vs 0.8437（Vanilla 全 token），平均视觉 token 保留 54.45%——即剪掉近一半 token 后精度反超全 token 基线。

### 4.3 跨 OCR 之外的可迁移性

在非 OCR 基准上的迁移测试表明，ET-Prune 的证据感知机制不局限于文本密集场景，对一般多模态理解也保持竞争力。

### 4.4 定性证据保留

图示对比显示：在需保留小答案标签的样例上，FastV/PyramidDrop/IVC-Prune（分别保留 50%/50%/53%）会模糊答案承载标签，而 ET-Prune（保留 61%）能保留这些关键标签。这直观验证了"证据保护"的有效性。

### 4.5 兼容性与效率

- 与现有 MLLM 即插即用，无需重训练；
- 报告了剪枝深度、模型规模、推理效率与跨基准迁移的消融。

### 4.6 保留目标消融

对逐样本预算的下限设定做消融，验证动态预算相对固定比例的增益来源。

## 5. 局限性与未来展望 (Limitations & Future Work)

### 5.1 局限性

- **依赖 partial-QK 的可用性**：问题条件证据读取依赖解码侧 partial query-key block，对注意力结构不同的架构（如无显式 QK 的线性注意力/SSM 多模态模型）适配性不明。
- **点估计而非分布**：结果为单次确定性前向的点估计，未报告跨随机种子的方差；动态预算的稳定性需更多统计证据。
- **文本检测的轻量性权衡**：文本样区域的空间线索用轻量方法获取，可能在复杂版式（表格嵌套、弯曲文本、低对比度）上漏检，影响保护质量。
- **仅 8B 规模**：缺少更大规模（30B+）与更小规模（端侧 2-3B）MLLM 的验证；动态预算在极端规模下的行为未探。
- **未做端到端延迟实测**：报告 FLOPs 与 token 保留比，但未给出实际 prefill/解码墙钟延迟与显存节省的硬件实测数据。
- **与训练型方法的对比缺失**：仅与 training-free 基线比，未与 DiffPrune 等训练型剪枝器在同一 backbone 上对比。

### 5.2 未来方向

- 将证据分配思想与 token 合并/恢复结合，保留被剪 token 的信息而非纯丢弃。
- 探索在视频 MLLM（时序证据）与多图文档场景的扩展，动态预算需建模时序/跨图证据。
- 引入轻量学习（如少量标注训练一个证据打分器）以超越 training-free 上限。
- 与 KV cache 压缩联合优化，证据感知预算同时指导视觉 token 与 KV 保留。

## 6. 学术启发 (Takeaways for My Research)

### 6.1 "逐样本动态预算"应成为剪枝的默认考量

ET-Prune 用 15,194 样本的数据集级分析硬证了"固定比例既非一致保守也非一致激进"。这与 F-WANDA 的"逐行自适应预算"思想在样本维度上呼应。启示我：在任何剪枝/压缩任务中，应先做"预算维度异质性分析"，识别哪些维度（样本/层/头/通道）还在用固定预算，再设计自适应分配。

### 6.2 问题条件化是 VLM 剪枝的关键

通用显著性（注意力/范数/冗余）忽略了一个事实：token 重要性由问题指定。ET-Prune 的 partial-QK 问题条件读取是一个简洁有效的实现。在我的多模态压缩研究中，应确保重要性信号是 query-conditioned 而非 query-agnostic，否则会保留"显著但无关"的区域。

### 6.3 脆弱证据的显式保护

文本样区域在 patch 级移除下脆弱这一观察极具启发性：不同 token 的"移除后果"非对称，小而关键的证据需显式保护。我可在我的剪枝中引入"脆弱性/不可恢复性"权重，对移除后果严重的结构给予保护加成。

### 6.4 渐进中间层剪枝的工程经验

三层渐进压缩而非单层一次性剪枝，避免信息断裂。这一工程经验可直接用于我的多层 token/KV 压缩实现：分阶段、按深度递进，比单点激进取舍更稳。

### 6.5 数据驱动的动机呈现范式

论文用 15,194 样本的证据跨度分析驱动方法设计，是"用数据讲动机"的典范。我应在论文动机部分用类似的大样本统计分析（而非个别样例图）来证明"现有方法的假设失效"，使方法设计的必要性更具说服力。

### 6.6 与 F-WANDA/DiffPrune 的互补性思考

ET-Prune（training-free、样本动态预算、问题条件）、F-WANDA（训练后、行级 Fisher 预算）、DiffPrune（训练型、可微节流）三者分别从"样本维度""神经元维度""训练范式"推进剪枝。在我的研究中，可考虑将三者的维度正交组合：例如用 DiffPrune 的可微训练学一个问题条件的逐样本预算器，再用 F-WANDA 式 Fisher 信号做行级细化。
