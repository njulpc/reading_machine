- 作者: Yanning Hou, Jingyuan Zhang, Xiaoyun Wang, Qixiang Ma, Sihang Zhou, Ke Xu
- 发布日期: 2026-08-04

## 1. 核心速览

### 1.1 研究主题

本文研究零样本视觉异常检测（zero-shot visual anomaly detection）的推理效率优化问题，核心聚焦于一种专门为异常检测设计的"保缺陷"token 剪枝框架 KeepAD。该框架将 token 选择建模为高召回率的异常感知路由问题，在浅层和深层分别采用不同策略，确保在大幅削减 token 数量的同时不丢失异常证据，实现高效且保真的零样本异常检测。

### 1.2 一句话总结

论文提出 KeepAD 框架，将 token 选择建模为高召回异常感知路由，在浅层通过 2x2 邻域覆盖保留选择与确定性异常救援降低误删风险，在深层通过冻结正常/异常原型引导图像自适应预算剪枝，并辅以稠密-稀疏自蒸馏，在 6 个工业和 7 个医学基准上将 token 保留率降至 20% 以下，AUROC 退化控制在 2.7 个百分点内，最激进设置下实现 7.9 倍加速。

## 2. 研究背景与动机 (Background & Motivation)

零样本视觉异常检测近年来取得了显著进展，尤其是仅视觉（vision-only）方法进一步提升了性能并简化了推理流程。这类方法利用预训练视觉模型（如 CLIP）的泛化能力，无需在目标数据上训练即可检测异常，在工业质检和医学影像等场景中具有重大应用价值。

然而，论文指出当前方法存在严重的效率瓶颈：**现有方法通常对所有图像和所有空间 token 执行密集计算**。这一设计在异常检测场景下是极度浪费的，原因有二：

1. **正常样本占主导**：在真实场景中，绝大多数待检样本是正常的（无异常），异常样本占比极低。对海量正常样本执行全量 token 的密集计算是纯浪费。
2. **异常区域占比极小**：即使在异常样本中，异常区域通常只占图像的很小一部分（如工业产品上的微小划痕、医学影像中的微小病灶）。绝大多数 token 对应正常区域，对检测和定位贡献为零。

**token 剪枝的不对称风险。** 上述观察看似支持直接应用 token 剪枝——既然大量 token 是冗余的正常区域，剪掉它们即可。但论文敏锐地揭示了一个**异常检测特有的不对称剪枝风险（asymmetric pruning risk）**：

- **保留正常 token 的代价**：主要是冗余计算（浪费算力），但不影响检测正确性。
- **移除异常 token 的代价**：可能是灾难性的——异常 token 可能是检测和定位的唯一证据。一旦被误删，异常将无法被检测到，产生漏检（false negative），这在质检和医疗场景中代价极高。

这种不对称性是异常检测区别于一般视觉理解任务的根本特征。在一般任务中，误删一个 token 只是轻微降低理解质量；在异常检测中，误删异常 token 可能直接导致检测失败。

**浅层剪枝的特殊风险。** 论文进一步指出，这种风险在网络的浅层（early layers）尤为严重。浅层剪枝能带来最大的计算收益（因为被剪掉的 token 不再参与后续所有层的计算，节省是累积的），但浅层恰恰是异常语义最不可靠的地方——异常的高层语义（如"这是裂缝""这是肿瘤"）在浅层尚未充分形成，浅层特征更多是低级的纹理、边缘信息，难以可靠地区分正常与异常。因此，在浅层基于语义重要性进行剪枝极易误删异常 token。

现有 token 剪枝方法（多为通用视觉理解设计）完全没有考虑这种不对称风险和浅层不可靠性，直接应用于异常检测会导致严重的漏检。这正是 KeepAD 要解决的核心痛点。

## 3. 核心方法与创新点 (Methodology & Innovations)

KeepAD 框架将 token 选择建模为**高召回率的异常感知路由（high-recall, anomaly-aware routing）**，并在浅层和深层采用差异化策略：

**1. 浅层：覆盖保留选择 + 确定性异常救援**

浅层的目标是在最大化计算节省的同时，将误删异常 token 的风险降至最低。KeepAD 采用了双保险设计：

- **覆盖保留选择（coverage-preserving selection）**：在局部 2x2 patch 邻域内进行选择。2x2 邻域意味着每 4 个相邻 token 中至少保留一定数量，保证了空间上的覆盖性，避免某区域被完全清空。这种设计不依赖于浅层不可靠的语义判断，而是基于空间覆盖的几何原则，确保任何潜在异常区域都有 token 被保留。
- **确定性异常救援（deterministic anomaly rescue）**：作为额外保险，对于某些检测到可能异常信号（即使在浅层也不确定）的 token，执行确定性的保留决策，确保这些"嫌疑 token"不被删除。这种救援机制以确定性（而非概率性）方式工作，保证在任何情况下异常嫌疑 token 都被保留。

**2. 深层：原型引导的图像自适应预算剪枝**

在深层，异常语义已充分形成，可以进行更可靠的重要性判断。KeepAD 的深层策略包含：

- **冻结的正常和异常原型（frozen normal and abnormal prototypes）**：预先构建并冻结正常模式和异常模式的原型表示，作为判别基准。冻结保证一致性，不随输入变化。
- **图像自适应 token 预算（image-adaptive token budget）**：每个图像的 token 保留预算不是固定的，而是根据图像内容自适应确定。正常样本（无异常迹象）可以更激进地剪枝，疑似异常样本保留更多 token 以保护证据。
- **激进剪除低风险正常 token**：在原型引导下，识别出低风险的正常 token 并激进移除，同时保留局部异常证据。深层策略的哲学是"在语义可靠后大胆剪枝"。

**3. 稠密-稀疏自蒸馏**

为监督早期 token 路由（浅层决策）的准确性，KeepAD 引入**稠密-稀疏自蒸馏（dense-to-sparse self-distillation）**：

- 用稠密（未剪枝）模型的输出作为教师，指导稀疏（剪枝后）模型的学生学习。
- 这种自蒸馏仅用于训练阶段（如果有的话）或校准阶段，**不引入额外的推理开销**——推理时只使用剪枝后的稀疏模型。
- 自蒸馏确保浅层的路由决策尽可能接近稠密模型的行为，弥合剪枝带来的信息损失。

**4. 分层渐进式设计**

KeepAD 的整体设计是渐进式的：浅层保守（覆盖+救援，少剪），深层激进（原型引导，多剪）。这种设计精准地匹配了"浅层语义不可靠但节省大"与"深层语义可靠但节省小"的矛盾，在风险与收益间取得最优平衡。

## 4. 实验设计与结果 (Experiments & Results)

论文在异常检测领域进行了广泛且全面的实验：

**基准覆盖**：
- **6 个工业（industrial）零样本异常检测基准**
- **7 个医学（medical）零样本异常检测基准**

共 13 个基准，覆盖工业质检和医学影像两大核心应用领域，验证了方法的广泛适用性。

**核心效率结果**：
- 将 **token 保留率降至 20% 以下**（即剪掉了 80% 以上的 token），实现了大幅压缩。

**精度保持结果**：
- 在如此激进的剪枝下，图像级（image-level）和像素级（pixel-level）AUROC 的**平均退化控制在 2.7 个百分点以内**。这一结果至关重要——在异常检测这种对漏检极度敏感的任务中，仅 2.7 个百分点的退化是可接受的，说明 KeepAD 的"保缺陷"设计有效。

**加速结果**：
- 在最激进的运行点（most aggressive operating point），KeepAD 相对于**最强的 CLIP 基线**实现了 **7.9 倍加速**。这是一个非常显著的效率提升，使实时异常检测成为可能。

**对比基线**：
- 与最强的 CLIP-based 基线方法对比，在精度-效率权衡上全面领先，验证了保缺陷剪枝相对于通用剪枝的优越性。

## 5. 局限性与未来展望 (Limitations & Future Work)

**原型构建的数据需求**：深层策略依赖冻结的正常/异常原型，这些原型的构建需要代表性数据。在异常类型极为罕见或多样的场景中，覆盖所有异常类型的原型构建可能困难。

**2x2 邻域的固定粒度**：浅层覆盖保留使用固定 2x2 邻域，粒度固定。对于不同分辨率或异常尺度的图像，固定邻域可能不是最优——大尺度异常可能需要更大邻域，微小异常可能需要更小邻域。

**自蒸馏的训练开销**：虽然推理时无额外开销，但稠密-稀疏自蒸馏在校准/训练阶段引入了额外计算（需运行稠密模型作为教师）。对于需要快速部署的场景，这一开销需要考量。

**正常/异常二分的假设**：方法基于正常与异常的二元分类原型。对于存在多种异常类型或渐进性异常（如疾病早期阶段的细微变化）的场景，二元原型可能不足以建模复杂性。

**未来展望**：可探索动态原型更新以适应分布漂移；研究多尺度邻域的覆盖保留策略；将框架扩展到视频异常检测的时序维度；探索与量化的联合压缩；研究在线学习实现原型自适应。

## 6. 学术启发 (Takeaways for My Research)

**不对称风险的深刻洞察**：KeepAD 对"保留正常 token vs 移除异常 token"代价不对称的分析，是本文最具启发性的贡献。这一不对称性思维模式可迁移到许多场景：在稀疏检索中，漏召回（丢失相关文档）的代价远高于多召回（多返回无关文档）；在主动学习中，误标困难样本的代价高于漏采；在数据清洗中，误删有价值样本的代价高于保留噪声。在设计中应识别这种不对称性并据此设计非对称策略。

**分层差异化策略**：浅层保守、深层激进的设计，精准匹配了"语义可靠性随深度增加"的规律。这种"按可靠性分配风险"的思路可迁移到：量化中浅层用高比特、深层用低比特；蒸馏中浅层柔和约束、深层严格对齐；模型分片中敏感层保留完整、鲁棒层进行分片。

**高召回率路由的建模视角**：将 token 选择建模为"高召回异常感知路由"，而非简单的"重要性排序+截断"。路由视角引入了"保证不漏"的约束思维。这种将选择问题重构为带约束路由问题的方法，可应用于任何需要"保证不丢失关键元素"的选择场景。

**覆盖+救援双保险**：几何覆盖（2x2 邻域）+ 语义救援（确定性保留）的双保险设计，是一种稳健的工程模式。在自己的系统设计中，面对不可靠判断的场景，可采用"几何/规则保底 + 语义增强"的双层保险策略，确保最坏情况下的安全性。

**稠密-稀疏自蒸馏**：用稠密模型指导稀疏模型的训练/校准，推理时只用稀疏模型，是一种"训练时多花成本、推理时零额外开销"的高效范式。可迁移到任何压缩后模型的恢复训练中。
