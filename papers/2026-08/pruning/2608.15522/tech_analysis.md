# Efficient Audio-Visual Generation via Synchrony-Aware Cross-Modal Sparse Attention：技术精读

> arXiv: [2608.15522](https://arxiv.org/abs/2608.15522) · submitted 2026-08-16 · Shengchuan Gao 等 · cs.CV

## 1. 核心速览

**研究主题**：音视频联合扩散中的同步感知稀疏注意力与缓存。
**一句话总结**：方法只对同步关键 token 保留稠密计算，并在跨步缓存中监测交互变化，从而避免普通稀疏化破坏声画对齐。

## 2. 研究背景与动机

视频 token 数远多于音频 token，长序列注意力和多步去噪成为主要延迟；现成视频稀疏注意力/缓存忽略双分支交互，可能提高速度却损害同步。

## 3. 核心方法与创新点

- 从双向音视频 cross-attention 构造模态特定 saliency，保护声音相关视觉区与关键时间片。
- 其余 query-key 连接按比例稀疏；复杂度写为稀疏项与少量 dense-row 保护项之和。
- 同步感知缓存复用相邻去噪步的 fusion block，但在交互变化时拒绝复用；整体 training-free。

## 4. 实验设计与结果

在 Ovi 上，dense latency 为 **448.75 s**；本文为 **225.30 s / 1.992×**，同时 PSNR **25.6857**、LPIPS **0.1398**、SSIM **0.8385**、Sync-C **4.606**。在 LTX-2.3 上，延迟从 **255.41 s** 降到约 **199.4 s / 1.281×**，PSNR **20.8737**、SSIM **0.6737**、Sync-C **5.134**。这些指标优于普通稀疏或多种缓存基线的质量-同步折中。

## 5. 局限性与未来展望

依赖可访问 cross-attention 与中间 block 输出，闭源生成器难直接应用；实际 wall-clock 仍受稀疏内核支持影响。同步 saliency 在复杂多声源、长音乐和镜头切换场景的稳健性仍需扩展。

## 6. 学术启发

对多模态模型做 token/注意力剪枝时，应该保护跨模态“关系边”而不只是单模态高激活 token；缓存门控也应基于任务语义变化而非单纯特征距离。
