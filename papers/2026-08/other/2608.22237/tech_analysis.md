# Read Less, Solve More: Token-Efficient Sparse Reading for AI Agents

> arXiv: [2608.22237](https://arxiv.org/abs/2608.22237) · v1: 2026-08-23 · 主分类: cs.AI
> 证据：官方摘要与 9 页 v1 PDF 全文。

## 1. 核心速览

**研究主题**：长程智能体的上下文准入压缩。
**一句话总结**：SparseRead 不等材料进入上下文后再总结，而是在读取接口前用 Read Gate、Reader Backend 和有状态证据协议限制准入；在 6 个前沿模型、5 类工作负载和 3 个智能体框架上，最多减少 92.9% token 与 89.0% 墙钟时间，同时保持或提高任务质量。

## 2. 研究背景与动机

长程智能体会重复读取网页、日志和文档，传统接口一次暴露整个对象，使无关内容先污染上下文，再由事后压缩补救。问题既是费用和延迟，也是证据稀释：真正有用的局部片段可能被长文本淹没。

## 3. 核心方法与创新点

- Regime-aware Read Gate 判断直接读、局部检索还是逐步细化，而不是固定裁剪率。
- 可扩展 Reader Backend 将不同数据源映射成可定位、可回溯的证据单元。
- 有状态协议显式包含 refinement、verification、stopping 与 fallback，避免只读到支持当前假设的片段。
- 训练自由且不改基础模型，压缩对象是“进入上下文的信息量”，不是参数。

## 4. 实验设计与结果

论文覆盖 6 个前沿模型、5 类工作场景及 3 种 agent 框架。最高 token 降幅 92.9%，墙钟时间降幅 89.0%；作者报告质量持平或提升，说明收益不只是截短输出。跨框架结果是其可移植性的主要证据，但“最高”数字不是所有任务的平均值。

## 5. 局限性与未来展望

实验依赖外部材料可被可靠切片和定位；检索器漏召回会在上下文入口形成不可逆信息损失。前沿闭源模型的结果也难完全归因于接口本身。未来应报告不同召回率下的质量退化、恶意文档鲁棒性和超长运行中的累计错误。

## 6. 学术启发

压缩可以前移到信息准入层：先决定“哪些字节有资格进入模型”，往往比事后总结更可控。对 agent 系统，压缩评价应同时包含答案质量、证据覆盖、token、延迟与 fallback 触发率。
