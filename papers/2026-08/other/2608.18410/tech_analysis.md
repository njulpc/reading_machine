# 技术深度分析：Role-Conditioned Sub-Token Routing for Efficient VLA Policies

> arXiv: [2608.18410](https://arxiv.org/abs/2608.18410) · v1: 2026-08-19 00:38:23 UTC · 主分类：cs.LG

## 1. 核心速览

**研究主题**：视觉-语言-动作模型的 token 内价值维压缩与 KV 预算分配。

**一句话总结**：RoleSub 不再只删除整枚视觉 token，而是在正交空间中把每个 value 向量分成 16 组，并由角色、token 状态与语言上下文共同路由保留组；在相同视觉 KV 预算下 36 个设置中赢了 33 个，视觉与语言联合后总 KV 仅为原始的 9.2%–11.3%。

## 2. 研究背景与动机

VLA 模型要处理长视觉、语言和动作上下文，KV 存储与注意力计算昂贵。现有方法多做视觉 token pruning，但在激进预算下删除整枚 token 会一起丢掉位置和全部通道信息。作者提出更细的压缩轴：保留较多 token 位置，只压缩其 value 宽度；同时承认感知、语言和控制依赖的子空间不同，不能照搬通用子 token 方法。

## 3. 核心方法与创新点

- 对每层 value 用冻结正交矩阵旋转，再划分为 16 个、每组 256 维的子空间。
- 路由分数同时依赖 token 表示、6 个潜在角色分量和语言上下文；每 token 取 top-K 组。
- 视觉 token 数与 value 组数分别控制，形成“token 数 × value 宽度”的二维压缩预算；语言 token 不删，只压 value。
- 在层内引入预算分配器，使不同 token 可获不同 K，但平均预算保持不变。

## 4. 实验设计与结果

模型为 OpenVLA-OFT-7B：value 维 4096，原始视觉 token 512，测试保留 8/16/32 枚并令 K=1/2/4。骨干冻结，训练 rank-32、scale-16 的 LoRA（约 110.8M 参数）、4.20M 路由头和 0.55M 角色估计器；四个 LIBERO 套件每任务 50 次闭环试验。

在 8 个视觉 token、K=1、视觉 KV 仅 0.83% 的设置下，RoleSub 在 Goal/LIBERO-10/Object/Spatial 的成功率为 93.5/74.2/95.5/95.6%，匹配预算 token-only 为 85.7/73.6/96.5/88.3%。所有匹配预算组合共 36 项，RoleSub 赢 33 项。单独压缩语言 value 几乎无损，但和极端视觉压缩叠加时 LIBERO-10 可下降 10.0–11.2 个点；提高语言预算能恢复，例如 32 个视觉 token 时 K_lang=8 达 84.8%，完整语言 value 为 87.6%。

## 5. 局限性与未来展望

潜在角色不保证可解释；视觉和语言预算独立设定，没有显式优化跨模态耦合。论文衡量的是保留 KV 比例，而非端到端延迟；真正加速还需要稀疏 value 计算与高效路由内核。实验也只覆盖 OpenVLA-OFT-7B 和 LIBERO。

## 6. 学术启发

压缩粒度不必在“整 token 保留/删除”之间二选一。把序列长度与表示宽度解耦后，可为任务关键位置保留空间锚点，同时削减不重要子空间。多模态压缩还应把预算视为联合资源分配问题，而非分别调视觉和语言超参数。
