# FORTE: A Production Framework for Feature Evaluation and Deprecation in Industrial Recommender Systems

## 1. 核心速览

研究主题：工业推荐系统的结构性输入特征剪枝及生产落地。

一句话总结：FORTE 将特征重要性从一次离线排名变成持续评估—联合消融—重训—A/B—血缘删除流程，以真实线上指标决定可安全删除的特征。

## 2. 研究背景与动机

推荐系统长期加入特征，却很少有对称的退出机制：单个特征弱不代表联合删除安全；重要性随数据和模型变化；在线实验流量有限；同一特征还可能被多个模型使用。参数较多的嵌入或特征通道被移除时，收益可贯穿模型、网络、存储和训练链路。论文研究的不是权重幅值剪枝，也不是提出新的教师蒸馏算法。

## 3. 核心方法与创新点

1. 定义方向统一的归一化变化 Δ=100·s·(M_G−M_0)/M_0。负值说明扰动损害效果、模型依赖该特征，不能把符号反读。每次基线和扰动共享检查点与样本。
2. 跨观察窗口、全部任务头检查低平均依赖、排名稳定及非正趋势，结合成本形成嵌套删除集合；窗口长度和阈值由模型团队配置，并非通用固定超参。
3. 对候选集合联合扰动以检测替代关系，再用重训与数周在线A/B验证。联合扰动仍不是条件重要性或因果估计。
4. 将 original/perturbed 两份特征字典按列选择，复用数据物化、模型加载和GPU启动开销；默认每批一次随机置换。最后追踪所有消费者，逐级停用数据、物化任务与日志。

## 4. 实验设计与结果

证据为正文§7表1–2。Search Relevance 有111个输入特征，候选规模32/48/59，均通过离线门槛，59特征方案因线上次要护栏退化被拒绝。最终删除48个（43.3%输入特征），参数只减少2.3%，吞吐增加2.0%；页面等待时间降低0.1696%，p=0.0012。

Pin Ranker 比较删除2与8个特征：pairwise accuracy 都变化+0.0001，NDCG@3 分别−0.0015/−0.0010（跨输出头平均绝对差）。三周A/B未发现点击、closeup、repin显著退化，最终删除8特征。参数−29.9%，CUDA Graph基准吞吐+19.8–25.5%，推理成本约−10%。按等精度参数数目估计压缩倍率1/(1−0.299)=1.43×，不代表实际文件字节或端到端业务吞吐。

## 5. 局限性与未来展望

边际置换可能产生分布外组合，相关特征和高阶交互仍可能误判；单次置换的稳定性证据只覆盖一个模型的两个头。重要性趋势应在同一检查点窗口内解释。两种架构的参数收益悬殊，不能泛化成固定剪枝收益。后续可引入条件重要性、自动发现交互、成本敏感集合搜索，并披露多种模型的重复实验。

## 6. 学术启发

可迁移的是验证顺序：先用便宜的联合消融筛选，再花训练资源和真实流量验证；特征数量、参数、吞吐和基础设施成本应分开报告。对LLM结构剪枝也可采用多窗口稳定性及成组移除，而不是仅凭单次重要性排名。新研究可对照单特征排名与集合效应，并把被线上拒绝的方案作为关键反例。
