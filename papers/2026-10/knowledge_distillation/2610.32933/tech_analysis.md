## 一、核心速览

**研究主题：** 用大模型的检索相似度分布蒸馏小型波斯语嵌入模型。

**一句话总结：** Yalda 在 Qwen3-Embedding-0.6B 上结合对比学习与 F2LLM-v2-8B 关系蒸馏，将八项 FaMTEB 检索任务宏平均从非蒸馏配置的 0.4813 提升至 0.5488，保持 595,776,512 参数。

这是教师知识向小学生迁移，不是低比特量化论文。文中 BF16/FP32 混合精度用于常规训练，最终权重导出为 FP32；不应据此归入 quantization。[全文 §IV–VI](https://arxiv.org/html/2610.32933v1)

## 二、研究背景与动机

波斯语检索缺少足够的专用训练数据及紧凑模型。直接对小型多语言编码器进行对比微调虽然能改善平均分，却可能使特定任务退化。作者在固定学生架构和一轮数据曝光下，研究扩大批次、稳定优化及关系蒸馏如何逐步改变检索质量。

蒸馏的目标不是让学生逐坐标复制教师嵌入，而是让它保留一个查询对整批文档的相对偏好。这样教师和学生即使原始表示宽度不同，也能通过共同的排序分布传递知识。离线教师表示又将昂贵的教师推理与学生训练解耦。[§I、III、IV](https://arxiv.org/html/2610.32933v1)

## 三、核心方法与创新点

1. **固定学生与数据流程。** 学生采用 28 层 Qwen3-Embedding-0.6B，隐藏维度 1,024，FFN 3,072，16 个 query heads、8 个 KV heads，最大训练长度 512。使用最后一个非 padding token 池化和 L2 归一化；查询附固定检索指令，文档不加指令。训练集由 13 个来源组成，共 1,035,981 对查询—正例文档，不重采样来源。
2. **大批次 InfoNCE。** 全局 batch=512，每个查询面对一个正例和 511 个批内负例；只计算 query→document 方向。学生 logits 为归一化嵌入余弦相似度除以温度 0.05。没有显式挖掘的 hard negatives，不意味着测试任务没有 hard negatives。
3. **关系蒸馏。** F2LLM-v2-8B 的 4,096 维 Matryoshka 表示截取前 1,024 维后再次归一化，教师温度 0.07。逐查询对整批文档分布做前向 KL：
   \[
   L_{KD}=B^{-1}\sum_i KL(p_i^T\|p_i^S),\qquad L=0.25L_{NCE}+0.75L_{KD}.
   \]
   传递的是批内相似度关系，不是嵌入坐标回归。1,024 维前缀减少教师缓存数据量，不能把 4,096→1,024 直接当成模型权重压缩四倍。
4. **离线教师缓存与开放训练资产。** 教师嵌入在单 NVIDIA P100 上约耗时 250 小时，生成约 17.5 GB、36 个 Parquet shards。学生在八张 TPU v5e（每张 16 GB）上做单轴 FSDP 和激活重计算。创新侧重可复查的数据/训练配方与实证，不是新的 KL 公式。[§III–V](https://arxiv.org/html/2610.32933v1)

## 四、实验设计与结果

全参数 AdamW 微调一轮，学习率峰值 2e-5，10% warmup 后 cosine decay，梯度范数上限 1；2,023 步共消费 1,035,776 样本，舍弃最后 205 个不满批样本。参数、梯度、优化器状态和敏感归一化等为 FP32，部分激活和矩阵乘为 BF16。最终训练约五小时；所有消融合计约 480 TPU-device-hours，另计教师缓存成本。

评估采用八个 FaMTEB 检索测试任务，最大长度 512、编码 batch=64；采用各模型自身提示和池化规则，报告 MTEB 返回的检索分数及等权宏平均，而不是整个 FaMTEB 的综合成绩。

| 配置 | 八任务宏平均 |
|---|---:|
| Qwen3-Embedding-0.6B 初始化 | 0.4713 |
| InfoNCE，batch 64 | 0.4350 |
| batch 增至 512 | 0.4738 |
| 再加 clipping、warmup、cosine | 0.4813 |
| KD 权重 0.25 | 0.5125 |
| KD 权重 0.50 | 0.5313 |
| KD 权重 0.75：最终 Yalda | **0.5488** |
| F2LLM-v2-0.6B | 0.5063 |
| Qwen3-Embedding-4B | 0.5563 |

最终模型较非蒸馏配置增加 0.0675；较初始化增加 0.0775，约 16.4% 相对提升。对比 4B 参考模型，八任务中赢四项、平一项，宏平均落后 0.0075。上述 4B 模型不是训练教师，不能把此表理解为学生全面追平 8B 教师。

按名义 8B 教师/精确学生参数估算，参数规模约 13.43:1；相对名义 4B 参考模型约 6.71:1。这是跨架构参数规模比，不是实测权重文件、运行内存或吞吐加速比。[表 II–V](https://arxiv.org/html/2610.32933v1)

## 五、局限性与未来展望

- 只覆盖八项波斯语检索任务；没有跨语言全面泛化，也未证明统计显著性。各模型沿用不同提示/池化配置，比较不是所有组件完全对齐的实验。
- 最终数据置乱 seed 未固定，MTEB 未固定版本；单模型 seed=0 不代表完整可重复。对照配方把 clipping、warmup、decay 同时加入，不能区分三者独立贡献。
- 教师离线推理成本较高，缓存复用能降低后续成本但不能消除最初的 250 GPU 小时；大批次负例也可能含语义假负例。
- 论文未提供师生端到端延迟、峰值内存的统一测量。未来应补多 seed、固定评测版本、数据污染核验及同精度下实际部署成本。[§III、V、VI](https://arxiv.org/html/2610.32933v1)

## 六、学术启发

小模型蒸馏值得对齐的是任务决策几何：检索任务中，批内文档分布比逐维嵌入更自然。应固定学生架构后比较 InfoNCE 与蒸馏，避免把大批次收益全部归给 KD；本论文的累积消融仍需要进一步正交拆分。

对后续压缩研究，可测试温度、批大小与教师前缀维度的交互，并把预计算成本摊销到多次学生训练中。可复现材料包括作者声明开放的[代码](https://github.com/yaldat/yalda-embedding)、[权重](https://huggingface.co/Yaldat/Yalda-Embedding)和[教师嵌入数据](https://huggingface.co/datasets/Yaldat/Persian-Pairwise-Embedded)。本次已核读官方全文，未独立训练或运行这些资产；它不是新增量化论文，因此没有伪造 Qwen3-0.6B 量化复现目录。
