# VFold: Symmetry-Aware Cross-Layer Value Cache Compression

## 1. 核心速览

研究主题：跨层value cache压缩，不以降低数值位宽为核心。

一句话总结：VFold 先把邻层value头对齐并将变换折入权重，再共享平均缓存，在25%总KV节省下保留大部分长上下文能力。

## 2. 研究背景与动机

邻层缓存存在冗余，但未对齐时直接平均容易损伤能力；key和value的变换对注意力的影响不同，不能盲目同时压缩两者。逐步重建低秩缓存又有解码开销。

## 3. 核心方法与创新点

1. 在每对KV头上做CCA，Hungarian求跨层头匹配，head内满秩T避免跨头混合；同时置换Q/K/V并把T与逆映射折入V/O权重，保持原attention函数。
2. 当前步先使用完整value算注意力，再渐进平均写入共享历史缓存；当前token不提前损失信息。
3. 128×2048 WikiText2校准；保护4个sink和128个最近token。两层一组压V到1/2，即总KV约25%节省；四层一组总KV约37.5%。

## 4. 实验设计与结果

Qwen3-8B RULER16K：全KV93.14，未对齐平均78.84，VFold91.63；LongBench49.52→48.92。A10080GB、Llama3.1-8B、8K prompt+256生成：KV1.11→.84GB，TTFT781→786ms，TPOT21.0→27.8ms，最大batch33→38。因此省缓存但单请求解码慢约32.4%。与4bit KIVI组合后压缩3.2×→4.27×，这是组合结果，非VFold独立倍率。

## 5. 局限性与未来展望

25%是渐近缓存节省，保护token使实测略偏；整机还包含权重和临时张量。长序列及更大group仍有质量损失。本文量化只是既有KIVI组合实验，本轮按核心跨层合并归other，不将之描述为新量化器或声称本地完成KV复现。

## 6. 学术启发

优先把可逆对齐变换移到离线权重中，再在运行时有损共享状态，可把变换误差和合并误差分开。评估必须同时看容量、batch提升与TPOT，省显存不等于更快。

评分（1–10，高分更优；压缩评分只评价实际压缩对象）：

- 精度效果 8/10：25%KV节省下保留至少98.3%相对任务分
- 压缩倍率 5/10：独立总KV仅约1.33倍，组合另计
- 创新性 8/10：对称性对齐与attention后合并
- 可复现性 7/10：校准、保护窗口和效能协议明确
