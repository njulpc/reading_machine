# Slot3R: Set-Associative Spatial Memory for Streaming 3D Reconstruction

## 1. 核心速览

研究主题：流式3D模型记忆读出稀疏化与状态管理。

一句话总结：Slot3R 将空间地址和特征状态区分，保留多槽状态并限制每帧读出的记忆token数。

## 2. 研究背景与动机

Point3R依据空间邻近就融合特征，可能把不同表面、视角或可见性过早平均；全历史读出又随场景增长拖高注意力成本。

## 3. 核心方法与创新点

1. 球坐标中的方位、仰角、对数半径离散哈希到bucket，每bucket保留至多K个位置/特征/置信度槽。这里坐标离散化是地址索引，非低比特神经权重量化。
2. 去掉帧内低置信分位候选；相似且可信时融合，不相似且更可信时占空槽或替换低置信槽，单候选比较O(K)。
3. 以前帧pointmap定位局部邻域，拼接全局anchor并去重，最多读640个token；persistent memory并非因此固定640。

## 4. 实验设计与结果

600–1000帧压力测试中，Core版本7Scenes约19.18 FPS、NeuralRGBD18.91 FPS；Point3R和InfiniteVGGT从800帧起OOM。NeuralRGBD 1000帧峰值GPU内存20.0095 GB。读出预算消融（200帧）：128→640时Acc .043→.038、FPS20.000→19.114；超过512后精度趋平。算法改善质量并限定注意力读出，但未给出统一模型参数或持久内存压缩倍率。

## 5. 局限性与未来展望

定位依赖相邻帧重叠，快速运动时近似先验可能失配。持续探索新区域时存储仍增长；不能把有界读出写成有界总内存。多槽容量、置信门槛和硬件性能仍需跨场景检查。本轮未复现3D模型。

## 6. 学术启发

压缩中先判定哪些状态可合并，再控制访问预算；“存得多、每步读得少”与“总状态压得小”是不同工程目标，报告要分开。
