# DVD: Dynamic Vector Decoding for Efficient MLLM-based Perception

## 1. 核心速览

研究主题：多模态感知输出token压缩；VQ作用于坐标表示，不是模型权重低比特量化。

一句话总结：DVD 把2D/3D几何向量编码为少量离散token，以轻量解码器缩短MLLM生成序列。

## 2. 研究背景与动机

文本坐标耗费大量token，固定范围坐标量化又限制3D范围和精度。需要在少token与几何重建误差之间折中，不能只比较字符串长度。

## 3. 核心方法与创新点

1. 将2D框、轮廓点和3D框统一展平为1D序列；2D按图像尺寸归一化，3D保留原始数值。
2. 1D encoder以K=2下采样，16维latent在4096码本中做最近邻编码；decoder恢复向量。训练含L1、VQ和双向L1 Chamfer几何损失，三项权重均1。
3. 给MLLM添加4096个专用词表token，以标准生成训练；推理只对这些token调用去token器。

## 4. 实验设计与结果

使用约1.98M个3D框、2.31M个2D框、1.52M个mask，三类1:1:1采样；autoencoder训练24 epochs、lr1e−3；MLLM全参264K iterations，batch64，8×A100。30%训练预算消融：3D文本表示AP3D 37.5，DVD 34.1，固定token17.5；文本延迟4165 ms/对象，DVD499 ms，约8.3×。这不是全任务统一加速。K从2增到4时2D重建P@50从100降至31.5，说明高压缩严重失真。

## 5. 局限性与未来展望

附录F指出去token器与MLLM分开训练可能不对齐。几何重建表与端到端感知表的指标对象不同，不能混成同一精度。未压缩权重，反而增加词表和解码组件；本轮不将语义VQ误归为需要Qwen文本模型低比特复现的quantization。

## 6. 学术启发

输出表示本身决定串行解码长度；应同时汇报每对象token数、实际延迟和原始几何误差。几何不变量损失比单纯逐坐标L1更适合学习压缩表示。

评分（1–10，高分更优；压缩评分只评价实际压缩对象）：

- 精度效果 7/10：较固定坐标token好，但3D低于文本
- 压缩倍率 7/10：报告特定3D场景8.3倍延迟收益
- 创新性 7/10：跨任务几何token与Chamfer约束
- 可复现性 6/10：设置明确，训练成本高且未本地复现
