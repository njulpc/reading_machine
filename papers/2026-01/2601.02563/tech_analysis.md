## 一、核心速览

### 研究主题

压缩（量化、蒸馏、缩放、任务微调）对 LLM 编程语言 token 表示与代码生成质量的隐性影响：从 tokenizer 词汇分布到冷启动概率的 token 级系统分析。

### 一句话总结

作者分析编程语言在 LLM tokenizer 中的词汇分布与关键字覆盖，提出无需提示的冷启动概率分析方法，系统评估量化/蒸馏/缩放/微调对 token 级表示与代码质量的影响，给出保持代码能力的实证准则。

---

## 二、研究背景与动机

代码生成是 LLM 的高价值能力，但 token 级机制——尤其压缩模型中——几乎未被研究。代码 token（关键字、缩进、符号）分布与自然语言迥异，对量化扰动可能异常敏感；而量化与蒸馏正被广泛用于部署代码模型，其隐性代价需要被刻画。

---

## 三、核心方法与创新点

- **Tokenizer 级语言画像**：分析编程语言在词汇表中的分布与关键字覆盖模式。
- **冷启动概率分析**：无需构造提示即可探查模型行为的新方法，适合系统性比较压缩前后模型。
- **四类优化技术统一评估**：量化、蒸馏、模型缩放、任务微调对 token 表示与代码质量的对比，辅以概率分布分析与评测指标，给出实证准则。

---

## 四、实验设计与结果

通过概率分布分析与代码生成评测揭示压缩技术对 token 级行为的关键影响（摘要未给出具体数值），并形成"保持代码生成质量"的实证指导方针。

---

## 五、局限性与未来展望

局限：具体影响的量级未在摘要量化；未覆盖最新的 4-bit 以下量化与 KV 压缩；准则的跨模型普适性待验证。未来方向：代码 token 感知的混合精度量化、蒸馏数据的代码覆盖度控制、形式化（语法约束）解码与压缩的交互。

---

## 六、学术启发

- **压缩研究的"领域 token 敏感性"视角**：代码、数学等结构化语言的 token 分布特殊，量化评估应按 token 类别分解——这提示我们做量化误差分析时增加"词表分层"维度。
- **冷启动概率探针**是低成本比较压缩模型的实用工具。
