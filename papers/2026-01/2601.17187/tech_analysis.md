## 一、核心速览

### 研究主题

量化矩阵乘的信息论极限研究：无校准统计先验的 Generic MatMul 设置（权重+激活双量化），用高率理论刻画量化率-失真的基本权衡，并与 absmax INT/FP 等主流方案的实测性能对照。

### 一句话总结

信息论大牛（Polyanskiy 等）为量化 MatMul 建立高率理论基准：给出率-失真基本权衡，推导 absmax INT 与 FP 量化方案的精确启发式近似，回答"现有量化方案离理论极限还有多远"。

## 二、研究背景与动机

量化 MatMul 是 LLM 高效部署的核心，但方法论多为工程启发式，缺乏信息论基准：给定比特率，失真的理论下限是多少？absmax INT、FP 格式（FP8/FP4）与极限的差距多大？无校准统计信息时（Generic 设置）最优量化器长什么样？这些第一性问题决定改进空间。

---

## 三、方法创新

1. **Generic MatMul 设置**：两矩阵都需量化（权重+激活）且无先验统计——比 weight-only 更一般、更贴近实际推理。
2. **高率理论基准**：率-失真权衡的信息论刻画，为所有量化方案提供不可逾越的下限。
3. **主流方案的精确近似**：为 absmax INT 与 FP 量化推导准确的启发式近似——理论与实践的桥梁。
4. **系列论文 Part I**：Part II 将处理有激活二阶统计可用的 weight-only 设置。

## 五、局限与展望

- 高率理论在高比特（≥8bit）精确，对 LLM 热门的 2-4bit 低比特区近似精度下降。
- Generic 设置假设无校准先验，与实践中校准总可用的现实有距离。
- 理论最优量化器（如格量化）的实现成本未讨论。

## 六、学术启发

1. 量化研究需要"理论锚点"——知道离极限多远才能判断新方法的价值，本文提供的基准应成为引用标准。
2. INT vs FP 格式的选择可以用率-失真理论严格比较，而非纯经验——格式之争有了裁判。
