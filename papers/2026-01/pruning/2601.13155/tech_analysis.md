# 技术深度分析：Probe and Skip: Self-Predictive Token Skipping for Efficient Long-Context LLM Inference (arXiv:2601.13155)

> **论文**: Probe and Skip: Self-Predictive Token Skipping for Efficient Long-Context LLM Inference
> **作者**: Zimeng Wu, Donghao Wang, Chaozhe Jin, Jiaxin Chen
> **arXiv**: https://arxiv.org/abs/2601.13155 ｜ 提交: 2026-01-19 ｜ 分类: cs.CL, cs.LG

---

## 一、核心速览

### 研究主题

免训练的长上下文推理 token 跳过框架 SPTS（自预测 token 跳过）：跳过前先用低成本"探针"预测目标层影响，为 MHA 与 FFN 两类结构分别设计选择性跳过策略。

### 一句话总结

SPTS 提出部分注意力探测（PAP，用部分前向注意力计算选出有信息 token）与低秩变换探测（LTP，为 FFN 构造低秩代理）两种探测策略，解决现有 token 剪枝/跳过方法结构优化不足、选择标准过时、冗余干扰的问题。

---

## 二、研究背景与动机

长上下文增强推理能力但计算开销大。token 级方法（剪枝/跳过）降延迟有效，但存在三大痛点：结构优化不足（一刀切跳过不区分注意力/FFN 结构差异）、选择标准过时（用早期层信号决定后期层跳过）、冗余干扰（被保留 token 中的冗余仍干扰判断）。核心缺口：跳过决策前应"先探测后行动"。

---

## 三、方法创新

1. **先探测后跳过（probe-then-skip）**：跳过目标层前先用轻量计算探测该层对各 token 的实际影响，避免用过时/间接标准做决策。
2. **PAP（部分注意力探测）**：对多头注意力，只跑部分前向注意力计算即可选出有信息 token——探测成本远小于全层计算。
3. **LTP（低秩变换探测）**：对 FFN，构造低秩代理变换近似其 token 影响——利用 FFN 变换的低秩性做廉价探测。
4. **免训练**：全部基于预训练模型推理期统计，即插即用。

---

## 四、实验结果

摘要报告 SPTS 改善长上下文推理的速度-精度折中（摘要截断，未给出具体加速比与任务精度数字）。

---

## 五、局限与展望

- 探测本身引入额外计算，净收益依赖探测成本与跳过节省的比值。
- 逐层探测-跳过的串行决策误差累积风险未讨论。
- 与 KV cache 驱逐的正交互补关系未探索。

---

## 六、学术启发

1. "先探测后行动"是动态压缩决策的通用原则——廉价探针+昂贵主干的结构可推广到层跳过、专家跳过。
2. 注意力与 FFN 结构差异大，跳过策略按结构定制（PAP/LTP）而非一刀切，这一观察值得所有 token 级方法借鉴。
