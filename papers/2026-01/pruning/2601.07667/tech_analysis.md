## 一、核心速览

### 研究主题

KV cache 逐层 token 剪枝中"选择层"的自适应选择：ASL 利用注意力分数排序的 token 秩方差，免训练地为每个任务/输入选择做 token 筛选的层。

### 一句话总结

固定预定义选择层的 KV 剪枝在难任务（如 KV 检索）上精度大跌；ASL 在预填充阶段根据 token 秩方差自适应选择选择层，在满足用户 KV 预算的同时平衡不同任务性能，且可与现有 KV 压缩方法联合使用。

---

## 二、研究背景与动机

逐层 token 剪枝（在特定层用注意力分数筛 token 留入 KV cache）是主流 KV 削减方案，但"在哪一层筛"通常是预先固定的。然而不同任务的信息分布不同——简单问答早期层即可判断重要性，KV 检索类难任务则需要更深层的信息汇聚——固定选择层导致任务间精度波动大。

---

## 三、核心方法与创新点

- **秩方差信号**：以注意力分数排序的 token 秩的方差作为"该层是否已能区分 token 重要性"的度量。
- **免训练自适应**：推理时即时决策，无需任何训练。
- **预算感知**：满足用户指定 KV 预算约束。
- **正交可组合**：可与现有 KV cache 削减方法联合。

---

## 四、实验设计与结果

摘要未给出具体数字；论文在多种任务（含 KV 检索等难任务）上验证 ASL 相比固定层基线在同等 KV 预算下的精度均衡性提升。

---

## 五、局限性与未来展望

局限：秩方差作为可区分性信号的理论依据较启发式；自适应选择引入预填充阶段的额外计算；对极深模型（100+ 层）的适用性未验证。未来方向：选择层+保留率联合自适应、与量化 KV 的联合预算分配、理论刻画秩方差与信息流的关系。

---

## 六、学术启发

- **压缩的"超参"（选择层）本身应自适应化**：固定配置在不同任务上的脆弱性是压缩方法的通病。
- **排序统计量（秩方差）是廉价而有效的自适应信号**，值得在剪枝率自适应、位宽分配中借鉴。
