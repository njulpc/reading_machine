## 一、核心速览

### 研究主题

视觉 token 压缩下 LVLM 对抗鲁棒性的首个系统研究与攻击方法 CAGE：解决"在全 token 表示上优化扰动、推理却经压缩瓶颈"的优化-推理失配。

### 一句话总结

CAGE（Compression-AliGnEd attack）两组件：期望特征扰动（把失真集中到在各候选预算下都大概率存活的 token 上）+ 秩失真对齐（主动把 token 失真与重要性秩分数对齐，促使高失真证据被保留）——无需知晓部署的压缩机制与预算即可有效攻击压缩 LVLM。

---

## 二、研究背景与动机

视觉 token 压缩（剪枝/合并）广泛用于 LVLM 加速，但其对抗鲁棒性未探索。本文指出既有基于编码器的攻击不能充分揭示压缩模型的脆弱性：扰动在全 token 表示上优化，而部署推理经过压缩瓶颈——攻击者精心构造的扰动 token 可能在压缩时被丢弃，优化与推理失配。真实攻击面是"压缩后的存活 token 集"。

---

## 三、方法创新

1. **优化-推理失配的形式化**：把压缩明确建模进攻击优化目标——攻击必须与压缩推理对齐。
2. **期望特征扰动**：对压缩预算做期望（不假设知道具体预算），把失真集中到各预算下都大概率存活的 token——攻击的可迁移性设计。
3. **秩失真对齐**：利用压缩机制依赖重要性秩分数的特点，把 token 失真与秩分数对齐——让高失真 token 反而被优先保留，"毒化幸存集"。
4. **黑盒性**：无需访问部署的压缩机制或其 token 预算。

---

## 四、实验结果

- 在多种代表性压缩方法与 LVLM 上验证 CAGE 有效揭示压缩模型的鲁棒性漏洞（摘要截断，未给出具体攻击成功率数字）。

---

## 五、局限与展望

- 期望预算的分布设定影响攻击强度。
- 防御方向（随机化压缩预算、对抗训练）未给方案。
- 与 2601.12042（重要性排序不稳定是根因）的发现互相印证，但两文的防御均缺位。

---

## 六、学术启发

1. 压缩模型的安全评测必须在"压缩态"做——CAGE 与 2601.12042 共同确立：压缩是独立攻击面，未压缩态的安全结论不可外推。
2. "与部署机制对齐的攻击"是通用红队原则——任何推理期变换（量化、剪枝、缓存驱逐）都应有对应对齐攻击。
