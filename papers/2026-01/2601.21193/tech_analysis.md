## 一、核心速览

### 研究主题

文生视频检索（TVR）两阶段范式中的生成式召回：用多视角语义 ID（量化产生的离散标识）做召回模型，解决生成式检索的语义歧义问题，配合稠密重排序。

### 一句话总结

生成式检索（GR）以离散语义 ID 替代稠密视频嵌入做召回——推理与存储近常数复杂度、量化捕获高层视频特征，适合快速排除无关候选；但 GR 作召回模型存在语义歧义（每个 ID 语义混杂），本文以多视角语义 ID 学习解决。

---

## 二、研究背景与动机

TVR 对视频平台至关重要。稠密双塔检索精度高但计算/存储随语料扩展差；两阶段方案中召回模型是性能上限。GR 用量化产生的语义 ID 检索——解码 query 成 ID token，复杂度近常数。但语义歧义问题：单个 ID 承载混杂语义（量化码本的表达限制），召回质量受损。

---

## 三、方法创新

1. **多视角语义 ID**：为多义的视频学习多组互补的语义 ID——不同视角（内容/动作/场景）各一套码本，缓解单 ID 语义混杂。
2. **生成式召回 + 稠密重排**：GR 负责近常数成本的快速召回，现成稠密检索器重排——各自发挥所长。
3. **量化即特征抽象**：语义 ID 经量化捕获高层视频特征——向量量化作为语义压缩工具。
