# 深度技术分析：Diff-ES: Stage-wise Structural Diffusion Pruning via Evolutionary Search

## 1. 核心速览

**研究主题**：扩散模型的分阶段结构化剪枝与进化搜索稀疏调度

**一句话总结**：Diff-ES 指出扩散模型各去噪步的重要性高度非均匀且依模型而异，现有方法（如 MosaicDiff）靠手工调的阶段稀疏调度、推理时拼接多个独立剪枝模型而增显存；Diff-ES 用进化搜索自动寻找分阶段结构化剪枝的稀疏调度，在真实加速与图像质量间取得更好平衡。

---

## 2. 研究背景与动机

扩散模型生成质量高但**多步去噪 + 大模型**计算昂贵。提效有两条路：减少采样步数、压缩模型参数。现有结构化剪枝难以平衡**真实加速**与**图像质量**：MosaicDiff 等方法依赖**启发式手工调的阶段稀疏调度**，且推理时**拼接多个独立剪枝模型**，增加显存开销。关键洞察：**扩散步重要性高度非均匀、且因模型而异**——手工调度不可能普适最优。

## 3. 核心方法与创新点

1. **进化搜索稀疏调度**：用**进化搜索**自动寻找分阶段（stage-wise）的稀疏度分配；
2. **结构化剪枝**：面向真实加速的结构级剪枝；
3. **单一模型推理**：避免 MosaicDiff 式多模型拼接的显存开销；
4. **模型自适应**：调度随模型自动适配，而非手工统一。

## 4. 实验设计与结果

- **对象**：图像生成扩散模型；
- **对比**：MosaicDiff 等启发式阶段剪枝；
- **结论**：Diff-ES 在真实加速与图像质量保持上取得更好平衡；

## 5. 局限性与未来展望

- 进化搜索的计算成本需评估；
- 摘要未给出具体数字；

## 6. 学术启发

- **扩散步重要性非均匀且依模型而异**——调度必须自动搜索而非手工统一；
- **进化搜索适合这类离散结构优化**；
- 对自己的研究：多阶段模型的压缩调度是独立的优化维度，值得专门算法。
