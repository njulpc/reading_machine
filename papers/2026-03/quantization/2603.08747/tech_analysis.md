# 深度技术分析：Diagnosing FP4 inference: a layer-wise and block-wise sensitivity analysis of NVFP4 and MXFP4

## 1. 核心速览

**研究主题**：NVFP4 与 MXFP4 两种 FP4 格式推理的逐层/逐块敏感度诊断

**一句话总结**：本文对 NVFP4 与 MXFP4 两种主流 FP4 微缩放格式做了逐层、逐块的敏感度分析，系统诊断 FP4 推理中哪些层、哪些块最易受量化损伤，为 FP4 部署提供可操作的诊断依据与格式选择指导。

---

## 2. 研究背景与动机

FP4（4-bit 浮点）推理是压缩 LLM 的前沿，NVFP4 与 MXFP4 是两大主流微缩放 FP4 格式，二者在**块大小、缩放机制**上存在差异。然而实践中缺乏对这两种格式的**细粒度敏感度画像**：哪些层对 FP4 最敏感？同层内不同块（block）的敏感度如何分布？两种格式的敏感模式是否一致？缺少这些诊断，部署者只能盲目套用统一精度，要么损失精度、要么浪费比特。

## 3. 核心方法与创新点

1. **逐层敏感度分析**：量化每一层对 FP4 量化的敏感度，定位"敏感层"与"可压缩层"；
2. **逐块敏感度分析**：深入到微缩放格式的块粒度，刻画块级误差分布；
3. **双格式对比**：对 NVFP4 与 MXFP4 做并排诊断，揭示块大小与缩放机制差异如何影响敏感度模式；
4. **诊断驱动的方法论**：为后续混合精度/差异化 FP4 分配提供数据支撑。

## 4. 实验设计与结果

- **对象**：NVFP4 与 MXFP4 两种 FP4 格式；
- **粒度**：逐层（layer-wise）+ 逐块（block-wise）；
- **产出**：两种格式的敏感度画像与对比结论，指导 FP4 部署时的差异化精度策略。
- 摘要侧重诊断框架与洞察，未给出单一"刷分"式主结果。

## 5. 局限性与未来展望

- 诊断结论可能依赖所测模型与任务，跨架构普适性需更多验证；
- 仅诊断权重/激活的 FP4，未覆盖 KV cache；
- 敏感度指标与下游任务精度的定量映射关系待建立；
- 未来方向：把诊断结果转化为自动化混合精度分配器；扩展到更多微缩放格式；建立公开的 FP4 敏感度基准。

## 6. 学术启发

- **先诊断、后设计**：在提出新的 FP4 方法前，细粒度敏感度画像是必不可少的地基；
- **两种 FP4 格式不可混用假设**：块大小/缩放机制差异会导致不同敏感模式，格式选择应基于诊断而非习惯；
- 对自己的研究：做微缩放格式研究时，逐块粒度分析比逐层更能暴露问题本质。
