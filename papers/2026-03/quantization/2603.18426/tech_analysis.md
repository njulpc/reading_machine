# 深度技术分析：Prune-then-Quantize or Quantize-then-Prune? Understanding Compression Order in Joint Model Compression

## 1. 核心速览

**研究主题**：联合模型压缩中"压缩顺序"的理论与实证分析

**一句话总结**：本文首次系统研究"先剪枝后量化"还是"先量化后剪枝"的顺序问题，形式化压缩顺序优化并提出**渐进强度假说**（较弱扰动应先于较强扰动），给出理论保证——一种顺序的相对收益随底层性能差距增大而增大；在语言与视觉模型上验证假说，并推广到多阶段压缩与混合精度量化。

---

## 2. 研究背景与动机

联合模型压缩（组合剪枝、量化等多种方法）能实现更高效率，但**压缩顺序**（各方法在管线中的先后）这一核心因素长期未被探索：多数研究假设各技术**正交**来回避该问题，少数只在高度受限的情形下考察。压缩顺序在更大范围如何影响最终性能，认知模糊。

## 3. 核心方法与创新点

1. **形式化压缩顺序优化**：把压缩顺序作为显式优化对象建模；
2. **渐进强度假说（Progressive Intensity Hypothesis）**：**较弱的扰动应先于较强的扰动**——这是核心可检验命题；
3. **理论保证**：证明一种顺序的相对收益**随底层性能差距增大而增大**；
4. **广泛验证**：语言 + 视觉模型，并推广到**多阶段压缩**与**混合精度量化**。

## 4. 实验设计与结果

- **模型**：语言模型与视觉模型；
- **结论**：大量实验**验证渐进强度假说**——弱扰动先行更优；
- **普适性**：结论在多阶段压缩与混合精度量化等更广设置下依然成立；
- 摘要未给出具体数字，强调假说的稳健性与普适性。

## 5. 局限性与未来展望

- "扰动强度"的度量需要可操作化，不同技术间如何比较强度待细化；
- 理论保证依赖特定假设，极端组合下的边界情况待研究；
- 仅考察剪枝 × 量化，更多技术（蒸馏、低秩）的顺序待探索；
- 未来方向：自动化最优顺序搜索；把强度度量与敏感度分析统一；扩展到三种以上技术的联合压缩。

## 6. 学术启发

- **压缩顺序是一等设计变量**：不能假设技术正交而随意级联；
- **渐进强度原则（弱先于强）**简单却深刻，可直接指导实践；
- 对自己的研究：组合多种压缩技术时，应先做顺序消融，把"顺序"纳入方法设计而非事后补救。
