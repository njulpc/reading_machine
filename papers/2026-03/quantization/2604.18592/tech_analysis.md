# 深度技术分析：Two-dimensional Early Exit Optimisation of LLM Inference

## 1. 核心速览

**研究主题**：层级 × 句级二维协同的 early exit

**一句话总结**：本文提出二维 early exit——逐句增量处理输入的同时渐进激活更深层，协调"层级退出"与"句级退出"获得超过任一单维的乘性算力节省；在 4 个 SOTA LLM（Llama 3.1/3.2、Gemma、Qwen，3B–8B）、3 个情感分类数据集上，较最优层级 early exit 再提速 1.4–2.3×（简单任务），复杂任务上优雅退化。

---

## 2. 研究背景与动机

early exit 通常只沿"层"这一维度优化。但对分类任务，**输入也可逐句增量处理**——简单样本可能读几句就够，且浅层就够。把**句级退出**与**层级退出**协同起来，能获得乘性节省。

## 3. 核心方法与创新点

1. **二维 early exit**：同时协调**层级退出**（逐 token 提前停层）与**句级退出**（逐句增量读输入）；
2. **乘性节省**：两维独立优化之外的**额外乘性收益**；
3. **渐进加深**：随输入句数增加**渐进激活更深层**；
4. **优雅退化**：复杂任务上自动退回更深/更全的计算。

## 4. 实验设计与结果

- **模型**：Llama 3.1、Llama 3.2、Gemma、Qwen（3B–8B）；
- **任务**：3 个情感分类数据集；
- **结果**：较最优层级 early exit **再提速 1.4–2.3×**（简单任务 + vanilla 模型），复杂任务优雅退化。

## 5. 局限性与未来展望

- 目前限分类任务，生成式任务的二维退出未验证；
- 句级增量处理改变注意力模式，对长程依赖任务可能不适用；
- 摘要未给出精度影响细节；
- 未来方向：推广到生成任务；与 token 级退出（TIDE）三维统一；难度自适应的二维调度。

## 6. 学术启发

- **"退出维度"可以组合**：层 × 句的乘性节省思路可推广到层 × token × 句；
- **简单样本简单处理**是自适应计算的永恒主题；
- 对自己的研究：设计自适应推理时，枚举所有可"提前退出"的维度再组合。
