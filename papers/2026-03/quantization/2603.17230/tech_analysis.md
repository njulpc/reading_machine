# 深度技术分析：KANtize: Exploring Low-bit Quantization of Kolmogorov-Arnold Networks

## 1. 核心速览

**研究主题**：Kolmogorov-Arnold 网络（KAN）的低比特量化探索

**一句话总结**：KANtize 系统研究低比特量化对 KAN 的影响——KAN 用可学习 B 样条激活（系数为可学习参数），推理时样条求值增加计算复杂度；本文考察 8-bit 以下量化对 KAN 精度与计算复杂度的影响，填补 KAN 量化研究的空白。

---

## 2. 研究背景与动机

KAN 因参数效率与可解释性潜力受到关注：与 MLP 不同，KAN 使用**可学习非线性激活**（通常为 B 样条线性组合），**B 样条系数即为可学习参数**。但推理时**样条求值增加计算复杂度**。传统量化能降低参数与激活的数值精度、减小复杂度，但量化对 KAN 的影响——尤其是 **8 bit 以下**—— largely 未被探索。

## 3. 核心方法与创新点

1. **首个 KAN 低比特量化系统研究**：聚焦 sub-8-bit 区间；
2. **双维度评估**：量化对**精度**与**计算复杂度**（样条求值成本）的双重影响；
3. **KAN 结构特异性分析**：B 样条系数量化 vs 传统权重量化的差异；
4. **探索性定位**：为后续 KAN 高效推理研究奠基。

## 4. 实验设计与结果

- **对象**：KAN（B 样条激活）；
- **设置**：8-bit 以下多个量化级别；
- **产出**：量化对 KAN 精度与推理复杂度的影响画像；
- 摘要未给出具体数字，为探索性研究。

## 5. 局限性与未来展望

- 探索性研究，缺少与 MLP 量化的大规模对照；
- 未涉及 KV/注意力（KAN 目前多用于小模型/科学计算）；
- 样条求值的硬件 kernel 优化未涉及；
- 未来方向：KAN 专用量化格式；样条系数与权重的联合量化；KAN 在更大模型上的量化。

## 6. 学术启发

- **新架构（KAN）的量化不能套用 MLP 经验**——可学习激活函数的参数是新的量化对象；
- **量化收益要同时看精度与"实际复杂度降低"**（样条求值未必因量化变快）；
- 对自己的研究：面对新架构时，量化研究应从"哪些参数最敏感"的第一性原理重新做起。
