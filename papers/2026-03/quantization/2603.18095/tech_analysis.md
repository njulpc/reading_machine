# 深度技术分析：Q-Drift: Quantization-Aware Drift Correction for Diffusion Model Sampling

## 1. 核心速览

**研究主题**：扩散模型采样侧的量化感知漂移校正

**一句话总结**：Q-Drift 把量化误差视为每个去噪步上的隐式随机扰动，推导出保持边缘分布的漂移校正，仅需 5 组配对的全精度/量化校准运行估计逐步方差统计，即插即用于常见采样器与 PTQ 方法；在 6 个文生图模型、3 种采样器、2 种 PTQ 方法上多数场景改善 FID，PixArt-Sigma（SVDQuant W3A4）最高降低 4.59 FID 且 CLIP 分数不变。

---

## 2. 研究背景与动机

后训练量化是部署大型扩散模型的现实路径，但量化噪声会沿**去噪轨迹逐步累积**，最终损伤生成质量。已有工作多从"量化器本身"入手减误差，却忽视了**采样器维度**：去噪是一个多步随机过程，量化扰动在每一步都会改变后续的漂移方向。能否在**不动量化器**的前提下，从采样侧校正这种累积误差，是本文的出发点。

## 3. 核心方法与创新点

1. **误差建模为随机扰动**：把量化误差刻画为每个去噪步上的隐式随机扰动；
2. **边缘分布保持的漂移校正**：据此推导出一个 drift adjustment，使采样过程的**边缘分布不被量化扰动改变**——这是方法的理论核心；
3. **极轻校准**：从校准中估计**逐时间步方差统计**，实践中**仅需 5 组**配对的全精度/量化校准运行；
4. **即插即用**：校正项与常见采样器、扩散模型、PTQ 方法完全解耦，推理开销可忽略。

## 4. 实验设计与结果

- **模型**：6 个文生图模型（涵盖 DiT 与 U-Net 架构）；
- **采样器**：Euler、flow-matching、DPM-Solver++；
- **PTQ 方法**：SVDQuant、MixDQ；
- **结果**：在大多数设置下 FID 优于对应量化基线；**PixArt-Sigma（SVDQuant W3A4）最高降低 4.59 FID**，同时保持 CLIP 分数不变。

## 5. 局限性与未来展望

- "多数设置改善"意味着并非全部场景受益，个别配置可能无效；
- 依赖少量校准运行，极端域偏移下方差统计的代表性待验证；
- 仅校正权重/激活量化引起的漂移，未覆盖 KV cache 或注意力低比特；
- 未来方向：扩展到视频扩散；把方差统计估计做成免校准在线版本；与采样器调度联合优化。

## 6. 学术启发

- **采样器是扩散量化的"第二战场"**：不必只盯着量化器，采样侧的概率校正能以极小成本补救累积误差；
- **把量化误差当随机扰动**并做分布保持校正，是把 SDE 理论引入量化的优雅示范；
- 对自己的研究：多步生成过程中的误差累积值得专门建模——单步最优≠轨迹最优。
