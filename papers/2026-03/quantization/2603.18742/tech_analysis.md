# 深度技术分析：6Bit-Diffusion: Inference-Time Mixed-Precision Quantization for Video Diffusion Models

## 1. 核心速览

**研究主题**：视频扩散模型的推理时 NVFP4/INT8 混合精度量化与时序缓存

**一句话总结**：6Bit-Diffusion 发现"块的输入-输出差异"与其内部线性层量化敏感度强线性相关，据此设计轻量预测器动态分配 NVFP4（时序稳定层）与 INT8（易变层），并利用块残差的时序一致性提出 Temporal Delta Cache 跳过不变块计算，实现 1.92× 端到端加速与 3.32× 显存削减，刷新视频 DiT 高效推理基线。

---

## 2. 研究背景与动机

视频扩散 Transformer（DiT）生成能力强，但高显存与高计算成本严重制约部署。后训练量化是现实选择，但现有方法施加**静态比特分配**，忽视了**跨去噪时间步激活量化难度的变化**，导致效率-质量权衡次优。此外，视频生成中相邻时间步的计算存在大量冗余。如何同时利用"时序敏感度差异"与"时序冗余"，是本文动机。

## 3. 核心方法与创新点

1. **关键相关性发现**：一个块的**输入-输出差异**与其内部线性层的量化敏感度呈**强线性相关**——这提供了一个廉价的敏感度探针；
2. **轻量预测器动态分配**：基于上述探针，动态把 **NVFP4 分配给时序稳定的层**（最大化内存压缩）、**INT8 保留给易变层**（保证鲁棒性），实现激进量化而不损质量；
3. **Temporal Delta Cache（TDC）**：观察到 Transformer 块输入-输出残差**跨时间步高度一致**，据此跳过这些不变块的计算，进一步降低算力消耗；
4. **推理时框架**：整个混合精度策略在推理时完成，无需重训练。

## 4. 实验设计与结果

- **对象**：视频扩散 Transformer（Video DiTs）；
- **结果**：
  - **1.92× 端到端加速**；
  - **3.32× 显存削减**；
  - 设立视频 DiT 高效推理新基线，生成质量在激进量化下保持。

## 5. 局限性与未来展望

- "输入-输出差异↔敏感度"的线性相关性在更多架构上的普适性待验证；
- TDC 依赖时序冗余，对快变/高动态内容的视频可能收益下降；
- NVFP4/INT8 混合在 kernel 层的调度复杂度未披露；
- 未来方向：扩展到图像/音频扩散；把敏感度预测器与层间混合精度统一；在线自适应缓存策略。

## 6. 学术启发

- **"块输入-输出差异"是一个免费的敏感度信号**——无需额外前向即可估计量化难度，值得推广；
- **时序冗余是视频生成的宝藏**：TDC 证明相邻步残差高度一致，可大量跳算；
- 对自己的研究：视频/序列模型中，优先挖掘"跨步不变量"来同时做量化分配与计算跳过，一举多得。
