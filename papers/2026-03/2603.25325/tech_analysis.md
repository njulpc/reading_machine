# 深度技术分析：How Pruning Reshapes Features: SAE Analysis of Weight-Pruned Language Models

## 1. 核心速览

**研究主题**：用稀疏自编码器探针系统研究剪枝如何重塑特征几何

**一句话总结**：本文首次用稀疏自编码器（SAE）系统研究非结构化剪枝对 LM 内部表示的影响——跨 3 个模型家族（Gemma 3 1B/Gemma 2 2B/Llama 3.2 1B）、2 种剪枝方法（magnitude/Wanda）、6 个稀疏度（0–60%）、5 个研究问题，最惊人发现是低激活率的稀有 SAE 特征对剪枝特别脆弱。

---

## 2. 研究背景与动机

权重剪枝是 LLM 压缩标准技术，但**其对学习到的内部表示的影响知之甚少**。剪枝后的模型"少了什么"？传统指标（PPL/精度）回答不了表示层面的问题。SAE 作为可解释性探针能把表示分解为人类可读的特征，正好用来回答。

## 3. 核心方法与创新点

1. **首个系统研究**：剪枝对特征几何的影响，用 SAE 做探针；
2. **广覆盖**：3 模型家族 × 2 剪枝方法 × 6 稀疏度（0–60%）；
3. **五个研究问题**：种子稳定性、特征存活、SAE 可迁移性、特征脆弱性、因果相关性；
4. **关键发现**：**稀有 SAE 特征（低激活率）对剪枝特别脆弱**。

## 4. 实验设计与结果

- **设置**：Gemma 3 1B / Gemma 2 2B / Llama 3.2 1B；magnitude 与 Wanda；稀疏度 0–60%；
- **核心发现**：稀有特征（低 firing rate）在剪枝中最易丢失——这解释了剪枝模型在长尾能力上的退化；
- 其他四维问题（稳定性/存活/迁移/因果）的系统结论支撑该图景。

## 5. 局限性与未来展望

- SAE 本身的训练噪声可能混入分析；
- 仅到 60% 稀疏度，更高稀疏度的特征崩塌模式待研究；
- 1–2B 小模型，大模型上的结论待验证；
- 未来方向：用特征脆弱性指导保护式剪枝；与概率空间分析（2603.24652）统一；研究稀有特征恢复方法。

## 6. 学术启发

- **可解释性工具（SAE）是压缩分析的新武器**——能看到精度指标看不到的特征级伤害；
- **稀有特征脆弱 = 长尾能力退化**的机理，提示剪枝应保护低频特征；
- 对自己的研究：评估压缩时，"哪些特征死了"比"分数掉了多少"更有诊断价值。
