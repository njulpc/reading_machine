# 深度技术分析：Dual-Space KD with Key-Query Matching for LLMs with Vocabulary Mismatch

## 1. 核心速览

**研究主题**：词表不匹配 LLM 间蒸馏的注意力机制解析与改进

**一句话总结**：本文系统分析词表不匹配蒸馏 SOTA 方法 DSKD-CMA 的注意力机制——通过手工 token 对齐探针与热力图可视化揭示其优势与局限，并提出 Key-Query 匹配的改进，推进跨 tokenizer 知识蒸馏的可理解性与效果。

---

## 2. 研究背景与动机

知识蒸馏能把大模型能力迁移到小模型，但当师生使用**不同 tokenizer（词表不匹配）**时，logit 无法直接对齐，蒸馏变得困难。DSKD-CMA（Dual-Space KD with Cross-Model Attention）是该方向的 SOTA，但**其内部工作机制仍不透明**。

## 3. 核心方法与创新点

1. **机制解析**：通过**手工 token 对齐探针**与**热力图可视化**系统分析 DSKD-CMA 的跨模型注意力；
2. **优劣揭示**：明确该方法在何种对齐情形下有效、何处失效；
3. **Key-Query 匹配改进**：提出基于 K-Q 匹配的改进方案；
4. **可理解性贡献**：为跨 tokenizer 蒸馏提供机制级理解。

## 4. 实验设计与结果

- **对象**：词表不匹配的师生 LLM 对；
- **结论**：分析揭示 DSKD-CMA 的对齐机制与局限，K-Q 匹配改进提升蒸馏效果；

## 5. 局限性与未来展望

- 手工探针的覆盖度有限；

## 6. 学术启发

- **跨 tokenizer 蒸馏的核心是对齐问题**，注意力可视化是诊断对齐质量的利器；
- **SOTA 方法也值得"打开黑盒"**——机制理解常常暴露可修复的局限；
- 对自己的研究：做跨模型蒸馏时，先验证 token 对齐质量再谈损失设计。
