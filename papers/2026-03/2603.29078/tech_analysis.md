# 深度技术分析：PolarQuant: Optimal Gaussian Weight Quantization via Hadamard Rotation for LLM Compression

## 1. 核心速览

**研究主题**：利用权重分布结构的免校准 LLM 后训练权重量化

**一句话总结**：PolarQuant 通过"块级归一化到单位超球面 → Walsh-Hadamard 旋转 → 匹配高斯分布质心量化"三阶段，使 Qwen3.5-9B 的 absmax Q5 困惑度从 6.90 降至 6.40（距 FP16 仅 +0.03），消融显示 Hadamard 旋转贡献 98% 的改进，且无需任何校准数据；作为 INT4 预处理还能把 absmax INT4 的 PPL 从 6.68 降到 6.56。

---

## 2. 研究背景与动机

LLM 后训练权重量化追求"近无损压缩"。已有观察表明，Transformer 权重经适当旋转后坐标会近似服从高斯分布，而高斯分布的最优量化质心有解析形式。这提示：与其在原始（非平稳、含异常值）坐标系里量化，不如先把权重变换到"友好"的分布族，再做理论最优的量化。难点在于如何用**免校准**的方式稳定地诱导出高斯性，并把增益落实到实际量化管线。

## 3. 核心方法与创新点

1. **三阶段管线**：
   - **块级归一化到单位超球面**：消除块间幅度差异，统一量化尺度；
   - **Walsh-Hadamard 旋转**：把坐标变换为近似高斯随机变量，摊平异常值；
   - **高斯匹配质心量化**：用与高斯分布匹配的质心做量化，逼近该分布的理论最优。
2. **旋转贡献主导**：消融实验显示 **Hadamard 旋转单独贡献 98% 的质量改进**——说明"分布重塑"才是核心，而非复杂的质心设计。
3. **完全免校准**：不依赖任何校准数据，属于 data-free PTQ。
4. **可作为下游量化器的预处理**：PolarQuant Q5 反量化后再用 torchao INT4 重量化，PPL 6.56，优于直接 absmax INT4 的 6.68，同时保持 43.1 tok/s 吞吐、6.5 GB 显存。

## 4. 实验设计与结果

- **模型**：Qwen3.5-9B；
- **主结果**：absmax Q5 PPL 6.90 → PolarQuant 6.40（FP16 基线 6.37，差距仅 +0.03），几乎无损；
- **消融**：Hadamard 旋转贡献 98% 改进；
- **作为预处理**：PolarQuant Q5 + torchao INT4 = 6.56 PPL，优于直接 absmax INT4 的 6.68；推理 43.1 tok/s @ 6.5 GB VRAM；
- **开源**：代码与模型公开。

## 5. 局限性与未来展望

- 主结果仅在 Qwen3.5-9B 单一模型上展示，跨模型/跨规模的普适性待验证；
- Q5 已属较保守比特数，未展示 3–4 bit 等更激进设置下的表现；
- 仅做权重量化，未覆盖激活与 KV cache；
- 未来方向：推广到 W4/W3；与激活旋转（QuaRot 类）联合形成全链路旋转量化；理论刻画"旋转→高斯化"的收敛条件。

## 6. 学术启发

- **分布重塑优先于量化器设计**：当旋转已能解决 98% 的问题时，应优先研究"如何更好地重塑分布"，而非在劣质分布上堆复杂量化器；
- **免校准 + 近无损**是部署友好的组合，尤其适合数据隐私敏感场景；
- 对自己的研究：消融实验要敢于回答"哪个组件真正起作用"——98% 归因其一，反而是最有说服力的结论。
