# 深度技术分析：Bielik-Q2-Sharp: Extreme 2-bit Quantization for a Polish 11B LM

## 1. 核心速览

**研究主题**：波兰语 11B 语言模型极端 2-bit 量化的系统对比

**一句话总结**：Bielik-Q2-Sharp 是首个针对波兰语 LLM 的 2-bit 量化系统评测——以 Bielik-11B-v2.3-Instruct（Mistral 架构）为基座，在波兰语语料（CulturaX-PL）与共享 Hessian 下对比 QuIP#/SpinQuant+GPTQ/ButterflyQuant/QTIP/VPTQ/AQLM 六种方法，最优变体 QuIP# E8P12 在 22 个波兰语基准上达 71.92%（与 IQ2_XXS 的 72.07% 处于统计噪声内），并发现旋转类方法"保对数似然但生成崩溃"的 MC-生成解离现象。

---

## 2. 研究背景与动机

极端 2-bit 量化在非英语 LLM 上的效果缺乏系统研究——大多数评测集中在英语模型。波兰语等形态丰富的语言对量化可能更敏感。作者要回答：六种 SOTA PTQ 方法在波兰语 11B 模型上孰优孰劣？极端 2-bit 能否保住多语言能力与高阶推理？

## 3. 核心方法与创新点

1. **首个波兰语 2-bit 系统评测**：覆盖六种 SOTA PTQ 方法（QuIP#、SpinQuant+GPTQ、ButterflyQuant、QTIP、VPTQ、AQLM）；
2. **严格受控对比**：所有方法在**同一波兰语语料（CulturaX-PL）**、**共享 Hessian 矩阵**下校准，消除混淆变量；
3. **发现 MC-生成解离（MC-generation dissociation）**：旋转类方法能保持对数似然（MC 选择题）质量，却在**自回归生成**上灾难性失败——揭示了评测指标选择的陷阱；
4. **极致成本效率**：单个独立研究者在 vast.ai 云 GPU 上、**285 美元预算**内完成全部实验，模型/Hessian/日志全部公开。

## 4. 实验设计与结果

- **基座**：Bielik-11B-v2.3-Instruct（11B，Mistral 架构）；
- **最优变体 QuIP# E8P12**：22 个波兰语基准 **71.92%**，与 IQ2_XXS 基线 72.07% **处于统计噪声内**，代价是体积略大（3.26 GB vs ~2.6 GB）；eq_bench 上 **47.14 vs 43.53（+3.6pp）**，高阶推理保留更好；
- **QTIP 最佳每比特效率**：~2.4 bpw、3.27 GB 下达 **79.4% MC acc_norm**，以 35% 更小体积追平 VPTQ 质量；
- **MC-生成解离**：旋转类方法 MC 好但生成崩。

## 5. 局限性与未来展望

- 单一模型（11B Mistral 架构）与单一语言，结论泛化需更多验证；
- 体积与质量的权衡（QuIP# 体积略大）需按部署场景取舍；
- MC-生成解离的机理未深入解释；
- 未来方向：扩展到更多语言/模型；研究解离现象的根源并设计兼顾 MC 与生成的方法；自动化最优方法选择。

## 6. 学术启发

- **非英语 LLM 量化是被低估的研究空白**，语言特异性（形态复杂度）影响量化难度；
- **MC 与生成可能解离**：只用选择题评测会高估旋转类方法，必须同时测生成；
- 对自己的研究：低预算（<$300）也能做出严谨的对比研究——受控变量 + 全量开源比规模更重要。
