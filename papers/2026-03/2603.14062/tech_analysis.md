# 深度技术分析：TMPDiff: Temporal Mixed-Precision for Diffusion Models

## 1. 核心速览

**研究主题**：扩散模型去噪时间步上的时序混合精度量化

**一句话总结**：TMPDiff 打破"所有去噪步用同一精度"的惯例，提出按时间步分配不同数值精度的框架；基于"量化误差随时间步加性累积"的假设（已实验验证），设计线性复杂度的自适应二分分配算法，在 4 个 SOTA 扩散模型、3 个数据集上相同加速比下感知质量提升 10–20%，FLUX.1-dev 上以 2.5× 加速达到全精度 90% 的 SSIM。

---

## 2. 研究背景与动机

扩散模型是文生图主流，但迭代去噪导致推理延迟高。量化能降低单步计算，但传统做法对**所有去噪时间步施加固定精度**——这等于放弃了"时间"这一整个优化维度。不同时间步对量化误差的敏感度其实不同（早期大步去噪 vs 晚期细节修复），理应差异化分配精度。难点在于**逐时间步的精度搜索空间是指数的**。

## 3. 核心方法与创新点

1. **时序混合精度框架（TMPDiff）**：首次系统地把"去噪时间步"作为精度分配的维度，不同步用不同比特；
2. **加性累积假设及其验证**：提出并实验验证**量化误差随时间步加性累积**的假设，为分配算法提供理论依据；
3. **自适应二分分配算法**：基于加性结构，把原本指数的逐步精度搜索降为**线性评估复杂度**；
4. **强实证**：4 个 SOTA 扩散模型 + 3 个数据集上全面验证。

## 4. 实验设计与结果

- **设置**：4 个 SOTA 扩散模型、3 个数据集，与均匀精度基线在**相同加速比**下对比；
- **结果**：
  - 一致优于均匀精度基线，**感知质量提升 10–20%**；
  - **FLUX.1-dev**：2.5× 加速（相对 16-bit 推理）下达到全精度模型 **90% 的 SSIM**。

## 5. 局限性与未来展望

- 聚焦图像扩散，视频/音频扩散中的时序混合精度待验证；
- 加性累积假设在更长轨迹/不同采样器下的普适性需更多证据；
- 逐时间步的精度切换在 kernel/硬件层的调度开销需评估；
- 未来方向：扩展到视频扩散与 LLM 的逐步推理；与层间混合精度统一为"时空混合精度"；在线自适应精度调度。

## 6. 学术启发

- **"时间"是被忽视的量化维度**：迭代式生成模型（扩散、自回归）都应考虑按步分配精度；
- **找到一个可验证的结构假设（加性累积）能把指数搜索降为线性**——先建模结构、再设计算法；
- 对自己的研究：面对多步过程，先问"各步对误差的敏感度是否相同"，往往能找到免费的优化空间。
