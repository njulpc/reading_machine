# 深度技术分析：DIET: Dimension-wise Global Pruning of LLMs via Merging Task-specific Importance Score

## 1. 核心速览

**研究主题**：免训练、任务感知的维度级全局结构化剪枝

**一句话总结**：DIET 只用每任务 100 个样本分析各任务的激活幅度，再以多数投票融合任务特异重要性分数构建单一全局掩码，实现维度级粒度 + 任务感知选择的免训练剪枝；在 Gemma-2 2B/9B 七个零样本基准上，20% 稀疏度时较此前 SOTA 结构化剪枝平均精度提升近 10%。

---

## 2. 研究背景与动机

结构化剪枝通过移除整个维度或层来压缩 LLM，但现有方法面临两难：**任务无关方法**无法适配任务特异需求；**任务感知方法**又需要昂贵训练来学习任务适应性。能否既**任务感知**又**免训练**？DIET 给出肯定答案。

## 3. 核心方法与创新点

1. **任务特异重要性分析**：每个任务仅用 **100 个样本**分析激活幅度，得到任务特异的重要性分数；
2. **多数投票融合**：把多个任务的特异性分数通过**多数投票**合并为**单一全局掩码**，兼顾任务感知与全局一致性；
3. **维度级粒度**：在维度（dimension）级别做全局剪枝，粒度更细；
4. **免训练、低成本**：无需预计算大成本或训练。

## 4. 实验设计与结果

- **模型**：Gemma-2 2B 与 9B；
- **评测**：7 个零样本基准；
- **结果**：**20% 稀疏度下，Gemma-2 2B 平均精度较此前 SOTA 结构化剪枝提升近 10%**；
- **鲁棒性**：优势在各稀疏度水平与模型规模上均保持。

## 5. 局限性与未来展望

- 多数投票是硬融合，对任务冲突的处理可能粗糙；
- 仅在 2B/9B 规模验证，超大模型待测试；
- 每任务 100 样本的代表性在窄域任务上可能不足；
- 未来方向：软投票/加权融合；推广到更大模型与 MoE；与量化联合的任务感知压缩。

## 6. 学术启发

- **任务感知 ≠ 必须训练**：小样本激活画像 + 投票融合即可免训练获得任务适应性；
- **多数投票是融合多任务重要性的简单有效基线**；
- 对自己的研究：多任务压缩中，先用低成本的逐任务画像再融合，比直接全局估计更稳健。
