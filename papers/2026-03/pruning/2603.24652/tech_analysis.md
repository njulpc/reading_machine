# 深度技术分析：Demystifying When Pruning Works via Representation Hierarchies

## 1. 核心速览

**研究主题**：从表示层级视角解释"剪枝何时有效"

**一句话总结**：本文把语言模型内部计算分解为嵌入（表示）、logit（softmax 前）、概率（softmax 后）三个顺序空间，发现嵌入与 logit 空间的表示对剪枝基本鲁棒、而概率空间脆弱——这解释了剪枝模型在非生成任务表现好、生成任务常失败的分歧。

---

## 2. 研究背景与动机

剪枝被期望在保持性能的同时提效，但**这一期望在语言任务上并不一致成立**：剪枝模型在**非生成任务**上表现不错，却在**生成式设置**中频繁失败。为何有这种分歧？本文从**表示层级**视角给出解释。

## 3. 核心方法与创新点

1. **三空间分解**：把 LM 内部计算分为**嵌入空间**（隐藏表示）、**logit 空间**（softmax 前输出）、**概率空间**（softmax 后分布）；
2. **分空间鲁棒性分析**：发现**嵌入与 logit 空间表示对剪枝基本鲁棒**；
3. **概率空间的脆弱性**：生成任务依赖概率空间的细粒度分布，剪枝在此处伤害最大——**解释了生成/非生成分歧**；
4. **统一解释框架**：为"剪枝何时有效"提供表示层级判据。

## 4. 实验设计与结果

- **方法**：表示层级分解分析；
- **结论**：剪枝的伤害集中在概率空间；嵌入/logit 层相对鲁棒；
- 这解释了非生成任务（依赖表示）好、生成任务（依赖分布）差的实证模式。

## 5. 局限性与未来展望

- 三空间分解是分析框架，如何据此改进剪枝未充分展开；
- 不同剪枝方法在三空间的影响模式是否一致待验证；
- 摘要未给出具体模型与数字；
- 未来方向：设计"概率空间保护"的剪枝准则；与蒸馏（恢复分布）结合；推广到量化分析。

## 6. 学术启发

- **压缩的伤害在不同表示空间不均匀**——评估应分空间进行；
- **"非生成好、生成差"的模式与 MC-生成解离（Bielik-Q2、GenDistill）相互印证**；
- 对自己的研究：报告压缩效果时，区分"表示保持"与"分布保持"两类指标。
