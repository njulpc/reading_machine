# 深度技术分析：The Diminishing Returns of Early-Exit Decoding in Modern LLMs

## 1. 核心速览

**研究主题**：现代 LLM 中 early-exit 解码收益递减的再评估

**一句话总结**：本文重新评估逐层 early-exit（预测足够置信即提前停算），发现随着新模型采用更优预训练配方与架构、层冗余下降，early-exit 有效性呈逐代递减趋势；作者提出量化模型内在 early-exit 适配度的指标与基准，并发现稠密 Transformer 比 MoE/SSM 更具 early-exit 潜力、>20B 大模型与未专调基座模型潜力更高。

---

## 2. 研究背景与动机

early-exit 在预测足够置信时于中间层停止计算，以降低延迟与成本。但它成立的前提是**存在层冗余**。问题在于：**近期 LLM 采用改进的预训练配方与架构，层冗余在减少**——这可能压缩 early-exit 的机会空间。早期研究基于的旧模型结论，在新一代模型上还成立吗？

## 3. 核心方法与创新点

1. **现代 LLM 的 early-exit 再评估**：系统重测逐层 early-exit 在新一代模型上的有效性；
2. **训练动态分析**：分析中间表示在训练过程中的演化，理解层冗余的来源；
3. **适配度指标**：提出**量化模型内在 early-exit 适配度**的度量；
4. **公开基准**：为研究者提供探索不同模型/负载 early-exit 潜力的基准。

## 4. 实验设计与结果

- **核心发现**：early-exit 有效性**随模型世代递减**；
- **架构差异**：**稠密 Transformer 的 early-exit 潜力普遍高于 MoE 与状态空间模型（SSM）**；
- **规模差异**：**更大模型（尤其 >20B）与未专调的基座预训练模型** early-exit 潜力更高。

## 5. 局限性与未来展望

- "适配度指标"与最终实际加速收益的定量映射需更多验证；
- 结论依赖所测模型集合，未来架构可能改变趋势；
- 未深入探讨如何"重新引入"可利用的层冗余；
- 未来方向：研究训练时显式鼓励 early-exit 友好的层冗余；把 early-exit 与投机解码、KV 压缩组合；探索 MoE/SSM 专属的提前退出机制。

## 6. 学术启发

- **"层冗余下降"侵蚀了 early-exit 的根基**——压缩技术的有效性会随模型世代漂移，需持续再评估；
- **架构（稠密/MoE/SSM）与规模显著影响压缩潜力**，不存在跨架构普适结论；
- 对自己的研究：任何依赖"冗余"的压缩方法，都应在新一代模型上重新验证其前提是否仍成立。
