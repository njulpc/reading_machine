# 深度技术分析：Rényi Entropy: A New Token Pruning Metric for Vision Transformers

## 1. 核心速览

**研究主题**：基于 Rényi 熵的免训练视觉 token 重要性度量

**一句话总结**：本文指出依赖 [CLS] token 估计 patch 重要性在浅层不可靠（语义表示尚不成熟），提出源自 Rényi 熵的免训练度量 Col-Ln，能从网络第一层就识别信息性 token、实现更可靠的早期剪枝；在 ViT 与大型视觉语言模型上持续超越 SOTA 剪枝方法。

---

## 2. 研究背景与动机

ViT 的自注意力 O(N²) 复杂度使高分辨率输入推理昂贵，token 剪枝是关键加速手段。但多数方法**依赖 [CLS] token 估计 patch 重要性**——作者指出 [CLS] 在**浅层不可靠**，因为浅层语义表示尚不成熟。在浅层做剪枝时，不可靠的重要性估计会导致**不必要的早期信息损失**。

## 3. 核心方法与创新点

1. **问题诊断**：[CLS] token 在浅层的语义表示不成熟，以其为依据的早期剪枝不准；
2. **Col-Ln 度量**：提出源自 **Rényi 熵**的免训练 token 重要性度量；
3. **从第一层即可靠**：Col-Ln 能**从网络第一层**就识别信息性 token，使早期剪枝更可靠；
4. **广适用**：在 ViT 与 LVLM 上均有效，免训练。

## 4. 实验设计与结果

- **模型**：ViT 与大型视觉语言模型（LVLM）；
- **对比**：SOTA token 剪枝方法；
- **结果**：Col-Ln 在**多样基准上持续超越 SOTA 剪枝方法**；
- 免训练特性使其即插即用。

## 5. 局限性与未来展望

- 摘要未给出具体加速比与精度绝对数字；
- Rényi 熵的阶数等超参选择对结果的影响未披露；
- 聚焦分类/理解任务，对生成式任务的适用性待验证；
- 未来方向：把 Col-Ln 推广到视频/多模态；与深度自适应剪枝（逐层不同比率）结合；理论刻画 Rényi 熵与信息量的关系。

## 6. 学术启发

- **重要性度量的可靠性随深度变化**——浅层不能用依赖成熟语义的度量（如 [CLS]）；
- **换一个信息论度量（Rényi 熵）就能解锁早期剪枝**——度量设计本身值得研究；
- 对自己的研究：做逐层压缩时，应检验所用在每层都可靠，而非仅在深层有效。
