# 深度技术分析：ReDiPrune: Relevance-Diversity Pre-Projection Token Pruning for Efficient MLLMs

## 1. 核心速览

**研究主题**：投影前的相关性-多样性视觉 token 剪枝

**一句话总结**：ReDiPrune 在视觉-语言投影**之前**（视觉特征仍丰富可辨时）做免训练 token 剪枝，用轻量规则联合**文本条件相关性**与**最大-最小多样性**打分，确保所选 token 既贴合查询又互不冗余，保留细粒度空间与语义线索。

---

## 2. 研究背景与动机

MLLM 因处理大量视觉 token 而计算昂贵。多数剪枝在**投影之后**进行——但投影后的表示已被压缩，丢失了判别性。ReDiPrune 主张在**投影前**（视觉编码器输出处）剪枝，此时特征仍丰富且可辨。

## 3. 核心方法与创新点

1. **投影前剪枝（pre-projection pruning）**：直接在视觉编码器输出上选择信息性 token，保留细粒度空间与语义线索；
2. **双准则打分**：轻量规则联合**文本条件相关性**（贴合查询）与 **max-min 多样性**（互不冗余）；
3. **免训练**；
4. **对比优势**：优于在压缩表示上操作的后投影剪枝。

## 4. 实验设计与结果

- **对象**：多模态 LLM 视觉 token 剪枝；
- **结论**：投影前剪枝保持更强判别力，相关性-多样性双准则选择更优；

## 5. 局限性与未来展望

- 投影前剪枝节省的是 LLM 段计算，编码器成本不变（与 EvoPrune 互补）；
- 摘要未给出具体数字；
- 相关性与多样性权重需平衡；
- 未来方向：与早期编码剪枝（EvoPrune）级联；视频场景扩展；学习式双准则融合。

## 6. 学术启发

- **剪枝位置（投影前/后/编码中）是独立的设计维度**——各位置节省的成本段不同；
- **相关性 + 多样性双准则**是鲁棒的 token 选择配方；
- 对自己的研究：报告 token 剪枝时应明确剪枝点在 pipeline 中的位置及其影响。
