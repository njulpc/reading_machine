# 深度技术分析：Mix-and-Match Pruning: Globally Guided Layer-Wise Sparsification of DNNs

## 1. 核心速览

**研究主题**：全局引导的逐层差异化 DNN 稀疏化框架

**一句话总结**：Mix-and-Match Pruning 用敏感度分数与简单架构规则生成多样的高质量剪枝配置——推导架构感知的稀疏度范围（如保留归一化层、更狠剪分类层），并系统采样这些范围为每个模型产出十种策略组合，解决"不同层/架构对剪枝响应不同、单一策略次优"的问题。

---

## 2. 研究背景与动机

边缘部署 DNN 需要强压缩且精度损失最小。但**不同层与架构对剪枝的响应不同**，单一策略不可能处处最优。需要一个能系统性生成并组合多种逐层稀疏策略的框架。

## 3. 核心方法与创新点

1. **架构感知稀疏度范围**：推导简单规则——如**保留归一化层、更激进剪分类层**；
2. **全局引导 + 逐层执行**：敏感度分数全局引导，逐层差异化稀疏；
3. **系统采样策略组合**：在稀疏度范围内系统采样，**为每个模型生成十种策略**（Mix-and-Match）；
4. **边缘部署导向**：强压缩与精度保持并重。

## 4. 实验设计与结果

- **对象**：多种 DNN 架构的边缘部署压缩；
- **结论**：Mix-and-Match 生成的策略组合优于单一策略基线；

## 5. 局限性与未来展望

- 十种策略的选择仍需评估开销；
- 架构规则的覆盖度（新架构）有限；
- 摘要未给出具体数字；
- 未来方向：学习式策略组合；与神经架构搜索结合；扩展到 Transformer 大模型。

## 6. 学术启发

- **"层异质性"要求差异化稀疏策略**，组合多种简单规则优于单一复杂规则；
- **架构先验（归一化层敏感等）是廉价有效的剪枝指导**；
- 对自己的研究：剪枝框架应内置"按层类型差异化"的规则库。
