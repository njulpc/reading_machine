# 深度技术分析：ResPrune: Text-Conditioned Subspace Reconstruction for Visual Token Pruning in LVLMs

## 1. 核心速览

**研究主题**：文本条件化的子空间重构式视觉 token 剪枝

**一句话总结**：ResPrune 把视觉 token 剪枝建模为**子空间重构问题**——用残差能量引导的贪心子空间扩展选择 token 子集，保持原视觉 token 空间的几何结构；进一步融入文本条件的跨模态对齐，实现免训练的高效 LVLM 推理。

---

## 2. 研究背景与动机

LVLM 依赖稠密视觉 token 捕捉细粒度视觉信息，但处理全部 token 带来巨大计算与显存开销。剪枝要回答的核心问题是：**选出的 token 子集能否"代表"原空间的结构**？ResPrune 用子空间重构来形式化这个问题。

## 3. 核心方法与创新点

1. **子空间重构建模**：把 token 选择形式化为**重构原视觉 token 子空间**的问题；
2. **残差能量引导的贪心扩展**：逐步加入最能降低重构残差的 token，保持几何结构；
3. **文本条件化**：融入跨模态对齐——选择与文本查询相关的子空间方向；
4. **免训练**：无需任何训练。

## 4. 实验设计与结果

- **对象**：LVLM 视觉 token 剪枝；
- **结论**：子空间重构式选择在保持视觉结构的同时实现高效推理；

- **"剪枝 = 子空间重构"提供了有几何保证的选择准则**——比启发式打分更有原则；
- **文本条件化让剪枝感知查询意图**；
