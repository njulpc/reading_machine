# 深度技术分析：TED: Training-Free Experience Distillation for Multimodal Reasoning

## 1. 核心速览

**研究主题**：免训练、基于上下文经验的多模态推理蒸馏

**一句话总结**：TED 把蒸馏的更新目标从模型参数转移到注入学生提示词的"上下文经验"——学生对每个输入生成多条推理轨迹，教师独立解题后把经验提炼进上下文，无需任何参数更新与大规模训练数据，实现资源受限环境下的多模态推理蒸馏。

---

## 2. 研究背景与动机

传统知识蒸馏通过监督或强化优化把教师知识灌进学生参数，**需要反复参数更新与大规模训练数据**，在资源受限环境难以适用。能否**不改参数**也实现"蒸馏"？TED 的回答：把知识放进**上下文**。

## 3. 核心方法与创新点

1. **蒸馏目标转移**：从**参数**转移到**注入提示词的上下文经验（in-context experience）**；
2. **流程**：学生对每个输入生成**多条推理轨迹**；教师**独立产生自己的解答**；教师再把经验提炼注入学生上下文；
3. **完全免训练**：无参数更新、无大规模训练数据；
4. **面向多模态推理**：资源受限环境友好。

## 4. 实验设计与结果

- **任务**：多模态推理；
- **结论**：TED 在免训练条件下提升学生推理表现；

## 5. 局限性与未来展望

- 上下文经验不占参数，但占用上下文窗口且每次推理需注入；
- 效果依赖教师现场解题质量；
- 摘要未给出具体数字；
- 未来方向：经验的选择性压缩与复用；与参数蒸馏混合；推广到 agent 场景。

## 6. 学术启发

- **"蒸馏"的本质是知识迁移，参数只是载体之一**——上下文也是合法载体；
- **免训练蒸馏特别适合资源受限/黑盒学生场景**；
- 对自己的研究：当无法更新参数时，"上下文蒸馏"是可行的降级方案。
