# 深度技术分析：Revisiting On-Policy Distillation: Empirical Failure Modes and Simple Fixes

## 1. 核心速览

**研究主题**：在策略蒸馏（OPD）的失效模式诊断与简单修复

**一句话总结**：本文从理论与实现双面重审 OPD——标准实现把分布匹配简化为采样 token 对数比，在长 rollout（前缀漂移出教师支撑集）上信号脆弱；理论上 token 级 OPD 相对序列级 reverse-KL 有偏但方差界更紧，受控合成研究显示更强的未来奖励相关性可缓解；据此给出简单修复。

---

## 2. 研究背景与动机

在策略蒸馏（OPD）在 LLM 后训练中日益流行：教师为学生 rollout 提供稠密监督。但**标准实现把分布匹配简化为采样 token 的对数比**——当 rollout 变长、前缀逐渐漂移出教师的典型支撑集时，学习信号变得脆弱。

## 3. 核心方法与创新点

1. **理论分析**：token 级 OPD 相对序列级 reverse-KL 最小化**有偏**，但具有**显著更紧的最坏情况方差界**——解释了实践中 token 级为何仍流行；
2. **受控合成研究**：更强的**未来奖励相关性**可改善 OPD 表现；
3. **失效模式刻画**：长 rollout 前缀漂移导致的信号脆弱被明确诊断；
4. **简单修复**：针对失效模式给出易实现的修复方案。

## 4. 实验设计与结果

- **方法**：理论分析 + 受控合成实验 + 实证；
- **结论**：token 级 OPD 的偏差-方差权衡被厘清；所提修复改善长 rollout 下的稳定性；

## 5. 局限性与未来展望

- 合成研究与真实 LLM 蒸馏的差距需桥接；
- 摘要未给出具体数字；
- 修复方案在大规模训练中的成本未评估；
- 未来方向：序列级校正的实用化；与奖励整形结合；推广到多轮 agent 蒸馏。

## 6. 学术启发

- **"有偏但低方差"常是实践选择的真正原因**——理论分析应同时刻画两者；
- **长 rollout 的前缀漂移是 OPD 的阿喀琉斯之踵**；
- 对自己的研究：设计蒸馏目标时，需检验其在"学生偏离教师支撑集"时的行为。
