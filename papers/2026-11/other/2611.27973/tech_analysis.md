# MemOnce: A Scalable Memory Architecture for Large Language Models

官方 [摘要](https://arxiv.org/abs/2611.27973) · [全文](https://arxiv.org/html/2611.27973v1)

v1：2026-11-20T18:51:29+00:00；北京时间：2026-11-21T02:51:29+08:00。分类：Computation and Language (cs.CL)。证据为官方摘要及已阅读的正文/方法/实验，作者数字与本地验证分开列示。

## 1. 核心速览
研究主题：跨层、跨时间的语言模型记忆压缩。
一句话总结：只保存部分末层状态，并按需恢复各层 KV，降低长期交互的缓存成本。

## 2. 研究背景与动机
逐层保存全部 token KV 会重复保存历史信息；固定容量线性状态又容易丢失细节。关键问题是将持久记忆、当前活跃记忆和临时解码缓存分开计量。

## 3. 核心方法与创新点
- 每段保留末端 1/r 的最终层状态，消除逐层重复，结构性压缩因子为 Lr。
- 分层 MLP 将检索状态恢复为各层 K/V，避免简单共享同一 KV 的表达限制。
- 一次检索的索引跨层复用；默认 r=8、top-K=64。
- 预训练联合学习；后训练冻结主干，训练投影和编码阶段 LoRA。

## 4. 实验设计与结果
官方表 2：r=8 的 WikiText-103 PPL 为 21.08，Transformer 为 20.90；因此不能宣称所有指标无损。表 3：4B 记忆任务均分 60.07，相对完整上下文 54.30 增加 5.77 个百分点。作者在 1M 上下文报告状态缓存缩减 1313 倍、prefill 加速 6.9 倍、吞吐提升 3.5 倍。实验使用 8 张 H100。

## 5. 局限性与未来展望
读者判断：1313 倍是特定长度和缓存口径的结果，不是模型参数压缩倍率，也不是全系统内存缩减。持久存储仍随历史增长；应同时测量 CPU 存储、索引、传输和临时解码峰值。检索遗漏对罕见事实的影响需要单独测试。这里未运行该架构，所有指标均为论文报告。

## 6. 学术启发
可将“保存什么”与“每层如何读取”分离，研究跨层共享潜变量与低比特编码的组合。建议消融固定检索预算、固定总内存预算与固定延迟预算，避免不同资源口径掩盖瓶颈。
