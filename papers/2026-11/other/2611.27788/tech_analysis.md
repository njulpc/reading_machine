# When Does Looking Closer Pay Off? Simple Foveated ViTs for Fine-Grained Recognition

官方 [摘要](https://arxiv.org/abs/2611.27788) · [全文](https://arxiv.org/html/2611.27788v1)

v1：2026-11-20T16:20:23+00:00；北京时间：2026-11-21T00:20:23+08:00。分类：Computer Vision and Pattern Recognition (cs.CV)。证据为官方摘要及已阅读的正文/方法/实验，作者数字与本地验证分开列示。

## 1. 核心速览
研究主题：ViT 输入 token 的多分辨率压缩与动态推理。
一句话总结：先低分辨率观察，再仅细化重要区域，减少高分辨率 token 计算。

## 2. 研究背景与动机
图像各区域对细粒度识别的价值不相等。研究重点是减少推理计算，不是压缩权重文件；本文据 token 缩减纳入 other。

## 3. 核心方法与创新点
- DINOv2 ViT-S/14 在 224px 图像上获取末层 CLS attention。
- 选择 K 个粗格，用 448px 图像对应细 patch 替换；空间 token 数为 256+3K，默认 K=64。
- 原始粗嵌入保留，不复用上下文化特征；细/粗输出联合监督。
- 置信度足够时跳过细化，阈值可在留出集校准。

## 4. 实验设计与结果
五个细粒度数据集、两个种子、每数据集 26 种配置。K=64 的 Transformer 计算量为 17.68 GMACs，相对统一 448px 的 31.61 减少约 44%；同训练目标比较中四个数据集无显著精度差异，Aircraft 平均损失 0.53 个百分点。计算量不含全部前后处理，不能等同墙钟加速。

## 5. 局限性与未来展望
读者判断：两次前向及 token 收集有额外开销；小目标分布和置信度漂移会影响策略收益。测试集排序门是离线预算工具，在线部署应使用独立校准阈值。未运行本地视觉复现，本轮也不要求非量化论文代码复现。

## 6. 学术启发
比较 token 压缩方法时应匹配辅助损失与训练预算，防止把训练正则化收益归因于稀疏推理。可进一步测试真实 batch 混合、动态形状和端到端延迟，判断节省的算术量能否转化为部署收益。
