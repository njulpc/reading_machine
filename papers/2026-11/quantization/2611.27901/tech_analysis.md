# QuantStream3D: Geometry-Aligned Low-Bit KV Cache Quantization for Streaming Visual Geometry Transformers

官方 [摘要](https://arxiv.org/abs/2611.27901) · [全文](https://arxiv.org/html/2611.27901v1)

v1：2026-11-20T17:38:48+00:00；北京时间：2026-11-21T01:38:48+08:00。分类：Computer Vision and Pattern Recognition (cs.CV)。证据为官方摘要及已阅读的正文/方法/实验，作者数字与本地验证分开列示。

## 1. 核心速览
研究主题：流式视觉几何 Transformer 的低比特 KV 缓存。
一句话总结：逐通道混合精度保护配合几何蒸馏，使历史缓存量化适应连续几何预测。

## 2. 研究背景与动机
历史 K 的误差改变注意力分布，V 的误差改变读出内容，两者还会影响后续缓存写入；语言模型的 K/V 敏感性结论未必适用于几何任务。

## 3. 核心方法与创新点
- K、V 均按 64 token 逐通道 affine RTN，scale 与 zero point 为 FP32，并实际位打包。
- 首帧或第 14 层为 4 bit，其余 2 bit；当前帧先以原精度参与读取，再写入量化历史。
- RoPE 后同时对 Q/K 做 H64/8，V 不旋转。
- 冻结教师，学生使用自身量化历史；联合更新块和几何头，训练 2000 步。

## 4. 实验设计与结果
两个主干、五个几何基准。表 4 的 StreamVGGT TUM ATE：原始 0.0269 m、KIVI 0.0493 m、本文 0.0264 m。H20 实测 KV 压缩 5.05 倍、单请求延迟降低 23.1%。本目录关联的 Qwen 脚本实测结果另列 README，不能当作论文几何实验的复现分数。

## 5. 局限性与未来展望
读者判断：层 14 和首帧保护是特定架构经验，迁移时应重新做敏感性扫描；低比特码字之外的量化参数、padding 和临时浮点重建都要计量。Qwen 没有相机、深度和点云头，因此本次仅实现可对应的量化推理部分，未复现几何 QAD、校准扫描或 Triton 内核；不能声称完整复现。

## 6. 学术启发
量化评估需追踪历史误差的递归传播，不只测单层重构 MSE。可在 Qwen 上比较固定层保护与独立校准集选层，并用不同文本测试长期缓存；需将该迁移实验和原论文算法严格区分。
