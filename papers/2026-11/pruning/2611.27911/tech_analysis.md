# Functional Depth Is Learned: Isolating the Computation That Layers Produce Only Together

官方 [摘要](https://arxiv.org/abs/2611.27911) · [全文](https://arxiv.org/html/2611.27911v1)

v1：2026-11-20T17:50:26+00:00；北京时间：2026-11-21T01:50:26+08:00。分类：Artificial Intelligence (cs.AI)。证据为官方摘要及已阅读的正文/方法/实验，作者数字与本地验证分开列示。

## 1. 核心速览
研究主题：层间联合计算及其对层剪枝判据的影响。
一句话总结：表征相似不等于功能冗余，剪层前还应测量跨层依赖。

## 2. 研究背景与动机
仅凭相邻层相似度判断可删除性，可能忽略只有多层共同参与才出现的计算。本文是剪枝机制分析，并非声称已得到高压缩率的新压缩器。

## 3. 核心方法与创新点
- 对保序的层子集前向计算做包含—排除分解，隔离 connected component。
- 用最终参与层的实际写入归一化，以区分相对协作增强和整体尺度增长。
- 将删除该分量与等范数随机方向删除比较，并直接测试连续层块移除。

## 4. 实验设计与结果
Pythia、OLMo、Amber 共七个模型，交互阶数 2–6；35 个模型—阶数组合中，删除协作分量均比等范数随机删除更损害 PPL。表 4：Amber-7B 删除两层时，低协作选择得到 PPL 23.8，高 CKA 选择为 55.7，原模型为 11.0。较好的判据仍导致明显损失，不能表述为无损剪枝。

## 5. 局限性与未来展望
读者判断：子集枚举随阶数指数增长，不适合无约束地扩展到全部深层组合。连续块实验不能自动证明任意非连续结构剪枝有效，也没有完整硬件加速或文件压缩结果。评分中的压缩倍率低分反映证据缺失，不代表其理论价值低。

## 6. 学术启发
可以将协作度作为候选剪枝块的风险筛查，再与激活、梯度指标联合；应单独留出校准和评估语料，并记录修复训练后的实际效果，避免在同一文本上选择和验证删除位置。
