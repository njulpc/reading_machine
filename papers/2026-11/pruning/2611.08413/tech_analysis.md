# T3R: Training-Free Two-Stage Token Refinement Towards Efficient and Robust VLA Models

> arXiv: 2611.08413；v1：2026-11-05T18:17:29+00:00（UTC） / 2026-11-06T02:17:29+08:00（北京时间）。
> 分类：Robotics (cs.RO) ; Computer Vision and Pattern Recognition (cs.CV)。归档以 v1 北京时间月份为准。
> 证据：[官方摘要与提交历史](https://arxiv.org/abs/2611.08413)；[官方HTML全文](https://arxiv.org/html/2611.08413v1)。以下论文结果均为作者报告，本地结果另行标注。

## 1. 核心速览

**研究主题**：pruning / T3R。

**一句话总结**：T3R在解码前剪除场景相机冗余token，再用任务级显著性修复注意力；85%场景token减少只带来1.16倍实测VLA调用加速。

## 2. 研究背景与动机

双相机VLA每步处理大量背景patch，既耗计算又可能在分布偏移时分散动作注意力。按单点相似度删除token会破坏完整物体边界；删除后的RoPE重新编号还会改变预训练位置结构。因此仅仅高剪枝率并不保证动作成功率。

## 3. 核心方法与创新点

1. 用SigLIP计算带词性权重的指令—patch相关性，先取50个高分点，以DBSCAN ε=2.0聚类，最大空间簇中选8个正点、全局低分取3个负点，交给EfficientTAM-S生成分割。
2. 覆盖像素比例超过0.3才保留patch；只剪场景相机，保留原始position ID，腕部相机及其他输入保留。分割每5次VLA调用异步更新，文本embedding按指令缓存。
3. 任务开始时对embedding做5步Integrated Gradients，以pad为基线，保留top 30%显著token；仅对动作query在解码层8–23加正偏置，β=2.0，视觉相似度权重乘0.5。
4. 剪枝移除明显无关内容，attention bias在保留集合中再次分配权重，二者解决不同误差。

## 4. 实验设计与结果

主要配置OpenVLA-OFT：SigLIP ViT-SO400M、LLaMA-2-7B、LoRA rank32，双相机共512视觉token，每次生成8动作chunk；L40S 48GB，LIBERO每任务10集。

表1：Spatial基线成功率97%、107.5ms；T3R剪85%场景相机token后96%、92.5ms；同剪枝率ADP66%、FastV14%。推导：调用加速107.5/92.5≈1.16倍；若两个相机均256token，则删除85%单相机token约减少全部视觉token的42.5%，不是85%。LLM-only 58.9→36.1ms与整次调用差额对应7.8ms剪枝/偏置开销。分割一次54ms异步执行，IG约1秒一次性成本。

消融：只剪枝90%、只bias98%、二者96%；768px的3.3倍是LLM-forward profiling，2.47倍整端是加固定非LLM成本后的预测。CogACT单相机Google Robot由73.2%降至67.7%；RoboTwin三相机在50%保留率下与基线均33.3%（表2）。本次未运行机器人模拟。

## 5. 局限性与未来展望

Object套件T3R82%低于TeamVLA86%，分割会错选容器或丢失后续阶段需要的区域。异步mask可能滞后，任务初始化IG开销未必可摊销。所有控制评估为仿真；没有实机时延、能耗或边缘硬件证据。未来宜按相机冗余和任务阶段自适应token预算。

## 6. 学术启发

压缩率必须注明分母，速度必须注明量测边界。保留原position ID是可迁移的实现细节；训练免校准不等于运行无额外模型，分割器与梯度显著性成本都应进入部署评估。

**四维评分（1–10，编辑判断而非客观排名）**：精度效果 7/10；压缩倍率 7/10；创新性 7/10；可复现性 6/10。

精度7：Spatial仅损失1个百分点但单相机退化；压缩7：85%仅一台相机token，非权重压缩；创新7：位置保持、分割与注意力修复协同；复现6：超参数完整，但模拟器、分割器和异步测时未本地复现。
