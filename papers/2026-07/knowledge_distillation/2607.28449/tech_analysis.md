> **论文**: Lightning OPD 2.0: Mitigating Style Bias in Cross-Teacher On-Policy Distillation for Large Reasoning Models
> **作者**: Yecheng Wu, Song Han, Han Cai（NVIDIA）
> **arXiv**: https://arxiv.org/abs/2607.28449
> **项目主页**: https://github.com/jet-ai-projects/Lightning-OPD

---

## 一、核心速览

### 研究主题

大推理模型（Large Reasoning Models）的跨教师在线策略蒸馏（Cross-Teacher On-Policy Distillation, OPD）。具体而言，本文研究当 SFT 数据生成器（demonstration generator）与 OPD 蒸馏教师（distillation teacher）不是同一模型时，如何消除教师不一致（teacher inconsistency）引入的风格偏置（style-token bias），使蒸馏信号仍然有效。

### 一句话总结

本文提出 **Lightning OPD 2.0**，通过交叉拟合的风格残差化（cross-fitted style residualization）机制，将原始教师-参考模型分歧中可跨 rollout 预测的"风格成分"估计出来并减去，仅用残留的推理相关信号驱动蒸馏更新，从而在跨教师设置下将教师一致性从 OPD 的必要前提放松为可选项，使 SFT 数据生成器与蒸馏教师可独立选择，在 Klear-Reasoner-8B-SFT 上达到 AIME 2024 的 82.4% 和 LiveCodeBench v5 的 63.0%。

## 二、研究背景与动机

### 现有研究的痛点

1. **OPD 依赖教师一致性（teacher consistency）**：在线策略蒸馏（OPD）利用高能力教师对学生生成的轨迹打分，将教师-学生分歧转化为密集的 Token 级监督，是强化学习（RLVR）的稳定且高性价比替代方案。前作 Lightning OPD 发现，有效的 OPD 需要"教师一致性"——即提供 OPD 监督的教师应当与生成 SFT 示范数据的模型相同。这一条件使 Token 级蒸馏信号与参考策略已学习的行为对齐，从而使完全离线的 Lightning OPD 能紧密追踪标准在线 OPD。

2. **教师一致性在实践中难以满足**：现实中，可用的 SFT 数据可能来源混合或来源未知，由多个不同模型生成，无法确定单一示范教师。即使原始数据生成器已知，从业者也可能希望复用已有 SFT 数据集，而非为每个候选教师重新生成示范数据并重做 SFT。更根本地，教师一致性将 SFT 数据生成器的选择与 OPD 教师的选择耦合在一起，但这两个角色的最佳模型未必相同——从业者可能希望用更强的生成器产出更高质量的示范并获得更强的 SFT 参考策略，同时选择不同的教师进行后续蒸馏。

3. **跨教师设置下蒸馏效果急剧退化**：当用不同的 OPD 教师替换一致教师时，即使新教师更强，性能也会大幅退化。原因在于：某些 Token 承载问题特定的推理，而另一些 Token 主要表达响应的风格。在推理相关 Token 上，教师的低概率可能识别出错误的中间结论或推理方向，提供有用的纠正监督；但在风格 Token 上，同样的低概率可能仅仅反映了对不同用词、过渡、格式、推导长度或推理节奏的偏好，而参考轨迹仍然有效。Lightning OPD 无法区分这两种情况，将两者都转化为相同的 Token 级更新。由于风格选择遍布整个响应且类似偏好跨 rollout 反复出现，其累积惩罚会系统性干扰更具上下文特异性的推理信号。

### 为什么要做这项研究

本文的目标是**将教师一致性从有效 OPD 的实际前提中移除**，解耦 SFT 数据生成器与 OPD 教师的选择，同时在不同教师组合下仍获得可靠的训练后性能。作者通过对 Token 角色的分析发现：风格 Token 的分歧更可能通过类似的词汇选择、响应位置和参考策略惊奇度（surprisal）在不相关的 rollout 间反复出现，而推理相关分歧则更强地依赖于当前问题和推理状态。因此，可以将"跨缓存 rollout 可预测的成分"作为风格 Token 偏置的代理（proxy），将剩余残差作为推理相关教师证据的候选载体。

## 三、核心方法与创新点

### 方法概述

Lightning OPD 2.0 在 Lightning OPD 的离线缓存框架之上，引入**交叉拟合的风格残差化（cross-fitted style residualization）**机制，包含以下核心步骤：

**1. 定义教师-参考模型分歧**

设 $\pi_G$ 为 SFT 数据生成器，$\pi_R$ 为 SFT 参考策略，$\pi_T$ 为 OPD 教师，$\pi_\theta$ 为从 $\pi_R$ 初始化的可训练策略。对每个冻结的响应 $x_i = (y_{i1}, \dots, y_{iL_i}) \sim \pi_R(\cdot|q_i)$，教师和参考策略对同一已实现 Token 打分，产生缓存的对数概率：

$$\ell^T_{it} = \log \pi_T(y_{it}|h_{it}), \qquad \ell^R_{it} = \log \pi_R(y_{it}|h_{it})$$

定义教师-参考分歧为 $d_{it} = \ell^T_{it} - \ell^R_{it}$。在初始化时 $\pi_\theta = \pi_R$，故基础优势 $A^{\text{base}}_{it} = d_{it}$。在跨教师设置下，$d_{it}$ 既包含上下文特异性的教师证据，也包含由与 SFT 数据生成器不匹配引入的反复出现的教师-参考差异。

**2. 将分歧分解为风格偏置与残差**

做出操作性假设：与反复出现的风格差异相关的分歧更易从简单的词汇和粗粒度上下文坐标跨缓存 rollout 预测，而潜在有用的推理相关教师证据更强地依赖于当前上下文。据此将分歧分解为：

$$d_{it} = b(z_{it}) + v_{it}$$

其中 $z_{it}$ 收集 Token 和上下文坐标，$b(z_{it})$ 是在这些坐标上跨 rollout 反复出现的成分，$v_{it}$ 是剩余变化。用 $b(z_{it})$ 作为反复出现的风格 Token 偏置的代理。

**3. 可观测坐标的定义**

为估计跨 rollout 反复出现的成分，需要既足够频繁以支持可靠平均、又足够表达以区分 Token 不同用法的坐标：

- **Token 身份坐标** $z^{\text{tok}}_{it} = y_{it}$：捕捉词汇偏好，但将每次出现等同对待。
- **上下文坐标** $z^{\text{ctx}}_{it} = (p_{it}, r_{it})$：基于归一化响应位置和参考策略惊奇度的粗粒度上下文坐标。参考策略惊奇度 $\xi_{it} = -\ell^R_{it}$ 衡量已实现 Token 在 SFT 参考下的非典型程度。将响应分为 $B_{\text{pos}}$ 个归一化位置箱，将惊奇度范围分为 $B_{\text{ref}}$ 个箱（上限 $\xi_{\max}$）：

$$p_{it} = \left\lfloor B_{\text{pos}} \frac{t-1}{L_i} \right\rfloor, \qquad r_{it} = \min\left\{B_{\text{ref}}-1, \left\lfloor B_{\text{ref}} \frac{\xi_{it}}{\xi_{\max}} \right\rfloor\right\}$$

分箱将不同长度响应中的可比出现汇总。Token 和上下文查找表分别构建，而非使用其完整叉积，以避免将缓存碎片化为过度稀疏的组。

**4. 交叉拟合估计反复出现的分歧**

采用交叉拟合（cross-fitting）作为样本拆分技术来构建留出预测并防止自拟合。将缓存 rollout 划分为 $K$ 个确定性折（$K=5$），来自同一 prompt 的所有 rollout 归入同一折。对折 $k$ 中的 rollout，仅使用其他 $K-1$ 个折估计所有统计量。

为防止较长响应主导估计，在拟合查找表时为每个响应分配单位总权重，均匀分布在其活跃 Token 上（响应平衡加权）。使用非留出折构建一张 Token 身份的平均分歧查找表和一张上下文坐标的平均分歧查找表。稀有组向非留出折的全局均值平滑，未见组直接使用全局均值。

对折 $k$ 中的 Token $(i,t)$，使用等权预测：

$$\widehat{b}_{it} = \frac{1}{2} m^{\text{tok}}_{(-k)}(z^{\text{tok}}_{it}) + \frac{1}{2} m^{\text{ctx}}_{(-k)}(z^{\text{ctx}}_{it})$$

由于两个查找表均排除了当前 rollout，$\widehat{b}_{it}$ 捕捉的是从其他缓存 rollout 可预测的反复分歧，而非专门拟合当前响应的变化。

**5. 残差化的 Lightning OPD 更新**

基础优势可分解为跨教师分歧和参考锚定项：

$$A^{\text{base}}_{it}(\theta) = d_{it} + \ell^R_{it} - \log \pi_\theta(y_{it}|h_{it})$$

由于 $\widehat{b}_{it}$ 估计反复出现的教师-参考分歧，仅对 $d_{it}$ 进行残差化，保留参考锚定项不变。设 $d^*_{it} = d_{it} - \widehat{b}_{it}$，则残差化优势为：

$$A^{\text{res}}_{it}(\theta) = d^*_{it} + \ell^R_{it} - \log \pi_\theta(y_{it}|h_{it}) = \ell^T_{it} - \widehat{b}_{it} - \log \pi_\theta(y_{it}|h_{it})$$

等价地，定义固定的有效教师分数 $\widetilde{\ell}^T_{it} = \ell^T_{it} - \widehat{b}_{it}$ 并用它替代 $\ell^T_{it}$。该分数和 $\widehat{b}_{it}$ 在训练前计算并在整个优化过程中保持固定。

### 核心创新

1. **形式化跨教师 OPD 设置**：首次明确提出"跨教师 OPD"问题设定，即 SFT 数据生成器与 OPD 教师独立选择，并证明在此设置下蒸馏效果会大幅退化。这一定义使一个被实践忽视但普遍存在的问题获得了清晰的研究框架。

2. **识别风格 Token 偏置的可观测代理**：发现原始教师-参考分歧中存在一个可跨 rollout 预测的反复成分，与风格 Token 偏置相关（用词、格式、推理节奏差异），解释了为何原始跨教师监督会产生误导。这一发现将"风格 vs. 推理"的语义区分转化为可操作的统计可预测性判据。

3. **交叉拟合的双查找表残差化机制**：引入 Token 身份和上下文坐标（归一化位置 + 参考惊奇度）两张查找表，通过 rollout 级交叉拟合估计反复分歧成分并减去，再使用残差驱动蒸馏更新。该方法兼具理论严谨性（交叉拟合防止自拟合）和工程实用性（训练前预计算、训练中固定不变，不增加在线开销）。

4. **解耦 SFT 与蒸馏的教师选择**：最终成果是将教师一致性从 OPD 的前提条件放松为可选项，允许从业者为 SFT 数据生成和后续蒸馏独立选择最佳模型，最大化整体训练后效果。

## 四、实验设计与结果

### 实验设置

- **跨教师设置**：两个互补的设置，均以 Qwen3-30B-A3B-Thinking-2507 为 OPD 教师 $\pi_T$：
  - **Qwen3-4B 设置**：以 Lightning OPD 使用的 Qwen3-4B SFT 参考为起点，其 SFT 示范由 Qwen3-8B 生成，来源已知，可直接识别跨教师风格不匹配的来源。
  - **Klear-Reasoner-8B-SFT 设置**：使用 Klear-Reasoner-8B-SFT，由 Qwen3-8B-Base 训练，SFT 数据从 DeepSeek-R1-0528 蒸馏而来，测试同一校正是否适用于从不同初始化和数据生成器训练的更强 SFT 参考。

- **训练数据**：数学推理使用 DAPO-Math-17k（17K 竞赛级数学问题）；代码生成使用 KlearReasoner-CodeSub-15K（15K 精心清洗过滤的代码问题）。每个 OPD prompt 从 SFT 参考采样一个响应并预计算教师对数概率。交叉拟合使用 5 个 prompt 级折。训练框架基于 slime，每个模型训练 150 步，PPO 裁剪范围 0.2。

- **评估**：数学推理评估于 AIME 2024、AIME 2025、HMMT February 2025；代码生成评估于 LiveCodeBench v5 和 v6。温度 0.6，top-p 0.95，最大生成长度 40,960。数学每题 64 个解，代码每题 8 个解，报告平均 Pass@1。

- **基线**：SFT 参考、Lightning OPD（原始 Token 级蒸馏无风格校正）、IW-OPD（按累积教师-学生差异加权 Token 以解决位置偏置）、TA-OPD（选择教师信号预测可学的位置）。所有 OPD 方法从同一 SFT 参考开始，使用相同 rollout、缓存教师对数概率和训练预算。IW-OPD 和 TA-OPD 原为在线 rollout 设计，此处适配到冻结的 Lightning OPD 回放。

### 机制分析：风格 Token 偏置（4.3 节）

为评估残差化是否将跨教师训练信号向教师一致性下的信号靠拢，作者使用事后诊断模型 $\pi_D$ 衡量原始信号和残差化信号与诊断参考信号的绝对偏差：

$$o_{it} = |d_{it} - (\ell^D_{it} - \ell^R_{it})|, \qquad o^*_{it} = |d^*_{it} - (\ell^D_{it} - \ell^R_{it})|$$

在 Qwen3-4B-SFT 设置中，$\pi_D$ 为 Qwen3-8B（即生成 SFT 示范的来源教师 $\pi_G$），诊断参考信号即为精确的教师一致信号。在 Klear-Reasoner-8B-SFT 设置中，使用 Klear-Reasoner-8B 作为诊断代理。

Figure 3 比较了 $\tau$ 从 0.5 到 3.0 nats 变化时 $o_{it} > \tau$ 和 $o^*_{it} > \tau$ 的经验比例。在两个设置的所有评估阈值下，校正后曲线均低于校正前曲线。在代表性参考点 $\tau=1$ 处：

| 设置 | 校正前超标率 | 校正后超标率 | 相对降低 |
|------|:---:|:---:|:---:|
| Qwen3-4B-SFT | 8.14% | 3.85% | 52.8% |
| Klear-Reasoner-8B-SFT | 7.19% | 2.02% | 71.9% |

相对降低在更高阈值处进一步增大，表明残差化减少了与诊断参考信号的大偏差的普遍性。Figure 4 的 Token 级示例进一步显示，多个大的原始偏差出现在话语标记（discourse markers）和推理过渡上，残差化后大多降至参考阈值以下。这些证据支持了被移除成分作为反复出现的风格 Token 偏置的操作性解释。

## 五、局限性与未来展望

### 局限性

1. **任务与模型范围有限**：评估仅限于数学推理和代码生成两类任务，以及 Qwen 系列模型（Qwen3-4B-SFT、Klear-Reasoner-8B-SFT、Qwen3-30B-A3B-Thinking-2507）。论文明确承认"While our evaluation is limited to these tasks and Qwen-family models"。
2. **操作性分解的近似性**：风格与推理的区分是操作性（operational）的而非语义级精确标注。方法不假设每个可预测效应都是风格，也不假设每个残差都反映正确推理。这是一种近似而非 ground-truth 语义划分。
3. **Tokenization 兼容性要求**：方法假设教师和参考的分数对齐到相同的响应 Token，实验使用兼容的 Qwen 系列 Tokenization。跨不同 Tokenization 体系的教师组合可能需要额外处理。

### 未来展望

1. **扩展到更多任务领域**：将跨教师 OPD 验证扩展到数学和代码之外的推理任务（如科学推理、逻辑推理、多步问答）。
2. **跨 Tokenization 体系的泛化**：研究不同 Tokenization 体系下如何对齐教师与参考的分数，使方法适用于更广泛的模型组合。
3. **更精细的风格/推理分离**：探索比简单查找表更具表达力的风格偏置估计方法，如基于轻量学习的预测器。
4. **与在线 OPD 的结合**：当前方法基于 Lightning OPD 的离线回放框架，未来可探索在在线 OPD 场景中动态估计和更新风格偏置。

## 六、学术启发

1. **"教师一致性"约束的工程意义**：本文揭示了一个被广泛忽视但极具实践意义的约束——OPD 的有效性隐式依赖 SFT 数据生成器与蒸馏教师的一致性。在真实场景中，SFT 数据来源混合或未知是常态，这一约束的发现和放松对 OPD 的工程落地至关重要。它提醒从业者：蒸馏并非"换个更强的教师就一定更好"，教师间的风格不匹配可能系统性抵消推理监督信号。

2. **"可预测性即风格"的统计判据**：本文最巧妙的思想在于将"风格 vs. 推理"这一难以直接标注的语义区分，转化为"跨 rollout 可预测性"这一可操作的统计判据。风格选择（用词、格式、推理节奏）因反复出现而可预测，推理证据因上下文特异而不可预测。这种将抽象语义问题映射为可估计统计量的思路，对其他需要区分"信号 vs. 偏置"的蒸馏/对齐问题具有方法论启发。

3. **交叉拟合防止自拟合的严谨性**：采用 rollout 级交叉拟合（同 prompt 的 rollout 归入同一折，留出折的估计排除当前 rollout）来估计风格偏置，体现了方法论的严谨性。这种做法借鉴了因果推断/双重机器学习中的样本拆分思想，确保估计的风格成分不是对当前响应的过拟合，而是真正"跨 rollout 反复出现"的系统性成分。

4. **双坐标体系的设计智慧**：Token 身份坐标捕捉词汇偏好但过于粗粒度，完整前缀上下文精确但几乎不重复。作者选择以归一化响应位置和参考惊奇度作为中间粒度的上下文坐标，并分别构建两张查找表而非使用叉积（避免稀疏碎片化），体现了在表达力与估计稳定性之间的精心权衡。这种"多粒度坐标 + 分别估计 + 等权融合"的设计模式可迁移到其他需要跨样本聚合统计的场景。

5. **对推理模型训练后流水线的影响**：本文使 SFT 数据生成器与蒸馏教师可独立选择，意味着从业者可以"用最强生成器做 SFT + 用最合适教师做蒸馏"的组合策略，而不必为满足一致性而妥协某一阶段。这对于大规模推理模型的训练后流水线设计具有直接的工程价值，也可能影响未来 SFT 数据生产和蒸馏教师选择的最佳实践。
