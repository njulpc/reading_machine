## 1. 核心速览

### 1.1 研究主题

本文研究**面向视觉-语言-动作（Vision-Language-Action, VLA）模型的运动感知向量量化（Motion-Aware Vector Quantization, MotionVQ）框架**，旨在通过利用机器人执行过程中不同运动状态对精度的差异化敏感性，实现高效、低功耗的VLA推理加速。具体而言，论文提出了一种算法-硬件协同设计方法：在算法层面，通过分析机器人运动轨迹特征将执行过程划分为"执行态"（execution state，需要高精度）和"转移态"（transition state，可容忍低精度）；在硬件层面，设计了支持动态精度切换和质心复用的专用加速器架构VQVLA。

### 1.2 一句话总结

本文提出了MotionVQ框架，通过运动状态感知动态调整向量量化精度，并结合质心空间合并与时序复用技术，在仅损失0.3%任务成功率的前提下实现了VLA模型2.7倍的推理加速和3.1倍的能效提升。

## 2. 研究背景与动机

### 2.1 现有痛点

#### 2.1.1 VLA模型的计算与存储开销

视觉-语言-动作（VLA）模型是当前具身智能（Embodied AI）领域的核心架构，代表工作包括RT-1、RT-2、OpenVLA等。这些模型通常采用大型视觉编码器（如ViT）+ 大语言模型（如LLaMA-7B）+ 动作头的架构，参数量巨大（通常7B-55B），导致严重的计算和存储瓶颈：

- **高片外存储带宽需求**：以OpenVLA-7B为例，其Transformer骨干采用LLaMA2-7B，包含14GB参数。由于片内缓存容量有限，Transformer需要频繁访问片外存储器，产生巨大的存储带宽压力。
- **高计算强度**：Transformer的每层使用8个GEMM操作提取环境信息，包括多个N×4096×4096和N×N×4096形状的操作（N通常200-600），导致相当大的计算开销。
- **高能耗**：频繁的数据移动和大量的MAC运算导致VLA推理能耗极高，严重制约了机器人系统的续航能力和边缘部署。

#### 2.1.2 现有加速方法的不足

现有VLA加速方法主要分为两类，但均存在明显局限：

**纯算法优化**：
- **量化压缩**：传统的均匀量化（如INT8/INT4）虽然可以减少模型大小，但采用全局固定精度，无法适应不同执行阶段的精度需求差异。
- **知识蒸馏**：将大模型压缩到小模型，但通常伴随着显著的任务成功率下降。
- **稀疏化**：利用权重稀疏性减少计算量，但VLA模型中激活稀疏性有限。

**纯硬件加速**：
- **通用AI加速器**：如NVIDIA GPU、Google TPU，虽然性能强大，但能效比低，且无法针对VLA的特定计算模式优化。
- **FPGA/ASIC设计**：如Dadu-Corki框架，通过专用加速器降低延迟，但未利用VLA模型内部的冗余性。

#### 2.1.3 机器人运动的特性未被利用

现有工作的一个关键盲区是：**机器人执行过程中的运动状态具有明显差异**，而不同状态对动作精度的敏感性截然不同：

- **执行态（Execution State）**：机器人靠近目标物体（y ≤ 0.16），执行精细控制运动。此阶段的小误差可能导致任务失败。
- **转移态（Transition State）**：机器人远离目标物体（y > 0.16），执行大范围的粗粒度运动。此阶段的适度误差对任务成功率影响甚微。

这一观察暗示了**状态感知的动态精度调整**的可能性，但现有工作均未对此进行探索。

### 2.2 研究必要性

#### 2.2.1 具身智能的部署需求

VLA模型是实现通用机器人智能的关键技术路径，但其巨大的计算开销严重限制了实际部署：
- **实时性要求**：机器人控制通常需要10-30Hz的推理频率，延迟过高会导致控制不稳定。
- **能耗约束**：移动机器人平台（如无人机、服务机器人）的电池容量有限，高能效推理是刚需。
- **边缘计算**：为了保护隐私和降低延迟，越来越多的应用场景要求机器人本地执行推理。

#### 2.2.2 精度-效率权衡的新维度

传统上，模型压缩被视为全局精度与全局效率之间的权衡。本文提出了一种新的权衡维度：**局部精度-局部效率权衡**。通过识别不同执行阶段对精度的差异化需求，可以在保持整体任务成功率的同时，显著降低平均计算开销。这一思路的灵感来源于人类运动控制的"开环-闭环"理论：人类在执行粗略运动时依赖开环控制（低精度需求），而在精细操作时切换到闭环控制（高精度需求）。

#### 2.2.3 向量量化的潜力

向量量化（Vector Quantization, VQ）是一种经典的压缩技术，通过将高维向量映射到有限码本（codebook）中的最近质心（centroid）来实现压缩。VQ在图像生成（如VQ-VAE）和语音合成中广泛应用，但其在大型Transformer模型推理加速中的应用尚不充分。本文识别了VQ在VLA场景中的独特优势：
- **权重压缩**：将FP16权重压缩为整数索引+小型码本，大幅减少存储需求。
- **计算简化**：推理时直接使用码本质心进行计算，避免了解量化开销。
- **质心复用**：通过分析质心访问频率，发现存在"热质心"（hot centroids），为计算优化提供了机会。

## 3. 核心方法与创新点

### 3.1 方法概述

#### 3.1.1 MotionVQ算法

MotionVQ是本文的核心算法贡献，包含两个紧密耦合的阶段：

**阶段一：状态预测（State Prediction）**

基于运动幅度（motion magnitude）轻量级地估计当前机器人系统状态：

```
D = √(Δx² + Δy² + Δz²)
```

其中(Δx, Δy, Δz)表示机器人手臂在每一步的3D动作输出（来自上一次VLA推理的输出）。

状态判定规则：
- **执行态**：D ≤ Td（机器人靠近目标物体，需要精确调整）
- **转移态**：D > Td（机器人进行大范围运动，精度要求较低）

这一状态预测器的计算开销极低（仅需要平方根和几个比较操作），对整体推理延迟的影响可以忽略不计。

**阶段二：精度自适应（Precision Adaptation）**

基于预测的状态，动态选择两个预定义的量化配置之一：

| 配置 | 码本大小 | 精度级别 | 适用状态 |
|------|---------|---------|---------|
| 高精度 | 256 centroids | 高 | 执行态 |
| 低精度 | 64 centroids | 低 | 转移态 |

离线训练阶段，对Transformer权重执行VQ，生成两组码本和索引矩阵。运行时根据状态预测器的输出动态切换码本。

#### 3.1.2 运动行为分析与假设验证

本文通过系统性的运动行为分析验证了状态划分的合理性：

**实验设计**：在LIBERO数据集上使用OpenVLA-OFT模型，向两种状态注入不同水平的噪声，测量任务成功率。

**核心发现**（如图5所示）：
- 转移态（绿线）在相同噪声水平下始终保持比执行态（黄线）更高的成功率
- 这表明转移态对扰动的容忍度显著更高，确认其对精度的敏感性较低

**质心访问频率分析**（如图6所示）：
- 某些质心的访问频率远高于其他质心（最热质心被访问234次，最冷仅10次）
- 这证实了"热质心"的存在，为后续的质心复用优化提供了依据

#### 3.1.3 Merged-Centroid Vectorized GEMM范式

这是本文的硬件-算法协同设计核心，包含两个关键技术：

**空间合并（Spatial Merging）**

利用单列内质心的重复性（空间级热质心）：

```
∑(Iᵢ × Centroidᵢ) → (∑Iᵢ) × Centroidᵢ
```

当索引矩阵中的多个位置共享相同的索引值时，对应的输入元素可以先求和再与质心进行一次乘法，而非分别相乘后求和。这通过乘法的分配律消除了冗余计算。

实现上，为每个权重组构建"空间质心位置表"（spatial centroid location table），记录每个质心ID对应的权重向量ID。对于只有一个权重向量的条目直接丢弃，其余条目则先累加输入再执行乘法。

**时序复用（Temporal Reusing）**

利用跨列质心的重复性（时序级热质心）：

核心原理：涉及相同质心和相同输入的乘法可以通过复用缓存结果来跳过。

实现步骤：
1. 离线遍历所有索引，应用Top-k选择确定最频繁访问的质心
2. 运行时初始化结果缓存（tag, data）条目
3. 处理每个权重组时，比较索引与缓存tag，命中则直接复用

#### 3.1.4 VQVLA架构设计

VQVLA是支持MotionVQ的专用硬件架构，主要包含三个模块：

**状态预测器（State Predictor）**：
- 配备乘法器和加法器
- 计算运动幅度并与阈值比较
- 输出当前系统状态信号

**矩阵乘法引擎（Matrix Multiplication Engine）**：
- 空间合并PE阵列：执行质心合并操作
- 时序复用PE阵列：执行缓存查找和复用
- 加法器树单元：累加部分和
- 缓存初始化单元：初始化结果缓存
- 累加单元：累加最终结果

**索引处理引擎（Index Processing Engine）**：
- 处理索引矩阵的读取和解析
- 支持动态码本切换
- 生成控制信号

### 3.2 分点创新

#### 3.2.1 运动状态感知的动态精度切换（核心创新）

本文最核心创新是首次将机器人运动状态分析与模型精度调整相结合：

- **理论洞察**：识别了执行态和转移态对精度的差异化敏感性
- **实证验证**：通过噪声注入实验量化了两种状态的容忍度差异
- **动态切换**：基于运动幅度实时切换高精度/低精度配置
- **低开销**：状态预测器的计算成本可忽略不计

这一创新的普适性在于：任何具有阶段性特征、且不同阶段对精度要求不同的物理系统，都可以借鉴这一"状态感知精度调整"的思路。

#### 3.2.2 质心复用的双重优化策略

本文提出的空间合并+时序复用的双重优化是VQ推理加速的系统性方法：

- **空间维度**：在同一列内合并相同质心的计算
- **时间维度**：跨列复用相同质心的计算结果
- **协同效应**：两种技术可以叠加使用，产生乘法增益

与现有VQ推理方法（需要先解量化再执行标准GEMM）相比，本文方法直接在压缩域执行计算，避免了解量化开销。

#### 3.2.3 算法-硬件协同设计

本文不是孤立的算法或硬件工作，而是完整的协同设计：

- **算法驱动硬件**：MotionVQ的状态切换和质心复用特性直接指导了VQVLA架构的设计
- **硬件约束算法**：VQVLA的可变列分配能力反过来影响了压缩方法的设计（保持矩形核形状）
- **联合优化**：通过联合优化达到了单一维度优化无法实现的性能

#### 3.2.4 无重训练的即时压缩

与需要微调或重训练的结构化剪枝/量化方法不同，本文的VQ方法可以在**不修改模型参数、不进行重训练**的情况下直接应用。这大大降低了实际部署的门槛。

## 4. 实验设计与结果

### 4.1 实验设置

#### 4.1.1 模型与数据集

- **VLA模型**：OpenVLA-7B（基于LLaMA2-7B的Transformer骨干）
- **视觉编码器**：ViT
- **数据集**：LIBERO（机器人操作任务基准）
- **评估指标**：任务成功率、推理延迟、能耗、片外存储带宽

#### 4.1.2 基线方法

- **原始FP16模型**：未压缩的OpenVLA-7B
- **均匀INT8量化**：全局INT8量化
- **均匀INT4量化**：全局INT4量化
- **静态VQ（256 centroids）**：全局使用256质心
- **静态VQ（64 centroids）**：全局使用64质心

#### 4.1.3 硬件平台

VQVLA加速器基于以下配置实现：
- 工艺节点：先进CMOS工艺
- PE阵列：可配置的二维阵列
- 片上缓存：Global Buffer
- 片外存储：DRAM

### 4.2 核心实验结果

#### 4.2.1 任务成功率对比

| 方法 | 成功率 | 相对FP16损失 |
|------|--------|-------------|
| FP16（原始） | 78.5% | - |
| 全局INT8 | 77.8% | -0.7% |
| 全局INT4 | 72.3% | -6.2% |
| 静态VQ-256 | 78.2% | -0.3% |
| 静态VQ-64 | 74.1% | -4.4% |
| **MotionVQ（本文）** | **78.2%** | **-0.3%** |

**关键发现**：
- MotionVQ在仅损失0.3%成功率的情况下实现了动态精度调整
- 全局INT4虽然压缩率高，但导致6.2%的成功率下降，不可接受
- MotionVQ的成功率与静态VQ-256持平，但计算效率更高

#### 4.2.2 推理加速比

| 方法 | 相对FP16加速比 | 主要优化来源 |
|------|---------------|-------------|
| 全局INT8 | 1.8× | 权重位宽减半 |
| 全局INT4 | 2.5× | 权重位宽减至1/4 |
| 静态VQ-256 | 1.9× | 码本压缩 |
| 静态VQ-64 | 2.8× | 更小码本 |
| **MotionVQ+VQVLA** | **2.7×** | 动态精度+质心复用 |

**关键发现**：
- MotionVQ实现了2.7倍加速，接近静态VQ-64的2.8倍
- 但MotionVQ的成功率（78.2%）远高于静态VQ-64（74.1%）
- 质心复用技术贡献了约15-20%的额外加速

#### 4.2.3 片外存储带宽减少

| 方法 | 相对FP16带宽减少 |
|------|------------------|
| 全局INT8 | 50% |
| 全局INT4 | 75% |
| 静态VQ-256 | 65% |
| 静态VQ-64 | 80% |
| **MotionVQ** | **72%** |

**关键发现**：
- MotionVQ的平均带宽减少（72%）介于静态VQ-256（65%）和VQ-64（80%）之间
- 这与理论预期一致：执行态使用256质心（带宽减少较少），转移态使用64质心（带宽减少更多）

#### 4.2.4 能效提升

| 方法 | 相对FP16能效提升 |
|------|------------------|
| 全局INT8 | 2.1× |
| 全局INT4 | 2.6× |
| 静态VQ-256 | 2.2× |
| 静态VQ-64 | 2.9× |
| **MotionVQ+VQVLA** | **3.1×** |

**关键发现**：
- MotionVQ+VQVLA实现了最高的3.1倍能效提升
- 这得益于：(1)动态精度减少了不必要的计算；(2)质心复用减少了MAC操作；(3)专用硬件减少了控制开销

#### 4.2.5 各阶段时间分解

如图3所示，VLA推理的四个阶段时间分解：
1. **Tokenizer**：文本编码，占比最小
2. **ViT**：视觉特征提取，计算密集
3. **Transformer**：主要瓶颈，占比最大
4. **Action Head**：动作解码

MotionVQ主要优化Transformer阶段的权重访问和计算，对该阶段的加速最为显著。

### 4.3 消融实验

#### 4.3.1 状态预测器的准确性

状态预测器基于运动幅度阈值的简单规则，在LIBERO数据集上的分类准确率超过95%。这说明运动状态与空间位置的高度相关性足以支持可靠的状态预测。

#### 4.3.2 阈值Td的影响

| 阈值Td | 执行态比例 | 转移态比例 | 成功率 | 加速比 |
|--------|-----------|-----------|--------|--------|
| 0.4 | 85% | 15% | 78.4% | 1.9× |
| 0.8 | 60% | 40% | 78.2% | 2.7× |
| 1.2 | 40% | 60% | 77.5% | 3.2× |
| 1.6 | 25% | 75% | 75.8% | 3.5× |

**最优选择**：Td = 0.8在成功率和加速比之间提供了最佳平衡。

#### 4.3.3 质心复用的贡献

| 配置 | 空间合并 | 时序复用 | 加速比 | 成功率 |
|------|---------|---------|--------|--------|
| 基线 | × | × | 2.3× | 78.2% |
| +空间合并 | √ | × | 2.5× | 78.2% |
| +时序复用 | × | √ | 2.4× | 78.2% |
| **+两者** | **√** | **√** | **2.7×** | **78.2%** |

**关键发现**：空间合并和时序复用具有近似正交的增益，叠加后产生协同加速效果。

## 5. 局限性与未来展望

### 5.1 局限性

#### 5.1.1 状态划分的二元性

本文采用二元状态划分（执行态 vs 转移态），这是一种简化：
- 实际机器人运动可能存在更多中间状态
- 某些任务可能需要多于两种精度级别
- 状态切换的硬阈值可能导致边界处的抖动

#### 5.1.2 任务类型限制

实验主要在LIBERO数据集上评估，该数据集包含相对简单的桌面操作任务：
- 更复杂的任务（如多步骤装配、动态避障）可能对精度更敏感
- 不同类型的任务可能需要不同的阈值Td
- 在真实机器人上的验证尚不充分

#### 5.1.3 VQ的训练开销

虽然VQ本身不需要重训练VLA模型，但码本的生成需要额外的聚类步骤：
- 对大型Transformer权重执行k-means聚类的计算成本
- 码本质量对压缩性能的影响
- 不同层可能需要不同大小的码本

#### 5.1.4 硬件实现复杂度

VQVLA架构引入了额外的控制逻辑：
- 状态预测器的硬件实现
- 动态码本切换的电路设计
- 质心复用缓存的管理

这些增加了芯片面积和设计复杂度。

### 5.2 未来展望

#### 5.2.1 多精度级别扩展

将二元状态扩展为多元状态（如3-5个精度级别），实现更细粒度的精度-效率权衡。这需要：
- 更精细的运动状态分类算法
- 多级码本设计

### 6.1 可迁移思路

#### 6.1.1 状态感知的动态精度调整
