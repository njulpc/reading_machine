# 深度技术分析：WitCert: Sound Runtime Risk Observability and Gating for KV-Cache Quantization

## 1. 核心速览

- **研究话题**：为KV-cache量化提供可证明可靠的运行时风险度量器（meter），实现压缩误差的实时可观测与门控。
- **一句话总结**：提出两层证书体系——Tier A确定性带范数见证界（适用于任意黑盒量化器）和Tier B概率性亚高斯证书（受控减法抖动INT8量化器），通过Lean 4机器验证证明其可靠性，在SGLang中集成后将FP8质量从22.8恢复到79.7，认证INT8缓存可服务1.88x更多KV token。

## 2. 研究背景与动机

自回归解码需要为每个历史token缓存键值对（KV-cache），32k上下文下7B模型的KV-cache达到数GB，128k时甚至超过模型权重本身。KV-cache压缩的四条路线——token驱逐（H2O、SnapKV）、通道/频率剪枝（ThinK、RAP）、低秩分解（Palu、KQ-SVD）和量化（KIVI、KVQuant）——共享一个根本缺陷：它们是开环的（open loop）。策略在离线或启发式地固定，当前输入实际产生的误差既不可观测也不可控。极端情况下，SnapKV在RULER needle任务上从100分骤降到1.1-65分，而服务系统完全没有发出任何信号。

将压缩从开环转为闭环需要运行时可计算的误差界。Runtime-Certified Quantized Attention虽然提供了证书，但其界是最坏情况的（TV ≤ tanh(max|ε|)，数据无关），在所有实际阈值（τ ≤ 0.2）下授权零压缩——证书成立但过于保守而无法使用。

WitCert的出发点是：证书要授权压缩，必须是数据依赖的。两个挑战随之而来：（1）数据依赖的界需要每token的误差幅度，但误差依赖于尚未到达的query；（2）现代缓存在RoPE旋转后存储key，任何见证（witness）必须对位置不变，否则需要按位置重算。

## 3. 核心方法与创新点

**（1）残差见证与频带范数（Tier A）**

残差见证定义为 r_t = k̂_t - k_t（重建key与精确key之差）。将d/2个RoPE频率对分为B个连续频带（系统集成用B=16，即32 bytes/token/head），存储每个频带的欧几里得范数 w_{t,b} = ‖r_{t,b}‖。该见证在写入时计算一次，与query无关。

**（2）RoPE带酉性（Lemma 1）**

RoPE在每个频率对上表现为2×2旋转（角度为nθ_j），每个频率对完全包含在单个频带内。因此对任意频带b、任意向量x和任意位置n，有 ‖(R_n x)_b‖ = ‖x_b‖。这意味着post-RoPE残差的见证等于pre-RoPE残差的见证，实现了位置不变性——无需按query位置重算。

**（3）有缺陷证书的发现与Sound Replacement（Theorem 1）**

论文发现一个看似合理的证书公式（公式1）实际上是有缺陷的。最小反例：p̃ = (1/2, 1/2)，c = (0.1, 0.1)，ε = (0.1, -0.1)，真实TV = 0.049834，而缺陷公式返回0.006423——偏差7.8倍。该缺陷公式在32,256次批量检查中未被发现，因为检查是按批次均值而非逐query进行的。

Sound Replacement定理：令 A = E_{p̃}[e^c]，若 |ε_t| ≤ c_t 对所有t成立，则 TV(p, p̃) ≤ ½(A² - 1)。证明基于Cauchy-Schwarz不等式和log域分析，溢出时返回平凡界1。该定理通过500,000次对抗试验验证（极端符号模式、尖峰/平坦分布、大c值）。

**（4）Tier B：亚高斯概率证书**

针对受控的减法抖动（subtractively-dithered）INT8量化器，提供更紧的概率性证书，具有显式的请求级失败预算δ_req，且无需存储见证。核心定理在Lean 4中机器验证，确保证明的形式化正确性。

**（5）门控机制**

度量器报告为 min(1, ·)（因TV ≤ 1恒成立）。当τ < 1时为认证模式（certified），提供数学保证；当τ ≥ 1时为风险排序模式（risk-ranked），度量值仍具经验判别力但不提供保证。门控策略：认证模式下直接授权压缩，风险模式下按风险排序选择回退。

## 4. 实验设计与结果

**SGLang集成**：度量器通过env-guarded patch进入SGLang，任何注册为单一张量函数的量化方案均可被实时测量。

**修复效果**：在硬RULER任务上，raw-cast FP8从22.8恢复到79.7，与未压缩版本的差异被配对测试界定在[+0.0, +0.8]区间内。

**跨层误差累积分析**：28层扫描发现，没有单层的污染单独导致损失（0/28）。这揭示了激进量化方案之所以能存活，靠的是跨层误差消除（cross-layer error cancellation），而非每步保真度。这一发现也解释了为什么每步界本质上保守——单步误差可以很大但不影响最终输出。

**认证INT8缓存容量**：在相同内存下，认证INT8缓存可服务1.88x更多KV token。

**对抗试验**：500,000次对抗试验验证Sound Replacement定理的正确性，并将反例和对抗测试套件冻结为回归测试。

## 5. 局限性与未来展望

**局限性**：（1）Tier A仅适用于缓存保持型方案（即能重建每token的key），不适用于token驱逐、池化/合并、隐式缓存等无逐token重建的方案；（2）Tier B的概率证书仅针对受控的减法抖动量化器，对其他量化器的扩展需要新的分析；（3）认证模式下度量器在饱和时退化为风险排序，缺乏严格保证；（4）系统成本中仍存在重复page-in而无请求级修复缓存的问题；（4）门控阈值τ的校准目前是手动的，未利用保形预测等自动化方法。

**未来展望**：将保形预测用于在线流量校准门控阈值τ；扩展到token驱逐方案的在线认证（论文明确列为开放问题）；探索跨层误差消除的可预测性，将单步保守界转化为多步紧界。

## 6. 学术启发 (Takeaways for My Research)

1. **逐query验证的必要性**：缺陷证书在32,256次批量检查中未被发现，却在逐query检查下立即暴露。这是对所有量化误差界评估的方法论警示——均值聚合会掩盖个体违规，证书必须逐样本、对抗性地验证。
2. **RoPE带酉性的巧妙利用**：RoPE在每个频率对上的2×2旋转酉性使得频带范数对位置不变，这一洞察将"位置依赖的误差"转化为"位置无关的见证"，是KV-cache压缩认证的关键技术杠杆。
3. **跨层误差消除的实证发现**：0/28层单独污染不导致损失，说明LLM的误差容忍度是系统性的而非逐层的。这提示量化策略可以更激进地牺牲单步精度，只要跨层累积可控——但需要更深层的不确定性传播分析。
4. **Lean 4机器验证**：将核心定理在Lean 4中形式化验证，为量化研究引入了形式化方法的严谨性。这种"证明即代码"的实践值得在所有声称理论保证的量化论文中推广。
5. **开环到闭环的范式转换**：从"离线固定策略"到"运行时可观测+门控"的转换，是KV-cache压缩从实验室走向部署的关键一步，与控制系统中的观测器-控制器设计理念一脉相承。
