## 一、核心速览

### 研究主题

本文研究视觉语言模型（VLM）在长视觉上下文（如多图像集合或小时级长视频）中的信息检索问题。当输入包含大量与问题无关的干扰帧/图像时，VLM 的回答性能显著下降，且将全部视觉 token 一次性送入模型在 GPU 显存约束下不可行。论文提出将长视觉上下文处理归结为一个检索问题：从大量视觉 token 中选择与查询相关的稀疏子集，再据此生成答案。

### 一句话总结

论文通过诊断性实验发现 VLM 中的注意力分数（query-key）对视觉信息检索不可靠，而 value 空间携带更强的检索信号，由此提出 ReToken——一个可学习的检索 token，在冻结的 VLM 之上仅添加一个 token 嵌入和一个投影矩阵，通过显式检索损失训练，在图像和视频基准上实现了一致的性能提升，且训练和推理均可在单张 H100 上完成。

## 二、研究背景与动机

### 现有研究的痛点

**1. 注意力信号在 VLM 中不可靠。** 在纯文本 LLM 中，注意力分数可以作为有效的检索信号来选择性关注输入上下文，这得益于大量长上下文训练（如 InfLLM、EM-LLM 等工作在 NLP 领域已证明有效）。然而，论文发现 VLM 中的类比信号并不可靠：文本 token 与视觉特征之间的注意力与相关性弱相关。在 QAEgo4D 的 Test-MC 子集上，基于注意力的检索器（ReKV 方法）在 Qwen3VL-8B 上的各层平均 Recall@1 仅为 5.1%，在最后一层也仅约 15% 左右（论文图 1b 显示 ReToken 在最后一层实现超过 3 倍的召回提升）。

**2. VLM 训练数据中缺少"选择"场景。** 注意力机制本身是为下一 token 预测训练的，而非为检索任务训练。更关键的是，典型 VLM 训练数据中，输入的图像或视频几乎总是与问题完全相关的——模型从未被要求在多个视觉输入之间进行"选择"。这导致模型没有学到区分相关与不相关视觉内容的能力。

**3. 外部检索器引入额外开销与误差累积。** 传统视觉检索方法（如 CLIP、SigLIP2、E5-V、LamRA）需要训练独立的外部检索模型，选出的图像还需被 VLM 重新编码，带来双重计算开销。长视频 QA 领域的流水线方法（如 SeViLA、VideoAgent、VideoTree）通过链接独立的定位器和回答器，或构建 agentic 管道迭代检索关键帧，存在误差累积和系统复杂度高的问题。基于注意力分数的内部检索方法（如 ReKV）虽统一了检索与生成，但直接将 NLP 领域的 query-key 检索机制移植到视觉域，未针对 VLM 特性进行适配。

**4. 现有 token 压缩与记忆方法与查询无关。** 基于记忆的方法（如 MovieChat、MA-LMM）和 token 压缩方法（如 Chat-UniVi、LLaMA-VID、LongVU、Video-XL）在 LLM 之前对视觉 token 进行裁剪、合并或摘要，但它们独立于查询来约束视觉上下文，无法保留与特定问题相关的细粒度证据。

### 为什么要做这项研究

论文的核心动机来自一个关键的诊断性发现：在 VLM 中，**value 空间比 key 空间提供更强的视觉检索信号**。在一个受控的双图像设置中，将精确的目标短语与视觉 value 投影（而非 key 投影）进行匹配，在 Qwen3VL 上将 Recall@1 从 65.7 提升到 78.0，在 InternVL3.5 上从 78.8 提升到 83.8。这是因为 value 承载了通过注意力实际传播的内容，为基于文本的视觉检索提供了更好的空间。

然而，value-value 匹配并非在任意检索文本上都优于 query-key 评分——简单地对所有问题 token 取平均会引入噪声，反而逆转了 value 空间的优势。这一发现促使作者设计一个**可学习的检索 token**，用显式监督替代启发式的问题 token 平均，从而稳定地利用 value 空间的检索优势。

## 三、核心方法与创新点

### 方法概述

ReToken 的方法可以概括为以下流程：

1. **预填充视觉 KV 缓存**：首先将所有视觉输入（多张图像或视频帧）的视觉 token 送入 VLM，预填充视觉 KV cache。对于长视频，这一步可以分块进行。

2. **第一遍前向传播生成 ReToken 输出**：将问题 token 和一个初始的 ReToken 占位符送入冻结的 VLM 进行前向传播。ReToken 经过 VLM 各层 transformer 的计算后，在最终层产生一个输出嵌入。由于 VLM 已预填充了视觉 KV cache，ReToken 在此过程中可以"看到"所有视觉内容。

3. **Value 空间检索评分**：取出 ReToken 在最终层的输出嵌入，通过一个可学习的投影矩阵投影后，与每一帧视觉 token 在最终层的平均 value 向量计算余弦相似度，得到每帧的检索分数。

4. **Top-K 帧选择**：根据检索分数选择 Top-K 最相关的帧（K 远小于总帧数 F），从预填充的 KV cache 中提取这些帧的视觉 token。

5. **第二遍生成**：使用选出的稀疏视觉上下文，通过冻结的 VLM 自回归生成最终答案。

**训练目标**：ReToken 使用类平衡的二元交叉熵（class-balanced binary cross-entropy）损失进行监督，标签为 ground-truth 的相关性标注（即哪些帧/图像与问题真正相关）。VLM 默认保持冻结，仅训练 ReToken 嵌入和单个投影矩阵。

### 核心创新

**创新一：Value 空间检索的诊断与利用。** 论文系统性地揭示了 VLM 中注意力检索失败的根本原因，并提出在 value 空间而非传统的 query-key 空间中进行视觉检索。这是本文最核心的诊断贡献。在受控实验中，value-value 匹配相比 query-key 匹配在 Qwen3VL 上提升 12.3 个 Recall@1 点（65.7→78.0），在 InternVL3.5 上提升 5.0 个点（78.8→83.8）。这一发现对整个 VLM 检索方向具有启发性意义。

**创新二：单一可学习 token 作为显式检索目标。** 与 Q-Former（BLIP-2）或 Perceiver Resampler（Flamingo）使用 32-64 个可学习 token 作为视觉压缩器不同，ReToken 仅需一个 token。论文从三个维度区分了 ReToken 与已有可学习 token 方法：
- **运行机制**：Q-Former 的可学习 token 是静态的、与查询无关的输入条件；ReToken 是动态生成的——第一遍前向传播产生的输出 token 会检索与查询相关的视觉 KV 上下文。
- **监督方式**：Q-Former 在对齐或生成损失下作为视觉压缩器训练；ReToken 由显式检索损失监督，直接对最终层 value 向量评分。
- **容量**：仅需一个 token 而非 32-64 个。

**创新三：图像到视频的零样本迁移。** ReToken 仅在多图像 QA 数据集上训练，却能零样本迁移到长视频理解任务。在 LVBench 上（平均视频时长超过一小时），使用 Qwen3VL-8B 获得 8.0 分的提升，且无需任何视频训练数据。这表明图像级别的检索能力可以泛化到视频时序维度，为可扩展的长上下文多模态推理提供了一条实用路径。

**创新四：极轻量设计。** 整个方法仅新增两个参数组件：一个 token 嵌入向量和一个投影矩阵。VLM 保持冻结，训练和长视频推理均可在单张 H100 GPU 上完成。这与需要大规模重新训练或额外检索模型的方法形成鲜明对比。

## 四、实验设计与结果

论文的实验围绕两个核心基准展开，并辅以消融实验验证各设计选择的有效性。

### 4.1 实验设置

- **基础模型**：Qwen3VL-8B 和 InternVL3.5，均为当前主流的开源 VLM。
- **训练数据**：仅使用一个小规模的多图像 QA 数据集（论文附录 B.1 描述了训练数据过滤策略）。
- **硬件**：单张 H100 GPU 即可完成训练和长视频推理。
- **评估基准**：
  - **Visual Haystacks**（Wu et al., 2024）：多图像 QA 基准，测试模型在大量干扰图像中找到相关图像并回答问题的能力。
  - **LVBench**（Wang et al., 2025a）：长视频理解基准，平均视频时长超过一小时。
  - **QAEgo4D Test-MC**：用于诊断性分析的 Egocentric 视频 QA 基准。

### 4.2 Visual Haystacks 检索与准确率

在 Visual Haystacks 基准上，ReToken 带来了显著提升：

| 模型 | 提升幅度 | 相对提升 |
|------|---------|---------|
| Qwen3VL-8B | +13.4 分 | >20% |
| InternVL3.5 | +12.4 分 | >20% |

这一结果验证了 ReToken 在多图像场景下的有效性：通过 value 空间的可学习检索 token，模型能够更准确地从大量干扰图像中定位与问题相关的视觉内容。

### 4.3 图像到视频的零样本迁移

在 LVBench 上，尽管 ReToken 仅在多图像 QA 上训练，它成功零样本迁移到长视频理解：

- **Qwen3VL-8B + ReToken**：在 LVBench 上获得 **8.0 分**的提升。

这一结果尤为值得关注，因为它表明：（1）图像级别的视觉检索能力可以泛化到视频的时序维度；（2）ReToken 学到的是一种与模态细节无关的通用检索能力，而非过拟合于图像特有的模式。论文图 1(b) 显示，在 QAEgo4D 上，ReToken 在最后一层的 Recall@1 达到注意力检索器的 3 倍以上（从约 5.1% 提升到显著更高的水平）。

### 4.4 消融实验

论文通过多项消融实验验证设计选择：

- **Key vs. Value 空间**（论文表 1 和附录 B.3）：在受控的双图像设置中，value 空间检索显著优于 key 空间检索。使用目标短语时，Qwen3VL 上 Recall@1 从 65.7（key 空间）提升到 78.0（value 空间）；InternVL3.5 上从 78.8 提升到 83.8。但使用完整问题句子平均所有 token 时，value 空间的优势会被噪声逆转，这验证了需要可学习 token 来稳定利用 value 空间。

- **目标短语 vs. 完整问题句子**（论文表 1、图 2）：将完整问题句子（如"For the image with a cow, is there a truck?"）替换为直接命名目标实体的短语（如"a cow"）可显著提升检索效果，说明问题 token 平均引入了大量无关信号。ReToken 通过学习自动生成最优的检索表示，避免了手动选择目标短语的需求。

- **单 token vs. 多 token**（附录 C.1）：论文验证了使用单个 token 已足够，无需多个 token。

- **检索目标的选择**（附录 C.2）：论文对比了 query composition（检索+组合）与 visual summarization（视觉摘要）两种范式，验证了检索导向的设计更为有效。

- **Chain-of-Thought (CoT) 检索基线**（附录 B.2）：论文还与基于思维链的检索基线进行了对比。

## 五、局限性与未来展望

### 局限性

1. **两遍前向传播的额外开销**：ReToken 的推理流程需要两遍前向传播——第一遍生成 ReToken 输出并进行检索评分，第二遍使用稀疏视觉上下文生成答案。虽然相比全上下文推理已大幅节省显存，但相比单次推理仍有额外延迟。不过，第一遍前向传播可以使用较短的上文（仅问题和 ReToken），且 VLM 处于冻结状态，实际开销可控。

2. **训练数据的相关性标注依赖**：ReToken 的训练需要 ground-truth 的帧级/图像级相关性标签（即哪些帧与问题相关）。虽然论文使用的是小规模数据集，但构建此类标注数据本身可能需要领域知识或人工标注。论文附录 B.1 描述了训练数据过滤策略，但数据构建的成本和可扩展性仍有待进一步讨论。

3. **Value 空间检索的理论解释尚不充分**：虽然论文通过实验验证了 value 空间优于 key 空间，但对这一现象的深层理论解释仍较为初步。论文提出"value 承载了通过注意力实际传播的内容"这一直觉性解释，但缺乏对为什么 key 空间在视觉模态中失效的系统性理论分析。

4. **帧级粒度的限制**：ReToken 在帧级别进行检索（选择 Top-K 帧），而非更细粒度的 token 级别。对于一帧中同时包含相关和无关区域的情况，帧级检索可能无法精确聚焦到关键区域。

5. **评估基准的覆盖范围**：虽然论文在 Visual Haystacks 和 LVBench 上展示了令人信服的结果，但尚未在更多样化的长上下文多模态基准（如 Needle-in-a-Haystack 的多模态变体、更长视频的细粒度理解任务）上进行全面评估。

### 未来展望

1. **token 级检索**：将 ReToken 的检索粒度从帧级扩展到 token 级，可能进一步提升细粒度视觉推理能力，特别是在单帧内需要聚焦特定区域的场景。

2. **与 token 压缩方法的结合**：ReToken 的检索范式与 token 压缩方法（如 LongVU、Video-XL）是正交的——可以先通过压缩减少 token 总量，再用 ReToken 进行查询相关的精细检索，两者结合可能实现更好的效率-性能权衡。

3. **多模态长上下文训练范式**：论文的发现（VLM 训练数据中缺少"选择"场景导致注意力检索失效）启示了一种新的训练范式：在预训练或后训练阶段引入包含大量干扰视觉内容的训练样本，让模型自然习得视觉选择能力。

4. **value 空间检索的理论深化**：进一步研究 VLM 中 key 和 value 在视觉信息编码上的角色差异，可能催生新的检索和注意力机制设计。

5. **更长视频和更复杂任务**：将 ReToken 扩展到更长视频（如数小时监控视频）或更复杂的多跳推理任务，验证其可扩展性上限。

## 六、学术启发

1. **诊断驱动的方法设计**：本文最大的方法论启发在于"先诊断、再设计"的研究范式。作者没有直接提出新方法，而是首先系统性地分析了为什么已有的注意力检索方法在 VLM 中失败（5.1% 的 Recall@1），进而发现了 value 空间的检索优势（12.3 个点的提升），最后基于这一发现设计了 ReToken。这种由诊断洞察驱动的方法设计往往比盲目堆砌模块更有针对性和说服力。

2. **轻量化即可能有效**：在当前追求大规模训练的趋势下，ReToken 证明了仅添加一个 token 和一个投影矩阵（VLM 冻结）就能获得超过 20% 的相对提升，且训练和推理均在单张 H100 上完成。这提醒研究社区：与模型规模相比，找到正确的"信息瓶颈"（value 空间 + 显式检索监督）可能更为关键。

3. **跨模态迁移的潜力**：图像到视频的零样本迁移结果（LVBench +8.0）揭示了一个重要现象——视觉检索能力具有跨粒度的泛化性。这为未来研究提供了思路：可以在更简单、更可控的模态（多图像）上训练能力，再迁移到更复杂的模态（长视频），从而降低训练数据和计算成本。

4. **注意力机制的可信度审视**：本文对 VLM 注意力可靠性的质疑具有广泛意义。随着 VLM 被越来越多地应用于 RAG 系统、agentic 工作流等需要依赖注意力进行信息选择的场景，系统性地审视注意力信号的可信度（而非默认信任）是一个值得深入的研究方向。论文在 value 空间的发现也可能启发对注意力机制本身的改进。

5. **与长上下文 LLM 研究的对话**：本文揭示了 NLP 和多模态领域在长上下文处理上的关键差异——LLM 的注意力选择能力得益于大量长上下文训练，而 VLM 因训练数据特性缺乏这一能力。这暗示 VLM 的长上下文能力提升可能需要不同于 LLM 的路径，显式的检索模块（如 ReToken）可能比单纯扩大上下文窗口更有效。

6. **对工业实践的启示**：ReToken 的轻量设计使其具有很高的工程实用价值。对于需要在有限 GPU 资源下处理长视频/多图像的工业应用（如视频监控分析、大规模图像检索问答），ReToken 提供了一个即插即用的解决方案，无需重新训练基础模型即可获得显著的性能提升。
