# Argus-Unified 深度技术分析

**论文标题**: Argus-Unified: A Lightweight Unified Multimodal Model via Hybrid Token Design

**论文作者**: Fanjia Lin, Dongqi Cai, Siran Ding, Biao Yang, Qidong Huang, Yunhan Yang, Haoran Wei, Shijia Yang, Yikai Wang, Jiaqi Wang, Lewei Lu, Kai Zhang, Xiangtai Li, Jing Xu, Xihui Liu, Henghui Ding, Kai Chen, Yanwei Fu, Shuicheng Yan, Chen Change Loy

**发表时间**: 2026年7月

---

## 1. 核心速览

**研究主题**: 本研究聚焦于统一多模态模型（Unified Multimodal Model, UMM）的设计与训练，旨在构建一个能够同时执行图像理解和图像生成的轻量级模型，并通过创新的混合令牌设计（Hybrid Token Design）大幅降低训练数据需求与计算成本。

**一句话总结**: Argus-Unified提出了一种基于混合令牌设计的两阶段训练框架，通过冻结预训练视觉语言模型（VLM）的视觉编码器并仅训练量化器和解码器，在仅使用15.6M公开数据的情况下实现了与使用数百倍数据量的现有UMM相媲美的图像理解与生成性能，证明了UMM可以通过有效利用预训练VLM而非从零训练来高效构建。

---

## 2. 研究背景与动机

### 2.1 现有痛点

**视觉语言模型（VLM）的局限性**: 当前主流的VLM架构（如CLIP、SigLIP、InternViT等）采用连续视觉令牌（Continuous Visual Tokens）进行图像理解，通过与文本嵌入对齐实现跨模态理解。然而，这类模型仅能处理文本形式的视觉理解任务，缺乏视觉生成能力。换言之，VLM可以"看懂"图像并用文本描述，但无法"画出"图像。

**统一多模态模型（UMM）的三种设计范式及其缺陷**:

现有UMM主要存在三种架构设计，但各有明显不足：

1. **图像令牌替换方案（Image Tokenizer Replacements）**: 如图2(b)所示，该方案将VLM的视觉编码器替换为VQVAE或VQGAN类的分词器，使模型能够同时输出离散视觉令牌用于生成和连续令牌用于理解。代表性工作包括VILA-U、Emu3等。**核心缺陷**: 这种替换破坏了预训练视觉编码器中丰富的视觉-语言对齐信息，导致理解性能下降；同时需要同时优化离散令牌生成和视觉-文本对齐，训练难度大。

2. **双视觉编码器方案（Additional Image Tokenizers）**: 如图2(c)所示，该方案在保留原理解视觉编码器的基础上，额外添加一个专用于生成的视觉编码器和量化器。代表性工作包括Janus、Janus-Pro等。**核心缺陷**: 引入额外的编码器带来显著的参数开销（通常为原编码器参数的1.5-2倍），增加了模型复杂度和部署成本。

3. **扩散+自回归混合方案（AR+Diffusion）**: 如MetaQuery、Show-o等，将自回归（AR）用于文本生成，扩散模型用于图像生成。**核心缺陷**: 两种独立训练范式的耦合困难，图像和文本的令牌空间不统一，难以实现真正的统一建模。

**数据规模与训练成本的不可持续性**: 现有UMM的训练数据规模极其庞大。例如，Chameleon使用了1.4B样本，TokenFlow-L使用了760M+样本，VILA-U使用了726M样本。如此大规模数据的收集、清洗和训练需要消耗巨额计算资源。论文估算，8×H100 GPU节点的成本约为每小时$20.3，8×A100节点约为每小时$8.56，大规模UMM的训练成本动辄数十万甚至上百万美元。这种数据密集型范式不仅成本高昂，也阻碍了UMM技术的普及和复现。

**预训练VLM知识的浪费**: 当前主流UMM的训练范式通常从预训练语言模型（如LLaMA）初始化，然后进行大规模多模态预训练以学习视觉令牌建模和视觉-语言对齐。然而，这一过程中预训练VLM已经学到的丰富视觉理解能力被"重新学习"，造成了知识和计算资源的双重浪费。

### 2.2 研究必要性

**对高效UMM范式的迫切需求**: 随着多模态AI应用（如AI助手、内容创作工具、具身智能等）的快速发展，能够在单一模型中统一处理理解与生成任务的能力变得越来越重要。然而，现有方案的高昂训练成本和大规模数据需求限制了学术研究和工业应用的广泛展开。开发一种能够高效利用已有预训练模型、降低训练门槛的UMM范式具有重要的理论和实践价值。

**混合令牌类型的互补性**: 深入理解不同令牌类型的本质特性揭示了混合设计的潜力——连续令牌保留了丰富的语义信息，非常适合理解任务；离散令牌则便于自回归模型处理，更适合生成任务。这种互补性暗示了一个核心问题：**是否可以在单一视觉编码器中同时产出两种类型的令牌，各取所长？**

**预训练模型迁移的价值重估**: 预训练VLM（如LLaVA、Qwen-VL等）已经在数亿甚至数十亿图文对上进行了训练，建立了强大的视觉-语言对齐。如何在不破坏这些对齐的前提下，将VLM扩展为具备生成能力的UMM，是一个值得深入探索的方向。

## 3. 核心方法与创新点

### 3.1 方法概述

Argus-Unified的核心思想可以概括为：**冻结预训练VLM的视觉编码器以保持视觉-语言对齐，在其上构建量化器和解码器以支持离散视觉令牌生成，通过混合令牌设计让单一编码器同时服务理解与生成任务**。

整体训练流程分为两个关键阶段：

**阶段一：统一视觉令牌器训练（Unified Vision Tokenizer Training）**

该阶段的目标是让冻结的预训练视觉编码器同时输出连续令牌（用于理解）和离散令牌（用于生成）。具体实现上，Argus-Unified在冻结的视觉编码器之上训练一个量化器（Quantizer）和一个图像解码器（Vision Decoder）。

量化器采用经典的VQVAE/VQGAN架构，将视觉编码器输出的连续嵌入映射到学习到的码本（Codebook）中的最近邻条目，产生离散代码。这些离散代码可以作为自回归语言模型的预测目标。图像解码器则负责从这些离散代码重建原始图像。

训练损失函数是一个多目标组合：

$$L = L_R + \lambda_P L_P + \lambda_G L_G + \lambda_{VQ} L_{VQ}$$

其中，$L_R$是像素级重建损失（通常使用L1或L2损失），$L_P$是基于LPIPS的感知损失（Perceptual Loss），$L_G$是对抗性损失（Adversarial Loss，用于增强重建保真度），$L_{VQ}$是向量量化损失（Vector Quantization Loss，最小化编码器输出与其最近码本条目的距离）。$\lambda$为各损失的权重系数。

**关键设计决策**: 视觉编码器在阶段一中被完全冻结。这一决策具有多重优势：
- 保留预训练VLM中建立的视觉-语言对齐，无需重新学习
- 简化训练过程——仅需未标注图像数据，无需图文对齐数据
- 大幅降低计算成本——无需反向传播更新编码器参数

**阶段二：统一多模态训练（Unified Multimodal Training）**

该阶段将阶段一训练好的量化器和预训练VLM组件整合，通过统一的多模态训练让语言模型（LLM）同时掌握图像理解和图像生成能力。

模型架构包含三个主要组件：
1. **预训练VLM组件**: 视觉编码器、LLM、文本编码器和文本解码器，均从预训练VLM初始化
2. **阶段一组件**: 量化器和图像解码器，从阶段一初始化
3. **任务特定投影器**: 两个随机初始化的投影器，分别用于理解和生成任务

**混合令牌设计（Hybrid Token Design）**: 这是Argus-Unified最核心的创新。不同于以往UMM仅使用离散视觉令牌（这会损失理解所需的语义丰富性）或仅使用连续令牌（这不适合自回归生成），Argus-Unified让单一视觉编码器同时产出两种令牌类型：
- **连续令牌**: 直接使用预训练VLM视觉编码器的原始连续视觉表示，通过理解投影器映射到LLM嵌入空间，用于图像理解
- **离散令牌**: 通过量化器将连续表示转换为离散视觉令牌，通过生成投影器映射到LLM嵌入空间，用于图像生成

两种令牌类型通过各自的投影器映射到共享的LLM嵌入空间，使模型能够以统一的方式处理多模态输入和输出。

**训练目标**: 采用标准的下一个令牌预测（Next-Token Prediction）目标。每个样本被表示为多模态令牌序列，由视觉令牌和文本令牌拼接而成，并用特殊的`<image_start>`和`<image_end>`标记包裹。对于图像理解任务，模型最小化文本令牌上的负对数似然（NLL）；对于图像生成任务，模型输出的视觉令牌经过视觉头处理，同样计算NLL损失。

**训练策略**: 阶段二的训练分为预训练（Pretraining）和监督微调（SFT）两个阶段：
- **预训练阶段**: 使用生成数据JourneyDB（4.1M）和小规模理解数据ShareGPT4V（1.25M）进行预热训练。由于LLM已从预训练VLM初始化，具备强大的图像理解和文本生成能力，因此仅需少量数据即可让LLM适应视觉令牌生成
- **SFT阶段**: 在理解和生成数据上进行均衡微调。理解数据包括WiT、ShareGPT4V、VFLAN、ScienceQA、MGM-Instruct等（总计5.47M样本）；生成数据包括JourneyDB、BLIP3-o、Echo-4o Instruct等（总计4.23M样本）

### 3.2 分点创新

**创新点一：混合令牌设计（Hybrid Token Design）**

这是Argus-Unified最具原创性的贡献。混合令牌设计巧妙地解决了UMM面临的核心矛盾——理解与生成对视觉表示的不同需求。

- **连续令牌用于理解**: 保留预训练视觉编码器输出的连续表示，这些表示富含高级语义信息，与文本嵌入空间已对齐，直接适用于VQA、图像描述等理解任务
- **离散令牌用于生成**: 通过量化器将连续表示转换为离散代码，这些代码适合自回归语言模型的预测框架，使模型能够逐令牌生成图像

这一设计的关键优势在于：
1. **无需参数开销**: 与双编码器方案相比，混合设计仅使用单一视觉编码器，无额外参数
2. **无高级语义损失**: 与令牌替换方案相比，冻结原始编码器保留了预训练获得的视觉-语言对齐
3. **架构简洁**: 整个模型架构轻量且统一，便于训练和部署

**创新点二：两阶段训练框架**

Argus-Unified的两阶段训练框架体现了对预训练模型迁移的深刻理解：

- **阶段一专注于视觉表示的"双重能力"**: 在不破坏视觉-语言对齐的前提下，为视觉编码器添加离散令牌生成能力
- **阶段二专注于LLM的"多任务适应"**: 利用预训练VLM的LLM已具备的图像理解能力，仅需少量数据即可扩展出生成能力

这种分阶段策略使得每个阶段的训练目标清晰、数据需求明确，避免了端到端联合训练的不稳定性。

**创新点三：极低数据需求**

Argus-Unified在数据效率方面取得了突破性进展。如论文图1所示，Argus-Unified使用的总数据量仅为15.6M，而同规模（0.5B或1.5B参数）的UMM通常使用60M到1.4B的数据。这一数据效率的提升源于：

1. **预训练VLM的利用**: 不需要从头训练视觉-语言对齐，节省了大量图文对齐数据
2. **冻结视觉编码器**: 仅训练量化器和解码器，参数量小，数据需求低
3. **阶段分离**: 每个阶段专注于特定目标，避免了联合训练的样本竞争

论文明确指出，在他们的设置中，超过适度规模的预训练数据扩展带来的收益递减甚至为负，而扩大SFT数据量反而能改善性能。

**创新点四：对统一多模态模型范式的重新思考**

Argus-Unified的研究结果对UMM领域提出了一个重要的方法论启示：**UMM不必从零开始构建**。通过有效利用已有的预训练VLM，可以在极低的数据和计算成本下构建高性能的UMM。这一发现可能改变未来UMM研究的方向——从追求更大规模的数据和模型，转向更聪明地利用现有预训练模型。

## 4. 实验设计与结果

### 4.1 数据集

**阶段一（视觉令牌器训练）数据集**:
- 总计14M张图像
- 来源: CC3M (5.9M)、DALL-E 3数据集、DiffusionDB数据集，以及阶段二使用的图像数据集中的图像

**阶段二（统一多模态训练）数据集**:
- 总计9.7M图文对
- **理解数据 (5.47M)**:
  - WiT (Wikipedia-based Image Text)
  - ShareGPT4V (1.25M)
  - VFLAN (Visual Fact-Label Alignment)
  - ScienceQA
  - MGM-Instruct
- **生成数据 (4.23M)**:
  - JourneyDB (4.1M) — 用于预训练阶段
  - BLIP3-o
  - Echo-4o Instruct

**数据策略的关键决策**: 论文仅使用公开可用数据集，不使用任何内部或专有数据，以确保结果的可复现性。

### 4.2 评估指标

**图像理解评估**:
- **POPE** (Polling-based Object Probing Evaluation): 评估模型对物体存在性的判断准确性
- **VQAv2** (Visual Question Answering v2): 开放式视觉问答
- **GQA** (Graphical Question Answering): 需要组合推理的视觉问答
- **MME** (Multimodal Model Evaluation): 综合多模态理解能力评估

**图像生成评估**:
- **MJHQ-30K**: 使用FID（Fréchet Inception Distance）评估30K张生成图像的视觉保真度
- **GenEval**: 专注于组合推理和物体一致性的生成评估基准

### 4.3 核心结果

Argus-Unified在两个模型规模下进行了实验：0.5B和1.5B参数。以下是核心实验结果的详细分析：

**0.5B参数规模结果** (表1):

| 模型 | 类型 | LLM规模 | 数据规模 | GQA↑ | MME-P↑ | POPE↑ | VQAv2↑ | MJHQ-30K↓ | GenEval↑ |

| MetaQuery | AR+Diff. | 0.5B | 27.4M | - | 1238.0 | - | - | 6.3 | 0.74 |

**关键发现**:
1. **理解性能领先**: 在GQA（61.4 vs. 最佳竞品55.1-56.3）、MME-P（1312.6 vs. 最佳竞品1238.0）、POPE（87.5 vs. 最佳竞品86.5）和VQAv2（77.3）上均取得最佳或接近最佳的性能
2. **数据效率极高**: 仅使用15.6M数据，而竞品使用27.4M到109M数据，数据效率提升2-7倍
3. **生成性能平衡**: MJHQ-30K FID为8.0，GenEval为0.66，与使用更多数据的竞品相当

**关键发现**:
1. **GQA性能最佳**: 62.8的GQA得分在所有比较模型中最高，包括使用234M数据的Janus-Pro
2. **POPE和VQAv2领先**: POPE 87.9和VQAv2 79.1均为最高水平
3. **生成质量优秀**: MJHQ-30K FID 6.9，优于Janus的10.1；GenEval 0.71，与Show-o2和Janus-Pro相当

Argus-Unified的GQA（62.8）超过了所有7B-13B规模的竞品，POPE（87.9）也处于最高水平。这一结果表明，通过有效利用预训练VLM，小模型可以在特定理解任务上超越大得多的模型。

### 4.4 消融实验与训练策略分析

论文还进行了详细的消融实验，验证了关键设计决策的有效性。例如，预训练阶段使用JourneyDB（4.1M生成数据）+ ShareGPT4V（1.25M理解数据）的组合，使得LLM在保持视觉-语言对齐的同时快速适应视觉令牌生成。SFT阶段使用均衡的理解-生成数据比例，进一步优化了模型在两个任务上的性能平衡。

## 5. 局限性与未来展望

### 5.1 局限性

**生成质量的上限**: 虽然Argus-Unified在理解任务上表现优异，但在生成质量（以MJHQ-30K FID衡量）方面，与专门的扩散模型或大规模UMM（如MMaDA 8B的FID 6.3）相比仍有一定差距。这是因为自回归生成范式在图像保真度方面天然不如扩散模型。

**分辨率限制**: 当前实验主要在256×256分辨率下进行（从量化器设计推断）。对于高分辨率图像生成，模型的能力可能受限。扩展到更高分辨率可能需要更复杂的量化器设计或多尺度生成策略。

**对预训练VLM质量的依赖**: Argus-Unified的性能在很大程度上取决于预训练VLM的质量。如果基础VLM的视觉-语言对齐较弱，冻结视觉编码器的策略可能无法充分发挥优势。

**任务范围有限**: 当前实验仅覆盖了图像理解和文本到图像生成两个核心任务。对于更复杂的多模态任务（如图像编辑、视觉推理、多轮对话中的视觉引用等），模型的能力尚未验证。

**量化器设计的通用性**: VQVAE/VQGAN类量化器的码本大小和维度选择对生成质量有重要影响，但论文对这方面的探索相对有限。

### 5.2 未来展望

**扩展到更多模态**: 混合令牌设计的理念可以自然扩展到视频、音频等其他模态。未来可以探索在统一框架下处理更多模态的理解和生成任务。

**与扩散模型的融合**: 可以在Argus-Unified框架基础上，探索将自回归生成与扩散模型结合，在保持理解能力的同时提升生成质量。例如，使用Argus-Unified生成低分辨率图像，再用扩散模型进行上采样和细化。

**更高分辨率支持**: 通过引入多尺度量化器或渐进式生成策略，可以将模型扩展到512×512甚至更高分辨率。

**更高效的训练策略**: 论文发现数据扩展存在收益递减现象，未来可以探索更高效的数据选择和课程学习策略，进一步降低训练成本。

**零样本和少样本能力**: 探索Argus-Unified在零样本视觉理解和生成任务上的能力，以及通过上下文学习进行任务适应的潜力。

**实时交互应用**: 由于模型参数量小（0.5B-1.5B）且架构简洁，Argus-Unified非常适合部署在边缘设备上，支持实时多模态交互应用。

## 6. 学术启发

### 6.1 可迁移思路

**混合表示学习（Hybrid Representation Learning）**: Argus-Unified的混合令牌设计揭示了一个普适性原则——不同下游任务可能需要不同类型的表示，而单一编码器可以通过巧妙的设计同时支持多种表示类型。这一思路可以迁移到：
- **多模态检索**: 同时使用连续表示（用于语义匹配）和离散表示（用于快速索引）
- **语音处理**: 同时使用连续频谱特征（用于识别）和离散令牌（用于合成）
- **科学计算**: 同时使用连续物理场表示（用于模拟）和离散符号表示（用于推理）

**预训练模型的渐进式扩展**: Argus-Unified展示了"冻结核心能力 + 扩展新能力"的渐进式扩展范式。这一范式可以广泛应用于：
- 将预训练语言模型扩展为具身智能模型（冻结语言理解，添加运动控制）
- 将预训练视觉模型扩展为视频理解模型（冻结空间理解，添加时序建模）
- 将预训练科学模型扩展为跨领域模型（冻结基础物理，添加新材料特性）

**数据效率优先的研究范式**: Argus-Unified的结果挑战了"越大越好"的默认假设，证明了通过更好的架构设计和训练策略，小数据量也能取得优异性能。这启示研究者在追求规模之前，先充分探索架构和算法的优化空间。

### 6.2 实验设计借鉴

**两阶段分离训练的设计**: Argus-Unified的两阶段训练框架为复杂多任务模型的训练提供了范本：
- **阶段一**: 专注建立"双重表示能力"，使用单一类型数据（图像），目标单一（重建）
- **阶段二**: 专注"多任务适应"，使用多类型数据（图文对），目标复合（理解+生成）

这种分离使得每个阶段的训练更稳定、更可解释。

**公开数据策略**: 论文坚持使用仅公开数据，不使用任何专有数据。这一策略不仅确保了可复现性，也证明了公开数据在构建高性能模型方面的充分性。对于资源有限的研究团队，这是一个值得效仿的策略。

**多维度评估体系**: Argus-Unified的评估覆盖了理解（POPE、VQAv2、GQA、MME）和生成（MJHQ-30K、GenEval）两大维度，每个维度又包含多个互补指标。这种全面的评估设计避免了单一指标的偏差，为模型的全面能力画像提供了基础。

**数据效率的量化和可视化**: 论文通过图1直观地展示了Argus-Unified与其他UMM在数据规模上的对比，使数据效率优势一目了然。这种可视化策略对于突出论文核心贡献非常有效。

**跨规模一致性验证**: 论文同时在0.5B和1.5B两个规模上验证了方法的有效性，证明了混合令牌设计在不同容量模型上的普适性。这种多规模验证增强了结论的可靠性。

## 总结

Argus-Unified通过创新的混合令牌设计和高效的两阶段训练框架，在统一多模态模型领域取得了重要突破。其核心贡献在于证明了通过有效利用预训练视觉语言模型，可以在极低的数据和计算成本下构建高性能的统一理解与生成模型。这一工作不仅在技术上取得了优异的性能，更在方法论上为UMM研究指明了一条更高效、更可持续的发展路径。混合令牌设计的理念、冻结核心编码器的策略、以及数据效率优先的研究范式，都具有广泛的学术启发价值和应用潜力。
